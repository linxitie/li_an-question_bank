## 2. 申论文法的实测真相（v3 的三处错误）

### 2.1 区段结构（合订本）
```
一、注意事项    ← 噪声，现有切分器把它当 1-5 题
二、给定材料    ← 材料区，现有切分器把它当题 6/7
三、作答要求    ← 真正的问题区
（1）…（15分） 要求：（1）准确、全面；（2）恰当提炼…
（2）…（20分）
参考答案：      ← 答案
参考答案说明：  ← 解析
```
**实测**：仅把「三、作答要求」区段喂现有 `extract_question_blocks`，5 题卷从 **7 块（含注意事项）→ 5 块（题号 1..5，与分值锚点一致）**。

### 2.2 答案锚点三形态（T1 实测）
| 形态 | 出现于 | 锚点 | 实测计数 |
|---|---|---|---|
| ① 行内带冒号 | 2018/2019/2020/2022 合订本 | `参考答案\s*[:：](?!说明)` | 5/5/3/4/5/5/5 |
| ② 题号+卷别 | **2021 合订本（两套答案）** | `^[一二三四五六七八九十]+、\s*参考答案\s*[（(]\s*[HFperf]\s*[)）]` | T1 因缺 `re.M` 报 0，**属假阴性，需在 T1b 重测** |
| ③ 单独成行 | 各省分离型答案 PDF、2022 行政执法 | `^\s*参考答案\s*[:：]?\s*$` | 与题数 1:1（安徽4、广东5、北京4、国考5×3） |

**禁用**：`参考答案` 字样计数。D1 十份实测 `字样数/题数` = 5/5、**7/4**、**10/5**、**14/9**、5/5、5/5、**11/5**、**11/5**、5/5、**6/3**（因「参考答案说明」亦含该字样）。

### 2.3 分离型答案 PDF = **逐题就地配对**，不是文末答案区
T1 实测：国考/安徽/广东/北京答案 PDF 的答案锚点落在 **pos=78~133**，即**每题之后紧跟其答案**。

→ v3 的「定位答案区起点 → 统一切分」**对分离型完全失效**。
→ **采用甲方案：就地配对**——切题时就地绑定紧随其后的答案标记，一种模型同时适配合订本与分离型，不产生第二套体系。

### 2.5 安徽卷（主测试语料，用户指定）— **题组结构，两种题号样式并存**

**语料**：`题库\申论\安徽申论` 15 份 = 7 组配对 + 1 份 2025A（网友回忆版）。全分离型。

#### 题目PDF 结构
```
2023年公务员多省联考《申论》题（安徽A、普通选调卷）   ← 页眉噪声
给定材料                          ← 材料区锚点【裸行，无「二、」编号】
材料1 / 材料2 / 材料3 / 材料4     ← 4 个材料块（一整份共享材料）
1. 根据"给定资料1"，请概括A市…（15分）     ← 题号 =【半角 "1." + 空格】
要求：
（1）准确全面；                  ← 要求子项 =【全角 （1）】
（2）分条列出；
（3）成效与措施相对应；
（4）不超过200字。
2. 请结合"给定资料2"…（20分）    ← 依此
```

#### 答案PDF 结构（**自带完整题干+要求 → 可三方交叉校验**）
```
1. 根据"给定资料1"，请概括A市…（15分）   ← 题干+要求完整重复
要求：
（1）准确全面；…（4）不超过200字。
参考答案                            ← 【独占一行】形态③
1.创新项目落地机制。…                ← 答案正文（分点）
参考答案说明：本参考答案从…           ← 评分说明 → analysis
2. 请结合"给定资料2"…（20分）          ← 题2 紧随
```

实测数据：题目PDF 分值锚点 **4 个 = 15/20/25/40**，`给定材料`=1、`给定资料N`=4、无「一、/二、/三、」编号、无注意事项区。
答案PDF：**分值锚点同为 4（15/20/25/40）**，`参考答案` 出现 13 次、**独占成行 4 次**、`（N）` 编号 41 个。

#### 三条决定性结论

**① 两种题号样式必须分别识别（这是 F1 误判的根因）**
| 样式 | 出现于 | 例 |
|---|---|---|
| **半角 `N.`** | 安徽/多省联考 | `1. 根据"给定资料1"…（15分）` |
| **全角 `（N）`** | 国考合订本/国考分离 | `（1）根据"给定资料1"…（15 分）` |

现有切分器统一按 `（N）` 切题 → 在安徽卷上把**要求子项**（全角）切成独立题，而在国考卷上恰好正确。这正是"两种形态、两种病因"的统一解释。

**判据优先级（新增，覆盖 v3 的分值锚点法）**：
1. 若文中存在 `^\s*\d{1,2}\s*[.．、]\s*\S.*（N分）` → 判为**半角点号体**，用 `^\s*(\d{1,2})\s*[.．、]` 切题，全角 `（N）` 一律视为要求子项
2. 否则若存在 `^\s*（N）.*（N分）` → 判为**全角括号体**，用全角切题，要求子项靠"不含分值 + 要求特征词"排除
3. 两者皆无 → `_route_sections` 返回 `None`，走原路径

**② 答案PDF 自带题干 → 三方交叉校验（满足"映射精准"的硬要求）**

| 校验 | 数据源 | 不一致时 |
|---|---|---|
| C-1 题号对齐 | 题目PDF `N.` ↔ 答案PDF `N.` | `blocked`，不绑定 |
| C-2 分值对齐 | 题干 `（15分）` ↔ 答案PDF 同题 `（15分）` | `blocked`，不绑定 |
| C-3 题干指纹 | 两边题干归一化（去空白/标点）后哈希比对 | 记 `low_confidence`，仍阻断 |
| C-4 序号连续 | 题号序列无跳号 | 跳号 → 该题答案缺失 → `blocked`，**禁止就近填充** |

> **明确禁止**：出现"题数 == 答案段数"但逐题内容对不上却仍然放行。计数相等**只是必要条件**，放行判据是 C-1∧C-2∧C-4 全通过。

**③ 材料 → 题组（复用现有表）**
一整份材料 + N 小题 → `question_groups`（`shared_content`=材料全文、`group_type='material'`、`subject='申论'`、`title`=卷名）；N 题各写 `group_id`、`question_level=2`、`question_number='N'`。复用 `composite_matcher.py`，**不新建表**。

### 2.6 用户的展示结构要求（同套题内分区）
```
题干：xxxx
题目要求：xxxx
题目答案：（1）xxxx，（2）xxxx
题目解析：（1）xxxx，（2）xxxx
```
- 字段落位：`question_content` / **新增 `requirements`** / `answer` / `analysis`
- 分点：申论答案为 `一、二、三` 或 `1. 2. 3.` 结构，**必须保留换行与序号**，渲染层不得压成一行
- `analysis` 缺 `参考答案说明` 时**留空并标记待人工**，禁止用答案填充

## 3. 实现规格（全部为增量，落点已锁定）

### T2 `_route_sections(text) -> Optional[SectionMap]` — 新增于 `text_parser.py`
```
SectionMap: { noise:[(s,e)], material:(s,e), questions:(s,e), answers:[(s,e)], form:'inline'|'numbered'|'standalone' }
```
| 区段 | 锚点 | 容错 |
|---|---|---|
| 噪声 | `^[一二三四五六七八九十]+、\s*注意事项` | 亦兼容「注意事项」独占行 |
| 材料 | `^[一二三四五六七八九十]+、\s*给定材料\|给定资料` | 兼容无「一、」直接以 `材料1`/`给定资料1` 开头 |
| 问题 | `^[一二三四五六七八九十]+、\s*作答要求` | 兼容「作答要求」独占行 |
| 答案 | §2.2 三形态并集，**必须 `re.M`** | 排除「参考答案说明」 |

**安全门槛（保公专/行测零影响）**：仅当**同时命中 ≥2 个申论锚点**才返回非 `None`；否则返回 `None` 走原路径。

### T3 接入 `extract_question_blocks`
入口加分支：`sec = _route_sections(text)`；`None` → 原逻辑；否则只对 `sec.questions` 执行**原切分函数体**。
**红线**：不得修改原切分函数体的任何逻辑（仅新增函数 + 入口分支）。

### T4 `merge_requirement_items` — 切分后块后处理
| 判据 | 动作 |
|---|---|
| 块内**不含**分值标记 | 要求子项 → `content` 并入上一块 |
| 块内含分值但开头为要求特征词（准确全面/恰当提炼/不超过/紧扣资料/条理清晰/内容具体/语言流畅/逻辑清晰/观点明确/自选角度/字数） | 拆分：前半并入上一块；后半（自 `（N）`+分值起）为新块 |
| 归并后块数 **≠ 正确锚点数** | 置 `blocked=True` + `block_reasons`，**不生成 preview** |

要求子项识别**必须**以「无分值标记」为硬判据（A2：要求子项绝不含「分）」）。

### T5 就地配对答案
切分时对每块，取**该块题号之后、下一个题号之前**的答案段：
- `answer` = 参考答案正文
- `analysis` = `参考答案说明` + 采分点（`段N 中的要点④…`）。**无说明则留空，禁止用答案填充**
- 形态②（2021 双套）：`(H)` → `answer`，`(F)` → `analysis`

### T6 材料承载
复用现有 `question_groups`（`shared_content` / `group_type='material'` / `subject='申论'`），各题 `group_id` 指向它。`composite_matcher.py` 已存在，**不新建表**。

### T7 分值与题型
- `score`：块内 `（N分）` **去重**后取值；缺省 1 触发阻断
- 题型：**挂到已有 `_detect_question_type`**，不另写一套；申论仅允许 `简答题/论述题/写作题/简述题`，**禁止判为单选/多选**

### T8 阻断式校验
在**已有 `suspicious`** 基础上**追加** `blocked: bool` + `block_reasons: list`；前端据此禁用「确认导入」。保留 `suspicious` 以兼容现有前端消费。
