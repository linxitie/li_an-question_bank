## 一、问题分析

### 1.1 个人小目标（GoalCard / zjve4pgr）现状

当前首页（jjvdntly）使用的个人小目标组件存在以下问题：

| 问题 | 原因 | 影响 |
|------|------|------|
| 无法增删改目标 | 无 API 集成，使用硬编码假数据 | 用户无法管理目标 |
| 显示 NaN% | `goals` 为空时 0/0 = NaN | 糟糕的用户体验 |
| 缺少完成进度% | 旧版仅显示 SVG 环形图百分比 | 信息不完整 |
| 缺少倒计时 | 未使用 `deadline` 字段 | 用户无法感知紧迫性 |
| 缺少题目数量 | 旧版用 `current/total` 假数据 | 无法追踪真实进度 |
| 缺少空状态 | 无目标时不显示提示 | 用户不知如何开始 |
| 缺少状态徽章 | 无完成/超时标记 | 用户不清楚目标状态 |

**根因**：后端 `/api/goals/` 的 12 个端点均已完整实现，但前端 GoalCard 组件零 API 调用。

### 1.2 笔记功能现状

| 页面 | 组件 ID | 当前状态 |
|------|---------|----------|
| 题库页 | mjvdqdu1 | `ElMessage.info('笔记功能开发中')` |
| 答题页 | ujvdv5fe | 无笔记 UI |
| 错题集 | rjvduc4b | 无笔记 UI |
| 练习页 | exercise.vue | ✅ 完整实现（手写页面，可参考） |

**根因**：后端笔记 CRUD API 已就绪，但 VTJ 生成的 3 个页面均未集成。

## 二、解决方案

### 2.1 架构决策

| 决策 | 选择 | 理由 |
|------|------|------|
| GoalCard 重写方式 | .vue 文件完全重写 | 模板需从 SVG 环形图改为卡片列表，无法仅修改 script |
| GoalCard 组件选择 | 重写 zjve4pgr（删除 cjv83bou） | zjve4pgr 是首页实际使用的组件 |
| VTJ 设计器保护 | 标记 `raw: true` | 防止设计器保存时覆盖手写模板 |
| API 认证方式 | `window.__VTJ_AUTH__.apiFetch()` | 项目统一认证模式 |
| 笔记实现模式 | 参考 exercise.vue | 已有完整可工作的参考实现 |

### 2.2 修改范围


## 三、详细设计

### Phase 1: GoalCard（zjve4pgr）完全重写

#### 新 State
```javascript
state = reactive({
  goals: [],                    // API 数据
  loading: false,               // 加载中
  showDialog: false,            // 弹窗可见性
  dialogMode: 'create',         // 'create' | 'edit'
  editingGoalId: null,          // 编辑目标 ID
  dialogForm: {
    title: '', target_count: 1,
    goal_type: 'DAILY', deadline: '', priority: 2
  },
  goalTypes: [
    { value: 'DAILY', label: '每日' },
    { value: 'WEEKLY', label: '每周' },
    { value: 'MONTHLY', label: '每月' },
    { value: 'CUSTOM', label: '自定义' }
  ]
});
```

#### API 方法
| 方法 | HTTP | 端点 |
|------|------|------|
| `fetchGoals()` | GET | `/api/goals/` |
| `saveGoal()` | POST/PUT | `/api/goals/` 或 `/api/goals/{id}` |
| `deleteGoal(id)` | DELETE | `/api/goals/{id}` |
| `incrementProgress(id)` | POST | `/api/goals/{id}/progress?increment=1` |
| `confirmComplete(id)` | POST | `/api/goals/{id}/confirm-complete` |

#### 辅助方法
- `getDeadlineCountdown(deadline)` → `{ expired, text: "3天 12时 30分" }`
- `getGoalTypeLabel(type)` → "每日"/"每周"/"每月"/"自定义"
- `getGoalStatus(goal)` → `'completed'` | `'overdue'` | `'active'`

#### 新模板结构
```
goal-card
├── header: "个人小目标" + [+ 新增目标]
├── content:
│   ├── [empty] 🎯 还没有设计目标哦！
│   └── [cards v-for]
│       ├── 类型徽章 + 状态徽章(已完成/未完成)
│       ├── 标题
│       ├── 进度条 (progress_percent%)
│       ├── 完成进度% + 完成题目: N/M
│       ├── 倒计时 → 结束时间
│       └── 操作按钮: [+1] [完成] [编辑] [删除]
└── [dialog] 新增/编辑目标弹窗
```

#### NaN% 修复
```javascript
if (!goals || goals.length === 0) { progress = 0; return; }
// 后续安全计算百分比
```

### Phase 2-4: 笔记功能（3个页面统一模式）

每个页面追加相同的 pattern：
1. **State**: `showNoteEditor`, `noteText`, `currentNoteQuestionId`
2. **Methods**: `openNoteEditor(qId)`, `closeNoteEditor()`, `saveNote()`, `deleteNote()`
3. **Template**: 笔记按钮 + 笔记编辑弹窗（textarea + 保存/删除按钮）
4. **CSS**: 约 50 行

参考实现：`src/views/exercise.vue` 第 434-466 行和第 166-184 行
