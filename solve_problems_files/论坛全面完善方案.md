# 论坛功能全面完善方案 — 实施报告

> 实施日期：2026-08-12 | 状态：**已实施**

---

## 一、原方案诊断

原方案识别出三个核心问题，但解决方案存在 VTJ 规则违规和技术栈不匹配：

| 问题 | 原方案问题 | 修正方案 |
|------|-----------|----------|
| ① `$message` undefined | 提出 axios 拦截器 + ElMessage 导入（不匹配项目架构） | 新增 `_safeMsg()` 包装函数，所有 17 个方法统一使用 |
| ② 缺少用户发帖统计 | 提出新建 `src/components/forum/UserPostStats.vue` + `<el-card>`（违反 VTJ 单文件原则） | 在 `forum.vue` 右侧栏直接新增"我的帖子"卡片 + 后端 `GET /my-posts` 认证接口 |
| ③ 无法二次评论 | 提出 `ALTER TABLE comments ADD parent_id`（字段已存在） | 仅补齐前端评论 UI（后端 `parent_comment_id` 已完全支持） |

## 三、稳定性保障

| 机制 | 实现 |
|------|------|
| Modal 状态防泄漏 | `resetDetailState()` 在关闭/打开前调用 |
| 防双击加载 | `detailLoading` 互斥标志 |
| `$message` 安全 | `_safeMsg()` 全局兜底 |
| 评论不分页 | 一次加载全部（上限200），避免树形结构断裂 |
| 嵌套深度限制 | UI 渲染 2 层（顶级+一级回复） |
| 数据 null 安全 | `_mapPost` 全字段 `?.` + `??` 防护 |
| 后端唯一约束 | `uk_post_user_like` / `uk_comment_user_like` |
