## §0 为什么单独建这份基线

上一轮 QBDM v1/v2/v3 与角色卡里的关键数字**与仓库实际不符**（下表 R1–R8 标红项）。其中 R2、R3 属于**会导致破坏性操作**的错误：

- 说「2 个 raw 页」→ 实际 **47 个**；照旧文档判断会顺手动到 raw 页并触发 R2。
- 说 `scripts/qbdm/qbdm.py` 是入口 → 目录**根本不存在**；照旧文档开工第一步就会报错。

因此 v4 起，数字只认本表（实测日期 + 命令）。历史文档的错值**保留在 §2 对照表**里，作为反面凭证。

## §3 复现脚本（复制到 `%TEMP%\qbdm_measure.py` 后运行）

```python
# python -X utf8 qbdm_measure.py   （在仓库根执行）
import json, re
from pathlib import Path

root = Path(".").resolve()
out = {}

api = json.loads((root/"backend/data/refactor_baseline/api_surface.json").read_text(encoding="utf-8"))
entries = 0
full_paths, full_pairs = set(), set()
for mod, info in api.items():
    prefix = (info.get("prefix") or "").rstrip("/")
    for ep in info.get("endpoints") or []:
        entries += 1
        rel = ep.get("path") or ""
        full = prefix + rel if rel else prefix
        full_paths.add(full)
        full_pairs.add((str(ep.get("method") or "").upper(), full))
out["route_entries"] = entries
out["unique_full_paths"] = len(full_paths)
out["unique_method_full_paths"] = len(full_pairs)

main = (root/"backend/app/main.py").read_text(encoding="utf-8")
out["include_router"] = len(re.findall(r"app\.include_router\(", main))
out["api_v1_modules"] = len([p for p in (root/"backend/app/api/v1").rglob("*.py") if p.name != "__init__.py"])

mp = root/"backend/app/models/models.py"
src = mp.read_text(encoding="utf-8")
out["models_lines"] = len(src.splitlines())
out["models_classes"] = len(re.findall(r"^class ", src, re.M))

out["vtj_vue"] = len(list((root/".vtj/vue").glob("*.vue")))
out["vtj_dsl_json"] = len(list((root/".vtj/files").glob("*.json")))

raw = []
for jf in (root/".vtj/projects").glob("*.json"):
    d = json.loads(jf.read_text(encoding="utf-8"))
    pages = d.get("pages") or []
    out["pages_total"] = len(pages)
    raw = [p["id"] for p in pages if p.get("raw") is True]
out["raw_pages"] = len(raw)

out["router_vtj_imports"] = len(re.findall(r"\$vtj/vue/", (root/"src/router/index.ts").read_text(encoding="utf-8")))
out["backend_tests"] = len(list((root/"backend/tests").glob("test_*.py")))
out["vitest_specs"] = len(list((root/"src").rglob("*.spec.ts")))
out["gates"] = sorted(p.name for p in (root/"backend/scripts/gates").glob("*.py") if p.name != "__init__.py")
out["skills"] = len([p for p in (root/".agents/skills").iterdir() if p.is_dir()])

names = set()
for f in (root/"vtj-mcp-server/src").rglob("*.js"):
    for m in re.finditer(r"name: '(vtj_[a-z_]+)'", f.read_text(encoding="utf-8")):
        names.add(m.group(1))
out["mcp_tools"] = len(names)

def size_mb(p):
    if not p.exists(): return None
    total = sum(f.stat().st_size for f in p.rglob("*") if f.is_file())
    return round(total/1024/1024, 1)

out["题库_MB"] = size_mb(root/"题库")
out["static_MB"] = size_mb(root/"backend/app/static")
out["db_MB"] = round((root/"backend/data/example_db.sqlite").stat().st_size/1024/1024, 1)

print(json.dumps(out, ensure_ascii=False, indent=1))
```

**回填规则**：任何一项变化 → 更新 §1 对应行 + 升版本号 + 在 §4 记一行变更；未回填而引用旧值 = 违反 P1 事实先行。
