## 一、问题诊断与根因分析

### 1.1 问题清单与根因映射

| 问题编号 | 问题描述 | 根因分析 | 影响范围 |
|---------|---------|---------|---------|
| (1) | 个人信息点击显示404 | 路由配置缺失 `/admin/profile` 路由，AdminLayout头像菜单链接指向不存在的页面 | 用户体验、信息完整性 |
| (2) | 总用户数与实际不对应 | 用户统计使用 `func.count()` 统计全部记录，未排除测试用户/异常用户；数据库存在脏数据（FNL001、yyc5678） | 数据准确性、运营决策 |
| (3) | 用户管理编辑功能是占位符 | 后端 `/api/admin/users/{user_id}` PUT接口存在但前端弹窗未实现，缺少数据回显和表单验证 | 功能完整性 |
| (4) | 管理员端题目管理功能不完整 | 当前 `admin_questions.vue` 仅实现了基础列表，缺少ID排序、全量预览、编辑功能 | 核心业务功能 |
| (5) | 日志审批时间/角色/IP/模块/状态/耗时问题 | 后端 `record_operation()` 函数参数不完整，缺少角色查询、IP获取、耗时计算；前端时间格式化缺失 | 日志审计准确性 |
| (6) | 系统设置基本设置是占位符 | 前端仅展示硬编码数据，未调用 `/api/admin/settings` 接口 | 功能可用性 |
| (7) | 数据备份名称/状态/时间格式问题 | 备份名称使用英文时间戳；状态字段仅记录running/completed/failed；时间格式未处理 | 本地化、用户体验 |
| (8) | 权限管理缺少中文表示和编辑 | 前端权限列表使用英文key展示，无中文翻译；缺少编辑交互界面 | 可读性、可操作性 |
| (9) | 说明文档内容为空 | `admin_profile.vue` 页面未创建，头像菜单"说明文档"链接指向空页面 | 帮助文档 |

## 二、全局设计策略

### 2.1 设计原则

| 原则 | 说明 | 落地措施 |
|------|------|---------|
| **精准性** | 数据统计必须真实反映系统状态 | 用户统计排除异常用户；日志记录完整元数据 |
| **完整性** | 所有功能模块必须可用，不留占位符 | 逐一修复9个问题，确保前后端连通 |
| **一致性** | 管理员端与教师端功能对标，数据格式统一 | 题目管理对标教师端；时间格式统一；中文优先 |
| **可维护性** | 代码结构清晰，便于后期运维 | 统一API规范；组件化设计；配置外置 |
| **安全性** | 操作日志完整，敏感操作二次确认 | 日志记录角色/IP/耗时；删除操作需密码验证 |

<script setup>
import { ref, onMounted } from 'vue'
import { ElMessage, ElMessageBox } from 'element-plus'

// 默认头像

// 表单引用
const profileFormRef = ref(null)
const passwordFormRef = ref(null)

// 加载状态
const saving = ref(false)
const changingPassword = ref(false)

// 个人信息表单
const profileForm = ref({
  user_id: null,
  username: '',
  real_name: '',
  phone: '',
  email: '',
  gender: '未知',
  avatar: ''

  user_no: '',
  user_type: '',
  department: '',
  register_time: '',
  last_login: '',
  last_login_ip: ''
})

// 最近操作记录
const recentLogs = ref([])

// 修改密码弹窗
const passwordDialogVisible = ref(false)
const passwordForm = ref({
  current_password: '',
  new_password: '',
  confirm_password: ''
})

// 表单验证规则
const profileRules = {
  phone: [
    { pattern: /^1[3-9]\d{9}$/, message: '请输入正确的手机号', trigger: 'blur' }
  ],
  email: [
    { type: 'email', message: '请输入正确的邮箱地址', trigger: 'blur' }
  ]
}

// 密码验证规则
const passwordRules = {
  current_password: [
    { required: true, message: '请输入当前密码', trigger: 'blur' }
  ],
  new_password: [
    { required: true, message: '请输入新密码', trigger: 'blur' },
    { min: 6, message: '密码至少6位', trigger: 'blur' }
  ],
  confirm_password: [
    { required: true, message: '请确认密码', trigger: 'blur' },
    {
      validator: (rule, value, callback) => {
        if (value !== passwordForm.value.new_password) {
          callback(new Error('两次输入的密码不一致'))
        } else {
          callback()
        }
      },
      trigger: 'blur'
    }
  ]
}

// 获取角色名称
const getRoleName = (type) => {
  const map = { admin: '管理员', teacher: '教师', student: '学生' }
  return map[type] || type
}

// 获取角色类型
const getRoleType = (type) => {
  const map = { admin: 'danger', teacher: 'warning', student: '' }
  return map[type] || ''
}

// 格式化时间
const formatDateTime = (timeStr) => {
  if (!timeStr) return '-'
  return timeStr.replace('T', ' ').substring(0, 19)

// 加载个人信息
const loadProfile = async () => {
  try {
    const auth = window.__VTJ_AUTH__
    const userInfo = auth?.getUserInfo?.() || {}
    const userId = userInfo.user_id

    if (userId) {
      const res = await fetch(`/api/admin/users/${userId}`)
      const data = await res.json()
      if (data.success) {
        profileForm.value = {
          user_id: data.user.user_id,
          username: data.user.username,
          real_name: data.user.real_name || data.user.username,
          phone: data.user.phone || '',

          gender: data.user.gender || '未知',
          avatar: data.user.avatar || ''

          user_type: data.user.user_type,
          department: data.user.department,
          register_time: data.user.register_time,
          last_login: data.user.last_login,
          last_login_ip: data.user.last_login_ip

      recentLogs.value = data.items

const saveProfile = async () => {
  try {
    await profileFormRef.value.validate()

    const res = await fetch(`/api/admin/users/${profileForm.value.user_id}`, {
      method: 'PUT',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        real_name: profileForm.value.real_name,
        phone: profileForm.value.phone,
        email: profileForm.value.email,
        gender: profileForm.value.gender,
        avatar: profileForm.value.avatar

    })

    if (data.success) {
      ElMessage.success('个人信息更新成功')

      ElMessage.error(data.message || '更新失败')

const handleAvatarSuccess = (response) => {

    ElMessage.error('头像上传失败')

    return false

const changePassword = async () => {

    await passwordFormRef.value.validate()
    changingPassword.value = true

      method: 'PUT',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        current_password: passwordForm.value.current_password,
        new_password: passwordForm.value.new_password
      })

    const data = await res.json()
    if (data.success) {
      ElMessage.success('密码修改成功，请重新登录')

// 页面加载
onMounted(() => {

})
</script>

"""
清理数据库中的测试用户
运行方式: python -m backend.scripts.clean_test_users

import sys

from backend.app.core.database import SessionLocal
from backend.app.models.models import SysUser

def clean_test_users():

    db = SessionLocal()
    try:
        # 查找并删除无法登录的测试用户

        if test_users:

                db.delete(user)
            db.commit()
            print(f"共删除 {len(test_users)} 个测试用户")
        else:
            print("未找到需要清理的测试用户")
            
        # 显示当前有效用户数

            SysUser.status == 1,
            SysUser.is_disabled == 0,

<script setup>
import { ref, onMounted, computed } from 'vue'
import { ElMessage, ElMessageBox } from 'element-plus'

// 加载状态
const loading = ref(false)

// 分页
const currentPage = ref(1)
const pageSize = ref(20)
const total = ref(0)

// 筛选条件
const filters = ref({
  subject_id: null,
  type_id: null,
  difficulty: null,
  audit_status: null,
  keyword: ''
})

// 题目列表
const questionList = ref([])

// 题型列表
const typeList = ref([])

// 统计数据
const stats = ref({
  total: 0,
  xingce: 0,
  shenlun: 0,
  gongzhuan: 0,
  pending: 0
})

// 预览弹窗
const previewVisible = ref(false)
const previewData = ref({})

// 编辑弹窗
const editVisible = ref(false)
const editForm = ref({
  question_id: null,
  subject_id: 1,
  type_id: null,
  question_content: '',
  options: [],
  answer: '',
  answer_analysis: '',
  difficulty: 3,
  source: '',
  year: 2026
})

// 驳回弹窗
const rejectDialogVisible = ref(false)
const rejectForm = ref({
  question_id: null,
  reason_type: '',
  comment: ''
})

// 根据科目筛选题型
const filteredTypeList = computed(() => {
  if (!filters.value.subject_id) return typeList.value
  return typeList.value.filter(t => t.subject_id === filters.value.subject_id)
})

// 获取审核状态类型
const getAuditStatusType = (status) => {
  const map = { 0: 'warning', 1: 'success', 2: 'danger' }
  return map[status] || 'info'
}

// 获取审核状态名称
const getAuditStatusName = (status) => {
  const map = { 0: '待审核', 1: '已通过', 2: '已驳回' }
  return map[status] || '未知'
}

// 格式化时间
const formatDateTime = (timeStr) => {
  if (!timeStr) return '-'
  return timeStr.replace('T', ' ').substring(0, 19)
}

// 加载题目列表
const fetchQuestions = async () => {
  loading.value = true
  try {
    const params = new URLSearchParams({
      page: currentPage.value,
      page_size: pageSize.value,
      sort_by: 'question_id',
      sort_order: 'asc'
    })
    if (filters.value.subject_id) params.append('subject_id', filters.value.subject_id)
    if (filters.value.type_id) params.append('type_id', filters.value.type_id)
    if (filters.value.difficulty) params.append('difficulty', filters.value.difficulty)
    if (filters.value.audit_status !== null) params.append('audit_status', filters.value.audit_status)
    if (filters.value.keyword) params.append('keyword', filters.value.keyword)

    const res = await fetch(`/api/admin/questions?${params}`)
    const data = await res.json()
    if (data.success) {
      questionList.value = data.items
      total.value = data.total
    }
  } catch (error) {
    ElMessage.error('加载题目列表失败')
  } finally {
    loading.value = false
  }
}

// 加载题型列表
const fetchTypes = async () => {
  try {
    const res = await fetch('/api/questions/types')
    const data = await res.json()
    if (data.success) {
      typeList.value = data.items
    }
  } catch (error) {
    console.error('加载题型失败')
  }
}

// 加载统计数据
const fetchStats = async () => {
  try {
    const res = await fetch('/api/admin/questions/stats')
    const data = await res.json()
    if (data.success) {
      stats.value = data
    }
  } catch (error) {
    console.error('加载统计数据失败')
  }
}

// 重置筛选
const resetFilters = () => {
  filters.value = {
    subject_id: null,
    type_id: null,
    difficulty: null,
    audit_status: null,
    keyword: ''
  }
  fetchQuestions()
}

// 预览题目
const previewQuestion = (row) => {
  previewData.value = { ...row }
  previewVisible.value = true
}

// 编辑题目
const editQuestion = async (row) => {
  try {
    const res = await fetch(`/api/admin/questions?keyword=${row.question_id}`)
    const data = await res.json()
    if (data.success && data.items.length > 0) {
      const question = data.items[0]
      editForm.value = {
        question_id: question.question_id,
        subject_id: question.subject_id,
        type_id: question.type_id,
        question_content: question.full_content || question.question_content,
        options: question.options || [],
        answer: question.answer,
        answer_analysis: question.answer_analysis || '',
        difficulty: question.difficulty || 3,
        source: question.source || '',
        year: question.year || 2026
      }
      editVisible.value = true
    }
  } catch (error) {
    ElMessage.error('获取题目信息失败')
  }
}

// 科目变更
const onSubjectChange = () => {
  editForm.value.type_id = null
}

// 添加选项
const addOption = () => {
  editForm.value.options.push('')
}

// 移除选项
const removeOption = (index) => {
  editForm.value.options.splice(index, 1)
}

// 提交编辑
const submitEdit = async () => {
  try {
    const res = await fetch(`/api/admin/questions/${editForm.value.question_id}`, {
      method: 'PUT',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(editForm.value)
    })

    const data = await res.json()
    if (data.success) {
      ElMessage.success('题目更新成功')
      editVisible.value = false
      fetchQuestions()
    } else {
      ElMessage.error(data.message || '更新失败')
    }
  } catch (error) {
    ElMessage.error('更新失败：' + error.message)
  }
}

// 审核通过
const auditPass = async (row) => {
  try {
    await ElMessageBox.confirm(`确定通过题目 ${row.question_id} 的审核吗？`, '审核确认', {
      type: 'success'
    })

    const res = await fetch(`/api/admin/questions/${row.question_id}/audit`, {
      method: 'PUT',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        audit_status: 1,
        audit_comment: '审核通过'
      })
    })

    const data = await res.json()
    if (data.success) {
      ElMessage.success('审核通过')
      fetchQuestions()
    }
  } catch (error) {
    if (error !== 'cancel') {
      ElMessage.error('操作失败')
    }
  }
}

// 显示驳回弹窗
const showRejectDialog = (row) => {
  rejectForm.value = {
    question_id: row.question_id,
    reason_type: '',
    comment: ''
  }
  rejectDialogVisible.value = true
}
