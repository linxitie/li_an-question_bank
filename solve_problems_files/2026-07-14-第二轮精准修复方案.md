## 一、考试日历模块 — 4项修复

### 问题1: 考试内容未直接展示

**根因**: 爬虫用HTTP请求，未使用Playwright进入详情页抓取`div.ws-content.ws-card`内容

**修复**:
- `exam_scraper.py`: 改用Playwright打开详情页，精确提取`div.ws-content.ws-card`内容
- `exam_calendar.vue`: 引入Accordion点击展开模式（点击条目→展开显示完整考试内容）
- 标题以标题格式显示在卡片顶部正中间

### 问题2: "查看全部招考信息"未删除

**根因**: 前端模板可能残留或缓存

**修复**:
- 确认模板中无`.card-footer`元素
- 列表改为`overflow-y: auto`可滑动
- 后端增加自动过期删除: registration_end超过1天后硬删除
- 每天自动爬取新信息，不影响未过期内容

### 问题3: 标题不能完全展示

**根因**: CSS `white-space: nowrap; text-overflow: ellipsis`单行截断

**修复**:
- 标题区域放宽至两行显示：`display: -webkit-box; -webkit-line-clamp: 2; -webkit-box-orient: vertical`
- 只展示招考主信息：地点(省份/市县)、招聘类型(三支一扶/事业单位等)、招聘人数徽章
- 适当增加模块宽度

### 问题4: 截止时间未获取

**根因**: 正则只匹配单行，且未从详情页获取

**修复**:
- Playwright进入详情页后多行正则提取报名起止时间
- 前端展示"报名: MM/DD - 截止: MM/DD"
- 截止时间用红色高亮

## 二、每日新闻模块 — 3项修复

### 问题1: 人民网噪音未过滤

**根因**: `_extract_article_content()`回退到`body.get_text()`获取全页文本，包含导航/党建/登录等噪音

**修复**:
- 使用Playwright打开人民网详情页
- 精确提取`div.p2j_con3.clearfix.g-w1200`中内容
- 移除其内部的nav/sidebar/ad等噪音子元素
- 多选择器回退链: `div.p2j_con3` → `div.text-con` → `article` → `div.content`

### 问题2: 卡片缺笔记/收藏标识

**修复 — 卡片层面增强**:
```html
<div class="news-card-actions">
  <button @click.stop="toggleCardFavorite(item)" :class="{favorited: item.is_favorited}">⭐</button>
  <button @click.stop="openDetail(item)" class="note-indicator">📝<span v-if="item.note_count">{{item.note_count}}</span></button>
</div>
```

### 问题3: CPD图片URL解析Bug

**根因**: `img.get('src')`提取的URL包含HTML标签残留`xxx.jpg%3C/a%3E%3Cp%20style=`

**修复**:
```python
src = img.get('src', '').strip()
clean_match = re.match(r'^(.*?\.(?:jpg|jpeg|png|gif|webp|bmp))', src, re.IGNORECASE)
if clean_match:
    src = clean_match.group(1)
else:
    continue  # 跳过非图片URL
```

### 补充: 划线系统升级

**5种颜色 + 3种线型**:

| 颜色 | 色值 | 标记 |
|------|------|------|
| 黄色 | #FFD700 | 🟡 |
| 绿色 | #4CAF50 | 🟢 |
| 蓝色 | #2196F3 | 🔵 |
| 红色 | #EF4444 | 🔴 |
| 紫色 | #8B5CF6 | 🟣 |

| 线型 | CSS | 效果 |
|------|-----|------|
| 波浪线 | `text-decoration: wavy underline` + 对应颜色 | 如手划波浪线 |
| 直线 | `text-decoration: underline` + 对应颜色 | 普通下划线 |
| 马克笔 | `background-color` + 对应颜色(半透明) | 荧光笔高亮 |

**数据库存储**: `news_note`表`color`字段存颜色值，新增`line_style`字段存线型(`wavy`/`straight`/`marker`)

**选择菜单UI**:
```
选中文字 → 弹出菜单:
  ├── 颜色行: [🟡] [🟢] [🔵] [🔴] [🟣]
  ├── 线型行: [波浪线] [直线] [马克笔]
  └── 操作行: [📝 想法]
```

## 三、招考信息模块 — 3项修复

### 问题1: 部分信息未展示

**根因**: 爬虫选择器列表无`div.channel-main`

**修复**:
- 使用Playwright打开rszk.net详情页
- 精确提取`div.channel-main.clearfix`
- **排除**: `div.channel-article`、`div.channel-prompt`、`div.leftread`
- 保留其余全部内容

### 问题2: 不支持滑动查看

**修复**:
```css
.recruitment-list {
  max-height: 60vh;
  overflow-y: auto;
}
```
IntersectionObserver触底自动加载更多

### 问题3: 排版不完整+高亮截止时间

**修复**:
- 卡片`max-width: 1200px; font-size: 15px; line-height: 1.8`
- 报名截止时间用**红色加粗**高亮: `color: #c41e3a; font-weight: 700`
- 段落间距`margin-bottom: 16px`，图片响应式居中
