# 错题集模块优化方案 v4

## 一、问题诊断与根因分析

### 问题1：div不能点击显示题目具体内容

**现象**：用户点击错题列表中的题目卡片，无法弹出详情弹窗。

**根因分析**：
- 前端代码 `goToQuestion(q)` → `openQuestionDetail(q)` → 调用 `/api/wrong-questions/{wrong_id}/detail`
- `loadData()` 方法中 `wrong_id: item.wrong_id` 字段存在，数据正确
- 弹窗样式 `z-index: 2000` 足够高，不应被遮挡
- **真正根因**：`openQuestionDetail` 方法中的 `this.$message.info('加载题目详情...')` 可能与 Element Plus 的消息实例冲突；同时 `apiFetch` 可能因 token 过期返回 HTML（SPA fallback），导致 `res.json()` 解析失败，但错误被 catch 吞掉

**验证方式**：检查浏览器控制台是否有错误日志

### 问题2：题型识别错误（单选题被识别为论述）

**现象**：明显是单选题的题目（有ABCD选项），题型徽章却显示"[论述]"。

**根因分析**（3层错误）：

1. **数据库层**：`question_type` 表的 `is_objective` 字段标记错误
   - type_id=3 (单选题): is_objective=0（应为1）✗
   - type_id=4 (多选题): is_objective=0（应为1）✗

2. **数据层**：题目类型与实际内容不匹配
   - 16道错题中，type_id=2(填空题) 但实际是单选题/多选题（有选项、答案为字母）
   - 导入时题型识别逻辑有缺陷

3. **前端层**：`loadData()` 中 `type: item.question_type_detail || '单选题'` 未经过 typeMap 统一映射
   - 后端返回 "填空题" → 前端 getTypeLabel 映射为 "[论述]"
   - 但实际题目有选项，应识别为单选题/多选题

### 问题3：题目图片无法显示

**现象**：选项中显示 `[IMAGE:96_0]` 等占位符文本，而非实际图片。

**根因分析**：
- `[IMAGE:{num}_{seq}]` 是题目导入时从 Word 文档提取图片的占位符
- 图片应保存到 `backend/static/questions/{num}_{seq}.png`
- **关键发现**：`backend/static/questions` 目录不存在！
- `question_image` 表为空（0条记录），说明导入时图片保存失败
- 前端未实现 `[IMAGE:x_y]` → `<img src="/static/questions/x_y.png">` 的替换逻辑

### 问题4：交卷按钮答案比对失败

**现象**：点击交卷按钮后，没有显示答案解析页面。

**根因分析**（2层错误）：

1. **后端层**：`question_type` 表的 `is_objective` 字段错误
   - review/submit 接口判分逻辑：`if qtype and qtype.is_objective:`
   - 单选题(type_id=3)和多选题(type_id=4)的 `is_objective=0`
   - 导致后端不进行判分，`is_correct` 全部为 False

2. **前端层**：题型识别错误导致选项显示逻辑混乱
   - 单选题被识别为论述题，可能不显示选项
   - 提交的答案格式与后端期望不一致

#### 2.2 后端题型识别优化

**修改文件**：`backend/app/api/v1/wrong_questions.py`

**修改内容**：
- 优化 `_get_question_type_detail` 函数，增加基于 options 和 answer 的智能识别
- 当数据库题型与实际内容冲突时，以实际内容为准

```python
def _get_question_type_detail(question, db) -> str:
    """查询题目的题型名称，增加智能识别"""
    if not question:
        return '单选题'
    
    # 1. 先查 question_detail_category
    detail_row = db.query(QuestionDetailCategory).filter(
        QuestionDetailCategory.question_id == question.question_id
    ).first()
    if detail_row and detail_row.question_type_detail:
        db_type = str(detail_row.question_type_detail)
    else:
        db_type = '单选题'
    
    # 2. 智能校验：如果数据库说是论述/填空，但题目有选项，则修正
    import json as _json
    options = []
    if question.options:
        try:
            options = _json.loads(question.options) if isinstance(question.options, str) else question.options
        except:
            options = []
    
    answer = question.answer or ''
    
    # 有选项 + 答案是字母 → 选择题
    if options and len(options) >= 2:
        # 答案含多个字母 → 多选题
        import re
        letters = re.findall(r'[A-Z]', answer.upper())
        if len(letters) > 1:
            return '多选题'
        return '单选题'
    
    # 无选项 + 内容长 → 论述/写作
    content = question.question_content or ''
    if not options or len(options) < 2:
        if any(kw in content for kw in ['写作', '作文', '为题', '写一篇']):
            return '写作题'
        if len(content) > 80 or any(kw in content for kw in ['论述', '分析', '简答']):
            return '论述题'
    
    return db_type
```

#### 3.2 前端图片占位符替换

**修改文件**：`.vtj/vue/wrong_questions.vue`

**修改内容**：
- 添加 `renderImageMarkers(html)` 方法，将 `[IMAGE:x_y]` 替换为 `<img>` 标签
- 在题干和选项的 `v-html` 中应用此方法

```javascript
renderImageMarkers(html) {
    if (!html) return '';
    // [IMAGE:97_0] → <img src="/static/questions/97_0.png" 
    //   onerror="this.style.display='none'" 
    //   style="max-width:100%;height:auto;" />
    return html.replace(
        /\[IMAGE:(\d+)_(\d+)\]/g,
        '<img src="/static/questions/$1_$2.png" ' +
        'onerror="this.style.display=\'none\'" ' +
        'style="max-width:100%;height:auto;' +
        'border:1px solid #e8eaf0;border-radius:8px;' +
        'margin:4px 0;" alt="题目图片" />'
    );
}
```

### 方案4：修复交卷答案比对（后端+前端）

#### 4.1 后端判分逻辑优化

**修改文件**：`backend/app/api/v1/wrong_questions.py`

**修改内容**：
- review/submit 接口不依赖 `is_objective` 字段
- 改为根据题型名称（type_name）判断是否为客观题
- 优化多选题答案比对逻辑（支持 "A,B,C" 和 "ABC" 两种格式）

```python
# 判分逻辑优化
correct_answer = (q.answer or '').strip()
is_correct = False

# 根据题型名称判断是否为客观题
is_objective_type = unified_type in ['单选题', '多选题']

if is_objective_type:
    if unified_type == '多选题':
        # 多选题：支持 "A,B,C" 和 "ABC" 两种格式
        import re
        correct_letters = sorted(re.findall(r'[A-Z]', correct_answer.upper()))
        user_letters = sorted(re.findall(r'[A-Z]', user_answer.upper()))
        is_correct = correct_letters == user_letters
    else:
        # 单选题：直接比较
        is_correct = correct_answer.upper() == user_answer.upper()
```

#### 4.2 前端提交答案格式优化

**修改文件**：`.vtj/vue/wrong_questions.vue`

**修改内容**：
- 确保 `submitReviewAnswers` 提交的答案格式为字母（A/B/C/D），而非选项索引
- 对多选题答案进行排序后再提交
