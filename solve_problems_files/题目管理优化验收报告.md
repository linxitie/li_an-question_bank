## 五、事故记录与恢复

- **stash 事故（T2 期间）**：执行 `git stash --include-untracked` 做基线对比时，PowerShell stderr 噪音导致误判失败，未及时 pop；stash 将工作区全部修改（含从未提交的 exam_records.py 等 untracked 文件）收起。已通过 `git checkout stash@{0} -- <files>` 逐路径完整恢复并验证（测试通过、导入链正常、DB 数据核对无误）。stash 保留至本报告提交后清理。
- 教训：Windows PowerShell 下 git 命令的 stderr 输出不可作为失败判据，应以 `$LASTEXITCODE` + 实际状态双重验证。
