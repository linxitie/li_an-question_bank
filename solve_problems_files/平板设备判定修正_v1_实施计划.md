# 平板设备判定修正 实施计划 v1

> 状态：**已批准待执行**（2026-10-25，用户授权按最优方案实施）
> Spec：`docs/superpowers/specs/平板设备判定修正_v1.md`

**Goal:** 让平板（含「桌面版网站」UA、宽度 >1024）被判为 `tablet`，同时不误伤触摸笔记本、横屏手机与普通 PC。

**Architecture:** 把判定逻辑抽成纯函数 `detectDeviceFrom(signals)`，`detectDevice()` 只采集 `window` 信号后调用它。所有既有导出签名与 `resolveDevicePath` 保持不变。

**Tech Stack:** TypeScript、vitest（node 环境，纯函数无需 jsdom）、Playwright（端到端）。

## Global Constraints

- 只改 `src/utils/device.ts`，新增 `src/utils/__tests__/device.spec.ts`。
- 不移动文件、不改导出名、不改 `resolveDevicePath` 与 `DEVICE_ROUTE_MAP`（R4）。
- 判定顺序：UA 平板 → 粗指针 → 手机 → pc（见 spec §3.2）。
- 粗指针判据必须带 `!/mobile/.test(ua)` 排除项（spec §3.5）。
- `matchMedia` 不可用时兜底 `false`，行为退回当前版本。

- [ ] **Step 3: 实现**

```ts
export interface DeviceSignals {
  userAgent: string;
  width: number;
  touchable: boolean;
  coarsePointer: boolean;
  hoverable: boolean;
}

const TABLET_UA = /(ipad|tablet|(android(?!.*mobi))|(windows(?!.*phone)(.*touch)))/;
const MOBILE_UA = /iphone|ipod|android.*mobi|windows phone|blackberry|opera mini|iemobile/;

export function detectDeviceFrom(s: DeviceSignals): DeviceType {
  if (TABLET_UA.test(s.userAgent) || (s.width >= 768 && s.width <= 1024 && s.touchable)) return 'tablet';
  if (s.coarsePointer && !s.hoverable && s.width >= 768 && !/mobile/.test(s.userAgent)) return 'tablet';
  if (MOBILE_UA.test(s.userAgent) || s.width < 768) return 'mobile';
  return 'pc';
}

export function detectDevice(): DeviceType {
  const mq = (q: string) => {
    try {
      return typeof window.matchMedia === 'function' && window.matchMedia(q).matches;
    } catch {
      return false;
    }
  };
  return detectDeviceFrom({
    userAgent: navigator.userAgent.toLowerCase(),
    width: window.innerWidth,
    touchable: 'ontouchstart' in window || navigator.maxTouchPoints > 0,
    coarsePointer: mq('(pointer: coarse)'),
    hoverable: mq('(hover: hover)')
  });
}
```
