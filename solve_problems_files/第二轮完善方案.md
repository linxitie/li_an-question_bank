# 三端分离架构 — 第二轮完善方案

## 完成时间
2026-07-12

## 解决的问题

### 1. JWT Token Payload 修复（根因）
**问题**：Token 只含 `user_id`/`user_no`，缺少角色信息，导致前端路由守卫全部失效。
**修复**：
- `backend/app/api/v1/auth.py` — login/sms-login/refresh 三个端点
- JWT payload 新增：`user_type`、`role_level`、`permissions`
- 修复后 ycc5678 的 JWT 含 `{user_type:'teacher', role_level:1, permissions:[19项]}`

### 2. 文件重命名（27对文件）
**问题**：VTJ 文件使用无意义随机 ID（如 cjv83bou=个人小目标）
**修复**：
- 重命名映射表：27 个 ID → 语义化英文名
- 自动更新：DSL JSON、Projects JSON、Router、Vue useProvider、交叉引用
- 页面：home_page, question_bank, about, forum, wrong_questions, score_analysis, gold_purchase, answer_page, question_import
- 区块：navbar, personal_goal, daily_quote, exam_calendar, signin_card, goal_card 等

### 3. 教师/管理员 DSL JSON 创建（11个）
**问题**：仅有 .vue 文件，缺少 .vtj/files/*.json DSL 文件
**修复**：
- 创建 teacher_dashboard/questions/papers/scores.json（4个）
- 创建 admin_dashboard/users/questions/settings/logs/backup/permissions.json（7个）
- 在 projects JSON 注册所有新页面
- DSL 遵循 VTJ 规范（id, name, state, methods, lifeCycles, css, nodes）

### 4. 登录系统完善

#### 4a. 注册角色限制
- **后端**：register 端点强制 `user_type="student"`，忽略前端传入值
- **前端**：login.vue 隐藏 teacher/admin 选项，显示"请联系管理员创建"

#### 4b. 个人信息面板
- **后端**：新增 `PUT /api/auth/profile` 端点
- **前端**：NavBar 点击头像 → 弹出个人中心面板（非退出登录）
- 面板：展示/编辑 用户名/手机/性别/学院/班级/邮箱
- 保留"退出登录"按钮

#### 4c. Cookie/Session/Application 三层认证
- **Cookie**：`__vtj_session__` (HttpOnly, Secure, SameSite=Strict)
- **Session**：后端 SessionManager 内存存储 `{user_id, ip, login_time}`
- **Application**：localStorage `__VTJ_AUTH_STATE__`（保持兼容）
