# 砺安题库 — 每日新闻爬虫 & 招考信息 修复方案

> 生成日期：2026-06-27 | 状态：待审批

---

## 一、问题分析

### 1.1 每日新闻

| 问题 | 原因 | 影响 |
|------|------|------|
| 人民公安报无法爬取 | 纯 HTTP requests 无法跟随 JS 重定向链 | 零新闻入库 |
| 无正文内容 | DB 缺 `content` 字段 | 前端无法展示正文 |
| 点击标题跳转外部 | 前端用 `<a href>` 外链 | 无内部阅读体验 |
| 仅显示5条标题 | `slice(0,5)` 硬编码 | 信息量不足 |

### 1.2 招考信息

| 问题 | 原因 | 影响 |
|------|------|------|
| 6个模块笼统展示 | 旧版仅显示分类名+1条标题 | 无法浏览各分类信息 |
| 标题不可点击查看详情 | 点击仅 `$message.info()` | 用户无法获取详细内容 |
| 缺少正文/条件/截止日期 | API 未返回 `content`/`requirements` | 前端无数据展示 |
| 爬虫不抓详情页 | 仅抓标题+链接 | 数据库缺完整信息 |

---

## 二、解决方案

### 2.1 架构决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 爬虫引擎 | Selenium + headless Chrome | JS 重定向自动执行，模拟真实浏览 |
| WebDriver 管理 | webdriver-manager | 自动匹配 Chrome 版本，无需手动维护 |
| 反检测 | UA 轮换 + 随机延迟 + AutomationControlled 禁用 | 避免被反爬系统拦截 |
| 招考前端的实现 | 重写 HomePage 内联招考区 | 替换旧的3个重复实现，统一为模块卡片 |

### 2.2 修改范围

```
修改 11 个文件：
├── backend/requirements.txt                   ← 添加 selenium, webdriver-manager
├── backend/app/models/models.py               ← NewsArticle 添加 content 列

├── backend/app/services/news_scraper.py       ← 完全重写（Selenium + 正文）
├── backend/app/api/v1/news.py                 ← 返回 content 字段
```

## 三、详细设计

### Phase 1: 新闻后端

**NewsArticle 新字段：**
```python
content = Column(Text, comment="文章正文")
```

**Selenium 爬虫核心流程：**
```
_create_driver() → headless Chrome + 反检测
  → driver.get(epaper.cpd.com.cn)
  → WebDriverWait 等待 JS 重定向完成
  → BeautifulSoup 解析 <area title> 标签
  → 逐个进入文章详情页 → 提取正文
  → 写入 DB（title + url + content 去重）
```

**新闻 API 响应新增：**
```json
{ "content": "文章正文全文..." }
```

### Phase 2: 新闻前端 — 详情弹窗

```
QuoteBanner 新闻列表
  └── [点击标题]
        └── 弹窗：标题 + 来源徽章 + 日期 + 正文全文 + [查看原文] [关闭]
```

### Phase 3: 招考后端

**详情页抓取 `_scrape_article_detail(url)`：**
- 正则匹配提取：发布单位、招聘条件、截止日期、工作地点、标签
- 正文提取：多选择器 fallback 链
- 标签自动检测：报名中/即将报名/已截止/笔试通知/公示等

### Phase 4: 招考前端 — 模块卡片重设计

```
招考信息区域（2x3 网格）
├── [国考省考]                  [事业单位]                  [教师招聘]
│   ├── 标题1 🏷报名中          ├── 标题1                    ├── 标题1
│   ├── 标题2                   ├── 标题2                    ├── 标题2
│   ├── 标题3                   ├── 标题3                    ├── 标题3
│   ├── 标题4                   ├── 标题4                    ├── 标题4
│   ├── 标题5                   ├── 标题5                    ├── 标题5
│   └── [展开全部 (10条)]       └── [展开全部 (10条)]        └── [展开全部 (10条)]
│
├── [国企招聘]                  [医疗卫生]                  [三支一扶]
│   └── ...                     └── ...                     └── ...
│
└── [点击任意标题] → 详情弹窗
      ├── 分类 + 标签 + 发布单位 + 截止日期
      ├── 招聘条件
```
