# 错题集模块优化方案 v5（最终版）

## 一、问题诊断与根因分析（精确版）

### 问题1：div不能点击显示题目具体内容

**控制台报错**：
```
Cannot read properties of undefined (reading 'success') at restoreZhanti (wrong_questions.vue:1335)
Cannot read properties of undefined (reading 'info') at openQuestionDetail (wrong_questions.vue:1043)
Cannot read properties of undefined (reading 'error') at openQuestionDetail (wrong_questions.vue:1068)
```

**精确根因**：`this.$message` 是 undefined！

- `wrong_questions.vue` 中 29 处使用 `this.$message.xxx()`，但 VTJ 组件未自动注入 Element Plus 的 `$message` 服务
- 对比 `question_import.vue` 使用的是 `import { ElMessage } from 'element-plus'` + `ElMessage.xxx()`，这种方式可用
- 其他 .vue 文件（answer_page.vue、navbar.vue、forum.vue）也用 `this.$message`，但可能因 VTJ 上下文不同而失效

**修复策略**：
1. 在 `wrong_questions.vue` 顶部 import ElMessage
2. 将所有 `this.$message.xxx(...)` 替换为 `ElMessage.xxx(...)`
3. 对可能未加载的情况做安全保护 `(ElMessage || this.$message)?.xxx(...)`

### 问题2：题型识别错误（单选题被识别为论述）

**3层错误叠加**：

1. **数据库层**：`question_type` 表的 `is_objective` 字段标记错误
   - type_id=3 (单选题): is_objective=0（应为1）✗
   - type_id=4 (多选题): is_objective=0（应为1）✗

2. **数据层**：16道错题中，type_id=2(填空题)但实际是单选题/多选题（有选项、答案为字母）
   - 导入时 `_normalize_type_name` 识别缺陷

3. **前端层**：`loadData()` 中 `type: item.question_type_detail` 未经 typeMap 统一映射
   - 后端返回"填空题" → 前端 getTypeLabel 映射为"[论述]"

### 问题3：题目图片无法显示

**精确根因（图片保存链路分析）**：

1. **导入链路**：
   - `_extract_text_from_docx` 提取图片 → 保存到 `backend/static/questions/{num}_{seq}.png`
   - `_extract_and_save_images` 读取这些图片 → 复制到 `backend/static/questions/{question_id}/img_docx_{num}_{seq}_{md5}.png`
   - 图片路径保存到 `question_image` 表（image_path 字段）

2. **当前问题**：
   - `backend/static/questions/` 目录存在但为空（之前导入的图片已被清理或从未成功保存）
   - `question_image` 表为空（0条记录）
   - 题目 content/options 中仍保留 `[IMAGE:x_y]` 占位符
   - 前端未实现占位符到 `<img>` 的替换

3. **前端缺失**：未将 `[IMAGE:x_y]` 替换为 `<img src="/static/questions/{qid}/{filename}">`

### 问题4：交卷按钮答案比对失败

**2层错误**：

1. **后端层**：review/submit 接口判分逻辑 `if qtype and qtype.is_objective:`
   - 单选题(type_id=3)和多选题(type_id=4)的 `is_objective=0`
   - 导致后端不判分，`is_correct` 全部为 False

2. **前端层**：题型识别错误导致选项显示混乱，提交答案格式与后端期望不一致

#### 2.2 后端智能题型识别

**修改文件**：`backend/app/api/v1/wrong_questions.py`

**修改内容**：优化 `_get_question_type_detail` 函数，增加基于 options 和 answer 的智能识别

```python
def _get_question_type_detail(question, db) -> str:
    """查询题目的题型名称，增加智能识别"""
    if not question:
        return '单选题'
    
    # 1. 先查 question_detail_category
    detail_row = db.query(QuestionDetailCategory).filter(
        QuestionDetailCategory.question_id == question.question_id
    ).first()
    db_type = str(detail_row.question_type_detail) if (detail_row and detail_row.question_type_detail) else '单选题'
    
    # 2. 智能校验：如果数据库说是论述/填空，但题目有选项，则修正
    options = []
    if question.options:
        try:
            options = json.loads(question.options) if isinstance(question.options, str) else question.options
        except:
            options = []
    
    answer = question.answer or ''
    
    # 有选项 → 选择题
    if options and len(options) >= 2:
        import re
        letters = re.findall(r'[A-Z]', answer.upper())
        if len(letters) > 1:
            return '多选题'
        return '单选题'
    
    # 无选项 + 内容长 → 论述/写作
    content = question.question_content or ''
    if not options or len(options) < 2:
        if any(kw in content for kw in ['写作', '作文', '为题', '写一篇']):
            return '写作题'
        if len(content) > 80 or any(kw in content for kw in ['论述', '分析', '简答']):
            return '论述题'
    
    return db_type
```

### 方案3：修复图片显示（前端+重新导入）

#### 3.1 前端图片占位符替换

**修改文件**：`.vtj/vue/wrong_questions.vue`

**修改内容**：
- 添加 `renderImageMarkers(html, questionId)` 方法
- 将 `[IMAGE:x_y]` 替换为 `<img src="/static/questions/{questionId}/img_docx_x_y_{md5}.png">`
- 同时查询 `question_image` 表获取真实图片路径
- 使用 `onerror` 隐藏不存在的图片

```javascript
renderImageMarkers(html, questionId) {
    if (!html) return '';
    // [IMAGE:97_0] → 尝试从 question_image 表查询真实路径
    // 若无 question_image 记录，则尝试直接访问 /static/questions/{questionId}/
    return html.replace(
        /\[IMAGE:(\d+)_(\d+)\]/g,
        function(match, num, seq) {
            // 先尝试 question_image 表的路径（通过 detail 接口返回）
            // 后备：直接拼接路径
            return '<img src="/static/questions/' + questionId + 
                   '/img_docx_' + num + '_' + seq + '_placeholder.png" ' +
                   'onerror="this.style.display=\'none\'" ' +
                   'style="max-width:100%;height:auto;' +
                   'border:1px solid #e8eaf0;border-radius:8px;' +
                   'margin:4px 0;" alt="题目图片" />';
        }
    );
}
```

#### 3.2 后端 detail 接口返回图片路径映射

**修改文件**：`backend/app/api/v1/wrong_questions.py`

**修改内容**：detail 接口返回 `image_map` 字段，包含 `[IMAGE:x_y]` → 真实图片 URL 的映射

```python
# 查询题目的所有图片
images = db.query(QuestionImage).filter(
    QuestionImage.question_id == q.question_id
).all()
image_map = {}
for img in images:
    # 从 image_path 中提取 num_seq
    # image_path 格式：/static/questions/{question_id}/img_docx_{num}_{seq}_{md5}.png
    import re
    m = re.search(r'img_docx_(\d+)_(\d+)_', img.image_path or '')
    if m:
        key = f"{m.group(1)}_{m.group(2)}"
        image_map[key] = img.image_path

return {
    ...
    'image_map': image_map,  # {"97_0": "/static/questions/123/img_docx_97_0_abc12345.png"}
}
```

### 方案4：修复交卷答案比对（后端+前端）

#### 4.1 后端判分逻辑优化

**修改文件**：`backend/app/api/v1/wrong_questions.py`

**修改内容**：
- review/submit 接口不依赖 `is_objective` 字段
- 改为根据统一后的题型名称判断
- 优化多选题答案比对逻辑

```python
# 判分逻辑优化
correct_answer = (q.answer or '').strip()
is_correct = False

# 根据统一后的题型判断是否为客观题
is_objective_type = unified_type in ['单选题', '多选题']

if is_objective_type:
    if unified_type == '多选题':
        # 多选题：支持 "A,B,C" 和 "ABC" 两种格式
        import re
        correct_letters = sorted(re.findall(r'[A-Z]', correct_answer.upper()))
        user_letters = sorted(re.findall(r'[A-Z]', user_answer.upper()))
        is_correct = correct_letters == user_letters
    else:
        # 单选题：直接比较
        is_correct = correct_answer.upper() == user_answer.upper()
```

## 五、风险评估

1. **数据库迁移风险**：UPDATE is_objective 为可回滚操作
2. **前端兼容性**：ElMessage 是 Element Plus 标准 API，兼容性好
3. **图片方案可持续性**：基于 question_id + MD5 命名，避免冲突和重复
4. **不影响其他模块**：所有修改集中在错题集相关文件
