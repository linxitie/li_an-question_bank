## 三、操作步骤（每对文档）

1. 登录**教师端** → 题目导入（/question-import）
2. 选择**分离导入**模式（题目文档 + 答案文档分别上传）
3. 上传上表左列的**题目文档** + 右列的**答案文档**
4. 点击解析 → 预览确认（系统已自动匹配答案与解析）
5. 确认入库 —— 完成消息预期：
   - `复用 N 题` + `回填缺失字段 N 题`（存量题被补全）
   - 部分试卷会出现 `识别复合题组 N 组（M 题挂组）`（情境材料题自动成组）
6. 逐对重复步骤 1-5（建议按表中顺序，便于核对）
