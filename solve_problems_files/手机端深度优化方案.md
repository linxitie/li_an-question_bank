# 手机端深度优化方案（对标 PC 端 + 去硬编码 + 修复跳转）

> **版本**: v1.0
> **日期**: 2026-09-15
> **状态**: 待用户确认后实施
> **核心诉求**: 手机端风格/字体/图标/功能真正对标电脑端；彻底移除前端硬编码、实施三端数据同步；修复手机端潜在 bug，保证功能正常使用。

---

## 一、问题总览

| # | 问题 | 严重度 | 根因定性 |
|---|------|--------|---------|
| 1 | 底部 Tab 栏跳转 PC 端路由（点击无反应/跳错页） | 🔴 高 | 5 个手机端页面 `switchTab` 的 `tabRoutes` 写死 PC 路由 |
| 2 | 大量功能入口跳转 PC 端路由（404） | 🔴 高 | 功能跳转未适配移动端路由 |
| 3 | 手机端仍有大量前端硬编码（模拟数据） | 🟡 中 | 部分数据已接入 API，但 home/practice/question_bank 仍有硬编码 |
| 4 | 风格/字体/图标未完全对标 PC 端 | 🟡 中 | 颜色/图标/组件细节不一致 |

## 二、根因分析（含代码证据）

### 2.1 底部 Tab 栏跳转 PC 路由（🔴 最严重）

**证据**：5 个手机端页面的 `switchTab` 方法（`mobile_home.vue` L300、`mobile_question_bank.vue` L383、`mobile_practice.vue` L280、`mobile_forum.vue` L325、`mobile_profile.vue` L263）均使用：

```js
const tabRoutes = {
  home: '/',                    // ❌ 应 /mobile/home
  question: '/question-bank',   // ❌ 应 /mobile/question-bank
  practice: '/practice',        // ❌ 应 /mobile/practice
  forum: '/forum',              // ❌ 应 /mobile/forum
  profile: '/profile'           // ❌ 应 /mobile/profile
};
```

**后果**：手机端用户点击底部 Tab，跳转到 PC 路由 → 路由守卫检测到移动设备 → 重定向或 404，导致**底部导航完全失效**。

### 2.2 功能入口跳转 PC 路由（404）

| 页面 | 跳转目标 | 问题 |
|------|---------|------|
| mobile_question_bank | `/smart-exam`、`/practice/${id}` | PC 路由 |
| mobile_practice | `/practice/quick`、`/practice/weak`、`/practice/smart`、`/mock-exam`、`/practice/history`、`/practice/${id}` | PC 路由 |
| mobile_forum | `/forum/create`、`/forum/${id}` | PC 路由 |
| mobile_profile | `/profile`、`/page/notes`、`/feedback`、`/help`、`/page/about` | PC 路由 |
| mobile_home | `/notifications` | 无此路由 |

### 2.3 剩余前端硬编码（模拟数据）

**mobile_home.vue**（L192-223）：
| 字段 | 硬编码值 | 应接入 API |
|------|---------|-----------|
| `streakDays` | `15` | `/api/stats/` 的 `streak` |
| `dailyGoal` | `40` | `/api/goals/stats/summary` |
| `dailyCompleted` | `30` | `/api/goals/stats/summary` |
| `studyHours` | `1.8` | `/api/stats/` 的 `totalStudyHours` |
| `weekData` | 硬编码 7 天数组 | `/api/stats/practice-trend` |

**mobile_practice.vue**（L203-230）：
| 字段 | 硬编码值 | 应接入 API |
|------|---------|-----------|
| `dailyGoal` | `40` | `/api/goals/stats/summary` |
| `recentList` | 硬编码 3 条 | `/api/practice/recent-records` |

**mobile_question_bank.vue**（L203-286）：
| 字段 | 硬编码值 | 应接入 API |
|------|---------|-----------|
| `categories` | 静态 6 分类 | `/api/quick-practice/subjects`（动态） |
| `questions` | 硬编码 6 题集 | `/api/papers/list`（已接入，但保留硬编码兜底） |

> 注：`mobile_profile.vue` 的错题/收藏/笔记计数已由上一轮"三端数据接入"接入（`/api/wrong-questions`、`/api/collection`、`/api/notes`），无需重复处理。

### 2.4 风格对标差距

- **底部 Tab 栏图标**：手机端用 emoji/XIcon 混杂，PC 端统一 XIcon 矢量图标
- **主色**：手机端深蓝 `#1A365D`，PC 端品牌红 `#C91F37` 为强调色（按钮/高亮），需统一强调色使用
- **字体**：三端已基本统一 `PingFang SC/Microsoft YaHei/Noto Sans SC`，需核查个别页面

## 三、解决方案（细节下钻）

### 3.1 修复底部 Tab 栏跳转（问题 1，P0）

**改动**：5 个手机端页面的 `switchTab` 的 `tabRoutes` 统一改为移动端路由：

```js
const tabRoutes = {
  home: '/mobile/home',
  question: '/mobile/question-bank',
  practice: '/mobile/practice',
  forum: '/mobile/forum',
  profile: '/mobile/profile'
};
```

平板端（tablet_*.vue）同理改为 `/tablet/xxx`。

### 3.2 修复功能入口跳转（问题 2，P0）

逐页面修复跳转目标：

| 页面 | 跳转 | 修复为 |
|------|------|--------|
| mobile_question_bank | `smart`→`/smart-exam` | `/smart-exam`（该路由已存在，PC/移动共用，需验证）或提示 |
| mobile_question_bank | `startPractice`→`/practice/${id}` | 提示"答题功能请在电脑端使用"或跳移动答题页 |
| mobile_practice | `goToQuickPractice`等 6 处 | 跳移动端练习页或提示"开发中" |
| mobile_forum | `createPost`→`/forum/create` | 提示"发帖功能开发中"或实现移动发帖 |
| mobile_forum | `viewPost`→`/forum/${id}` | 跳移动端帖子详情（复用 PC 或新建） |
| mobile_profile | `goToSettings/goToHistory`→`/profile` | `/mobile/profile` 或对应页面 |
| mobile_profile | `goToNotes`→`/page/notes` | 提示或跳对应页面 |
| mobile_home | `goToNotifications`→`/notifications` | 提示"通知功能开发中"或实现 |

**原则**：已实现的移动端页面跳移动端路由；未实现的提示"开发中"（不 404）。

### 3.3 移除剩余硬编码（问题 3，P0）

**mobile_home.vue**：`onMounted` 的 `loadData()` 内补充：
- `streakDays` ← `/api/stats/` 的 `streak`
- `studyHours` ← `/api/stats/` 的 `totalStudyHours`
- `weekData` ← `/api/stats/practice-trend?days=7` 的 `trend`（映射为周图表数据）
- `dailyGoal/dailyCompleted` ← `/api/goals/stats/summary` 的 `total_goals/completed_goals`

**mobile_practice.vue**：`onMounted` 补充：
- `dailyGoal` ← `/api/goals/stats/summary`
- `recentList` ← `/api/practice/recent-records`（映射 `{name, accuracy, time_spent_seconds, started_at}`）

**mobile_question_bank.vue**：
- `questions` 移除硬编码兜底，改为空数组 + API 填充（空状态显示"暂无试卷"）

### 3.4 风格统一（问题 4，P1）

- **图标**：底部 Tab 栏统一用 `@vtj/icons` 的 XIcon（HomeFilled/Collection/EditPen/ChatRound/User），替换 emoji
- **强调色**：按钮/高亮统一品牌红 `#C91F37`，标题/文字深蓝 `#1A365D`
- **组件风格**：卡片圆角 12px、阴影、间距对齐 PC 端

## 五、验证方案

1. **底部 Tab**：手机端点击 5 个 Tab，均正确跳转对应移动端页面，无 404
2. **功能入口**：各功能跳转不再 404（已实现跳对应页，未实现提示"开发中"）
3. **硬编码**：home/practice/question_bank 数据来自后端 API，前端无写死模拟数据
4. **风格**：手机端图标/颜色/组件与 PC 端一致

---

## 六、风险与注意事项

1. **VTJ 规则**：`.vtj/vue/mobile_*.vue` 是 VTJ 生成页面（非 raw），修改 `<script>` 需同步 `.vtj/files/*.json` 的 methods 声明与 `__VERSION__`，避免设计器保存时覆盖
2. **不影响其他模块**：所有改动精准定位到 mobile_*/tablet_* 页面，不触碰管理员端/PC 端
3. **移动端答题/发帖等未实现功能**：跳转统一改为"开发中"提示，不跳 404
