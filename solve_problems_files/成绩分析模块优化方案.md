## 三、后端API设计

### 3.1 API接口清单

```
前缀: /api/exam-records

GET  /self                      - 获取自测成绩记录
GET  /mock                      - 获取模考成绩记录
GET  /stats                     - 获取成绩统计
GET  /trend                     - 获取成绩趋势（图表用）
GET  /{record_id}/wrong-questions - 获取错题详情
GET  /{record_id}/details       - 获取考试完整详情
```

## 六、代码设计考量

### 6.1 为什么新建 exam_records.py？

- **分离关注点**：`exams.py` 专注考试执行（开始/提交），`exam_records.py` 专注成绩查询
- **可维护性**：成绩相关逻辑集中管理，便于后期扩展
- **API清晰**：成绩相关接口统一前缀 `/api/exam-records`

### 6.2 为什么区分自测和模考？

- **数据隔离**：两类考试数据来源不同
- **统计维度不同**：自测关注进步趋势，模考关注排名
- **exam_type字段**：通过 `SELF_TEST` / `MOCK_EXAM` 区分

### 6.3 安全考量

- 所有接口需登录认证（`get_current_user`）
- 成绩记录归属验证（只能查看自己的记录）
- SQL注入防护（使用ORM查询）

### 6.4 运维便利性

- 统一的日志记录（logger.info）
- 异常友好处理（try-catch + 警告日志）
- API文档完整（summary装饰器）
