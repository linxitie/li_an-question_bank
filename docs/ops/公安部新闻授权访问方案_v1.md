# 公安部新闻授权访问方案 v1

> 状态：待执行（需要用户本人完成一次授权）
> 适用：`https://www.mps.gov.cn/n2255079/index.html`

## 1. 现状

- 普通 HTTP 请求返回 **521**；
- 页面使用 JS challenge 设置 `__jsluid_s` / `__jsl_clearance_s`；
- Playwright 能执行 challenge 并拿到 Cookie，但无头浏览器当前仍拿不到正文链接；
- **不得绕过验证码、登录、robots 或付费墙**。

## 2. 允许的三种授权方式

### A. 用户浏览器登录后的 storage_state（推荐）

1. 用户本人在本机 Edge/Chrome 正常访问公安部网站（含任何单位授权登录）；
2. 用 Playwright 以**有头模式**打开一次，保存登录态到仓库外路径；
3. 设置：

```powershell
$env:MPS_PLAYWRIGHT_STATE = "C:\Users\<you>\mps_state.json"
```

4. 运行：

```powershell
cd backend
python -m scripts.news.collect_news --source mps --limit 1
```

采集器会复用该 storage_state，不再自动登录。

### B. 官方提供的接口/授权 Header

如果公安部提供 RSS/API 或单位授权 Header，由用户配置：

```powershell
$env:MPS_HEADERS_JSON = '{"X-Auth-Token":"***"}'
$env:MPS_COOKIE = "***"
```

`MPS_HEADERS_JSON` / `MPS_COOKIE` 只从环境变量读取，不落库、不写日志、不提交仓库。

### C. 人工导出/白名单导入

对仍无法稳定访问的页面，由授权人员导出 HTML/JSON 或提供文章 URL 清单，使用同一 `NewsArticle` 入库；不把抓取失败伪装成成功。

## 3. 代码支持

- `backend/app/services/news_collector.py`：
  - `MPS_HEADERS_JSON` / `MPS_COOKIE` → HTTP headers；
  - `MPS_PLAYWRIGHT_STATE` / `NEWS_PLAYWRIGHT_STATE` → Playwright storage_state；
  - Playwright 使用本机 Edge channel，不下载浏览器。
- `news_source.adapter` 公安部为 `playwright`。
- 所有来源仍经过 host 过滤、去重、LocalStorage。

## 4. 安全要求

- `storage_state`、Cookie、Header 放在仓库外；
- 不把真实值写入 `.env.example`、Markdown、提交信息；
- 授权失效时采集器只报错，不重试暴力破解；
- 由用户本人完成登录与授权，AI 不经手账号密码。

## 5. 验收

1. `--source mps --limit 1` 返回至少 1 条新闻（dry-run）；
2. 不出现 521/403；
3. 日志不包含 Cookie/Token；
4. 失败时报告明确状态，不伪造入库。
