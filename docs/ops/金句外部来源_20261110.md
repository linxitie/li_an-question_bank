# 外部金句来源接入

> 日期：2026-11-10  
> 来源：用户明确批准并确认可引用

## 一、来源

- 人民网·理论频道
- 光明网·时评频道
- 求是网
- 中央纪委国家监委网站
- 共产党员网

## 二、采集策略

- 每个来源每日最多扫描 3 篇文章；
- 每篇文章最多提取 2 条候选金句；
- 只保留完整句、16–120 字、带关键词的句子；
- 新金句 `status=0`、`ai_quality=pending`，不直接展示；
- 自动写入来源、分类标签、normalized_hash；
- 通过 AI 质量审核后才 `status=1`。

## 三、调度

```text
06:00  collect_external_quotes
→ 采集外部来源
→ 同步写入来源/标签
→ 当批 AI 审核最多 30 条
```

## 五、robots / 备注

- 光明网 robots 仅限制 2013–2016 年路径；
- 共产党员网 robots 仅限制 download_busy；
- 人民网、求是网 robots 返回 404；
- 中央纪委 robots 返回 420，但文章公开可访问；
- 采集器使用固定 UA、串行请求和 0.3s 间隔，不绕过登录/反爬。
