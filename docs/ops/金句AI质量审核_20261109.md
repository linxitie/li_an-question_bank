# 金句 AI 质量审核与隔离

> 日期：2026-11-09

## 目标

对金句增加独立于新闻的 AI 质量审核；低质量金句不再出现在每日金句和列表接口。

## 实现

- `essay_quote` 新增：
  - `ai_quality`：pending / approved / rejected / error
  - `ai_quality_reason`
  - `ai_reviewed_at`
- 新增 `app/services/quote_ai_service.py`
  - 规则先拦截：占位内容、无有效文字、无作者且无出处
  - 其余调用现有 LLM 判断是否适合作为申论素材
  - rejected：`status=0`、`review_status=rejected`，立即从 `status=1` 查询中隔离
- 新增 CLI：
  - `python -m scripts.quotes.ai_review --limit 20`
  - `python -m scripts.quotes.ai_review --limit 20 --apply`
- 每日金句同步任务增加 30 条质量审核额度。

## 数据约定

- 古典名句只有书名/篇名出处、没有个人作者，不因缺少个人作者直接拒绝。
- 伪作者（引号、破折号、佚名等）已在同步服务中归一为空。
- `rejected` 不物理删除，保留审核原因，便于回溯。

## 验证

- 规则/AI 审核单测通过。
- 首批 20 条实际审核：18 条通过，2 条隔离。
