# 新闻 AI 摘要 404 排查与修复

> 日期：2026-11-04  
> 现象：`scripts.news.ai_process --apply` 处理 14 条新闻，全部 fallback，日志为 `news_summary 返回非 200: status=404 content_length=0`。

## 根因

`.env` 配置：

```text
LLM_API_URL=https://api.deepseek.com/chat/completions
```

旧客户端固定拼接：

```python
url = settings.LLM_API_URL.rstrip("/") + "/chat/completions"
```

实际请求变成：

```text
https://api.deepseek.com/chat/completions/chat/completions
```

DeepSeek 返回 404。

## 修复

1. `llm_client` 新增 `_chat_completions_url()`，同时兼容：
   - base URL：`https://api.deepseek.com`
   - 完整 endpoint：`https://api.deepseek.com/chat/completions`
   - `/v1` base：`https://api.deepseek.com/v1`
2. `news_ai_service.process_news()` 新增 `include_fallback`；
3. `ai_process` 新增 `--retry-fallback`，可重跑已写入 fallback 摘要的新闻；
4. 重跑结果：

```text
total: 14
processed: 14
fallback: 0
errors: []
```

## 验证

- LLM 最小请求返回 `OK`；
- 14 条 fallback 全部转为 `ai_status=ok`；
- 未输出或记录 API Key。
