## 三、FTS5

新增独立 FTS5 表 `quote_fts`，包含：

```text
quote_id / content / author / source
```

触发器自动同步：

```text
INSERT / UPDATE / DELETE essay_quote
```

公开检索：

```text
GET /api/quotes/search?q=法治
```

## 四、管理端审核页

路由：

```text
/admin/quotes
```

页面能力：

```text
待审核 / 已通过 / 已拒绝
关键词搜索
来源分布
标签分布
通过 / 拒绝 + 审核备注
```

接口：

```text
GET  /api/admin/quotes/stats
GET  /api/admin/quotes/review
POST /api/admin/quotes/{quote_id}/review
GET  /api/admin/quotes/sources
GET  /api/admin/quotes/tags
```

审核写入 `quote_review`，保留管理员 ID、原因和前后状态。
