# 新闻图片抓取过滤与历史清理

> 日期：2026-11-04  
> 问题：新闻页全页 `<img>` 被采集，二维码、Logo、栏目图标进入新闻图片表和 Obsidian 卡片。

## 1. 采集侧修复

修改 `backend/app/services/news_collector.py`：

1. **只在正文容器内取图**
   - 复用 `_CONTENT_SELECTORS` 选出的最佳正文节点；
   - 不再对整页 `soup.find_all("img")` 取图；
   - 未识别到正文容器时不抓取任何图片。

2. **URL / alt / class 关键词过滤**
   - 命中以下关键词直接丢弃：
     `qrcode`、`qr-code`、`二维码`、`logo`、`icon`、`avatar`、`banner`、`share`、`广告`；
   - 独立 `ad` 路径段同样丢弃。

3. **真实尺寸过滤**
   - 宽或高小于 `100px` → 丢弃；
   - 长宽比接近 1:1 且面积不超过 `90000px²` → 丢弃；
   - 用 Pillow 读取真实尺寸，不依赖网页声明。

4. **二维码识别**
   - 若本机有 OpenCV，则用 `QRCodeDetector` 再识别一次；
   - 识别到二维码 → 丢弃。

5. **Obsidian/AI 卡片侧**
   - 过滤后没有有效图片时，不再输出 `## 图片` 章节。

覆盖：

- 正文内保留有效图片；

## 3. 历史数据清理脚本

新增：

```text
backend/scripts/news/cleanup_noise_images.py
```

默认：

- 只清理 `pending/high_risk` 新闻；
- **dry-run**，不删除；
- 删除数据库记录；
- 把图片移到：
  ```text
  backend/data/archive/news_noise_images/
  ```
- 清理 Obsidian 卡片中对应图片行，保留审核勾选和备注。

dry-run 当前结果：

```text
待审图片记录：168
建议移除：128
保留：40
原因：too_small=107，square_icon=15，qrcode_detected=6
涉及卡片：38
```

执行清理：

```powershell
cd D:\砺安题库\li_an-question_bank\backend
python -m scripts.news.cleanup_noise_images --apply
```

如确认已发布新闻也要清理：

```powershell
python -m scripts.news.cleanup_noise_images --apply --include-published
```

## 4. 注意事项

- 清理会把原图归档，不直接物理删除，便于回滚；
- 已有 Obsidian 人工勾选/备注不会被重写；
- 清理后建议刷新 Obsidian；
- 新采集数据从本次修复后开始生效。
