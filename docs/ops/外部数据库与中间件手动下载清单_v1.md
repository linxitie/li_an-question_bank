# 外部数据库与中间件手动下载清单 v1

> 状态：待用户确认与手动准备（不是自动安装脚本）  
> 适用：砺安题库终态架构 F4 文档投影、F5 图投影、F6 向量投影，以及可选的 F2 Redis、F3 MinIO  
> 实测基线：2026-10-27，仓库 D:/砺安题库/砺安题库，main 98689c2  

## 0. 结论先行

**当前系统不需要你下载任何外部数据库。** 生产与开发仍然是：

| 项 | 当前事实 |
|---|---|
| 事实源 | SQLite（WAL），由 Python 标准库自带，不需要安装数据库服务器 |
| 对象存储 | 默认本地目录 ./data/foundation/objects，不需要 MinIO |
| 缓存/中继 | 单进程下不需要 Redis；只有多 worker 或 WS_RELAY=redis 才需要 |
| 文档/图/向量 | F4/F5/F6 尚未实施，代码中没有对应适配器，也不读取这些服务 |

因此本清单是 **F4/F5/F6 的前置采购与安装清单**，不是现在必须执行的步骤。
如果你现在提前准备，按本文第 3 节的顺序做；如果不准备，系统仍可完整运行 F0–F3 与 F2b-1。

## 1. 为什么必须由你手动下载

这不是流程繁琐，而是三条硬边界：

1. **许可与账号**：MongoDB、Neo4j、MinIO 等需要接受官网许可协议或注册账号，AI 不能代替你同意。
2. **真实凭据**：数据库密码、root 账号、证书必须由你本人设置；AI 不得经手真实密钥值（AGENTS §5）。
3. **本机环境**：安装路径、端口、磁盘、Windows 服务、Docker/WSL2 是否可用，只有你能决定并承担变更。

AI 负责的是：给出下载清单、版本兼容要求、环境变量、连接自检、适配器代码与回滚方案。

## 2. 组件矩阵：什么时候才需要

| 组件 | 角色 | 现在必需？ | 触发条件 | 对应阶段 |
|---|---|---|---|---|
| SQLite | 关系型事实源（SoT） | **是，但已内置** | 始终 | 已运行 |
| Redis | WS 中继 / 事件总线缓存 | 否 | WEB_CONCURRENCY>1 或显式 WS_RELAY=redis | F2 已完成，可选 |
| MinIO | S3 兼容对象存储 | 否 | OBJECT_STORE_BACKEND=minio | F3 已完成，可选 |
| MongoDB Community | 文档投影 | 否 | F4 启用文档投影时 | F4 |
| Neo4j Community | 图投影 | 否 | F5 启用图投影时 | F5 |
| Milvus | 向量投影 / 语义检索 | 否 | F6 启用向量投影时 | F6 |
| PostgreSQL | 替代关系型事实源 | 否 | 明确决定从 SQLite 迁移时 | 不在 F4–F6 默认路线 |
| MySQL | 现有 DB_TYPE 预留出口 | 否 | 明确决定迁移到 MySQL 时 | 不在 F4–F6 默认路线 |

**重要**：PostgreSQL 与 MySQL 不是 F4/F5/F6 的依赖。终态架构坚持 SQLite 为事实源，
外部关系库只作为未来迁移选项；迁移需要改数据访问层、迁移脚本与门禁，不是改一个环境变量就能完成。

## 3. 建议安装顺序与优先级

| 优先级 | 组件 | 原因 | 建议方式 |
|---|---|---|---|
| P0 | MongoDB Community | F4 文档投影的第一依赖 | Windows 原生 MSI，或 Docker |
| P1 | Neo4j Community | F5 图投影 | Windows 原生 zip，或 Docker |
| P2 | Milvus standalone | F6 向量投影 | **必须 Docker Desktop + WSL2**，Windows 原生不推荐 |
| P3 | MinIO / Redis | 已有本地默认实现；只有要多机/多 worker 才装 | Windows 二进制 / Docker |
| 暂不 | PostgreSQL / MySQL | 不改事实源就不装 | 迁移立项后再做 |

如果只准备一台开发机，建议先装 MongoDB；Neo4j 与 Milvus 等到 F5/F6 真正开始再装，避免长期常驻占用内存。

| PostgreSQL | 16.x 或 17.x | https://www.postgresql.org/download/windows/ | 官方 installer | 5432 | PostgreSQL License（宽松） |

### 4.1 许可提醒（不是法律意见）

- MongoDB 的 SSPLv1 不是 OSI 认可的开源许可。内部自用通常问题不大；**对外提供 SaaS、分发或嵌入商业产品前**须让法务确认。
- MinIO 的 AGPLv3 对“通过网络提供服务”有源码提供义务；商业分发需评估商业许可。
- Neo4j Community 是 GPLv3；企业版是商业许可，集群/热备等能力不在 Community。
- Redis 7.4+ 改为 RSALv2/SSPLv1；若不能接受，选 Redis 7.2.x 或 Valkey。
- MySQL 客户端库与服务器端许可不同；闭源分发前须复核 FOSS Exception 或购买商业许可。

## 5. 下载与安装后的最小自检

每一项装完后，先证明“服务真的在监听”，再谈接适配器。

### 5.1 MongoDB

    mongosh "mongodb://127.0.0.1:27017" --eval "db.runCommand({ ping: 1 })"

期望输出包含 ok: 1。然后创建专用库与最小权限账号，不要让应用用 root。

### 5.2 Neo4j

    cypher-shell -a bolt://127.0.0.1:7687 -u neo4j -p <你的密码> "RETURN 1 AS ok"

首次登录会要求修改默认密码。期望返回 ok=1。

### 5.3 Milvus

    curl http://127.0.0.1:9091/healthz

期望 HTTP 200。Milvus standalone 的 Docker Compose 会同时拉起 etcd 与 MinIO；
生产集群化时 etcd、对象存储、消息队列要单独规划，不能照搬 standalone。

### 5.4 MinIO

    mc alias set local http://127.0.0.1:9000 <access-key> <secret-key>
    mc ls local

如果不用 mc，也可以直接访问 http://127.0.0.1:9001 控制台。

### 5.5 Redis

    redis-cli -h 127.0.0.1 -p 6379 ping

期望 PONG。若设置密码，必须用 redis-cli -a 或环境变量，不要把密码写进命令历史/文档。

### 5.6 PostgreSQL / MySQL

    psql --version
    mysql --version

版本命令只证明客户端存在，不等于服务可用；还要用实际账号连接目标库并执行 SELECT 1。

## 7. 凭据、端口与配置规则

### 7.1 只写在本地 .env

- 真实密码只写 backend/.env 或 deploy/.env.<环境>，这些文件必须在 .gitignore 中。
- 文档、聊天、提交信息、测试快照里只写占位符，例如 <CHANGE_ME>。
- 每个服务使用独立账号，禁止应用共用 root/neo4j 默认账号。
- 数据库只监听 127.0.0.1 或内网地址，不对公网开放 27017/7687/19530/9000/6379。
- 交付/交接时只给“变量名 + 获取方式”，不给真实值；泄露后轮换是唯一彻底处置。

### 7.2 现有配置键（已实现）

| 变量 | 现状 |
|---|---|
| DB_TYPE | 默认 sqlite；目前只实现 sqlite 与 mysql+pymysql 分支 |
| DB_HOST / DB_PORT / DB_USER / DB_PASSWORD / DB_NAME / DB_CHARSET | MySQL 连接参数 |
| REDIS_HOST / REDIS_PORT / REDIS_PASSWORD / REDIS_DB | Redis 连接参数 |
| WS_RELAY | 留空为本地扇出；redis 为跨 worker 中继 |
| OBJECT_STORE_BACKEND | local 默认；minio 可选 |
| OBJECT_STORE_ROOT | 本地对象根，默认 ./data/foundation/objects |
| MEDIA_STORE_ENABLED | 媒体存储总开关，默认 true |

### 7.3 F4–F6 计划新增的配置键（尚未实现，以届时代码为准）

| 变量（建议命名） | 用途 |
|---|---|
| DOC_STORE_BACKEND / DOC_STORE_URI / DOC_STORE_DB | MongoDB 文档投影 |
| GRAPH_STORE_BACKEND / GRAPH_STORE_URI / GRAPH_STORE_USER / GRAPH_STORE_PASSWORD | Neo4j 图投影 |
| VECTOR_STORE_BACKEND / VECTOR_STORE_URI / VECTOR_STORE_COLLECTION | Milvus 向量投影 |
| PROJECTION_* | 投影开关、批大小、重试与对账周期 |

**不要现在就把这些键写进生产 .env**；未实现的键不会生效，反而会让人误以为已经接入。

## 9. 断网/内网环境的离线包

如果目标机器不能联网，需要提前在有网机器上准备：

| 组件 | 离线准备 |
|---|---|
| MongoDB | 下载 MSI/ZIP + 对应版本依赖（Windows 通常自带 VC++ 运行库） |
| Neo4j | 下载 zip 包，解压即用；Java 17/21 运行时需一并准备 |
| Milvus | docker pull 后 docker save -o milvus.tar，再到目标机 docker load；etcd/MinIO 镜像同理 |
| MinIO | 单个二进制 + 配置文件 |
| Redis/Valkey | WSL2 发行版离线包或 Docker 镜像 tar |

离线包同样要记录版本与 digest/SHA256；不要用“某台机器上能跑”的口头版本。

## 10. 回滚与卸载

- 外部库都是投影/加速器，不是事实源：停掉它们不应导致业务数据丢失；应用应显式降级并告警，而不是静默回源。
- 卸载前先确认没有投影游标/对账任务依赖它；F4–F6 的开关与降级路径在对应计划中定义。
- SQLite 主库的备份/恢复仍遵守 R10：用 sqlite3.backup()，回滚时同时处理 -wal/-shm。
- 不要为了“清理空间”删除 backend/data/*.bak、static/、题库/（R6–R8）。
