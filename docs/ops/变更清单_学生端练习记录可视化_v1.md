## 1. `chore(env)` 运行环境与门禁自愈

**为什么**：首次从零启动时后端接连失败（`No module named 'uvicorn'`、`ModuleNotFoundError: pydantic_settings`、
`email-validator is not installed`、登录 500），以及门禁出现「只有 L1 FAIL、0.2 秒」的假故障。

| 文件 | 改动 |
|---|---|
| `backend/requirements.txt` | 补 `pydantic-settings>=2.0.0`、`email-validator>=2.0.0`；`bcrypt==4.0.1` 钉版本 |
| `backend/scripts/gates/gate_all.py` | 新增 `_has_fastapi()` / `_ensure_venv_interpreter()`：当前解释器缺 fastapi 且 `backend/.venv` 存在时自动换解释器重跑（`GATE_REEXEC=1` 防递归） |
| `AGENTS.md` §10 | 记录「门禁必须用 venv 解释器」及 `0.2s 即失败＝解释器不对` 判据 |

**排查依据**：`passlib.handlers.bcrypt` 读 `_bcrypt.__about__.__version__` 触发
`AttributeError: module 'bcrypt' has no attribute '__about__'`，随后
`password cannot be longer than 72 bytes` → 全局异常处理器返回 500（`backend/logs/app.log` 有完整栈）。

## 3. `feat(practice)` 答题草稿持久化 + `type-summary` 去 N+1

**为什么**：Q16 用户选择「服务端草稿表」；`/type-summary` 原实现把整科目题目读入内存再逐子科目 count，
且三列 `Enum` 用 `case()` 合并会被判成公专枚举，抛 `'判断推理' is not among the defined enum values` → 500。

| 文件 | 改动 |
|---|---|
| `backend/app/models/models.py` | 新增 `PracticeDraft`（`user_id`+`scope`+`scope_key` 唯一键、`expires_at` 索引） |
| `backend/app/api/v1/exam/practice.py` | 新增 `POST/GET /api/practice/draft`、`GET /api/practice/drafts`、`DELETE /api/practice/draft`；`/type-summary` 改 3 条聚合 SQL 并对三列 `cast(..., String)`；`questions` 兼容「ID 数组」与「题目对象数组」（原 `int(dict)` 使前端草稿恒 400） |
