## 三、优先补做建议

### P0

1. `daily_quote` 表接入：每日 00:05 预生成，API 优先读表，跨天幂等。
2. 平板端每日金句/新闻模块对齐手机端。
3. PC 新闻详情补划线、想法、笔记入口。

### P1

4. 新闻正文生成 `[[IMG:n]]`，完成图片内联定位。
5. 金句 AI 审核结果写入 `quote_review`，补齐审核留痕。
6. 继续消化 1576 条 pending 金句。

### P2

7. 金句来源/tag/FTS/去重/关系表。
8. 管理端金句审核页。
9. 外部网页金句来源。

## 四、结论

- **每日新闻 UI 主链路基本完成**，主要缺口是平板、PC 划线和正文图片内联。
- **每日金句 UI 主链路基本完成**，主要缺口是 `daily_quote` 表未接入、平板、审核留痕和 1576 条待审。
- 金句 v2 设计方案中的来源/标签/FTS/关系/证据属于更大范围，不应和当前 UI 收尾混在一起直接全做。
