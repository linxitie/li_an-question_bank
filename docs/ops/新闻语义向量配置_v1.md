# 新闻语义向量配置 v1

> 状态：代码已支持；当前环境未配置真实 embedding，仍是 hash 降级索引

## 1. 为什么现在不能用 hash 当语义索引

`HashEmbedding` 是字符 1/2/3-gram 的确定性哈希，仅用于离线验证：

```text
provider = hash
degraded = true
```

它不能表达“同义/近义”，不能作为生产语义检索。

## 2. 配置真实 embedding

在 `backend/.env` 或环境变量中配置（值由用户本人填写）：

```dotenv
VECTOR_BACKEND=local
VECTOR_DIM=1024
EMBEDDING_ENABLED=true
EMBEDDING_PROVIDER=http
EMBEDDING_BASE_URL=https://<embedding-provider>/v1
EMBEDDING_MODEL=<embedding-model>
EMBEDDING_API_KEY=<仅环境变量，不提交>
EMBEDDING_DIM=1024
```

要求：

- `EMBEDDING_BASE_URL` 支持 OpenAI 兼容 `POST /embeddings`；
- `EMBEDDING_DIM` 必须与模型输出维度一致；
- `VECTOR_DIM` 与 `EMBEDDING_DIM` 一致；
- Key 不写入 Markdown/源码/提交。

## 3. 重建新闻向量

```powershell
cd backend
python -m scripts.news.project_news --vectors --provider http --reset
```

验收：

```text
provider = http
degraded = false
collection = news_articles
written = 已发布新闻数
```

## 5. 2026-11-02 根因修复

`app/core/config.py` 的 Pydantic `Settings` 确实读取了 `backend/.env`，但
`app/foundation/config.py` 是独立的纯 `os.environ` 配置层；Pydantic **不会**把
`.env` 导出到进程环境，所以 `build_embedding_port()` 之前看到的是 `off/空值`。

修复：`app/foundation/config.py` 增加 `load_env_files()`，按顺序加载：

```text
backend/.env
仓库根 .env
```

`override=False`，真实进程环境变量优先。

当前 `backend/.env` 已能正确得到：

```text
EMBEDDING_PROVIDER=http
EMBEDDING_BASE_URL=https://api.deepseek.com/v1
EMBEDDING_MODEL=deepseek-embedding
```

但实测该 endpoint 返回 **HTTP 404**，说明 DeepSeek Chat 地址/模型并不提供
OpenAI 兼容的 `/embeddings`。需要换成真实提供 embedding 的 base_url + model
后，再执行第 3 节重建。

## 6. 注意

- 新闻只投影 `status=1 AND review_status=published`；
- 向量库是 PoC 投影，SQLite 仍是唯一事实源；
- 重建失败时保留旧索引，不静默清空。
