# 新闻语义向量配置 v1

> 状态：代码已支持；当前环境未配置真实 embedding，仍是 hash 降级索引

## 1. 为什么现在不能用 hash 当语义索引

`HashEmbedding` 是字符 1/2/3-gram 的确定性哈希，仅用于离线验证：

```text
provider = hash
degraded = true
```

它不能表达“同义/近义”，不能作为生产语义检索。

## 2. 配置真实 embedding

在 `backend/.env` 或环境变量中配置（值由用户本人填写）：

```dotenv
VECTOR_BACKEND=local
VECTOR_DIM=1024
EMBEDDING_ENABLED=true
EMBEDDING_PROVIDER=http
EMBEDDING_BASE_URL=https://<embedding-provider>/v1
EMBEDDING_MODEL=<embedding-model>
EMBEDDING_API_KEY=<仅环境变量，不提交>
EMBEDDING_DIM=1024
```

要求：

- `EMBEDDING_BASE_URL` 支持 OpenAI 兼容 `POST /embeddings`；
- `EMBEDDING_DIM` 必须与模型输出维度一致；
- `VECTOR_DIM` 与 `EMBEDDING_DIM` 一致；
- Key 不写入 Markdown/源码/提交。

## 3. 重建新闻向量

```powershell
cd backend
python -m scripts.news.project_news --vectors --provider http --reset
```

验收：

```text
provider = http
degraded = false
collection = news_articles
written = 已发布新闻数
```

## 4. 当前状态

```text
provider = hash
degraded = true
news_articles = 11
```

在真实 provider 配置前，不应把当前向量用于线上语义搜索。

## 5. 注意

- 新闻只投影 `status=1 AND review_status=published`；
- 向量库是 PoC 投影，SQLite 仍是唯一事实源；
- 重建失败时保留旧索引，不静默清空。
