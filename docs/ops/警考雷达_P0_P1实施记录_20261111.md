2. 公安部官网 521，省级来源尚未给出具体列表 URL。
3. 当前雷达匹配基于历史公告粗解析，学历/专业等字段覆盖有限，需 P2 LLM 解析和人工复核。
4. 历年考情表为空，等待用户提供 Excel。
5. VTJ 招考看板入口需用户在设计器添加。
