## 0. 一句话结论

**代码能合、数据不会跟着走。** `backend/data/question_bank.db` 未被 Git 跟踪，
新环境必须执行本文第 3 节的三条命令，否则会出现「页面在、卡片 0 张、成就解不开」。

## 1. 前置条件（缺一不可）

| 项 | 要求 | 校验命令 |
|---|---|---|
Python | 3.11+（本项目实测 3.14） | `python --version` |
Node | 20+ | `node -v` |
前端包管理器 | **npm**（`package.json` 的 `packageManager` 已锁定，pnpm 会报 *This project is configured to use npm*） | `npm -v` |
后端启动目录 | **必须在 `backend/`** | 在仓库根启动会 `ModuleNotFoundError: No module named 'app'` |
| **改完代码重启后行为没变** | 旧进程仍占用 8010，新进程 [Errno 10048] 绑定失败**静默退出**（日志可见） | 结束所有 python 进程 → **轮询等端口释放** → 启动 → 校验新 PID 与 logs/app.err.log |
| 自动分类不生效（category 为空） | ① 跑的是旧进程（见上一行）② 正文偶发词抢占标题词（v2 已改标题优先+命中数计分） | 先确认进程是新的；仍为空时跑 scripts/init_material_data.py 核对规则是否已播种 |
数据库 | `backend/data/question_bank.db`（SQLite WAL） | `ls backend/data/question_bank.db` |
原始语料 | `题库/`（662MB，门禁/重导依赖） | —— |

## 2. 启动顺序

```powershell
# 1) 后端（必须在 backend 目录）
cd backend
python -m uvicorn app.main:app --host 127.0.0.1 --port 8010

# 2) 前端（仓库根，必须指定后端代理）
$env:DEV_BACKEND_ORIGIN="http://127.0.0.1:8010"
$env:ENV_TYPE="local"
npm run dev          # Vite，端口 9527（strictPort）
```

## 3. 数据初始化（新环境必做，幂等可重复）

```powershell
cd backend
python scripts/init_material_data.py --dry-run   # 先看要做什么，不写库
python scripts/init_material_data.py             # 实际执行
```

四条动作与判重键：

| # | 动作 | 判重键 | 预期首次输出 | 预期二次输出 |
|---|---|---|---|---|
① | 迁移自愈：补 `study_material.source_material_id` + `idx_material_owner`；建 `material_share` / `material_adopt_log` | 列/表是否存在 | 「补列…；建表…」或「无需处理」 | 无需处理 |
② | 卡片种子（行测 12 / 申论 10 / 公专 10） | `(subject, type, title)` | 新增 32 | 新增 0 / 跳过 32 |
③ | 成就（开卷有益/勤读不辍/博览群书） | `(name, trigger_type)` | 新增 3 | 新增 0 / 跳过 3 |
④ | 分类规则（16 条 keyword） | `rule_name` | 新增 16 | 新增 0 / 跳过 16 |

**验收基线（本机实测）**：行测 21 卡 + 1 说明；申论 10 + 1；公专 10 + 1；`material` 成就 3；启用规则 16。

## 5. 数据资产与备份（**禁止** `shutil.copy2`）

| 资产 | 路径 | 说明 |
|---|---|---|
主库 | `backend/data/question_bank.db` | WAL 模式，须用 `sqlite3.backup()` API 备份 |
历史备份 | `backend/data/*.bak*` | **禁止清理**（R8），含全系统唯一 10,171 道行测题副本 |
题图 | `backend/app/static/`（4.3GB） | **禁止删除**（R7） |
语料 | `题库/`（662MB） | **禁止移动**（R6） |

备份示例：

```python
import sqlite3
src = sqlite3.connect("backend/data/question_bank.db")
dst = sqlite3.connect("backend/data/question_bank.db.bak_before_deploy")
src.backup(dst)   # 不要用 shutil.copy2：WAL 只拷主库会丢数据
dst.close(); src.close()
```

回滚：停服 → 用备份覆盖主库 → **同时删除 `-wal` 与 `-shm`** → 重启。

## 6. 常见故障对照

| 现象 | 根因 | 处理 |
|---|---|---|
入口页「资料 0 项」 | `window.__VTJ_AUTH__` 未注入时页面直接调 `apiFetch` 抛错被吞 | 已修（`_apiGet` 兜底）；若复现，看控制台 `[StudyMaterials] count failed:` |
卡片翻转背面空白 | 列表接口不返回 `card_back` | 已修（`_item_brief` 补字段）；确认后端已重启 |
详情页 404 / 被弹回登录 | 路由守卫要求登录 | 先登录；未登录访问会 `next('/login?redirect=...')` |
点卡片不跳转 | 前端未刷新（旧 JS） | `Ctrl+F5` |
手机打不开 | ① 非同一 Wi-Fi ② 防火墙拦 9527 ③ 用了 VMware 虚拟网卡 IP | 放行 9527：`New-NetFirewallRule -DisplayName "Vite 9527" -Direction Inbound -Protocol TCP -LocalPort 9527 -Action Allow` |
`ModuleNotFoundError: app` | 在仓库根启动后端 | `cd backend` 再启动 |
`This project is configured to use npm` | 用了 pnpm | 改用 `npm run dev` |
