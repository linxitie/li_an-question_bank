**配套 script 增补**（在 `<script setup>` 内任意位置）：

```js
      // ① 排课：loadToday() 里补一行，把后端排课存进 state
      //    state.today = await res.json();
      //    state.schedule = state.today.schedule || null;      ← 新增
      async function toggleScheduleItem(item) {
        if (!item || !item.goal_id) return
        try {
          const res = await window.__VTJ_AUTH__.apiFetch(`/api/plan/task/${item.goal_id}/toggle`, { method: 'POST' })
          if (!res.ok) return
          // 后端在 toggle 时已重算排课，这里重新拉今日面板即可（任务与排课同步）
          await loadToday()
          const cur = await window.__VTJ_AUTH__.apiFetch('/api/plan/current')
          if (cur.ok) state.plan = await cur.json()
        } catch (e) { /* 勾选失败不影响其它区块 */ }
      }
      // 排课完成度：按"已完成分钟 / 已安排分钟"算，比原来按死数据算准
      const schedulePercent = computed(() => {
        const s = state.schedule
        if (!s || !s.slots) return 0
        let total = 0, done = 0
        s.slots.forEach(p => p.items.forEach(it => {
          total += it.minutes || 0
          if (it.done) done += it.minutes || 0
        }))
        return total ? Math.round(done / total * 100) : 0
      })
```

**state 增补**：`state` 里加 `schedule: null`；若已有 `slot`（旧静态勾选）与 `toggleSlotTask()`、`getScheduleProgress()`，可一并删除。

## 验收步骤（做完模板后，三端各过一遍）

1. PC：登录学生账号 → `/study-plan`：
   - 排课三段是否显示今天日期、项目与"今日任务"一致；勾选任一项 → 该行变 ✓，且「今日已安排/完成%」变化；
   - 能力画像是否显示六维 + 分科正确率；「我的」页是否只剩一行入口。
2. 平板：`/tablet/study-plan`、`/tablet/profile` 同上（同一页，看是否横向溢出）。
3. 手机：`/mobile/study-plan`、`/mobile/profile`：375px 宽不横向滚动；排课项可点；雷达图高度自适应。
4. 换账号（教师/管理员）→ 学习计划不可进（路由 roles 已限制）。
5. 断网刷新 → 排课显示上次缓存/空态提示，不白屏。
