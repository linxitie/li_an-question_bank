## 4. P2 考点规则引擎（已落地并落库）

### 4.1 组件
- `backend/app/services/taxonomy/exam_points.yaml`：91 条考点规则（关键词 + 正则 patterns + 科目→知识点映射）。
- `backend/app/services/taxonomy/classifier.py`：`classify(题干, sc_id, options_text, subject_id, context_text)`。
  选项参与打分（实测关键）、材料每条命中 +1 封顶、权重 长词 3/三字 2/双字 2/单字 1、
  三档 `AUTO_SCORE=6` / `REVIEW_SCORE=3` / `AUTO_MARGIN=2`。
- `backend/scripts/taxonomy/reclassify_points.py`：`--dry-run` / `--apply [--include-review] --batch-id` / `--revert --batch-id` / `--subject`。

### 4.2 覆盖率演进（每次均实跑 dry-run，总数 3528）
38.5% → 52.4%（解析 options JSON）→ 60.6% → 61.6%（接材料）→ 75.3%（双字词权重 2）→ 79.5%（补 161 词）→ **79.9%**（再补 48 词）。
最终：auto 1883 / review 936 / unmatched 709。

| 科目 | 题量 | 已定位 | 覆盖率 |
| --- | --- | --- | --- |
| 行测 | 613 | 459 | 74.9% |
| 申论 | 39 | 35 | 89.7% |
| 公专 | 2876 | 2326 | 80.9% |
| 合计 | 3528 | 2820 | **79.9%** |

### 4.3 已落库与可回滚证明
- 行测试点：`--subject 1 --apply --include-review --batch-id v8-pilot-xc` → 458 题；`--revert` → 行测非收容回到 5 题；再 apply 恢复 458。
- 全量：`v8-full-sl` 35 题、`v8-full-ga` 2326 题；合计 non-fallback 由 459 → 2820。
- 审计表按 (batch_id, question_id) 去重后：auto 1883 + review 936 = 2819 行。

### 4.4 未命中的真实原因（重要）
709 条未命中里主因不是词表不足，而是 **sub_category 标注与题干自相矛盾**：
图形推理（“从所给四个选项中…填入问号处”）被标成「言语理解与表达」、「微生物发酵」标成「判断推理」、数学运算题标成言语。
放开 sc 约束只读测算可再定位 auto 135 + review 130 ≈ **+265 题（整体 ~87%）**，但需同时改 `question_bank.sub_category_id`，超出 M2 授权范围 → **未实施，等用户拍板**。

## 5. P3 考点复核队列（已落地）

`backend/app/api/v1/exam/point_review.py`（已在 main.py 注册）：
- `GET /api/point-review/queue?batch_id=&page=&page_size=`：返回 tier=review 且 pending 的分配（题干摘要、旧/新考点名、分数）。
- `POST /api/point-review/{audit_id}` body `{accept, note}`：确认保留；驳回则把题还原到 old_point_id 并置 rejected。
- `GET /api/point-review/stats`：按批次统计只读进度。
- 仅教师/管理员可调用（403 拦截学生）。
- 当前积压：**936 条待复核**。
