## 一、模块 4（学习执行）· 六个炫技点

### 4-1 专注力热力图 · 时段 × 星期

**炫点**：一周 7×24 的专注强度方块阵，越深色代表越专注；鼠标悬停浮出「周三 21:00 累计 3 小时 12 分」。
**实现**：纯 Canvas 2D 手绘网格（约 120 行），数据来自番茄钟记录 + 签到。
**依赖**：番茄钟需把每次专注落库（新增 `focus_record` 表，1 个端点）。
**工时**：2 天｜**视觉冲击**：★★★★

### 4-2 记忆强度曲线 · 类 Anki 仪表盘

**炫点**：每道错题一条衰减曲线，答对一次曲线抬升并向右延伸；答错则断崖下坠。SVG Path 动画，300ms 缓动。
**实现**：新增 `MemoryCurve.vue`，读 `next_review_at / review_ease / review_interval_days`。
**依赖**：已有字段，零后端改动。
**工时**：2 天｜**视觉冲击**：★★★★

### 4-3 签到星图 · 连续天数长成星座

**炫点**：签到 7 天连成北斗，30 天连成猎户座，断签则星线黯淡。这是把「3D 日历」再往上推一档。
**实现**：Canvas 2D 星点 + 贝塞尔连线 + 呼吸闪烁；星座骨架硬编码 3 套。
**依赖**：签到接口已有，零新增。
**工时**：3 天｜**视觉冲击**：★★★★★（最适合截图传播）

### 4-4 番茄钟升级 · 沉浸式全屏专注模式

**炫点**：点击后进入全屏黑场，中央一圈呼吸光晕，背景是缓慢流动的噪声粒子；结束时一声钟鸣 + 粒子爆散。
**实现**：CSS 动画 + Canvas 粒子（约 80 行）+ Web Audio API 合成音（不需音频文件）。
**依赖**：无。
**工时**：2 天｜**视觉冲击**：★★★★★

### 4-5 任务完成反馈系统 · 音效 + 微动效

**炫点**：勾掉任务时卡片弹一下、右上角 +1 金币飞入钱包、播放合成音（叮）。
**实现**：`@vueuse/core` 的 `useSound` 替代品自写 + CSS keyframes。
**依赖**：无。
**工时**：1 天｜**视觉冲击**：★★★

### 4-6 学习周报 · 自动生成的战绩卡

**炫点**：每周一自动生成一张卡片：本周专注时长、错题下降率、最强/最弱考点、一句 AI 点评。可长按保存成图。
**实现**：Canvas 绘制卡片 → `toDataURL` 导出 PNG。
**依赖**：需要一个聚合端点（1 个）。
**工时**：3 天｜**视觉冲击**：★★★★

## 二、模块 7（小智 / 画像 / 图谱）· 六个炫技点

### 7-1 知识图谱 3D 力导向

**炫点**：把现在的 2D 图谱升级成可旋转的 3D 星球——科目是恒星，模块是行星，考点是卫星；掌握度低的考点发红光。鼠标拖拽旋转、滚轮缩放、点击下钻。
**实现**：Canvas 2D 手写 3D 投影 + 简易力导向（约 300 行），不引 three.js。
**依赖**：数据已在库（613 节点 / 573 边）。
**工时**：5 天｜**视觉冲击**：★★★★★（**本方案最强的一个**）

### 7-2 画像能力雷达 · 结绳式生长动画

**炫点**：答完问卷后，六维雷达不是直接出现，而是从中心「长」出来，每根轴配一条描边流光；数值低于 40 的轴标红并给出建议。
**实现**：SVG polygon + `stroke-dasharray` 生长动画。
**依赖**：画像字段已有。
**工时**：2 天｜**视觉冲击**：★★★★

### 7-3 小智「溯源气泡」

**炫点**：小智回答里凡是提到考点的词，自动变成可点气泡；点开在侧边浮出该考点卡片 + 图谱定位 + 相关真题数。
**实现**：回答文本做关键词匹配（已有 knowledge_point 名称表）→ 富文本渲染 → 侧滑卡片。
**依赖**：一个按名称匹配知识点的端点（1 个）。
**工时**：3 天｜**视觉冲击**：★★★★（**最能体现"系统懂我"**）

### 7-4 方案动态重排 · 双栏 diff 动画

**炫点**：改画像或改计划后，老方案和新方案左右并列，变动部分高亮滑动；点击可回滚。
**实现**：两栏对照 + 差异标红/标绿 + FLIP 位移动画。
**依赖**：方案版本快照（后端加 1 张表或复用已有 meta）。
**工时**：4 天｜**视觉冲击**：★★★★

### 7-5 多角色互评 · 三顶帽子

**炫点**：小智给答案后，自动追加三条短评：**出题人**说考点是否答偏、**阅卷人**说采分点漏了没、**学长**说这题当年怎么错。三角色以不同气泡颜色并行出现。
**实现**：一次请求内并发三次 LLM 调用（不同 system prompt），前端三栏流式渲染。
**依赖**：复用 `/api/llm/chat`，零新端点。
**工时**：3 天｜**视觉冲击**：★★★★★（**演示效果炸裂**）

### 7-6 知识库双向跳转 · 题目 ↔ 考点 ↔ Obsidian

**炫点**：题目页右侧常驻「知识定位」小地图，标出这道题考哪个考点、该考点的掌握度、以及 vault 里对应笔记的入口。
**实现**：`question_knowledge` 关联表（现为空，需题目回流后填充）+ 小地图组件。
**依赖**：**题目回流先做**，否则空转。
**工时**：3 天｜**视觉冲击**：★★★

## 四、技术底线（不破的规矩）

1. **零新前端依赖**：不引 three/d3/gsap。Canvas 2D + SVG + CSS 3D 够用，且构建体积不涨。
2. **不碰 `/api/v1` 既有 343 端点**：新增端点单独记账，同步更新 `api_surface.json`。
3. **`.vtj` 模板改动先备份再改**，`<script>` 只加不改语义。
4. **动画必须尊重 `prefers-reduced-motion`**：所有炫技在减弱动效模式下退回静态。
5. **移动端降级**：Canvas 粒子在窄屏降到 30% 数量，避免掉帧。
