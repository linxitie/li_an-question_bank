## 一、现状诊断总结

### 1.1 致命问题：三个后端路由未注册

`backend/app/main.py` 第15行导入了 `wrong_questions`、`collection`、`notes` 三个路由模块，但第326-347行的 `app.include_router()` 调用列表中**完全缺失**这三个路由的注册。

| 路由模块 | 前缀 | 导入状态 | 注册状态 | 影响 |
|----------|------|----------|----------|------|
| wrong_questions | /api/wrong-questions | ✓ 已导入 | ✗ **未注册** | 错题集列表/复习/斩题全部404 |
| collection | /api/collection | ✓ 已导入 | ✗ **未注册** | 通用收藏聚合API不可用 |
| notes | /api/notes | ✓ 已导入 | ✗ **未注册** | 通用笔记聚合API不可用 |

**唯一能工作的错题录入路径**：通过 `/api/practice/record`（已注册）内部的 `_auto_record_wrong()` 函数自动写入错题表。但前端读取错题列表的接口失效，用户看不到已收录的错题。

### 1.2 各模块功能现状

| 模块 | 后端模型 | 后端API | 前端页面 | 核心问题 |
|------|----------|---------|----------|----------|
| 错题集 | ✓ WrongQuestionPersonal(15字段) | ✗ 路由未注册 | ⚠ wrong_questions.vue(功能多但接口失效) | 路由未注册、科目分类硬编码、复习界面需重设计 |
| 题目笔记 | ✓ QuestionNote | ✓ question_actions.py(已注册) | ✓ answer_page.vue有笔记功能 | 缺少聚合查看页面 |
| 新闻笔记 | ✓ NewsNote(支持划线) | ✓ news.py(已注册) | ✓ daily_news.vue(功能完整) | 缺少聚合查看页面 |
| 题目收藏 | ✓ FavoriteQuestion | ✓ question_actions.py(已注册) | ✗ 做题页无收藏按钮 | 前端入口缺失 |
| 新闻收藏 | ✓ NewsFavorite | ✓ news.py(已注册) | ✓ daily_news.vue(可用) | 缺少聚合查看页面 |
| 申论金句 | ✗ 无模型 | ✗ 无API | ⚠ quote_banner.vue(5条硬编码) | 完全无后端支撑 |

### 1.3 错题自动录入机制（已存在）

文件：`backend/app/api/v1/practice.py` 第22-47行

```python
def _auto_record_wrong(user_id, question_id, subject_id, db):
    """自动将错题收录到个人错题集"""
    existing = db.query(WrongQuestionPersonal).filter(...).first()
    if existing:
        existing.error_count += 1
        existing.last_review_time = datetime.now()
        existing.review_count += 1
    else:
        db.add(WrongQuestionPersonal(...))
```

调用点：
- `POST /api/practice/record`（单题记录）→ 第85行调用
- `POST /api/practice/batch-record`（批量记录）→ 第135行调用

**结论**：错题自动录入机制已存在且工作正常，无需重新设计。核心问题是前端读取不到错题列表（路由未注册）。

### 2.2 设计原则

1. **最小侵入**：不改动已正常工作的模块（如daily_news.vue的新闻笔记/收藏功能）
2. **路由注册优先**：首先修复3个未注册路由，恢复核心功能
3. **复用现有模型**：WrongQuestionPersonal、QuestionNote、NewsNote、FavoriteQuestion、NewsFavorite 均已存在，不重复建表
4. **VTJ规范**：所有新页面遵循VTJ Options API模式，使用useProvider，同步DSL JSON
5. **不影响其他模块**：改动范围严格限制在三大模块相关文件

#### 3.1.2 修复 accuracy_rate 计算逻辑

文件：`backend/app/api/v1/wrong_questions.py` 第123-124行

**当前错误逻辑**：
```python
existing.error_count += 1  # 先+1
total_attempts = existing.error_count + 1  # 再+1，导致total始终比error多2
existing.accuracy_rate = (total_attempts - existing.error_count) / total_attempts * 100
# 结果：accuracy_rate = 1/(error_count+2)*100，永远趋近0
```

**修复后**：
```python
old_error_count = existing.error_count or 0
existing.error_count = old_error_count + 1
# 总尝试次数 = 错误次数 + 正确次数(复习次数-错误次数)
total_attempts = existing.review_count or 1
correct_count = max(0, total_attempts - existing.error_count)
existing.accuracy_rate = round((correct_count / total_attempts) * 100, 2) if total_attempts > 0 else 0
```

```javascript
async loadSubcategories() {
  const res = await auth.apiFetch('/api/wrong-questions/subcategories');

  this.state.subcategoryGroups = data.reduce((groups, item) => {
```

```python
async def get_news_notes(
    page: int = Query(1, ge=1),
    page_size: int = Query(20, ge=1, le=100),
    current_user = Depends(get_current_user),
```

```python
class EssayQuote(Base):
    """申论金句表"""
    __tablename__ = "essay_quote"
    quote_id = Column(Integer, primary_key=True, autoincrement=True, comment="金句ID")
    content = Column(Text, nullable=False, comment="金句内容")
    source = Column(String(200), comment="来源")
    category = Column(String(50), comment="分类: 哲理/治国/民生/法治/品德")
    author = Column(String(100), comment="作者")
    create_time = Column(DateTime, default=datetime.now, comment="创建时间")
    status = Column(Integer, default=1, comment="状态")
    
    __table_args__ = (
        Index("idx_category_essayquote", category),
        Index("idx_status_essayquote", status),
    )

class QuoteFavorite(Base):
    """金句收藏表"""
    __tablename__ = "quote_favorite"
    fav_id = Column(Integer, primary_key=True, autoincrement=True)
    user_id = Column(BigInteger, ForeignKey("sys_user.user_id"), nullable=False)
    quote_id = Column(Integer, ForeignKey("essay_quote.quote_id"), nullable=False)
    create_time = Column(DateTime, default=datetime.now)
    
    __table_args__ = (
        UniqueConstraint("user_id", "quote_id", name="uq_user_quote_fav"),
        Index("idx_user_id_quotefavorite", user_id),
    )
```

```python
@router.get("/{news_id}", summary="获取新闻详情")
async def get_news_detail(
    news_id: int,
    current_user: Optional[SysUser] = Depends(get_optional_user),
    db: Session = Depends(get_db)
):
    """获取单条新闻完整内容，含图片、收藏状态"""
    article = db.query(NewsArticle).filter(
        NewsArticle.news_id == news_id,
        NewsArticle.status == 1
    ).first()
    if not article:
        raise ResourceNotFoundError("新闻")
    
    images = db.query(NewsImage).filter(
        NewsImage.news_id == news_id
    ).order_by(NewsImage.image_order).all()
    
    return {
        "id": article.news_id,
        "title": article.title,
        "url": article.url,
        "source": article.source,
        "category": article.category,
        "publish_date": article.publish_date.isoformat() if article.publish_date else None,
        "summary": article.summary,
        "content": article.content or "",
        "images": [{"url": '/' + img.image_path.lstrip('/'), "order": img.image_order} for img in images],
        "is_favorited": db.query(NewsFavorite).filter(
            NewsFavorite.user_id == current_user.user_id,
            NewsFavorite.news_id == news_id
        ).first() is not None if current_user else False,
    }
```

#### 5.3.2 题目详情接口（增强收藏列表返回字段）

文件：`backend/app/api/v1/collection.py` 的 `get_question_favorites` 接口

返回字段增强（对比现有question_actions.py仅返回content+answer）：

```python
@router.get("/question-favorites", summary="典题收藏列表")
async def get_question_favorites(
    subject_id: Optional[int] = None,
    page: int = Query(1, ge=1),
    page_size: int = Query(20, ge=1, le=100),
    current_user = Depends(get_current_user),
    db = Depends(get_db)
):
    """查询用户收藏的题目列表，含完整题目信息"""
    query = db.query(FavoriteQuestion).filter(
        FavoriteQuestion.user_id == current_user.user_id
    )
    if subject_id:
        query = query.join(QuestionBank).filter(QuestionBank.subject_id == subject_id)
    
    total = query.count()
    items = query.order_by(FavoriteQuestion.create_time.desc())\
        .offset((page - 1) * page_size).limit(page_size).all()
    
    result = []
    for fav in items:
        q = fav.question
        if not q:
            continue
        # 获取科目名和子科目
        subject = db.query(QuestionSubject).filter(
            QuestionSubject.subject_id == q.subject_id
        ).first()
        subcategory = _get_subcategory(q)  # 辅助函数获取子科目
        
        result.append({
            'fav_id': fav.fav_id,
            'question_id': q.question_id,
            'question_content': q.question_content,
            'options': q.options or [],            # 选项列表
            'answer': q.answer,                    # 正确答案
            'answer_analysis': q.answer_analysis or '',  # 答案解析
            'difficulty': q.difficulty or 3,       # 难度 1-5
            'accuracy_rate': float(q.accuracy_rate or 0), # 全网正确率
            'subject_id': q.subject_id,
            'subject_name': subject.subject_name if subject else '',
            'subcategory': subcategory,
            'create_time': fav.create_time.isoformat() if fav.create_time else '',
        })
    
    return {'total': total, 'page': page, 'page_size': page_size, 'items': result}
```

**辅助函数：获取子科目名称**

```python
def _get_subcategory(question) -> str:
    """根据科目ID返回对应的子科目名称"""
    if question.subject_id == 1:  # 行测
        return question.xingce_subcategory or '无'
    elif question.subject_id == 2:  # 申论
        return question.shenlun_subcategory or '无'
    elif question.subject_id == 3:  # 公专
        return question.gongzhuan_subcategory or '无'
    return '无'
```

```javascript
isCorrectAnswer(idx, item) {
  if (!item.answer || !item.options) return false;
  // answer可能是 "A"/"B"/"C"/"D" 或 "ABC"（多选）
  const correctLetters = item.answer.toUpperCase().split('');
  const currentLetter = String.fromCharCode(65 + idx);
  return correctLetters.includes(currentLetter);
}
```

## 八、安全与运维考量

### 8.1 安全性
- 所有接口使用 `get_current_user` 依赖注入进行JWT认证
- 收藏/笔记接口严格按 `user_id` 过滤，防止越权访问
- 金句管理接口仅管理员可增删（通过role_level校验）
- 文件上传（如有）沿用论坛模块的白名单+UUID重命名机制

### 8.2 性能优化
- 聚合查询接口使用JOIN避免N+1问题
- 错题列表添加复合索引 `idx_user_subject_wrong(user_id, subject_id, is_cut)`
- 笔记/收藏列表接口支持分页，默认20条/页，最大100条
- 金句随机接口使用 `ORDER BY RANDOM() LIMIT 1`，数据量小无性能问题

### 8.3 运维便利
- 自动迁移：新增 essay_quote/quote_favorite 表在 main.py 中添加自动迁移逻辑
- raw标记：新建页面在项目配置中标记 `raw: true`，防止VTJ设计器覆盖手写代码
- DSL同步：所有新页面同时生成 .vue 和 .json 文件，保持版本一致
- 统一错误处理：沿用现有 BusinessLogicError 等异常体系

### 8.4 不影响其他模块
- 不修改 daily_news.vue（新闻笔记/收藏功能已完整）
- 不修改 question_bank.vue（仅在工具栏提示处更新收藏入口）
