## 四、三端互通机制

### 统一认证
- 所有端口共用 JWT 双令牌体系（Access Token 480分钟 + Refresh Token 30天）
- Token payload 包含 `{user_id, user_type, role_level, permissions[]}`
- 前端通过 `window.__VTJ_AUTH__` 统一访问

### 数据共享
- 教师发布试卷 → paper_approval_workflow → 管理员审批 → 学生端历年试卷可见
- 学生答题 → exam_record + practice_record → 教师端成绩分析
- 管理员创建用户 → sys_user → 各端直接登录

### 权限控制
- 前端路由守卫：`router.beforeEach` 检查 `to.meta.roles`
- 后端权限中间件：每端点独立检查 `check_permission(user, permission)`
- 双重防御：前端 UX 层 + 后端安全层

## 六、启动验证步骤

1. **启动后端**: `cd backend && python -m app.start`
2. **启动前端**: `npm run dev`
3. **验证教师端**: 登录 ycc5678 → 自动跳转教师工作台 → 访问题目管理/试卷管理/成绩管理
4. **验证管理员端**: 登录 cbrycc → 自动跳转系统总览 → 访问用户管理/系统设置/日志审计
5. **验证学生端**: 注册学生账号 → 题库页无"题目导入"按钮 → 无法访问 /teacher/* 和 /admin/*
