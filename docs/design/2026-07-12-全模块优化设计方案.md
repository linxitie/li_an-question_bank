## 一、P1: 答题卡模块优化

| # | 问题 | 严重度 | 根因 |

### 1.2 修复方案

#### 1.2.1 选项解析引擎重构

**文件**: `backend/app/services/text_parser.py`

三层回退策略：
- **L1 结构化解析**: 增强正则 `([A-D])\s*[.、．)）]\s*(.+?)(?=\s*[A-D]\s*[.、．)）]\|$)`
- **L2 段落回退**: L1不足2个时，扫描连续段落查找选项
- **L3 LLM兜底**: 前两层不足时复用已有的LLM匹配基础设施

同时修复 `_extract_question_blocks`:
- 选项从content_text中移除时使用精确位置索引而非 `replace(line, '', 1)`
- 回退正则添加严格边界匹配

#### 1.2.2 图片链路修复

**文件**: `backend/app/api/v1/question_import.py`

导入时图片处理流程：
1. 从Word/PDF中提取图片 → 计算MD5去重
2. 保存到 `uploads/questions/{question_id}/img_{n}.png`
3. 写入 `question_image` 表（question_id + image_path + image_type）
4. API返回时附带images字段
5. 前端渲染：题干图片插入stem上方，选项图片插入对应选项内
6. 向后兼容：保留 `[IMAGE:x_y]` 占位符替换作为兜底

#### 1.2.3 题型分类入库

**文件**: 
- `backend/app/api/v1/question_import.py` — 每题写入时创建 QuestionDetailCategory 记录
- `backend/app/api/v1/questions.py` — 查询时 JOIN question_detail_category
- `backend/scripts/migrate_question_types.py` — 历史数据回填（根据answer长度+题干关键词）

题型映射:
```python
TYPE_MAP = {
    '单选题': '单选题', '选择题': '单选题', '单选': '单选题',
    '多选题': '多选题', '不定项': '多选题', '多选': '多选题',
    '判断题': '判断题', '填空题': '填空题', '简答题': '简答题',
}
```
历史数据回填规则：answer长度>1 → 多选题；题干含"多选/不定项/哪些/属于.*有" → 多选题

#### 1.2.4 多选题交互UI

**文件**: `.vtj/vue/answer_page.vue`

- 选项标签根据题型切换样式:
  - 单选题: `border-radius: 50%` (圆形)
  - 多选题: `border-radius: 6px` (方形) + 选中显示 ✓ 图标
- 多选提示条: "多选题 — 已选 N 项（点击选项切换选中状态）"
- 逻辑层已正确实现（`selectOption` 的 toggle 数组逻辑保持不变）

#### 1.2.5 答案解析修复

- 导入: text_parser.py 确保 analysis 字段正确提取
- API: random端点确保返回 answer_analysis
- 前端: 已有 `v-if="q.explain"` 渲染，增加fallback "暂未提供解析"
- 数据修复: 迁移脚本回填空解析

#### 1.2.6 渐进式IRT难度评估

**文件**: `backend/app/services/difficulty.py` (新增)

三阶段策略:
| 阶段 | 答题次数 | 模型 | 参数 |
|------|---------|------|------|
| 冷启动 | <30 | 正确率法 | difficulty = round(5*(1-accuracy)) |
| 预热期 | 30-200 | Rasch 1PL | 仅估计 b (难度) |
| 成熟期 | >200 | 2PL | 估计 b (难度) + a (区分度) |

定时任务: 每100次新答题触发全量重估

#### 1.2.7 VTJ DSL规范化

- `router.js`: 补充 `/answer` → `answer_page.vue` 路由
- `answer_page.json`: 补充 dataSources 配置，添加 images 数据源
- 接口调用: 统一走 `window.__VTJ_AUTH__.apiFetch()`

**文件**: `backend/app/api/v1/calendar.py`

```python
def _compute_status(e):
    now = datetime.now()
    if e.registration_end and e.registration_end < now:
        return "已截止"
    if e.registration_start and e.registration_start > now:
        return "即将报名"
    if e.registration_start and e.registration_end \
       and e.registration_start <= now <= e.registration_end:
        return "报名中"
    return "报名中"
```

#### 3.2.4 收藏+笔记功能

新增3张数据库表:
- **news_favorite**: user_id + news_id (收藏整篇新闻)
- **news_note**: user_id + news_id + note_text + quote_text + quote_position + color (划线+想法)
- **news_image**: news_id + image_path + image_order (图片关联)

新增API端点:
- `POST /api/news/{id}/favorite` — 收藏/取消收藏新闻
- `GET /api/news/favorites` — 获取收藏列表
- `POST /api/news/{id}/highlight` — 保存选中语句
- `GET /api/news/{id}/highlights` — 获取该新闻的高亮
- `POST /api/news/{id}/note` — 保存笔记（划线+想法）
- `GET /api/news/{id}/notes` — 获取该新闻的笔记
- `PUT /api/news/notes/{id}` — 更新笔记
- `DELETE /api/news/notes/{id}` — 删除笔记

前端交互:
- ⭐ 收藏按钮: 新闻详情页顶部
- 📝 划线: 选中文字 → 弹出颜色选择器 → 划线自动保存
- 💬 写想法: 划线后弹出输入框 → 自动保存到"笔记"
- 自动保存: 无需手动提交，失焦即保存

#### 3.2.5 数据库模型

```python
class NewsImage(Base):
    __tablename__ = "news_image"
    image_id = Column(Integer, PK)
    news_id = Column(BigInteger, FK->news_article.news_id)
    image_path = Column(String(500))
    image_order = Column(Integer, default=0)
    create_time = Column(DateTime)

class NewsFavorite(Base):
    __tablename__ = "news_favorite"
    fav_id = Column(Integer, PK)
    user_id = Column(BigInteger, FK->sys_user.user_id)
    news_id = Column(BigInteger, FK->news_article.news_id)
    create_time = Column(DateTime)
    __table_args__ = (UniqueConstraint("user_id", "news_id"),)

class NewsNote(Base):
    __tablename__ = "news_note"
    note_id = Column(Integer, PK)
    user_id = Column(BigInteger, FK->sys_user.user_id)
    news_id = Column(BigInteger, FK->news_article.news_id)
    note_text = Column(Text, nullable=False)        # 想法内容
    quote_text = Column(Text)                        # 划线原文
    quote_position = Column(Integer)                 # 位置锚点(字符偏移)
    color = Column(String(10), default="#FFD700")    # 划线颜色
    create_time = Column(DateTime)
    update_time = Column(DateTime)
```
