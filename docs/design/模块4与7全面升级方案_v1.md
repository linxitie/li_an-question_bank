## 2. 目标与差距

一句话：**把「问画像 → 出方案 → 能查看 → 能执行 → 能复习」这条链打通，并把小智与知识库接进这条链。**

| # | 用户诉求 | 目标 |
|---|---|---|
| 1(1) | 询问页样式单调，要动画过渡 | 分步问答 + 卡片进出场动画（参考多邻国/不背单词的节奏感） |
| 1(2) | 问题单一，要动态变换 + 用户自述 | 问题池扩到 30+ 分 6 维；每步动态抽题；末段自由自述写入画像 |
| 1(3) | 方案不能在首页/我的查看 | 首页 + 我的各加一张方案卡，点击进 `/study-plan` |
| 1(4) | 3D 学习日历进「每日签到」 | 签到页嵌入 3D 翻转日历，点亮当日 |
| 1(5) | 番茄钟进首页（小弹窗） | 首页浮动小窗 + 专注计时 + 结束后写签到/积分 |
| 1(6) | 遗忘曲线复习提醒（错题集） | 错题按 SM-2 简化算法排下次复习日，错题集出提醒入口 |
| 1(7) | 手机/平板缺失 | 三端同源，按 R12 复用 mobile 页 + `meta.platform` |
| 2(1) | Obsidian 自生长知识库 | 建 vault 骨架 + 采集/审核/发布流程，与画像、小智打通 |
| 2(2) | 知识图谱框架 | 定义节点/边模型 + 落库 + 图谱页可交互 |
| 2(3) | 小智手机/平板缺失 | 复用 `ai_chat.vue` 的数据契约，新增 mobile/tablet 入口 |
