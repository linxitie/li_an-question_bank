## 二、路由跳转关系

```
question_bank.vue (题库主页)
  ├── 点击"笔记"按钮 → this.$router.push('/page/notes')  → notes.vue
  ├── 点击"收藏"按钮 → this.$router.push('/page/favorites') → favorites.vue
  └── 点击"错题集"按钮 → this.$router.push('/page/wrong_questions') → wrong_questions.vue
```

**重要约定**：
- `question_bank.vue` 仅负责"跳转"，不负责目标页面的 UI 实现
- 各独立页面（notes/favorites/wrong_questions）自行加载数据和渲染
- 不允许在 `question_bank.vue` 中残留目标页面的弹窗、state、methods

## 四、VTJ 规范遵守清单

所有 VTJ 生成页面（.vtj/vue/*.vue）必须遵守：

- [x] 使用 `defineComponent` + `setup(props)` 返回 `useProvider` 上下文
- [x] `XIcon` 必须从 `@vtj/ui` 导入并在 `components` 注册
- [x] 图标必须从 `@vtj/icons` 导入（禁止从 `@element-plus/icons-vue` 导入）
- [x] 前后端通信必须使用 `window.__VTJ_AUTH__.apiFetch()`（禁止裸 `fetch`）
- [x] `.vue` 文件的 `useProvider({version})` 与 `.json` 文件的 `__VERSION__` 必须一致
- [x] 版本号修改时必须同时修改 .vue 和 .json（或运行 `npm run sync:vtj-version`）

```vue

</script>

<template>
  <VtjErrorBoundary>
    <MyComponent />
  </VtjErrorBoundary>
</template>
```

### 5.3 API 错误处理工具

```typescript
import { safeGetJson } from '@/utils/api-helpers';

// 在组件 methods 中使用
async loadStats() {
  const result = await safeGetJson('/api/notes/stats', {
    headers: this.getJsonHeaders()
  });
  if (result.ok) {
    this.state.stats = result.data;
  }
  // 错误已由 safeApiCall 统一处理，无需 try/catch
}
```

## 六、禁止行为清单

以下行为会导致系统稳定性下降，**严格禁止**：

1. ❌ 在 `question_bank.vue` 中添加笔记/收藏/错题集的弹窗或 UI 实现
2. ❌ 从 `@element-plus/icons-vue` 导入图标（应使用 `@vtj/icons`）
3. ❌ 使用 `<XIcon>` 但未在 `components` 中注册
4. ❌ 使用裸 `fetch()` 调用需要认证的 API
5. ❌ 修改 .vue 的 version 但不同步 .json 的 __VERSION__
6. ❌ 在 .vtj/files/*.json 中修改 nodes 节点树（应由 VTJ 设计器操作）

## 七、维护检查清单

每次修改 VTJ 模块时，请检查：

- [ ] `.vue` 的 `useProvider({version})` 与 `.json` 的 `__VERSION__` 是否一致
- [ ] 是否有 `XIcon` 使用但未注册
- [ ] 图标是否从 `@vtj/icons` 导入
- [ ] API 调用是否使用 `apiFetch`
- [ ] 是否有跨模块的 UI 代码残留
- [ ] 运行 `npm run sync:vtj-version` 验证版本同步
