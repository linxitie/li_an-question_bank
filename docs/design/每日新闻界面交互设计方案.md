# 每日新闻界面交互设计方案

> 日期：2026-08-14
> 范围：每日新闻模块全面完善（交互、图片内联、排版、笔记/收藏联动）

---

## 一、背景与目标

「每日新闻」模块需全面完善，核心诉求四点：

1. **前端交互**：⭐收藏、📝划线（选中文字→颜色选择器→自动保存）、💬写想法（划线后输入框→自动保存）、失焦即保存，并集中在新闻弹窗右上角。
2. **图片显示与存储**：完善前端图片路径、后端数据库图片路径存储；爬取新闻时获取正文相关图片（二维码/登录码不抓取），并**定位到对应正文位置**内联展示。
3. **排版美观**：不紧凑、不黏连、图片与字段不遮掩。
4. **笔记/收藏联动**：与「笔记-新闻笔记」「收藏-金句/新闻收藏」实时联动。

---

## 二、现状诊断（探索结论）

### 已就绪（无需重造）
- 划线/想法/收藏交互**已存在**于 `.vtj/vue/daily_news.vue`：⭐收藏（卡片+弹窗）、选中文字→5色+3线型浮动菜单、笔记列表。
- 后端模型齐全：`news_article`/`news_image`/`news_favorite`/`news_note`/`quote_favorite`/`essay_quote`。
- API 齐全：`news.py`（列表/详情/收藏/笔记）、`quotes.py`（金句随机+收藏）、`notes.py`/`collection.py`（聚合）。
- 图片静态链路**实际通畅**：爬取→`uploads/news/{id}/`→`news_image` 表(2555行=2555文件)→`main.py:399` mount `/uploads`→dev proxy→前端显示。

### 真实缺口
1. 正文图片内联定位丢失：爬虫 `get_text()` 剥离 `<img>`，正文 0 图，只能末尾扁平列表展示。
2. 划线需点「✅划线」才保存、想法用原生 `prompt()`——无失焦自动保存。
3. 金句收藏前端入口缺失：`quote_banner.vue` 无收藏按钮（后端接口已就绪但零调用）。
4. 排版：字段黏连、间距不足。
5. `news.py` 列表图片无序+N+1；`notes.py` 新闻分支 bug；爬虫未过滤二维码/登录码。

### 已确认决策
- 存量 1058 条：**仅新爬取生效**（旧新闻保持末尾扁平列表）。
- 划线/想法：**选中即触发**（不设模式开关），点颜色即自动保存、想法失焦即保存。

## 三、落地保证策略（分层 + 降级）

- **P0 确定性层**（不依赖爬虫/网络，立即可用现有数据验证）：前端交互、排版、图片路径、内联渲染函数、后端 API、金句收藏入口。覆盖 90% 诉求，无条件落地。
- **P1 增强层**（依赖真实爬取）：图片内联定位 + 二维码过滤。**增量 + 失败降级**：不改 `_extract_article_content` 核心逻辑，新增独立辅助函数；失败回退纯文本+扁平列表，前端「有 marker 渲染内联、无 marker 走扁平列表兜底」，任何一端失败另一端兜底。

## 四、具体改动

### A. 前端 `daily_news.vue`
- **A1 右上角工具栏**：⭐收藏（增强 `.favorited` 态+`title`）、📝划线说明（点击弹出气泡）、×关闭；正文顶部加浅色引导。
- **A2 划线自动保存**：点颜色圆点 = 立即划线保存（携带当前 `lineStyle`），删除「✅划线」确认按钮。
- **A3 想法自动保存**：内联 textarea 气泡替换原生 `prompt()`；`@blur` 失焦且非空→自动 POST；Enter 快捷保存、✕取消；`quote_text` 从 `state.selectedText` 缓存读取。
- **A4 内联图片渲染**：`renderContent` 建 `imageMap={order:url}`，命中 `[[IMG:n]]` 段输出 `<img class="news-inline-img">`；无 marker 时保留扁平列表兜底。
- **A5 排版**：新增 `.news-inline-img`（居中、max-width、圆角、阴影、上下留白）、`.news-hint-bubble`、`.note-input-bubble` 等；浮动菜单越界钳制。
- **A6 图片路径**：新增 `resolveImgUrl` 防御。

### B. 后端 `news.py`
- `get_news`/`get_today_news` 图片查询补 `.order_by(image_order)`；批量预取图片与收藏，消除 N+1。

### C. 后端 `notes.py`
- `GET /api/notes` 补 `note_type=="news"` 分支（复用 `NewsNote`），修正「笔记」页新闻 tab 数据。

### D. 前端 `quote_banner.vue`
- `quote-footer` 增加 ⭐收藏按钮 → `POST /api/quotes/{quoteId}/favorite`，切换 `quoteFavorited`，未登录 `ElMessage` 引导。

### E. 后端 `news_scraper.py`（P1）
- **F1** 新增 `_extract_content_with_inline_images`（按文档顺序遍历，图片处插 `[[IMG:n]]`）、`_walk_nodes`、`CONTENT_SELECTORS`（模块级复用）。
- **F2** 新增 `_should_skip_image`（尺寸<100px 图标 + URL/alt/父容器关键词过滤二维码/登录码）。
- **F3** `scrape_cpd_news`/`_fetch_article_detail` 接入内联提取+降级；`_fetch_people_detail_playwright` 图片过滤；新增 `_download_inline_images` 有序下载（`image_order`=标记 n）；修复 `article_soup` 残留变量 bug。
- **F4** `_filter_noise` 增加 `[[IMG:` 白名单保护。
