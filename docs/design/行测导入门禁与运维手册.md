## 5. DB 备份与回滚

### 5.1 备份（**库为 WAL 模式，必须用 sqlite3 备份 API**）

```python
import sqlite3, datetime, os
ts = datetime.datetime.now().strftime('%Y%m%d_%H%M%S')
bak = 'data/question_bank.db.bak_xingce_full_%s' % ts
src = sqlite3.connect('data/question_bank.db'); dst = sqlite3.connect(bak)
with dst: src.backup(dst)      # ★ 不要用 shutil.copy2
dst.close(); src.close()
```

> ⚠️ **`shutil.copy2` 在此库上是错的**：WAL 模式下只拷主库文件无法保证完整性，
> 且恢复时若残留旧 `-wal` 会被回放，把基线还原成错误行数。
> 若手工用文件覆盖恢复，**必须同时删除 `-wal` 与 `-shm`**。

### 5.2 回滚

```python
# 1) 先停后端，避免写入
# 2) 覆盖 + 清 WAL
import shutil, os
shutil.copy2('data/question_bank.db.bak_xingce_full_<ts>', 'data/question_bank.db')
for ext in ('-wal', '-shm'):
    p = 'data/question_bank.db' + ext
    if os.path.exists(p): os.remove(p)
# 3) 校验行数与备份一致后再启动后端
```

## 8. 批量重导入指引

### 8.1 铁律顺序（不可跳步）

```
1. DB 备份（sqlite3 备份 API）
2. 清 text_cache
3. 按省份分批（国考 → 江苏 → 北京 → 广东 → 其余 20 省）
4. 每批后跑 G1 + G2 + G3，**任一非 0 立即停止**
5. 确认通过再进下一批
```

### 8.2 ★ 当前禁止全量导入（阻塞中）

**T16 处于阻塞状态**，原因：`_upsert_question_core` 内的
`_detect_duplicate` 按文本相似度去重，而**行测图形推理题的区分信息在图片里、
不在文本层** —— 文本层只有共用指令句或 5–9 字类比短语。

实测单套「国考 2023 副省级」：7 题`content` 完全相同，最短 6 条全是类比题，
**131 题中 79 题被判重复（60%）并被静默丢弃**，且预览层完全拦不住
（match_rate 100%、blocked=0）。

```powershell
# 仅可 dry-run 观察逐套日志，其汇总数字不可信
python scripts/import_xingce_all.py --batches "国考行测" --dry-run
```

**解除阻塞前不得执行真实写入。** 详见
`.omo/evidence/task-16-dedup-rootcause.txt`。

## 9. 扩展流程

### 9.1 新增行测考点

```powershell
# 1) 重建清单（T5）
python scripts/build_xingce_kao_points.py
# 2) 层级化落库（幂等，可 --rollback）
python scripts/migrate_xingce_knowledge_points.py --dry-run
python scripts/migrate_xingce_knowledge_points.py --apply
```

约束：
- **省份私有值必须剥离前缀**（`江苏特色-综合资料` → `综合资料`），
  否则 24 省各产生一套互不相同的知识点
- `level` 映射为 `depth + 1`（既有约定：**顶层是 level 2，无 level 1**）
- 去重键是**完整路径**而非叶名，故不同分支下的同名叶子是合法的

### 9.2 新增行测分区

需同步**两处** `models.py`（第 191 行与第 956 行，两处声明必须一致）：

```python
xingce_subcategory = Column(Enum(
    "政治理论", "常识判断", "言语理解与表达", "数量关系",
    "判断推理", "资料分析", "知觉速度与准确性", "科学推理",
    "常识", "速度与知觉训练", "语言理解与表达", "无"  # 旧值兼容
), default="无", comment="行测细分类型")
```

SQLite 侧实测为 `VARCHAR(7)` 且**无 CHECK 约束**
（SQLAlchemy 2.0 `Enum.create_constraint` 默认 False），
故补枚举值**无需 DB 结构迁移**。

同时需在 `_xingce_review_flags()` 与分区映射表中登记。

### 9.3 新增图片阈值调整

**不得盲目下调 `_PDF_MIN_IMG_DIM`。** 必须先统计：

```powershell
python scripts/probe_xingce_image_stats.py    # 尺寸分布 + 阈值敏感性
python scripts/probe_xingce_image_geom.py     # 小 min 边 vs 大像素交叉复核
```

关键判据：`min<阈值 且 总像素>=2万` 的图数量必须为 **0**，
否则说明存在会被误杀的合法宽扁图表。

## 10. 前端改动须知（VTJ）

| 规则 | 说明 |
|---|---|
| **只改 `<script>`** | `question_import.vue` 的 template 是 1–493 行，改动须全部在 494 行之后 |
| **禁止同步 DSL** | `raw: true` 页面**禁止**同步 `.vtj/files/*.json`（R-2）——同步工具有损，48 方法中连 `_pollImportStatus` 都提不到 |
| **`useProvider` 不得改 version** | 当前 `version: '1790329880372'` |
| **行测分流不能依赖表单值** | `state.form.subject_category` **默认值是「公专」**，必须从题本正文探测分节头 |
| **模板缺结构须停下** | 若所需展示结构在 `<template>` 中不存在，**必须停下请用户在设计器拖拽**，不得自行改 template |

`question_import.vue` 已有可直接复用的结构：
`:disabled="state.loading || hasBlockedQuestions"`（阻断时禁用确认入库）、
`blocked-hint` + `blockedReasonText`（阻断原因）、
`blockedQuestionList()`（读 `q.blocked` / `q.block_reasons`）。

> ⚠️ 故新增代码**必须透传 `blocked` 与 `block_reasons`**，否则上述 UI 全部失效。

## 11. 常见故障速查

| 现象 | 根因 | 处置 |
|---|---|---|
| 经 9527 请求新端点返回 **502** | 8000 未 `--reload`，OpenAPI 无新路由 | 重启后端，先用 §4 第 2 条确认 |
| 导入内容「全文翻倍」 | text_cache 未清 | 铁律 R-1 |
| 行测仍走旧端点 | 分流探测未命中分节头 | 检查正文前 8000 字是否含分节头 |
| 行测题大量被判重复 | 见 §8.2（**当前已知阻塞**） | 不得直接全量导入 |
| 图片全部丢失 | 阈值被下调 / 上限过紧 | 先跑 §9.3 统计再改 |
| Vue 改动未生效 | 漏同步 DSL 会**反向覆盖**手改 | raw页禁止同步；若已同步需从 git 恢复 script |
| pytest 失败数增加 | 真回归 | 比对失败集合，勿只看总数 |
