### 3.3 触发限流策略

| 触发次数 | 处理 | 实现 |
|----------|------|------|
| 单次命中 blocked 词 | 直接拒绝,返回 400 + 命中词提示 | API 层 `check_before_post` |
| 单次命中 masked 词 | 提示用户选择"自动屏蔽发布"或"修改" | 前端弹窗二次确认 |
| 累计 3 次 blocked | 24 小时禁言 | Redis 计数 + `sys_user.is_disabled` 临时标记 |
| 累计 10 次 blocked | 永久禁言(需管理员解封) | 写入 `sys_operation_log` + 管理员通知 |
| 同一 IP 1 分钟内 5 次触发 | IP 限流 1 小时 | 复用 `RateLimiter` |

### 3.4 审计日志

所有触发记录写入 `sys_operation_log`:
- `user_id` / `ip` / `content_snippet`(前 100 字)/ `triggered_words` / `level` / `action`(rejected/masked/auto_banned)

管理员端可查看:
- 违规用户列表
- 敏感词触发统计(按词频/按用户)
- 禁言名单与解封操作

### 3.5 安全思考

- **防绕过**:DFA 支持全角/半角、繁简、拼音、同音字、插入符号变体(如"傻.逼")
- **防注入**:敏感词库为静态字典,不写入数据库,管理员通过独立接口增删(需 `FORUM_MANAGE` 权限)
- **隐私保护**:日志中 `content_snippet` 只存前 100 字,不存完整内容
- **热加载**:词库修改后通过 `reload()` 即时生效,无需重启服务

```python
@router.post("/posts", summary="发布新帖")
async def create_post(
    title: str = Form(..., max_length=200),
    content: str = Form(..., max_length=10000),
    share_type: str = Form("EXPERIENCE"),
    tags: Optional[str] = Form(None),
    attachments: Optional[str] = Form(None),  # JSON 字符串
    current_user: SysUser = Depends(get_current_user),
    db: Session = Depends(get_db)
):
    # 1. 关键词过滤(关键词工程核心)
    filter_result = sensitive_filter.detect(f"{title} {content}")
    if filter_result["level"] == "blocked":
        # 记录审计 + 累计计数 + 可能触发禁言
        log_violation(current_user.user_id, request, filter_result, "rejected")
        increment_violation_count(current_user.user_id)
        raise BusinessLogicError(
            message=f"内容包含违规词:{filter_result['words']},请修改后发布",
            code="SENSITIVE_CONTENT_BLOCKED"
        )
    
    # 2. 创建帖子

        user_id=current_user.user_id,
        title=title,
        content=content,

    db.commit()
    db.refresh(post)

    return {
        "id": post.post_id,
        "title": post.title,
        "content": post.content,
        "shareType": post.share_type,
        "attachments": post.attachments or [],
        "likeCount": 0,
```

```python
@router.get("/posts", summary="获取帖子列表")
async def get_forum_posts(
    limit: int = Query(20, ge=1, le=50),
    offset: int = Query(0, ge=0),
    db: Session = Depends(get_db)
):
    query = db.query(ForumPost).filter(ForumPost.status == "NORMAL")
    total = query.count()
    posts = query.order_by(
        ForumPost.is_top.desc(),
        ForumPost.create_time.desc()
    ).offset(offset).limit(limit).all()
    
    # 批量查询 user 信息(避免 N+1 查询)
    user_ids = list({p.user_id for p in posts})
    users = db.query(SysUser).filter(SysUser.user_id.in_(user_ids)).all()
    user_map = {u.user_id: u for u in users}
    
    return {
        "total": total,
        "limit": limit,
        "offset": offset,
        "posts": [serialize_post(p, user_map.get(p.user_id)) for p in posts]
    }
```

```python
@router.post("/upload", summary="上传学习资料附件")
async def upload_attachment(
    file: UploadFile = File(...),
    current_user: SysUser = Depends(get_current_user)
):
    # 1. 白名单校验
    ALLOWED_EXT = {".doc", ".docx", ".pdf", ".xls", ".xlsx"}
    ALLOWED_MIME = {
        "application/msword", "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
        "application/pdf", "application/vnd.ms-excel",
        "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"
    }
    
    ext = os.path.splitext(file.filename)[1].lower()
    if ext not in ALLOWED_EXT or file.content_type not in ALLOWED_MIME:
        raise ValidationError("仅支持 Word/PDF/Excel 文件")
    
    # 2. 大小校验(< 20MB)
    contents = await file.read()
    if len(contents) > 20 * 1024 * 1024:
        raise ValidationError("文件大小不能超过 20MB")
    
    # 3. 安全存储(UUID 重命名)
    import uuid
    filename = f"{uuid.uuid4().hex}{ext}"
    save_dir = os.path.join(settings.UPLOAD_DIR, "forum")
    os.makedirs(save_dir, exist_ok=True)
    save_path = os.path.join(save_dir, filename)
    
    with open(save_path, "wb") as f:
        f.write(contents)
    
    return {
        "name": file.filename,
        "url": f"/uploads/forum/{filename}",
        "size": len(contents),
        "type": ext.lstrip(".")
    }
```

## 五、独立数据库决策

### 5.1 用户原话

> "为了高效运行系统可以考虑分离出论坛观点发布的数据库,独立成库保证系统总体运维"

### 5.2 决策:**当前阶段不独立物理数据库**

**理由**:

| 维度 | 独立库方案 | 当前方案(单库+优化) |
|------|------------|----------------------|
| 运维复杂度 | 双库备份/监控/迁移/故障切换,运维成本翻倍 | 单库统一运维,已有 `SysBackupRecord` 备份机制 |
| 数据一致性 | 跨库事务难以保证(帖子与用户数据分库) | 单库 ACID 事务天然保障 |
| 性能 | 理论上隔离负载,但当前论坛数据量 < 10 万条,无性能瓶颈 | SQLite WAL 已支持并发读写;MySQL 连接池 pool_size=20 足够 |
| 开发成本 | 需要新建 engine、跨库 JOIN 困难、ORM 关系断裂 | 现有 `db_router.py` 已预留读写分离扩展点 |
| 扩展性 | 未来论坛爆发式增长时可平滑迁移 | 通过 `FORUM_DB_URL` 环境变量预留切换路径 |

**替代优化措施**(等效提升性能):

1. **索引优化**:新增 `idx_status_top_time` 复合索引,列表查询走索引扫描
2. **N+1 查询消除**:批量查询 user 信息,避免每条帖子单独查 user
3. **Redis 缓存**:热门帖子列表缓存 60 秒,统计接口缓存 5 分钟
4. **读写分离预留**:`db_router.py` 已实现,未来论坛库可独立挂为 slave
5. **冷热分离**:已删帖子归档表 `forum_post_archive`(预留,数据量大时启用)

**未来迁移路径**(预留):

#### 6.3.2 script 改造

```javascript
import { defineComponent, reactive } from 'vue';
import { XIcon } from '@vtj/ui';
import { ChatRound, EditPen, ChatLineRound, View, TrendCharts, User, Document, Upload, Star, StarFilled } from '@vtj/icons';
import NavBar from './navbar.vue';
import { useProvider } from '@vtj/renderer';

export default defineComponent({
  name: 'Forum',
  components: { NavBar, XIcon },
  setup() {
    const provider = useProvider({ id: 'forum', version: '<NEW_VERSION_TIMESTAMP>' });
    const state = reactive({
      page: 1,
      pageSize: 8,
      posts: [],
      total: 0,
      loading: false,
      showNewPost: false,
      showUserProfile: false,
      userProfile: {},
      newPost: { title: '', content: '', attachments: [] },
      forumStats: { posts: 0, users: 0, online: 0 }
    });
    return { state, provider, ChatRound, EditPen, ChatLineRound, View, TrendCharts, User, Document, Upload, Star, StarFilled };
  },
  computed: {
    totalPages() {
      return Math.max(1, Math.ceil(this.state.total / this.state.pageSize));
    },
    filteredPosts() {
      const start = (this.state.page - 1) * this.state.pageSize;
      return this.state.posts.slice(start, start + this.state.pageSize);
    },
    hotPosts() {
      return [...this.state.posts]
        .sort((a, b) => (b.likeCount + b.commentCount * 2) - (a.likeCount + a.commentCount * 2))
        .slice(0, 5)
        .map((p, i) => ({ ...p, rank: i + 1 }));
    }
  },
  methods: {
    async loadPosts() {
      this.state.loading = true;
      try {
        const auth = window.__VTJ_AUTH__;
        const headers = auth ? auth.getJsonHeaders() : {};
        const offset = (this.state.page - 1) * this.state.pageSize;
        const res = await fetch(`/api/forum/posts?limit=${this.state.pageSize}&offset=${offset}`, { headers });
        const data = await res.json();
        this.state.posts = (data.posts || []).map(p => ({
          id: p.id,
          title: p.title,
          content: p.content,
          author: p.user?.nickname || '匿名',
          avatar: p.user?.avatar || '',
          date: this.formatTime(p.createTime),
          likeCount: p.likeCount || 0,
          commentCount: p.commentCount || 0,
          liked: p.liked || false,
          attachments: p.attachments || [],
          userId: p.user?.id
        }));
        this.state.total = data.total || 0;
      } catch (e) {
        this.$message.error('加载帖子失败');
      } finally {
        this.state.loading = false;
      }
    },
    async loadStats() {
      try {
        const res = await fetch('/api/forum/stats');
        const data = await res.json();
        this.state.forumStats = data;
      } catch (e) { /* 静默失败,使用默认值 */ }
    },
    async submitPost() {
      if (!this.state.newPost.title.trim()) {
        this.$message.warning('请输入标题');
        return;
      }
      if (!this.state.newPost.content.trim()) {
        this.$message.warning('请输入内容');
        return;
      }
      
      const auth = window.__VTJ_AUTH__;
      if (!auth || !auth.isLoggedIn()) {
        this.$message.warning('请先登录');
        return;
      }
      
      try {
        const res = await fetch('/api/forum/posts', {
          method: 'POST',
          headers: { 'Content-Type': 'application/json', ...auth.getJsonHeaders() },
          body: JSON.stringify({
            title: this.state.newPost.title,
            content: this.state.newPost.content,
            attachments: this.state.newPost.attachments
          })
        });
        
        if (res.status === 401) {
          this.$message.warning('登录已过期,请重新登录');
          auth.logout();
          return;
        }
        
        const data = await res.json();
        
        if (!res.ok) {
          // 关键词过滤命中
          if (data.code === 'SENSITIVE_CONTENT_BLOCKED') {
            this.$message.error(data.message || '内容包含违规词,请修改');
          } else {
            this.$message.error(data.message || '发布失败');
          }
          return;
        }
        
        // 成功:unshift 到列表头(实时更新,无需重新拉取)
        this.state.posts.unshift({
          id: data.id,
          title: data.title,
          content: data.content,
          author: data.user.nickname,
          avatar: data.user.avatar,
          date: this.formatTime(data.createTime),
          likeCount: 0,
          commentCount: 0,
          liked: false,
          attachments: data.attachments || [],
          userId: data.user.id
        });
        this.state.total += 1;
        this.state.showNewPost = false;
        this.state.newPost = { title: '', content: '', attachments: [] };
        this.$message.success('发布成功!');
      } catch (e) {
        this.$message.error('网络错误,发布失败');
      }
    },
    async handleFileUpload(e) {
      const files = Array.from(e.target.files);
      const auth = window.__VTJ_AUTH__;
      if (!auth || !auth.isLoggedIn()) {
        this.$message.warning('请先登录');
        return;
      }
      
      for (const file of files) {
        const formData = new FormData();
        formData.append('file', file);
        try {
          const res = await fetch('/api/forum/upload', {
            method: 'POST',
            headers: { ...auth.getAuthHeaders() },
            body: formData
          });
          const data = await res.json();
          if (res.ok) {
            this.state.newPost.attachments.push(data);
            this.$message.success(`${file.name} 上传成功`);
          } else {
            this.$message.error(data.message || `${file.name} 上传失败`);
          }
        } catch (err) {
          this.$message.error(`${file.name} 上传失败`);
        }
      }
      e.target.value = '';  // 重置 input,允许重复选择同一文件
    },
    removeFile(index) {
      this.state.newPost.attachments.splice(index, 1);
    },
    async toggleLike(post) {
      const auth = window.__VTJ_AUTH__;
      if (!auth || !auth.isLoggedIn()) {
        this.$message.warning('请先登录');
        return;
      }
      try {
        const res = await fetch(`/api/forum/posts/${post.id}/like`, {
          method: 'POST',
          headers: { ...auth.getJsonHeaders() }
        });
        if (res.ok) {
          const data = await res.json();
          post.liked = data.liked;
          post.likeCount = data.likeCount;
        }
      } catch (e) { /* 静默 */ }
    },
    async viewUser(userId) {
      if (!userId) return;
      try {
        const res = await fetch(`/api/forum/users/${userId}/public`);
        const data = await res.json();
        this.state.userProfile = data;
        this.state.showUserProfile = true;
      } catch (e) {
        this.$message.error('获取用户信息失败');
      }
    },
    viewPost(post) {
      this.$message.info('帖子详情功能开发中:' + post.title);
      // TODO: 后续可跳转帖子详情页
    },
    formatTime(iso) {
      if (!iso) return '';
      const d = new Date(iso);
      const pad = (n) => String(n).padStart(2, '0');
      return `${d.getFullYear()}-${pad(d.getMonth() + 1)}-${pad(d.getDate())} ${pad(d.getHours())}:${pad(d.getMinutes())}`;
    },
    prevPage() {
      if (this.state.page > 1) {
        this.state.page--;
        this.loadPosts();
      }
    },
    nextPage() {
      if (this.state.page < this.totalPages) {
        this.state.page++;
        this.loadPosts();
      }
    },
    openNewPost() {
      const auth = window.__VTJ_AUTH__;
      if (!auth || !auth.isLoggedIn()) {
        this.$message.warning('请先登录后发帖');
        return;
      }
      this.state.showNewPost = true;
    }
  },
  mounted() {
    this.loadPosts();
    this.loadStats();
  }
});
```

## 七、安全与运维考量

### 7.1 安全设计

| 风险 | 防护措施 |
|------|----------|
| SQL 注入 | SQLAlchemy ORM 参数化查询,无原生 SQL 拼接 |
| XSS | 前端 `{{ }}` 默认转义,禁用 `v-html`;后端 `content` 入库前不做 HTML 转义,前端渲染时由 Vue 自动转义 |

| 限流 | 发帖 3/min、评论 10/min、点赞 30/min、上传 5/min,复用 `RateLimiter` |
| 敏感词绕过 | DFA 支持全角/半角/繁简/拼音/同音字/插入符号变体 |
| CSRF | JWT Bearer Token 天然防 CSRF |
| 文件下载 | 附件下载走 `/uploads/forum/` 静态服务,无执行权限 |

### 12.4 运维考量

- **独立数据库决策**:当前阶段不独立物理数据库,采用索引优化(`idx_status_top_time` 复合索引)+ N+1 查询消除(批量查询 user 信息)+ 批量点赞状态查询,性能满足当前规模。未来若论坛数据量超过 10 万帖,可考虑分库。
- **审计日志**:所有敏感词触发记录写入 `sys_operation_log`,管理员可查询违规用户和触发统计。
- **热加载**:敏感词库支持 `reload()` 热加载,管理员更新词库后无需重启服务。
- **文件上传安全**:白名单(扩展名+MIME 双重校验)+ 大小限制(20MB)+ UUID 重命名 + 独立目录(`uploads/forum/`)。
- **软删除**:帖子删除采用 `status=DELETED` 软删除,保留数据可恢复。
