## 四、已知轻微问题（不阻塞上线）

1. **import/status 的 elapsed_seconds 偏大**：`datetime.now()` 与 SQLite CURRENT_TIMESTAMP 时区口径不一致所致（显示问题不影响流程）。建议后续在 parse_result 记录单调起始时间戳计算。
2. **bleach strip=True 会保留 script 内部文字**为纯文本残留（不可执行）。如需彻底清除可在 sanitizer 中先正则剔除 `<script>...</script>` 整段。
3. 三科页面结构代码重复 ~85%（方案 B 既定代价）；主题差异集中在文件头 8 处锚点，后续可抽 composable。

## 六、使用指引（内容运营 SOP）

```
管理员登录 → 首页顶部「资料管理」(或直访 /admin/materials)
├─ 单条创建：新建资料 → 选类型(视频走分片上传/文章用富文本/卡片正反面) → 保存
├─ 批量导入：智能导入 → 拖入 docx讲义/xlsx词库/pdf → 预览确认 → 元信息 → 入库
└─ 上架：列表开启「上架」开关 → 学生端 /materials/{科目} 即时可见
学生入口：首页「备考资料」三科目卡片 → 行测/申论/公专页学习
```
