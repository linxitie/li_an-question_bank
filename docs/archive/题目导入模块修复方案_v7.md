- **状态**: ✅ 已实施（4 波完成）

## 一、根因诊断（代码级证据，全部已确证）

### 问题 1：公式图黑块「修改不彻底，多文档导入再现」

- **实测**: 清缓存后新提取 3 份行测答案 PDF——**黑块图 0 张**（SMask 修复对新提取生效）。
- **再现根因**: ①`text_cache` 里缓存的**旧文本**（旧 marker 指向修复前生成的旧黑图文件）；②磁盘上**旧黑图文件残留**（修复前 session 生成）。用户导入过的文档再次导入 → 缓存命中旧 marker → 指向旧黑图 → 黑块再现。
- **修复 A**: ①text_cache 加**版本前缀**（SMask 修复后旧缓存自动失效，重提取生成正确图）；②清理一次磁盘旧黑图文件（按文件时间戳批量清理全黑 PNG）。

### 问题 2：题目管理编辑无法对所有内容粘贴图片

- **现状**: 预览组件 question_preview_list 已支持题干/选项/答案/解析粘贴；但**教师端/管理员端题目管理**（teacher_questions.vue / admin_questions.vue）的编辑弹窗只有 textarea 无粘贴。
- **修复 B**: 两处编辑弹窗的题干/选项/答案/解析字段加 @paste（复用 handleEditPaste 模式：剪贴板图片 → data URI → 入库时 `_extract_and_save_images` 落盘）。

### 问题 3：申论题目管理仍无材料（含三端/三设备核验）

- **确证**: 库中**17 道申论题仅 1 道有组**——16 道是修复前导入的**存量数据**（12 题来源「联考」+4 题空）。
- **可恢复性**: 导入记录 1584/1587（安徽A/B卷题目 PDF，PREVIEW 状态）的 preview_data 含完整材料文本（326KB/372KB）→ 材料可恢复。
- **三端核验**: 教师端（31 处）/管理员端（18 处）/学生端 answer_page（47 处）已有组视图；手机端/平板端页面无 group 引用（需核验是否复用同一组接口）。
- **修复 C**: ①一次性**存量回填脚本**——扫描无组申论题，按 source 从导入记录/题库 PDF 恢复材料建组并回填 group_id；②核验移动端页面组展示。

### 问题 4：教师端「批量处理」按钮（真实功能）

- **现状**: 后端有单题删除（`DELETE /questions/{question_id}`）但**无批量删除接口**。
- **修复 D**: ①后端新增 `POST /questions/batch-delete`（真实接口：批量软删除/状态置 0 + 事务）；②前端教师端题目管理右上角「批量处理」按钮：进入选择模式（复选框）→ 批量删除/批量操作，全选/反选/确认弹窗。
