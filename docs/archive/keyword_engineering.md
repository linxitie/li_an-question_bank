# 题型识别关键词工程

## 核心原则

1. **确定性**：同一输入必得同一输出，可单元测试。
2. **可解释**：每个判定可回溯到具体规则/关键词。
3. **分层**：选项 → 选择题；答案多字母 → 多选；无选项 → 写作/论述关键词。
4. **单一事实来源**：`_detect_question_type` 是唯一判定入口，导入、读路径兜底、修复脚本全部复用。

## 分层分类器（text_parser._detect_question_type）

```
Step0 预处理：norm_answer = canonical_answer(answer)；opt_count = count_options(content, options)
Step1 有选项(opt_count>=2) → 客观选择题：
       len(norm_answer)>=2 → 多选题
       命中 MULTI_CHOICE_KEYWORDS → 多选题
       否则 → 单选题（判断题自然归入单选，选项为"对/错"两项）
Step2 无选项 → 命中 WRITING_KEYWORDS → 写作题
Step3 无选项 → 命中 ESSAY_KEYWORDS → 论述题
Step4 兜底 → 论述题（记低置信日志）
```

> 关键词冲突（如"分析"既出现在选择题又出现在论述题）由**分层优先级**消解：先判选项（Step1），无选项才走写作/论述（Step2/3）。

## count_options（选项数量判定）

- 优先使用传入的 `options`（list / dict / JSON 字符串）。
- 为空时从题干文本扫描 **A-H** 选项标记：**行首**（`(?:^|[\n；;])\s*([A-H])\s*[.、．)）:：]`）+ **内联**（`([A-H])\s*[.、．)）:：]\s*\S`），
  解决 OCR 文本内联选项漏检导致的"选择题→论述题"。

## 答案信号

- `canonical_answer(answer)` 归一化后长度 ≥2（如 "AB"、"ABC"）→ 多选题。
- 这是多选判定最可靠的信号，且不受题干措辞影响。

## 维护建议

- 新增关键词时，先确认不会与更高优先级层级冲突（选项 > 写作 > 论述）。
- 关键词含正则元字符（`.*`、`\d`）时注意转义语义。
- 任何类型判定逻辑变更，务必同步跑 `python backend/scripts/repair_question_types.py --dry-run` 回归。
