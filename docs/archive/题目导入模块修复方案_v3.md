## 一、问题 → 根因（代码级证据）

### 问题 4（最严重）：2024 国考卷 100 题仅 85 匹配、91 题缺解析

**根因**：答案 PDF 的答案是「**题号+字母+解析**」紧贴形态：
```
1、A本题考查公安时政。……故A正确。
19、D本题考查宪法基础知识。……
11.C本题考查人民警察的职业道德。……（题号用句点）
```
- 统计证据：**99/100 题**是「字母+本题」形态（剥题号后首行 `X本题…`，X 即答案字母）
- 但 `extract_answer_from_lines` 无「行首字母」规则 → 只能从正文抓「故X正确」等结论 → **8 题提出答案且全部是错的**（19 题正确答案 D 被抓成 A）
- 题号提取本身正常（实测 100 个题号全部识别）

**修复 A**：`extract_answer_from_lines` 新增最高优先级规则——剥题号后首行 `^([A-Da-d]{1,4})(?=本题)` → 答案=字母串，解析=首行剩余+后续行。99/100 形态精准命中，误伤面极小（限定词「本题」）。

### 问题 3：粘贴图片只能到文本末端

**根因**：`handleEditPaste`（Wave 6 新增）用 `editForm[field] = (editForm[field] || '') + tag` 追加到末尾，未使用 textarea 的 `selectionStart` 光标位置。

**修复 B**：读取 `event.target.selectionStart/selectionEnd`，在光标处插入图片标签，并把光标移到插入内容之后。

### 问题 2：复合题仍分割 + 题干信息黏在前一题

**根因（确凿复现，2017 公安院校联考卷）**：85-88 题组的材料**没有材料头标记**：
```
84、……侦查的方向有（  ）。（多选）
A、资金链    B、信息链    C、物流链    D、证据链
某日，有群众报警，称本市六盘岭街道无言路8号突发一起持刀砍人案件，……立即启动了应急预案。   ← 85-88 题组材料，无任何「回答第X-Y题」标记
85、市公安局110指挥中心应当立即做出的应对措施有（  ）。
```
`_strip_trailing_material` 只认「材料头正则」（需要「根据|阅读…回答N-M题」）和「分节指令段」——无标记材料无法识别 → 材料黏在 84 题尾。

**修复 C（启发式 + 可回退）**：`_strip_trailing_material` 增加「无标记材料」识别——当本题**选项已齐全**（≥2 个选项）且尾部存在**多行无题号、无选项行**的连续文本（≥2 行）时，剥离并回吐给下一题。风险控制：仅题目文档场景（选项后不会再有答案/解析）；用 85 套行测回归 + 公专 2583 指纹 + 8 份材料卷实测验证不破坏既有行为。

### 问题 1：upload 400 一次 + WebSocket 400

- **upload 400**（日志 14:26:59 仅一次）：三个来源——格式不支持 / 超大小 / 文件头嗅探不符（magic）。前端未把具体 detail 展示给用户。
- **WebSocket 400**：Vite HMR 连接失败（`ws://localhost:9527/?token=...` 握手 400）。不影响业务功能（页面正常），常见于 Vite 重启后浏览器还持有旧连接。处理：提示用户**重启浏览器页面**（代码层面无需改动，如需可给 devRuntimeSafety 加 HMR 失败提示）。

**修复 D**：upload 错误路径前端展示后端 detail（复用 `_extractErrorMessage`，检查现有 catch 是否已透传；未透传则补）。

## 三、多角度思考（按要求 3）

- **修复 A 为什么这样写**：规则限定 `(?=本题)` 后跟，99/100 语料实证；放在「题头权威声明」之后（题头声明需要「答案」二字，两者互斥不冲突）。好处：一行正则解决 92% 缺解析。安全：不触碰 extract_question_blocks 红线函数。运维：format 标记 `inline_letter` 便于日志排查。
- **修复 B**：纯前端 selectionStart，零后端改动；textarea 场景无 XSS 面（data URI 图片入库时走后端既有管线）。
- **修复 C**：只加剥离（材料给下一题），不改切题逻辑；选项齐全判据防止误剥长题干；真实语料回归是安全网。**不新建文件**，在既有 `_strip_trailing_material` 内增量。
- **修复 D**：复用既有错误文案机制，不新写。

## 四、风险与红线

| 风险 | 缓解 |
|---|---|
| 修复 A 误伤「行首字母非答案」形态（如选项行首） | 限定 `(?=本题)`；parse_answer_text_to_map 只处理答案文档 |
| 修复 C 误剥长题干/解析 | 选项齐全判据 + 多行长度阈 + 85 套行测回归 + 指纹 |
| 修复 C 涉及 text_parser（B-2 红线函数体之外） | `_strip_trailing_material` 不在 L0 红线清单内（红线只有 extract_question_blocks 函数体），但仍跑 gate_l0 确认 |
| 越改越退步 | 每波独立 commit + 真实语料回归，出问题单波回滚 |
