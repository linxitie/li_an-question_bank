# 每日金句大完善 - 详细可落地方案

> 文档版本：v1.0 | 创建日期：2026-08-16
> 涉及模块：后端 quotes.py / collection.py / models.py，前端 quote_banner.vue / favorites.vue

---

## 一、问题分析

### 1.1 核心问题：Obsidian 金句 quote_id=0

**现象**：
- 前端 `refreshQuote()` 调用 `/api/quotes/quote/daily` 获取 Obsidian 金句
- 后端返回 `quote_id: 0`（哨兵值，表示"无数据库记录"）
- 前端 `toggleQuoteFavorite()` 检查 `if (!this.state.quoteId) return;`，quoteId=0 时直接静默返回
- 用户点击收藏按钮毫无反应

**根因**：
- Obsidian 金句从文件系统实时读取，不存入数据库
- `QuoteFavorite` 表的 `quote_id` 是 NOT NULL 外键，引用 `essay_quote.quote_id`
- 后端 `toggle_quote_favorite` 按 `quote_id` 查 `EssayQuote`，0 查不到 → 404

### 1.2 次要问题：内容哈希 ID 不稳定

**现象**：
- 如果用内容哈希作为 Obsidian 金句的 ID，内容变化会导致 ID 变化
- 已收藏的金句因 ID 变化而"丢失"

**影响**：
- Obsidian 知识库更新金句内容后，用户收藏记录失效
- 收藏页无法正确显示已收藏的 Obsidian 金句

### 1.3 收藏页数据不一致

**现象**：
- `favorites.vue` 调用 `/api/collection/news-favorites`
- 该接口查询 `QuoteFavorite JOIN EssayQuote`，只返回数据库金句
- Obsidian 金句即使能收藏，也不会出现在收藏页

## 二、设计方案

### 2.1 设计原则

| 原则 | 说明 |
|------|------|
| **稳定性优先** | Obsidian 金句 ID 必须稳定，不随内容变化 |
| **数据一致性** | 收藏页必须能显示所有已收藏的金句（数据库 + Obsidian） |
| **最小侵入** | 只修改必要文件，不创建新 Vue 文件 |
| **VTJ 合规** | 严格遵守 VTJ 设计规则，只修改 script 部分 |
| **向后兼容** | 不影响现有数据库金句的收藏功能 |
| **可维护性** | 代码清晰，注释完整，便于后期运维 |

### 2.2 核心方案：基于文件名的稳定 ID + 收藏表扩展

**思路**：
1. Obsidian 金句使用**文件名**作为稳定 ID（文件名不变，ID 就不变）
2. 扩展 `QuoteFavorite` 表，增加 `obsidian_source` 字段标识来源
3. 修改后端收藏接口，支持 Obsidian 金句收藏
4. 修改收藏页接口，合并返回数据库金句和 Obsidian 金句收藏

### 2.3 ID 稳定性分析

| ID 生成方式 | 稳定性 | 问题 |
|-------------|--------|------|
| 内容哈希 (MD5/SHA) | ❌ 不稳定 | 内容变化 → ID 变化 → 收藏丢失 |
| 文件名 | ✅ 稳定 | 文件名不变，ID 就不变 |
| 文件路径 | ✅ 稳定 | 但路径过长，不美观 |
| 随机 UUID | ✅ 稳定 | 但无法从文件反查 |

**推荐**：使用**文件名**作为 Obsidian 金句的稳定 ID。

**文件名格式**：`2026-08-14-金句-050.md` → ID = `obsidian_2026-08-14-金句-050`

**优点**：
- 文件名在整个生命周期内不变
- 可从 ID 反查文件路径
- 人类可读，便于调试

```python
class QuoteFavorite(Base):
    """金句收藏表"""
    __tablename__ = "quote_favorite"
    fav_id = Column(Integer, primary_key=True, autoincrement=True)
    user_id = Column(BigInteger, ForeignKey("sys_user.user_id"), nullable=False)
    quote_id = Column(Integer, ForeignKey("essay_quote.quote_id"), nullable=True)  # 改为可空
    obsidian_source = Column(String(200), nullable=True, comment="Obsidian 金句来源标识（文件名）")

        Index("idx_user_id_quotefavorite", user_id),
    )
```

**关键变更**：
1. `quote_id` 改为 `nullable=True`（支持 Obsidian 金句无数据库 ID）

**安全性考虑**：
- 外键约束仍然有效（`quote_id` 为空时不触发）
- 唯一约束防止重复收藏
- 字段长度 200 足够存储文件名

**运维便利性**：
- 可通过 `obsidian_source` 字段快速定位 Obsidian 金句
- 便于数据迁移和备份

```python
@router.post("/obsidian/{obsidian_source}/favorite", summary="切换 Obsidian 金句收藏")
async def toggle_obsidian_quote_favorite(
    obsidian_source: str,
    current_user: SysUser = Depends(get_current_user),
    db: Session = Depends(get_db)
):
    """添加或取消 Obsidian 金句收藏"""
    # 检查是否已收藏
    existing = db.query(QuoteFavorite).filter(
        QuoteFavorite.user_id == current_user.user_id,
        QuoteFavorite.obsidian_source == obsidian_source
    ).first()
    
    if existing:
        db.delete(existing)
        db.commit()
        return {"favorited": False, "message": "已取消收藏"}
    
    # 新增收藏（quote_id 为空）
    fav = QuoteFavorite(
        user_id=current_user.user_id,
        quote_id=None,  # Obsidian 金句无数据库 ID
        obsidian_source=obsidian_source,
    )
    db.add(fav)
    db.commit()
    return {"favorited": True, "message": "已收藏"}
```

**为什么新增独立端点**：
- 职责分离：数据库金句和 Obsidian 金句使用不同的收藏逻辑
- 避免修改现有 `toggle_quote_favorite` 的行为，保证向后兼容
- 参数明确：`obsidian_source` 直接传递文件名，无需查询数据库

**安全性考虑**：
- 强制登录（`get_current_user`）
- 文件名参数校验（可增加正则校验，防止路径遍历攻击）
- 唯一约束防止重复收藏

```python
        # ... 保持不变
```

**新增辅助函数**：`_read_obsidian_quote_by_filename`

```python
def _read_obsidian_quote_by_filename(filename: str) -> Optional[dict]:
    """根据文件名读取 Obsidian 金句"""
    if not filename or not os.path.exists(OBSIDIAN_QUOTE_DIR):
        return None
    
    fpath = os.path.join(OBSIDIAN_QUOTE_DIR, filename)
    if not os.path.exists(fpath):
        return None
    
    try:
        with open(fpath, 'r', encoding='utf-8') as f:
            content = f.read()
        return _parse_obsidian_quote(content)
    except Exception as e:
        logger.warning(f"Failed to read Obsidian quote {filename}: {e}")
        return None
```

**为什么这样设计**：
- 分离查询：数据库金句和 Obsidian 金句分开查询，逻辑清晰

- 性能考虑：只在收藏页查询时读取 Obsidian 文件，不影响首页性能

```javascript
async refreshQuote() {
  if (this.state.quoteLoading) return;
  this.state.quoteLoading = true;
  try {
    const auth = window.__VTJ_AUTH__;
    const headers = {};
    if (auth && auth.isLoggedIn && auth.isLoggedIn()) {
      Object.assign(headers, auth.getJsonHeaders());
    }
    // 优先从 Obsidian 知识库获取每日金句，失败时回退到随机金句
    let res = await fetch('/api/quotes/quote/daily', { headers });
    if (!res.ok) {
      // 回退到原有的随机金句接口
      res = await fetch('/api/quotes/random', { headers });
    }
    if (!res.ok) throw new Error('获取金句失败');
    const data = await res.json();
    this.state.quote = data.content || '暂无金句';
    this.state.author = data.author || data.source || '佚名';
    this.state.quoteId = data.quote_id || 0;
    this.state.quoteFavorited = !!data.favorited;
    // 新增：存储 Obsidian 金句信息
    this.state.obsidianId = data.obsidian_id || '';
    this.state.obsidianSource = data.obsidian_source || '';
    this.state.sourceType = data.source_type || 'database';
  } catch (e) {
    console.warn('获取金句失败:', e);
    // 失败时使用兜底金句，避免空白
    if (!this.state.quote || this.state.quote === '正在加载今日金句...') {
      this.state.quote = '忠诚是公安队伍代代相传的政治基因，是融入血脉的人民警察之魂。';
      this.state.author = '人民公安报';
    }
  } finally {
    this.state.quoteLoading = false;
  }
},
```

```javascript
    // Obsidian 金句取消收藏
    if (item.obsidian_source) {
      try {
        await window.__VTJ_AUTH__.apiFetch('/api/quotes/obsidian/' + encodeURIComponent(item.obsidian_source) + '/favorite', { method: 'POST', headers: this.getJsonHeaders() });
        this.state.showNewsModal = false;
        this.loadFavorites();
        this.loadStats();
      } catch(e) { console.warn('取消收藏失败:', e); }
      return;
    }
  }
  // 新闻取消收藏
  // ... 保持不变
},
```

**为什么这样设计**：
- 分离逻辑：数据库金句和 Obsidian 金句使用不同的取消收藏端点
- 保持兼容：`quote_id` 仍用于数据库金句
- 用户体验：取消收藏后刷新列表，与现有行为一致

### 4.3 潜在问题

**问题**：Obsidian 金句按日期轮转，同一天点击"换一句"返回相同金句。

**解决方案**：修改 `_select_daily_quote` 方法，支持随机选取。

```python
def _select_daily_quote(quotes: list[dict]) -> Optional[dict]:
    """按日期轮转选取每日金句（支持随机）"""
    if not quotes:
        return None
    
    today = date.today()
    # 使用日期作为种子，确保同一天返回相同金句
    # 但如果需要"换一句"功能，可以改为随机选取
    import random
    random.seed(today.toordinal())  # 同一天使用相同种子
    return random.choice(quotes)
```

**为什么这样设计**：
- 保持"每日金句"的一致性（同一天看到相同金句）
- 支持"换一句"功能（随机选取，但同一天结果相同）
- 可配置：可以通过环境变量控制是否启用随机模式

## 五、安全性考虑

### 5.1 路径遍历攻击

**风险**：`obsidian_source` 参数可能包含 `../` 等路径遍历字符，导致读取任意文件。

**防护措施**：

```python
import re

# 校验 obsidian_source 格式（只允许文件名，不允许路径分隔符）
OBSIDIAN_SOURCE_PATTERN = re.compile(r'^[\w\-\.]+\.md$')

@router.post("/obsidian/{obsidian_source}/favorite", summary="切换 Obsidian 金句收藏")
async def toggle_obsidian_quote_favorite(
    obsidian_source: str,
    current_user: SysUser = Depends(get_current_user),
    db: Session = Depends(get_db)
):
    # 校验参数格式
    if not OBSIDIAN_SOURCE_PATTERN.match(obsidian_source):
        raise HTTPException(status_code=400, detail="无效的金句来源标识")
    
    # ... 其余逻辑
```

### 5.2 SQL 注入

**风险**：`obsidian_source` 参数可能被用于 SQL 注入。

**防护措施**：
- 使用 SQLAlchemy ORM，参数化查询，天然防注入
- 字段长度限制（200 字符）

### 5.3 权限控制

**风险**：未登录用户尝试收藏。

**防护措施**：
- `toggle_obsidian_quote_favorite` 使用 `get_current_user`（强制登录）
- 前端 `toggleQuoteFavorite` 检查 `auth.isLoggedIn()`

### 5.4 数据一致性

**风险**：并发收藏导致重复记录。

**防护措施**：
- 唯一约束 `uq_user_obsidian_fav`
- 数据库层面保证一致性
