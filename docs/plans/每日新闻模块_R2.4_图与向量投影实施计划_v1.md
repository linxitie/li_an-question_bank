# 每日新闻模块 R2.4 图/向量投影实施计划 v1

> 状态：首版完成（2026-11-01）
> 分支：`feat/news/r2-projection`
> 前置：R2.3 审核闭环已合并

## 1. 范围

- MPS 图片改为 Playwright 同上下文请求；
- 新闻 → Topic/Source/Media 的薄图投影；
- 新闻标题+摘要+正文的本地向量投影；
- 只投影 `published` 新闻，草稿/待审不进入图/向量；
- hash embedding 只用于离线验证，报告中标记 `degraded=true`。

## 2. 实现

| 项 | 实现 |
|---|---|
| 图片 | `_download_image_playwright`：Edge + 正文页上下文 + `context.request.get` |
| 图节点 | `News / Topic / Source / Media` |
| 图边 | `ABOUT / FROM_SOURCE / HAS_MEDIA` |
| 向量集合 | `news_articles` |
| 向量存储 | `LocalVectorStore`（默认 local） |
| CLI | `python -m scripts.news.project_news --graph --vectors --provider hash` |

## 3. 验收

- 图节点只含已发布新闻；
- 向量 `news_articles` 条数 = 已发布新闻数；
- hash 结果明确标记 degraded；
- 采集测试、投影测试通过；
- 不自动发布、不修改审核状态。
