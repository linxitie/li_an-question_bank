### 1.2 接管动作（本地已理解，远端操作待批准/网络恢复）

```powershell
git fetch origin --prune
# ① 父域快进（领先 0 才允许 --ff-only；本地更新，远端推送需用户批准）
git switch -c feature/study-plan origin/feature/study-plan 2>$null || git switch feature/study-plan
git merge --ff-only origin/main
git switch -c feature/ai-assistant origin/feature/ai-assistant 2>$null || git switch feature/ai-assistant
git merge --ff-only origin/main
# ② 从父域开子分支（方案 A：连字符；git D/F 硬约束见事实基线 F21）
git switch -c feature/study-plan-<子任务>
# ③ 单仓推送（或 fork+PR 用方案 B，见总纲 §7.3）
git push origin feature/study-plan:feature/study-plan     # 远端快进；获批后执行
git push origin HEAD:feature/study-plan                   # 子分支完成、测试通过后合回父域
```
