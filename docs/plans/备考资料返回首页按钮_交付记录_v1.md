> 你 2026-11-12 反馈：从首页点「备考资料」进到 `/materials/xingce` 后**没有返回入口**，只能用浏览器后退；
> 要求行测 / 申论 / 公专三个界面都有「返回首页」。
> 分支 `feat/material-multi-format-import`，**未碰 main**。

---

## 1. 一个页面覆盖三科，所以只改一处

`src/views/student/materials.vue` 同时服务三条路由：

```
/materials/xingce    → src/views/student/materials.vue
/materials/shenlun   → src/views/student/materials.vue
/materials/gongzhuan → src/views/student/materials.vue
```

（路由里就是同一个组件，靠 `route.path` 里的科目段切换主题色与数据）

## 2. 改了什么

| 位置 | 改动 |
|---|---|
| 模板顶部 | 新增一行 `.mp-crumb`，里面是 `← 返回首页` 按钮，点击 `go('/page/home_page')` |
| 样式 | 新增 `.mp-crumb` / `.mp-back`：白底 + 主题色描边（`.mp` 上的 `--c` 变量，行测蓝 / 申论绿 / 公专琥珀），hover 反色 |
| 空态按钮 | 原来空列表里的「返回首页」跳的是 `/home`，一并改成 `/page/home_page`（与顶部导航同一地址） |
| `navbar.vue` | 顺手把 `/home` 也映射成「首页」高亮（它和 `/page/home_page` 是同一个组件），避免出现"跳过去了但导航不亮" |

**为什么跳 `/page/home_page` 而不是 `/home`**：两者渲染同一个页面，但顶部导航「首页」用的是 `/page/home_page`；
用同一个地址，落地后导航高亮才会落在「首页」上，不会出现"两个首页地址、一个不亮"的错觉。

> 这个页面本身**不渲染全局导航栏**（它就是你在首页点进去的独立子页），所以它必须有页内返回入口 —— 这次补的就是这个。

## 3. 验证（headless 逐路由实测）

| 路由 | 有按钮 | 按钮文案 | 主题色 |
|---|---|---|---|
| `#/materials/xingce` | ✅ | ← 返回首页 | `rgb(59,130,246)` 蓝 |
| `#/materials/shenlun` | ✅ | ← 返回首页 | `rgb(16,185,129)` 绿 |
| `#/materials/gongzhuan` | ✅ | ← 返回首页 | `rgb(245,158,11)` 琥珀 |

- 点击后 `location.hash` 变为 `#/page/home_page`，回到首页；
- 落地后导航高亮 `.menu-item.active` = **首页**（`/home` 也验过，同样点亮首页）；
- `npx vue-tsc --noEmit` → 0 错误。

## 4. 回滚

`src/views/student/materials.vue` 删掉 `.mp-crumb` 那 3 行模板 + `.mp-crumb/.mp-back` 样式即恢复；
`navbar.vue` 里去掉 `/home` 那个分支即可（不影响其它路由高亮）。
