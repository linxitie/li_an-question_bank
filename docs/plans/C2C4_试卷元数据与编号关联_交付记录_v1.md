## 5. 踩到的两个坑（都值得记）

### 5.1 `Decimal` 不能直接 JSON 序列化

`exam_paper.total_score` 在 SQLite 里是 `NUMERIC` → SQLAlchemy 取出来是 `Decimal`，
`JSONResponse` 序列化直接 500（`TypeError: Object of type Decimal is not JSON serializable`）。
现在 `paper_backfill` / `paper_registry` 都显式 `float()`；预览与计划接口都返回 200。

### 5.2 模块边界门禁拦下了"library 直接读 exam 的表"

把 `ExamPaper` 直接 import 进 `library/materials.py` 后，L4 报：

```
[cross_write] library/materials -> ExamPaper (他域: catalog,exam,platform)
```

`boundary_baseline.json` 里**只有一条**历史违规（`library/materials → api.v1.catalog`，分类法契约），
门禁要求"不得新增"。做法：把这段跨域**只读**收敛到 `services/paper_registry.py`，
`materials.py` 只调服务函数、不再 import ExamPaper → 扫描结果"新增 0 条"，L4 通过。

> 这条约束对 **C3/P5 的上下架联动**同样成立（方案 §2.3 要求 `status` 变更时同步 `paper_type`）：
> 那是一次**写** exam 域，届时要么放进 `exam/contract.py` 并把这条违规登记进基线（需要你批准），
> 要么做成事件/队列。本批**没有**做联动写入，避免偷偷越过门禁。
