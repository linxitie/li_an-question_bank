## 1. 根因（一句话）

**写端点少回了 3 个字段，前端拿"缺字段"的状态当开关真值用。**

| 层 | 事实 |
|---|---|
| 后端 | `PUT /api/materials/admin/{id}/exam-open` 与 `.../exam-window` 返回 `contract.exam_state()`，**没有** `manual_open / paper_code / paper_id`；列表 `exam_gate.state_of()` 才补这三个 |
| 前端 | `row.exam = state` **整体替换** → 行的 `manual_open` 变 `undefined` |
| 派生 | `is-on: manual_open !== 0` → `undefined !== 0` **恒真**（按钮亮着但已关）；`nextOpen: manual_open === 0` → **恒假**（永远发 `open:false`，再也打不开）；副文案 `已手动关闭/手动开启` 与 aria 同错 |
| 定时 | 定时**保存成功**（toast「已保存考试时间」+ 行内 `20:00-22:00 定时`），但手动闸关着且打不开 → 状态仍「已关闭」，所以"设了没用" |

> 为什么之前没发现：刷新列表后 `state_of` 会把字段补回来，只有"点完不刷新"这一瞬能看见；P2 当时测的是列表过滤与开考拦截，没测写回后的界面状态。

## 2. 修了什么（3 代码文件 + 2 测试文件）

| 文件 | 改动 |
|---|---|
| `backend/app/services/exam_gate.py` | 新增 `_enrich(state, material, paper)`：唯一负责补 `paper_code / paper_id / manual_open`；`state_of`、`set_open`、`set_window` **三处共用** → 写端点回包与列表同形 |
| `src/utils/examGate.ts` | 新增 `examSwitchOn()`（缺 `manual_open` 时按 `reason` 兜底）、`nextExamOpen()`（与视觉同源）、`mergeExamState()`（合并而非替换，优先级 **回包 > 本次意图 > closed > 上一份**）；`examTimingText` 改用 `examSwitchOn` |
| `src/views/admin/materials.vue` | 开关 class / aria 改用 `examSwitchOn`；`toggleExam` 用 `nextExamOpen` + `mergeExamState(row.exam, state, nextOpen)`；`onExamWindowSaved` 同样合并 |
| `backend/tests/test_exam_switch_contract.py`（新） | 4 例：关闭回包与列表同形、关→开可逆、设定时保留手动闸、清空定时回到 ready |
| `src/utils/__tests__/examGate.spec.ts` | +7 例（3 组 describe）：缺字段兜底、取反可重开、合并保留 `paper_code/paper_id`、意图补齐、服务端值优先、空回包保留原行 |
