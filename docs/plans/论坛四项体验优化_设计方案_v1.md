## §1 附件重复渲染 + 点击二选一（问题 1）

### 1.1 根因（已定位到行）

`.vtj/vue/forum.vue` 帖子卡片里**同时存在两套附件渲染**：

```html
<!-- 第 66-69 行：新组件（带文件大小的 chip）-->
<AttachmentList v-if="post.attachments?.length" :attachments="post.attachments" mode="post" />

<!-- 第 70-78 行：遗留的旧渲染（只有图标+名字，无大小）-->
<div class="post-attachments" v-if="post.fileAttachments && post.fileAttachments.length">
  <span v-for="(att, idx) in post.fileAttachments" class="attachment-chip" @click.stop="downloadAttachment(att)">
    <XIcon :icon="Document" ... /><span>{{ att.name }}</span>
  </span>
</div>
```

**这正是截图里的两行**：
- 第一行 = `FileList`（`2025160099-兰文语.docx 3.0KB`）
- 第二行 = 旧块（`2025160099-兰文语.docx`，无大小）

`mobile_forum.vue:66`、`tablet_forum.vue:122` 需确认是否同样存在该旧块（下一步核对）。

### 1.2 方案

| 步 | 改动 |
|---|---|
| 1 | **删除旧的 `post-attachments` 块**（forum.vue 70–78；mobile/tablet 同名块），只保留 `AttachmentList` |
| 2 | 附件 chip 点击 → 打开**操作弹窗**：`[预览]` `[下载]` 两个按钮 + 文件名 |
| 3 | `预览`：`.docx` 走 `DocxPreview`（已实现）；`.pdf`/图片走内联新标签或内嵌 iframe；`.xlsx/.pptx` 暂不支持在线预览，提示改用下载 |
| 4 | `下载`：跳 `/media/{id}?download=1`（后端已支持强制 attachment） |
| 5 | 删除 `downloadAttachment` 旧方法（若不再被引用） |

### 1.3 格式一致性

- Word：`docx-preview` 渲染真实排版（已验证中文/段落正确，6/6）；
- PDF：浏览器原生渲染（服务端已 `inline`）；
- 图片：`ImageGrid` 缩略图 + 点击看大图；
- 无法在线预览的（xls/xlsx/ppt/pptx/zip/rar/7z）：弹窗只给「下载」。

## §2 搜索/筛选并入头部行 + 分类贴顶（问题 2）

### 2.1 现状

| 端 | 现状 |
|---|---|
| 学生 PC | `.forum-header`（备考论坛 + 我的收藏）独占一行；`.forum-search-bar` 单独一行；分类 tabs 在其下；`.forum-header` 为 sticky |
| 学生平板 | `.vtj/vue/tablet_forum.vue`，结构不同 |
| 教师 PC/平板 | `.tf-topbar`（标题+筛选）已吸顶（本轮刚做），但标题行与筛选行是**上下两行** |

### 2.2 方案

**学生 PC**：
1. `.forum-header` 改为三段式 flex：`[备考论坛] [分类 tabs] [搜索/日期/按钮]` 同一行；
2. 空间不足时 tabs 横向滚动（`overflow-x:auto`），搜索区固定右侧；
3. 整行 `position: sticky; top: 0`（滚动容器是 `.forum-main`，已验证有效）。

**学生平板**：按其模板结构做同样合并（分类行与搜索行并排）。

**教师 PC/平板**：
1. `.tf-head` 与 `.tf-filters` 合并为同一行：`[论坛管理] [搜索][日期][班级][查询] [⭐][发布新帖]`；
2. 继续用 `.tf-topbar` 一层吸顶（已生效：nav 0–56 / topbar 56–212）。

### 2.3 风险

- 一行放太多控件在 1280px 下会挤 → 用 `flex-wrap` + 最小宽度，必要时搜索框 `flex:1 1 200px`；
- 分类 tabs 与学生端"学习讨论/经验分享"文案来自后端分类，不改数据。

## §3 回到顶部（问题 3）

### 3.1 现状（已查）

```
src/components/common/BackToTop.vue   存在
src/App.vue:16                        <BackToTop />
src/App.vue:34                        import BackToTop from './components/common/BackToTop.vue'
```

组件**存在且已挂载**，但用户看不到。

### 3.2 根因（高置信度，待验证）

`BackToTop` 监听的是 **window scroll**；而论坛页的滚动发生在**内部容器**：

```
学生 PC：.forum-main { overflow-y: auto }
教师页 ：.tf-page   { overflow-y: auto }
```

window 从不滚动 → `scrollY` 恒为 0 → 按钮永不出现。

### 3.3 方案

给 `BackToTop` 增加可选属性 `scroll-target`（CSS 选择器），默认仍是 window：

```ts
props: { target?: string }
// 挂载时：const el = target ? document.querySelector(target) : window
// 监听 el 的 scroll；点击时 el.scrollTo({ top: 0, behavior: 'smooth' })
```

调用处：
- 学生 PC：`<BackToTop target=".forum-main" />`
- 教师页：`<BackToTop target=".tf-page" />`

## §4 右侧三卡：查看更多（问题 4）

### 4.1 现状

| 卡片 | 现状 | 位置 |
|---|---|---|
| 热门帖子 | `fetchForumPosts({ sortBy:'likes', limit:5 })` | teacher_forum.vue `loadSideCards` |
| 论坛活跃 | `/api/forum/stats` | 同上 |
| 我的帖子 | `fetchMyForumPosts({ limit:5 })` | 同上 |

### 4.2 方案

| 卡片 | 列表 | 查看更多 |
|---|---|---|
| 热门帖子 | 5 条（不变） | 「查看更多」→ 弹窗，`sortBy=likes&limit=100`，按点赞量降序；点条目 → 详情 |
| 论坛活跃 | 不变 | 无 |
| 我的帖子 | 5 条（不变） | 「查看更多」→ 弹窗，`limit=50` 翻页拉全量；点条目 → 详情 |

### 4.3 后端

- 热门：现有 `/api/forum/posts?sort=likes&limit=N` 是否支持 `sort` 参数需核对（`limit` 上限 50，取 100 需放宽或分页两次）；
- 我的帖子：`/api/forum/my-posts?limit=&offset=` 已支持。

> 若 `limit` 上限为 50，方案：前端分两页拉（50+50）合并去重，或把上限放宽到 100（后端一行改动，需你确认）。
