## P3-01 ③答题练习 + ④练习记录 + ⑥错题集

### ③ 答题练习（每端勾选 3 条）

- [ ] 进入题库选任意科目，随机练习可正常出题作答
- [ ] 快刷模式（quick-practice）提交后显示判分与正确答案
- [ ] 答题中途断网重连后，提交仍能成功（或明确失败提示，无白屏）
- [ ] 答题页图片题（若有）图片正常渲染，无裂图

### ④ 练习记录

- [ ] 完成一次练习后，练习记录页能看到本次记录（题数/正确率/耗时）
- [ ] 记录列表分页/筛选（科目）正常，空态有友好提示
- [ ] 记录详情与答题页数据一致

### ⑥ 错题集

- [ ] 故意答错一题后，错题集立即可见该题（E12 链路）
- [ ] 错题重练后标记「已掌握」，列表状态更新（E4 观测点）
- [ ] 同一题连续答错两次，错误次数显示累加为 2

### E 事件观测记录（在域卡「发布事件清单」注明观测方式）

| 事件 | 观测方式 | 结论 |
