# B2 批量导入 测试数据（说明）

这批文件用于验收**资料管理的「批量导入」**（同名 docx+pdf 合并、逐条队列、重复跳过、异常拦截）。

- 全部是**测试样张**：正文带 `—— 测试样张 TESTDOC-xxx`，不可当复习资料用。
- 每个文件内容唯一（sha256 互不相同）；`02_重复用例/04_讲义_正常.docx` **故意**与库里 ID 121 的原件字节相同，用来验证"重复跳过"。

| 目录 | 内容 | 预期 |
|---|---|---|
| `01_正常用例/` | 4 组同名 docx+pdf（2 套试卷题本 + 2 章讲义）+ 3 个单文件 | 分 3 批导入 → 共创建 **7 条**资料（4 组双格式合并 + 3 单文件） |
| `02_重复用例/` | `04_讲义_正常.docx`（与 121 同内容） | 队列标「重复」，**不新增**资料 |
| `03_同名冲突/` | `A/同名资料.docx`、`B/同名资料.docx`（同名不同内容） | 各导一次 → **两条独立资料**（不该合并） |
| `04_异常用例/` | `说明文本.txt`、`坏文件-假docx.docx` | txt 被前端直接拦；假 docx 后端 400「格式与扩展名不符」 |

**完整验收剧本、统计对账、清理办法**见：
`docs/plans/B2_批量导入测试数据_清单_v1.md`

> 提醒：入库参数（科目/类型）是**整批统一**的，试卷和讲义不要放在同一批里。
