## 2. 设计

### ① 平板三段分区（视频 ×2 + 文章）+ 只看收藏

**数据**（不动 store，避免影响手机分支）：
```ts
const tabletSections = reactive<Record<SectionKey, any[]>>({
  video_intro: [], video_advanced: [], article: [], card: []
});
const loadSections = async () => {
  await Promise.all(SECTION_DEFS.map(async (s) => {
    const r = await fetchLibraryList({ subject: activeSubject.value, type: s.key, pageSize: 50 });
    tabletSections[s.key] = r.items ?? [];
  }));
};
```
- `SECTION_DEFS`：`入门讲解视频 / 深度拓展视频 / 备考指南`（卡片段继续用现有网格，不重复拉）
- `showFavOnly`：`ref(false)`，过滤函数 `visible(key) = showFavOnly ? items.filter(i=>i.is_favorite) : items`
- 触发：`onMounted` 若 `isTabletLayout`，`switchSubject` 时重载

**渲染（平板分支，hero 之后、网格之前）**：
- 视频：`.t-hscroll` 横滑卡片（封面 `cover_image`、时长 `duration`、`is_studied`/`progress_percent` 角标）
- 文章：`.t-alist` 纵向列表（标题 / `summary` / `read_time`）
- 点击视频 → 页内 `.t-media` 弹层（`<video controls :src="video_url">`）
- 点击文章 → 页内 `.t-media` 弹层（`v-html="renderQuestionContent(content)"`，与手机详情同一清洗函数）
- 「只看收藏」：hero 右侧 `checkbox`（与 PC 同位置语义）

## 3. 多角度问答（AGENTS 规则③）

| 角度 | 结论 |
|---|---|
| **为什么** | 平板上一轮只有「hero + 卡片网格」：PC 的视频/文章分区看不到；详情是手机弹层，大屏浪费且与 PC 不一致；首页没有入口是「找不到资料模块」的直接原因 |
| **收益** | 平板资料链路与电脑端对齐（视频/文章/卡片 + 收藏 + 整页详情），入口可发现，减少「平板像放大手机」的观感 |
| **安全** | 不新增后端端点（R11 冻结）；只读接口 + 现有 `is_favorite`；HTML 统一走 `renderQuestionContent`（既有白名单清洗）；DOM 注入不写数据库、不改模板 |
| **运维** | 无迁移、无新配置；接口失败时该段不渲染（空态降级）；注入失败只影响入口卡片，不影响首页其它区块 |
| **可扩展** | 分区由 `SECTION_DEFS` 驱动，加类型只加一行；详情复用同一组件，PC/平板同源；将来平板双栏/分屏可在此基础上改 CSS |
| **文件位置** | 注入工具 → `src/utils/tabletMaterialsEntry.ts`（与 `materialsCreateEntry.ts` 同范式）；页面代码 → `mobile_materials.vue` 平板分支；响应式 → `material_detail.vue`；路由 → `src/router/index.ts` |
| **前端渲染** | 沿用主题变量 `--c1/--c2/--c-soft`；触控 44px 沿用 `(pointer:coarse)`；图片 `loading="lazy"`；不引入新依赖 |
| **后端字段** | 只用 `type/subject/is_favorite/video_url/cover_image/duration/read_time/summary/content/is_studied/progress_percent`（PC 页已在用，`_item_brief`/详情均有返回，零改动） |
| **路由** | 新增 1 条 `/tablet/materials/detail`；**不动** `DEVICE_ROUTE_MAP`（避免把 PC 链接改道），平板内部跳转显式写路径 |
| **闭环** | 列表 → 分区/网格 → 详情整页 → 收藏/标记已学（`reportProgress` 已有）→ 返回，全在平板内闭合 |
| **VTJ 一致性** | 不改 `.vtj/` 任何文件、不动 `@vtj/*` 版本；L6 版本锁定仍 8/8；`.vlj` 页面模板零改动（R3 合规） |

## 4. 验收标准（每条都跑脚本留证）

1. 768/1024：hero 下出现「入门讲解视频 / 深度拓展视频 / 备考指南」三段（无数据不显示），视频横滑可滚动
2. 勾选「只看收藏」→ 四段只剩 `is_favorite` 条目；无收藏时显示空态文案
3. 点视频 → 弹层内 `<video>` 有 `src` 可播；点文章 → 弹层有正文
4. 点「查看详情」→ `#/tablet/materials/detail?id=…&subject=…`，768 下无横向溢出、侧栏在正文上方
5. 平板首页 `.quick-actions` 出现「备考资料」卡片 → 点击进 `/tablet/materials`；刷新与 VTJ 重渲染后仍在（幂等）
6. 手机 390：仍是卡片栈 + 弹层详情，**20/20 不回退**
7. `gate_all` 10/10（页面路由 101、L6 101 同步）、vitest 全绿、vue-tsc 0

## 7. 实施结果（2026-11-02 实测）

### ① 视频 / 文章分区 + 只看收藏

| 项 | 实测 |
|---|---|
| 分区结构 | `blockCount=2`，标题 `🎬 入门讲解视频`、`📋 备考指南`，另有 `🃏 知识卡片`（网格） |
| 数据来源 | 逐 type 拉 `/api/materials?subject=&type=&page_size=50`（与 PC 完全一致），未新增端点 |
| 只看收藏 | 勾选后可见条目 `2 → 0`（当前库内无收藏），取消勾选回 `2` |
| 视频弹层 | `open=true`、`<video>` 存在、`src` 有值 |
| 文章弹层 | `open=true`、正文长度 `1331` 字 |
| 手机端 | 不渲染这些分区（仍是卡片栈），20/20 不回退 |

> **数据说明**：库内目前 `video_intro` / `video_advanced` **0 条**（实测 3 个科目都只有 `article` + `card`），
> 为验证视频分区与播放弹层这条 UI 路径，验收脚本用 **CDP Fetch 域 mock** 了一条视频（`id=999999`，
> 只作用于该次浏览器会话，不写数据库、跑完即 `Fetch.disable`）。截图 `05b`/`05d` 里带「(mock)」字样。

### ② 平板首页「备考资料」入口（DOM 注入，守 R3）

```
首页注入入口 {"present":true,"text":"📚备考资料卡片 · 指南","host":"quick-actions",
             "siblings":["智能组卷…","题库练习…","错题本…","模拟考试…","📚备考资料…"],
             "rect":[62,162],"gridCols":5}
点入口后路由 #/tablet/materials
```

- 注入位置：`.quick-actions`（VTJ 页 `tablet_home.vue:131`），与旁边 4 张卡同款 `.action-card` 样式
- 有入口时 `.quick-actions` 从 4 列自动变 **5 列**（`:has()` 规则），不会把第 5 张单独甩到第二行
- 幂等：`#tablet-materials-entry` 标记 + `hashchange`/`resize`/1.2s 定时 + `MutationObserver`（500ms 节流）兜底
- 判定纯函数 `shouldShowTabletMaterialsEntry()` 有 **8 条单测**（非平板/未登录/错角色/错路由/带 query/空 hash/教师/管理员）
- **`.vtj/vue/tablet_home.vue` 一行未改**
