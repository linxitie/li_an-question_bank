# 「平板与电脑用同一套页面」可行性分析与预期效果

> 版本：v1（2026-11-02）｜状态：**待你批准后实施**（AGENTS 规则②）｜分支 `feat/Study-Material-Management-r4`（`main` 未动）
> 你的要求：「平板端和电脑端使用同一套前端页面，所有布局均相同」
> 本文件的截图是**真实页面渲染**（平板视口 + 候选覆盖 CSS），不是画图：`docs/plans/assets/备考资料_平板PC同版预览/`

## 1. 结论：可行，而且代价比想象小

**电脑端页面在平板视口下版式本来就成立**——`知识卡片`用的是 `grid-template-columns: repeat(auto-fill, minmax(150px,1fr))`，768 宽自动落 3 列、1024 宽自动落 6 列，**横向溢出均为 0px**。
所以「同一套页面、同一套布局」不需要重做版式，只需要两件事：

1. **路由统一**：平板不再走 `/tablet/materials`（那是复用手机页的卡片栈），直接进电脑端的 `/materials/{科目}`；
2. **触控补齐**：5 个元素的点击高度只有 17–34px（返回首页 19、只看收藏 19、Excel 批量导入 34、＋创建卡片 34、收起 17），补到 44px 即可 —— **实测补完变成 0 个**，且**布局一个像素没动**（列数、卡片尺寸完全不变）。

## 4. 三种落地方案

| 方案 | 做法 | 优点 | 代价 |
|---|---|---|---|
| **A（推荐）** | 平板**直接使用电脑端路由**：`/tablet/materials` 改成 `redirect: '/materials/xingce'`；`/tablet/materials/detail` → `/materials/detail`；`/tablet/badges` → `/badges`；首页注入入口与「我的-离线下载」都指向 `#/materials/xingce` | 真正「同一套页面」，零复制（更符合 R12）；改动集中在路由 + 一处全局 CSS | 平板失去「科目 Tab 切换」，改成和电脑一样「回首页/顶部再选科目」；需要清掉平板专用页 |
| B | 保留 `/tablet/*` 路径，但组件换成 `.vtj/vue/materials_{科目}.vue`（3 条） | 路径仍是平板的 | 要新增 3 条路由 + 门禁数字再变，且与 A 的最终界面完全一样，属于多此一举 |
| C | 维持现状（平板专用网格页） | 无改动 | 与你的要求相反 |

## 6. 取舍与风险

| 事项 | 说明 |
|---|---|
| **科目切换** | 电脑端是三张独立页（`/materials/xingce`、`/shenlun`、`/gongzhuan`），没有科目 Tab。平板统一后同样没有 Tab —— 这是「与电脑完全一致」的必然结果。若你希望保留 Tab，需要在 PC 页 DOM 注入科目切换条（额外 0.5 天） |
| **平板专用页去向** | 现在 `/tablet/materials` 复用 `mobile_materials.vue` 的平板分支（hero + 网格 + 视频/文章分区）。统一后这段会被移除，**功能不会丢**：视频/文章分区 PC 页本来就有（更全，还有「收起/展开」与收藏） |
| **触控** | 电脑端若干链接只有 17–19px 高，必须补 44px；补法为全局 CSS，不影响 PC 鼠标端观感 |
| **R3 / R4 / R12** | 不动 `.vtj` 模板（R3）、不动 `device.ts`（R4）、不再有平板复制页（更符合 R12） |
| **回退** | 路由 3 行 redirect + 1 处全局 CSS + 1 处 script + 删平板分支，可整提交回退；`git revert` 单个提交即可 |
| **风险** | ①平板首页仍是 `tablet_home`（平板风格），点「备考资料」进电脑风格页面，风格有切换感 —— 若也要统一，需另议首页；②平板窄屏 768 下卡片刻字会更密（227×140 vs 手机卡片栈），需真机抽检可读性 |

## 7. 验收标准（8 条）

1. 平板 768×1024 打开 `/materials/xingce`：3 列网格、卡片 227×140、**溢出 0**、<44px 元素 **0 个**
2. 平板 1024×768：6 列、152×170、溢出 0、<44px 元素 0 个
3. 平板打开 `/materials/shenlun`、`/materials/gongzhuan` 同样正常（三科页同构）
4. 平板打开 `/materials/detail`、`/materials/upload`、`/badges`：与电脑同一页、溢出 0
5. 平板打开旧地址 `/tablet/materials`、`/tablet/badges`、`/tablet/materials/detail` → 自动 302 到电脑端路径（地址栏可见）
6. 平板首页「备考资料」入口 → 直接进 `#/materials/xingce`
7. 手机 390：仍是卡片栈 + 弹层详情，**20/20 不回退**
8. `gate_all` 10/10（页面路由数同步）、vitest 全绿、vue-tsc 0、`pc_desktop_regression` 7/7
