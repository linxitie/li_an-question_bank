## 1. 一句话结论

**答案可以按 PDF 上传了**：上传答案 PDF → 四层取答案（题号后直给 / 正确答案为X / 句尾结论 / 解析推断）→ 逐题核对 → 「确认写入」只动 `answer` 与 `answer_analysis` 两列。

实测三轮，最硬的一条证据是：**用解析器重算 4 套卷的答案，与库里已有的（人工核对过的）答案逐题一致** —— 2019 北京 100/100、2017 江苏 100/100、2024 国考 99/100（第 81 题只有推断建议，不自动填）。

## 2. 你拍板的 4 条，落地情况

| # | 决策（「按建议」） | 落地 |
|---|---|---|
| Q1 | 已有答案不同 → **默认保留** | `apply_draft` 计入 `kept`；仅 `overwrite=true` 才覆盖；抽屉底部有「覆盖已有答案」复选框 |
| Q2 | 推断层（L3）**只给建议不自动填** | `answer` 为空、`suggestion` 有值 → 表格里是「采纳 ABCD」按钮，点一下才变正式答案 |
| Q3 | 解析正文**一起入库** | `answer_analysis` 一并写（实测中位 255–344 字/题）；"没答案但有解析"的题单独计入 `analysis_only` |
| Q4 | **不做**按文件名自动匹配卷 | 入口就在具体那一行卷上（`paper_id` 显式传入）；题号不属于该卷 → 整份判失败并说明"多半传了别的卷的答案" |

## 4. 解析规则与两个实测坑

四层：`L0 题号后独立字母` → `L1 正确答案为X / 【答案】X` → `L2 故本题选X` → `L3 A项正确（仅建议）`。

| 坑 | 实测 | 修法 |
|---|---|---|
| **幻影题号** | 解析正文里的编号列表（`2.重点环节。1 控制场所…`、`3、创造警民协作新形式；4、…`）被当成题号 → 真实答案被顶掉 | 同题号出现多次**保留第一次**（真实题号行总在前） |
| **列举被吞** | `87、A、B、C 项：正确…D 项：正确` 被"题号后直给"读成 `A`（真实 ABCD） | ① 列举式开头（`A、B…`）不进 L0；② 推断层支持成串写法（`A、B、C 项：正确` → ABC）；③ **题型×字母数**交叉校验兜底 |

**题型交叉校验是本轮最有价值的一条**：单选应 1 个字母、多选应 ≥2；不符即标「题型冲突」、默认不写入。2017 江苏 #87 就是它抓出来的（现在解析结果 `ABCD`，与库里一致）。

```
  与库里一致 100 题｜冲突 0｜需人看 0｜无答案 0
GZ-2024-GK-T（卷 #4｜100 题）  解析 100，层级 {L0:99, L3:1}
  与库里一致 99 题｜需人看 1（#81 仅推断建议）
```

**HTTP 全链路（2017 江苏那份真 PDF）**：

```
[1] 解析 status=200 ok=True items=100 conflict=0 empty=0  message=识别 100 题 / 卷共 100 题
[2] 明细 items=100 paper=GZ-2017-JS-T
    #  1 单选 答案=C 层级=L1 库中=C
    # 87 多选 答案=ABCD 层级=L1 库中=ABCD     ← 列举坑已修好
[3] 可直接填空位 0｜与库里一致 100｜冲突 0
[4] 续传入口 exists=True draft=1 status=pending
[5] 放弃草稿 200 → discarded（不留待办）
```

（识别答案 100/100、需确认 0、无答案 0、`确认写入 100 题`、底部「覆盖已有答案」未勾选）

## 8. 已知边界

1. **不自动匹配卷**（Q4）：47 份答案 PDF 里目前只有 4 份能对上现有卷；扩容后再做"批量匹配 + 人工确认"。
2. **扫描版 PDF** 仍需 OCR，本轮不支持。
3. 答案只认 A–D 四选一；判断/多选超四选项的来源暂时吃不下。
4. 同题号重复（幻影）保留第一次是启发式 —— 若某份答案真的把题号写乱了，会在"题号不属于该卷/缺号"处暴露，不会静默错位。
