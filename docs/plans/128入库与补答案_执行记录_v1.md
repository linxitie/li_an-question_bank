## 2. 我自己的一个失误（已修，说明一下）

导题草稿里第 97 题被标了「有图待核对」（两张 592×201 / 535×201 的图）。我在界面上给你演示过"这两张是二维码/水印，删掉再入库"，
但**实际入库时是直接调接口确认的，没走那一步手动删除** → 两张图被复制进
`app/static/questions/397/` 并写进第 97 题题干 HTML，学生能看到广告。

发现后立即处理：

```
清理前图片: ['/static/questions/397/q397_docx_1.jpeg', '/static/questions/397/q397_docx_2.jpeg']
已从题干移除 2 张图；删除物理文件 2 个
清理后图片: []
清理后题干: 公民、法人或者其他组织对公安机关的下列具体行政行为不服的，可以提起行政复议的是（）。
integrity: ok
```

只动这一题的 `question_content` 与那两个文件；题干文字、选项、答案、解析均未变。
**教训**：以后凡"草稿里带「有图待核对」"的题，确认入库前必须先处理图片，不能只靠接口确认。
