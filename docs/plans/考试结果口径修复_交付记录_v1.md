## 1. P0：把"数"交出来，别让前端猜

### 后端（`app/api/v1/exam/exams.py` 交卷端点）

`data` 新增 4 个字段 + 逐题结果：

```json
{
  "correct_count": 2, "wrong_count": 0, "unanswered_count": 95,
  "question_total": 97, "answered_count": 2,
  "scored_count": 2,
  "time_used": 11,
  "details": [
    {"question_id": 301, "student_answer": "D", "correct_answer": "D",
     "is_correct": true, "score_obtained": 1.0}
  ]
}
```

口径（互不重叠，三者相加 = 总题数）：

| 字段 | 定义 |
|---|---|
| `correct_count` | `is_correct == 1` |
| `wrong_count` | `is_correct == 0` **且有作答**（空白不算"错误"，归未答） |
| `unanswered_count` | `question_total - answered_count` |

> `scored_count` 保留但**语义不变**（参与评分题数），并在注释里写明 —— 之前的 bug 就是把它当答对数。

### 前端（`.vtj/vue/paper_answer.vue`，只改 `<script>`/`<style>`）

- 逐题状态：`isCorrect(q)` → 查交卷回包 `details` 映射；新增 `reviewLabel/reviewClass/reviewAnswerHint`；
- 正确选项高亮：`isCorrectOption` 改用 `details[].correct_answer`（多选按逗号切分）；
- 弹窗：四个格子分别读 `summary`（得分 / 得分率 / 正确-错误 / 用时），不再用 `scored_count`。

## 8. 追加修复（2026-11-11 你第二次复测）

**现象**：答对 2 题、交卷后回到「历年试卷」，卡片仍显示「🏆 得分: **0 / 97**」。

**根因**（`.vtj/vue/student_papers.vue` 的 `loadUserProgress`）：

```js
// 改前：每一条「已完成」记录都会覆盖前一条
if (!progress[pid] || r.is_completed) { progress[pid] = { score: r.total_score, ... }; }
```

接口 `/api/exams/records` 按 `create_time DESC` 返回 → **循环最后落进 `progress` 的是最老那条**
（record #1，11-09 那场 0 分），于是刚考完的 #2/#3（2 分）被覆盖。

**修法**：抽成纯函数 `pickLatestProgress(records)`（`src/utils/examSummary.ts`），
口径 = **已完成优先于未完成；同类取 `record_id` 最大（最近一次）**；
页面只调它，不再自己写循环。另配 4 条单测（倒序不覆盖、未完成不盖已完成、全未完成取最新、多卷隔离）。

**验证**：DOM 实测卡片文本 `🏆 得分: 2 / 97`、状态「已完成 ✓」；`examSummary.spec.ts` **12 passed**。
