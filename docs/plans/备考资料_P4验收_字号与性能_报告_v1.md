# P4 残余验收报告 v1（字号三档 + 性能）

> 时间：2026-10-30　工具：`scripts/verify/p4_acceptance.mjs`（CDP，登录态真跑）
> 结论：**6 项断言全部 PASS**；需求(5) 三端适配从 85% → 100%

## 1. 字号三档（手机端 `.vtj` 手机卡片页，真实登录态）

| 档位 | 实测字号 | `--sm-font-scale` | 截图 |
|---|---|---|---|
| A- | **11.7px** | 0.9 | `字号_Aminus.png` |
| A（基准） | **13px** | 1 | `字号_A.png` |
| A+ | **14.95px** | 1.15 | `字号_Aplus.png` |

判定：A- < A < A+ 严格递增；A-/A=0.900、A+/A=1.150，与设计值完全一致（容差 0.05/0.06 内）。

## 2. 性能（PC 资料页 `/#/materials/xingce`，1440×900）

| 指标 | 实测 | 目标 | 结论 |
|---|---|---|---|
| 首屏 FCP | **36ms** | ≤ 2000ms | ✅ 远优于目标 |
| DOMContentLoaded | 273ms | — | ✅ |
| load | 282ms | — | ✅ |
| 资料列表接口 | 10–25ms | ≤ 800ms | ✅ |
| 翻页动画帧率 | **62fps**（800ms 采样 50 帧，最大间隔 17ms） | ≥ 50fps | ✅ |

> 说明：以上为本机 dev server + 本地 SQLite 的实测值，属"下限参考"；真机 + 生产构建会不同，但**接口耗时与动画帧率离阈值仍有很大余量**。

## 3. 方法

`p4_acceptance.mjs` 通过 CDP：
1. API 取 token → 写 `__VTJ_AUTH_STATE__` → 调 `window.__VTJ_AUTH__.login()` 同步内存态（与登录页契约一致）
2. 手机视口进 `#/mobile/materials`，依次点 `A- / A / A+`，读 `.card-text` 的 computedStyle 与 `.stack` 的 CSS 变量，每档截图
3. PC 视口进 `#/materials/xingce`，读 `performance.getEntriesByType('navigation'|'paint'|'resource')`
4. 点「下一张」触发翻页动画，用 `requestAnimationFrame` 采样 800ms 统计帧率与最大帧间隔

## 4. 复现

```powershell
# Chrome 带调试端口启动后
node scripts/verify/p4_acceptance.mjs
# 产物：docs/plans/assets/备考资料_P4验收/（3 张字号图 + 1 张资料页 + _report.json）
```
