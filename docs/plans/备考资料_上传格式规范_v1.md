# 备考资料 · 上传格式规范 v1（需求 3「严格的文档内容格式」）

> 状态：已实现（校验器 `backend/app/services/material_format_validator.py`）
> 适用：管理员导入（xlsx/csv）· 学生端上传（xlsx/csv，待 P2-C 开通）
> 与专利：本规范 + 校验器 + 分类机制，是《文档格式规范化与系统分类机制》交底书的主体

## 1. 两条上传通道

| 通道 | 入口 | 默认状态 | 校验强度 |
|---|---|---|---|
| 管理员导入 | `POST /api/materials/admin/import/upload` → `.../confirm` | 下架态（`status=0`），可 `publish=true` 直接上线 | 整表阻断 + 行级跳过 |
| 学生上传（P2-C） | `POST /api/materials/my/upload` | 待审（`status=0`） | 整表阻断 + 行级跳过 + 配额 |

## 2. 表头规范

必需列（缺一即整表拒绝）：

| 列 | 允许的表头写法 | 上限 |
|---|---|---|
| 正面 | `正面` / `卡片正面` / `题目` / `问题` / `front` | 120 字 |
| 背面 | `背面` / `卡片背面` / `答案` / `解析` / `内容` / `back` | 600 字 |

可选列：

| 列 | 允许写法 | 说明 |
|---|---|---|
| 分类 | `分类` / `子类` / `类别` / `category` | 必须是该科目 `sub_categories` 词表内的子类；留空由系统自动分类 |
| 考点 | `考点` / `知识点` / `point` | 必须是 `knowledge_point` 里的考点名；写错只警告，由自动分类兜底 |
| 难度 | `难度` / `difficulty` | 1–3 |
| 封面 | `封面` / `配图` / `cover` | 图片 URL 或已上传文件名 |

文件级上限：仅 `.xlsx` / `.csv`；≤ 10MB；单次 ≤ 200 行（`ROW_LIMIT`）。

## 3. 错误码（前端可直接标红单元格）

| 码 | 含义 | 处理方式 |
|---|---|---|
| E001 | 缺必需列 | **整表拒绝**，提示需补哪一列 |
| E004 | 行数超上限 | **整表拒绝**，提示拆分 |
| E009 | 扩展名不支持 | **整表拒绝**（上传阶段） |
| E010 | 文件超 10MB | **整表拒绝**（上传阶段） |
| E002 | 必填单元格为空 | 跳过该行，记入 `invalid_rows` |
| E003 | 正面 >120 或背面 >600 字 | 跳过该行 |
| E005 | 文件内重复行 | 跳过该行 |
| E008 | 含 `script/iframe/object/embed/style` | 跳过该行 |
| E006 | 分类不在词表 | 导入场景降级为**警告**（回退自动分类）；学生上传场景仍阻断 |
| E007 | 考点不在考点表 | **警告**，由自动分类兜底 |

> 设计取舍：`E006/E007` 是"标签写错"，不是"内容坏掉"。批量导入若因此整表失败，教师会被卡死；所以导入场景降级为警告并在响应 `warnings` 里回传行号与原值。交互式建卡仍严格 400，让用户当场改。

## 4. 响应示例

```json
{
  "created": 18,
  "invalid_rows": [7, 19],
  "skipped_count": 4,
  "warnings": [
    {"code": "E006", "row": 12, "column": "分类", "message": "分类「方法技巧」不在本子类词表内；可留空由系统自动分类"}
  ]
}
```

## 5. 与分类机制的关系

```
表格(正面/背面/分类/考点)
   → 校验器（本规范，E001–E010）
   → 分类收敛 _resolve_classification（显式 > 两级自动分类 > 空）
   → 落库 study_material(category, point_id)
```

自动分类规则 110 条（16 子类 + 94 考点），标题优先、全文兜底、命中数+优先级计分；
考点命中时自动带出父类子类，因此"只写考点不写分类"也是完备输入。

## 6. 验收标准

1. 缺「背面」列 → `400`，错误信息含 `E001` 与"背面"
2. 第 7 行正面为空 → 该行跳过，`invalid_rows` 含 7，其余行正常入库
3. 分类列写「方法技巧」→ 不阻断，`warnings` 含该行且实际入库分类为自动判定结果
4. 201 行 → `400` 且提示拆分
5. 单测：`tests/test_material_format_validator.py`（18 项）
