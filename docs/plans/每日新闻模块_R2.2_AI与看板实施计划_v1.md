# 每日新闻模块 R2.2 AI 与审核看板实施计划 v1

> 状态：实施中（2026-11-01）
> 分支：`feat/news/r2-ai`
> 前置：R2.1 采集已合并（`09966f5`）

## 1. 范围

- 新闻 AI 摘要（100 字内）；
- 申论考点/官方表述；
- 人物/机构/政策/地域实体；
- 硬合规规则 + 模型风险提示；
- Obsidian 新闻审核卡片与时效性看板；
- 真实处理 5 条已采集新闻。

## 2. 不做什么

- 不做新闻自动发布（必须人工审核）；
- 不接多模态图片描述（R2.4）；
- 不做新闻审核勾选回写（R2.3）；
- 不接向量/图投影（R2.4）。

## 3. 设计

| 项 | 实现 |
|---|---|
| 模型调用 | `llm_client._post`（OpenAI 兼容，修复完整端点重复拼接） |
| 输出 | summary/exam_points/official_phrases/entities/risk_flags/confidence |
| 硬风险 | 暴恐/颠覆/涉密等规则直接 `high_risk` |
| 软风险 | 时效/来源/标题提示只存 `ai_risk_flags`，不自动拒绝 |
| 存储 | `news_article.ai_*` 字段；原文/图片仍为 SoT |
| 看板 | `00-收件箱/新闻/<date>/news_XXXXXX.md` + `时效性看板.md` |

## 4. 验收

- 5 条新闻 AI 摘要/考点/实体全部落库；
- 硬风险测试可将 `review_status` 置 `high_risk`；
- 软风险不改变 pending；
- Obsidian 生成 5 张卡片 + 时效性 index；
- `pytest tests/test_news_ai.py` 通过；L0 7/7。
