## 2. 「我的徽章」页结构（对照效果图 1）

```
┌ 顶栏：返回 | 我的徽章 | 成长 ─────────────────────────────┐
│ ① 档位卡：当前档位大徽章 + 「累计积分 780 · 距钻石还差 20 分」  │
│     + 五段刻度进度条（0/200/400/600/800）+「钻石不封顶」提示     │
│ ② 筛选行：类型（全部54/成就48/称号6/科目0/稀有0）               │
│          品质（全部/黑铁/青铜/白银/黄金/钻石）+ 排序            │
│ ③ 徽章网格：5 列 × N 行，每卡 = 徽章 + 名称 + 「类型·品质」+ 状态 │
│ ④ 分页：上一页 / 第 1 / 3 页 · 共 54 枚 / 下一页               │
└──────────────────────────────────────────────────────────┘
```

### 2.1 三种卡片状态（同一组件）

| 状态 | 视觉 | 文案区 |
|---|---|---|
**已获得** | 正常渐变徽章 | 名称 + `类型 · 品质` + 绿色状态（`已获得` / `780 / 780`） |
**进行中** | 降饱和（保留 28% 色相）+ 半透明 + 进度百分比覆盖 | 名称 + 品质 + 橙色 `进度 62%` / `进度 21/30` |
**未解锁** | 降饱和 92%（近灰）+ 半透明 + **矢量锁图标** | 名称灰化 + 灰色 `未解锁` |

> 实现注意（画图时踩过）：灰化**必须保留原 alpha**，直接用 `convert("L")` 会得到一个灰方块。

### 2.2 筛选与排序

- 类型 chips：`全部 54 / 成就 48 / 称号 6 / 科目 0 / 稀有 0`（阶段一后两者为 0，仍展示以表达规划）
- 品质 chips：`全部 / 黑铁 / 青铜 / 白银 / 黄金 / 钻石`
- 排序：最近获得（默认）/ 品质高低 / 稀有度
- 状态筛选并入类型 chips 之外的「状态」选项（全部 / 已获得 / 进行中 / 未解锁）

## 3. 徽章详情弹层（对照效果图 2 左侧）

| 区块 | 内容 | 数据来源 |
|---|---|---|
头部 | 大徽章（220px）+ 名称 + 品质 chip + 类型 chip | 徽章目录 |
条件 | 「连续学习 30 天，且累计积分 ≥ 800」 | `achievement.condition_desc` |
时间 | 获得于 `2026-10-20 21:36` | `user_achievement.obtained_at` |
四行信息 | **获得时档位（快照）** / **当前档位（实时）** / 奖励（金币+成长值） / 全站稀有度（前 3%，共 1,204 人） | 快照字段 + 实时计算 + 统计 |
档位进度 | 五段进度条（钻石档显示「已满，积分继续累积」） | 累计积分 |
提示条 | 「档位随积分实时提升；已达成的徽章不会因积分变化而降级」 | 固定文案 |
动作 | 分享这枚徽章 | 复用分享能力 |

**关键设计**：同时展示**获得时档位快照**与**当前档位**，避免"我原来是钻石怎么变白银了"的争议。

## 4. 个人主页徽章墙（对照效果图 2 右上）

- 位置：个人主页「成长」区域，一屏 6 枚，单行横排
- 只显示**已获得**徽章（未获得不占位，避免空槽观感）
- 右上「查看全部 →」跳「我的徽章」页
- 可在「我的徽章」页把任意徽章**设为精选**（最多 6 枚）

## 7. 待确认

1. 层级：徽章页放在 **成长中心** 下，还是独立一级菜单？（建议独立：`#/badges`）
2. 排序默认值：**最近获得** 是否合适？还是默认「品质高低」更能激励？
3. 稀有度文案是否需要（"前 3% / 共 1,204 人"）？需要则要加统计接口。
4. 分享徽章：复用现有分享能力，还是先只做"复制文案"？
