## 7. AI 讲师方案（11-05 暂停，现向你汇报）

> 全部材料在仓库里（`docs/plans/AI讲师*` + `docs/superpowers/specs/AI讲师知识库_迁入Obsidian与知识供给_报告_v1.md`），索引见 `docs/README.md`。
> 一句话：**把「AI 讲师视频」做成由讲稿 JSON（DSL）驱动的网页交互微课**——讲师、板书、场景、公式动画都是 SVG/CSS；讲到检查点自动暂停、右侧弹出选择题，对错各有动画；同一套播放器以后直接吃「题目/资料卡」生成的脚本，这就是底座。

### 7.1 已拍板的 3 件事 + 不是什么事

| 决策 | 结论 |
|---|---|
| 交付形态 | **A 网页交互播放器**（不做数字人、不做真人合成） |
| 知识点来源 | 知识库（87 知识点 / 403 考点 / 12 个试点），不再等你手写 |
| 形象 | **另定**（先参数化 SVG 草案：卡通女性、深蓝发、绿衣） |
| 不是什么 | 不是数字人视频、不是真人录屏、不是长视频切片、不是 LLM 现场对话 |

### 7.2 内容模型：讲稿 DSL `lecture/1.0`

```
meta{subject,title,total_sec,avatar,style,audio}
segments[]:
  intro / concept / demo / scene / checkpoint / summary
  每段: speech(≤400字) + board[](≤6条) + avatar{gesture,expression} + scene{kind,...} + duration(5-60s)
checkpoint.question{stem,options[],answer,analysis,wrong_hint}
```

- 动作 7 类：`idle/wave/point_board/point_scene/open_hands/count/think`；
- 表情 5 类：`neutral/smile/serious/surprise/encourage`；
- 场景 5 类：`board/formula/police/flow/compare`（后两类是看桐哥视频后补的：程序流程图、新旧法对照表）；
- 校验：JSON Schema（构建期 + 运行时）；坏脚本**拒绝播放并降级为图文讲稿**，不白屏。

### 7.3 讲解方法论（要求②③的答案）

- **微课 7 段式**（时长占比）：引入 10% → 定义 15% → 拆解 30% → 例证/场景 20% → 易错 10% → 检查点 → 小结 10%；
- **5 条拆解规则**：一句一个动作、要点 3–6 条成组、先具体后抽象、每 60–90 秒一个锚点、检查点放在"刚讲完"处（≤3 分钟 1–2 题，3–6 分钟 2–4 题）；
- **与桐哥四步对照**：intro=条文定位、concept=要件拆解、demo=程序时序、scene=对比与陷阱；
- **动作触发词库**（7 类语义标签 → 动作/表情），讲稿只写语义，播放器负责映射。

### 7.4 视觉与交互

- 1920×1080 设计 + **四周 96px 安全边距**；标题 56–72 / 正文 40–48 / 注释 ≥32；≤3 色；页脚「模块名 · 考点 ID · 页码」；动效 200–400ms、同屏 ≤2 元素；
- 播放器状态机：`idle → playing → paused_dim → answering → feedback_correct | feedback_wrong → resume → ended`；
- 三端：≥1024 左 2/3 讲解 + 右 1/3 题目；768–1023 面板 320px；<768 上下堆叠（题目下面抽屉）；
- 检查点：数量不限、位置由脚本定（`after_point_N` / `segment_end` / `time:x`）、**答错不扣分不阻断**、每题埋点；
- 反馈动画：答对烟花 + 大对勾水印；答错「继续努力」弹入 + 抖动 + 答案解析；`prefers-reduced-motion` 静态降级。

### 7.5 数据供给（真正让内容"长出来"的那层）

- **三层键**：`point_id` 87（`GZ-JC-010` 这种，冻结 + 墓碑）→ `topic_id` 教学切片（`…-T04`）→ `exam_point_id` 403（`…-E03`，序号而非名字，因为 86 个考点都叫「其他」）；
- **关键实测**：12 个试点里 **8 个在 87 知识点里没有节点**（立案/管辖/回避/传唤/听证/当场处罚/处罚执行/新旧法对比），所以必须有 topic 层，否则「一个知识点=一节微课」要讲 30 分钟；
- **可讲清单**每单元 5 个字段全部由数据算（`lectureable/granularity/tier/coverage/est_minutes`），不许手填；
- **产物**：`lecture_source.json`（事实层，含 `sources[].sha256` 自证）+ 人读清单 md + 冻结 ID 表；生成器 `scripts/lecture/build_lecture_source.py`（`--build/--check/--stats`，只读、确定性、GBK 控制台安全）；
- **播放器只认 DSL**：清单 / 题目 / 资料卡三种来源最终都产出同一个 `lecture_script.json` → 这就是"底座"。
