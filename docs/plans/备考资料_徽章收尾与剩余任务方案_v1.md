## 3. 完成顺序与依赖

```
P5 徽章收尾 ──► F1/F2 分类回归 ──► C1/C2 配图与抽检 ──► S1/S2 科目说明抽检
   │(0.5d)         │(0.5d)              │(0.5d)               │(0.3d)
   ▼               ▼                    ▼                     ▼
 效果图验收      F3 专利交底书 A ──────► M1/M2/M3/M4 三端残余 ──► P7 交付（D1–D4）─► D5 合并(待批)
                (0.6d 写作)             (0.6d)                  (0.8d)
```

**为什么这个顺序**
1. **P5 先做**：它只依赖已完成的徽章数据契约，改动面最小，且能立刻出效果图验收——最短反馈环。
2. **F1/F2 紧跟**：分类是所有内容的"索引"，配图卡与抽检都要按分类核对，先修索引再验内容。
3. **F3 专利写作放在 F1 之后**：交底书的"实施例"需要 F1 的准确率数据支撑，先有数据再写，避免空话。
4. **M1–M4 放后**：三端验证是"全量回归"，内容定稿后再验一次即可，避免反复。
5. **P7 最后**：交付与合并必须等全部绿灯；D5 合并单独等你批准。
