## §1 #1 AI 标题

### 1.1 数据与接口

| 项 | 内容 |
|---|---|
| 新列 | `forum_post.ai_title TINYINT DEFAULT 0`（幂等 ALTER，与既有迁移段同处） |
| 判定条件 | `title in ('', '(无标题)')` **且** `content` 非空（去掉标签后仍有文字） |
| 服务 | `backend/app/services/forum_title_ai.py`：`generate_forum_title(content) -> str | None` |
| 创建时 | 标题为空且有正文 → `BackgroundTasks` 后台生成，**不阻塞发帖**；成功则写 `title` + `ai_title=1` |
| 回填 | `POST /api/admin/forum/ai-titles/backfill?limit=10`（管理员）：处理 `limit` 条（上限 50），返回 `{processed, generated, skipped, errors}` |
| 序列化 | 新增 `aiTitle: bool` |

### 1.2 Prompt 与清洗

- 约束：≤18 字、单行、不带引号/序号/「标题：」前缀、不加 emoji。
- 清洗：去首尾引号与空白、压平换行、超 200 字截断（仍受既有标题长度约束）。
- 内容输入：若 `content_format='HTML'` 先剥标签再喂给模型，避免把标签当正文。

### 1.3 成本与安全

- 只有管理员能触发回填；单次上限 50 条，避免一次烧掉大量 token。
- **不覆盖已有标题**，只填空标题；生成失败只记日志、不改数据、不重试（避免放大成本）。
- AI 结果按普通标题处理：仍过长度校验，仍走纯文本渲染（不引入 HTML 面）。
- **阻塞点**：`LLM_API_KEY` 当前为空，需要你在 `backend/.env` 里填（按项目规则，密钥由你本人填写，我不经手值）。

### 1.4 前端展示

- `aiTitle` 为真时，标题前显示前缀（文案见 D1）。
- 覆盖位置：帖子列表、帖子详情、收藏/热门/我的弹窗、管理员抽屉、教师端列表与详情。

## §2 #2 点赞 / 收藏特效

| 现状 | 问题 |
|---|---|
| 列表爱心 `.heart-icon` | 有动画，但幅度过小 → 感知不到 |
| 列表收藏星（`XIcon`） | 无任何动画类，选择器打空 |
| 详情弹窗 / 评论点赞 | 无动画 |

修法：

1. 动画挂到**容器**上而不是图标节点：`.meta-likes.active` / `.meta-favs.active`，
   容器加 `::after` 做「扩散光圈」（`box-shadow` + `scale`，420ms）以提升可感知度。
2. 图标本体放大到 `1.6`（爱心）/ `1.4 + 旋转`（星星），320–360ms。
3. 详情弹窗、评论点赞、教师端同款容器加上同一套类名与样式。
4. `prefers-reduced-motion: reduce` 继续关闭。

验收：Playwright 分别点爱心与收藏星，断言 `getAnimations()` 非空且 `animationName` 命中，
并截图对比（光圈在 100ms 时最明显）。

## §3 #3 草稿保存

### 3.1 根因

```
openNewPost() {
  this.state.showNewPost = true;          // ① 先开弹窗（此时 initial = null）
  fetchMyForumDraft().then(draft => {      // ② 草稿异步到达
    this.state.postDraftInitial = {...}    // ③ 但组件只 watch visible，不会因 initial 变化而回填
  })
}
```

实测：保存成功、toast 出现、关闭再打开标题为空 → 用户视角就是「存了没用」。

### 3.2 修法

- `PostComposer` 增加 `watch(() => props.initial)`：`visible` 为真且 `initial` 变化时回填一次。
- 用 `initialKey`（如 `updateTime` 或自增序号）去重，避免同一草稿反复覆盖用户正在输入的内容。
- 三端共用组件，改一处即都生效（学生 / 教师 / 管理员）。
- 补一条 e2e：填标题+正文 → 存草稿 → 关闭 → 重开 → 断言回填内容一致。

### 调试中发现的两个真问题（都不是功能 bug）

1. **上一轮特效「没生效」的原因已确认**：收藏星是 `XIcon` 组件，没有 `.star-icon` 类，
   旧选择器打空；爱心动画虽在跑但幅度太小。本轮改为容器级动画。
2. **e2e 定位器陷阱**：`locator('.meta-likes:not(.active)')` 在点击后会解析到**下一个**元素，
   导致断言读到别的节点。改用 `elementHandle()` 固定元素后通过。
