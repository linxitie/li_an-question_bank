## 1. C1：讲义大纲（章节树 + 字数）

### 1.1 做法

| 层 | 内容 |
|---|---|
| 抽取 | `services/doc_outline.py`：docx → `{word_count, chapter_count, chapters:[{level,title}]}`。优先 Word **Heading 样式**；无样式时退而识别「第X章/第X节/一、」编号行；两者都没有 → 只给字数、`chapters=[]`（**不编目录**） |
| 存储 | `study_material.doc_meta`（JSON 文本，启动期自动补列）——存快照，列表不必逐行解析 docx |
| 写入时机 | ①`POST /admin/files/upload` 落档后（primary 且 docx）；②导入确认落档后（`file_type=docx`）；③存量用 `scripts/backfill_doc_outline.py` 回填 |
| 预览 | `chapters` 从占位 `[]` 变成目录树；新增 `doc{word_count, word_count_label, chapter_count}` |
| 列表 | 每行返回 `chapter_count` / `word_count`；讲义行副标题显示 `3 章 · 120 字` |
| UI | 抽屉「章节（N）· 共 M 字」+ 两级目录（一级加粗、二级缩进）；元信息行加「字数：120 字」 |

### 1.2 实测

```
讲义列表：121 | 04_讲义_正常 | 3 章·120 字
          122 | 2026公专样章 | 1 章·57 字
          123/124 | 同名资料 | 1 章·87 字
121 预览：doc = {word_count:120, label:"120 字", chapter_count:3}
          chapters = [(1,'第一章 行政执法程序'), (2,'1.1 传唤'), (2,'1.1.1 要件')]
抽屉：字数：120 字 ｜ 章节（3）· 共 120 字 ｜ is-lv1 / is-lv2 两级渲染
回填脚本：5 条讲义（121/122/123/124/127）→ 已写入
```

截图：`docs/plans/assets/资料管理v3/C1_01_讲义目录与字数.png`

### 1.3 两个坑

1. **正则 `\b?` 非法**：`re.compile(r"...\b?")` 直接抛 `PatternError: nothing to repeat`（`\b` 是零宽断言）。
2. **「第X节」被当成「第X章」**：`RE_CHAPTER` 的字符类里含「节」，先匹配就走错分支 → 单测断言 `[1,1,2] != [1,2,2]` 抓到。
   修法：`RE_CHAPTER` 只留 `[章篇部]`，并且**先判节再判章**。

## 2. 删原件（C2b 补漏）

### 2.1 做法

| 层 | 内容 |
|---|---|
| 接口 | `DELETE /api/materials/admin/{material_id}/files/{file_id}`（`_require_admin`；R11 白名单 +1，基线仍 343） |
| 服务 | `material_files.delete_file()`：删登记行；**同一 sha256 没有别的资料引用时**才删物理文件（内容寻址下多资料可共用一份文件）；物理删除失败只记日志不阻断 |
| 返回 | `{ok, deleted:{physical_deleted, still_used_by_others}, files:[剩余原件]}` |
| UI | 「改信息」的原件行加「删除」按钮 + 二次确认（明确写"不可恢复；若仍被其它资料引用，物理文件会保留"）；成功后原地刷新原件列表 |

### 2.2 实测（活体，净零变更）

```
上传临时 pdf → material 126：#8 落盘 ef/ef9067….pdf
DELETE → 200 {"physical_deleted": true, "still_used_by_others": false}，剩余 0
物理文件仍存在：False          ← 真的清了盘
126 预览原件数：0
```

截图：`docs/plans/assets/资料管理v3/C1_02_改信息_删原件入口.png`

## 4. 现在能用它干什么

1. 讲义列表一眼看出规模：`3 章 · 120 字`（未解析的显示「未解析大纲」，PDF 讲义就是这种）。
2. 抽屉里直接看目录，点进讲义不用盲翻。
3. 「改信息」→ 原件行「删除」：误挂的文件可以单独删（含物理清理）。
4. 存量讲义补大纲：`python backend/scripts/backfill_doc_outline.py [--apply] [--force]`（默认 dry-run）。

## 5. 遗留

| 项 | 说明 |
|---|---|
| **PDF 没有大纲** | 只对 docx 抽（PDF 无样式信息，硬抽误报率高）。要支持得接 OCR/版面分析 |
| **章节无锚点跳转** | 目录只展示标题，不能点击跳正文（需要给正文加锚点 id，等正文渲染方案定了再做） |
| **C3 筛选** | 年份/地区筛选仍未做（`paper_meta` 已就绪） |
| **P5 上下架联动** | `exam_paper.paper_type` 同步仍是待决策项（写 exam 域会撞模块边界门禁） |
| 批量改信息 / 批量删原件 | 未做 |
