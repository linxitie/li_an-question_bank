## §1 学生手机端改造（第 1 条）

### 1.1 现状
- `.vtj/vue/mobile_forum.vue`（raw 页，改 template 需授权）：顶部 `.nav-right` 有「+」按钮 → `createPost()`；右下 `.fab-button` 也是发帖。
- 帖子卡底部：`浏览 / 评论 / ★收藏数`，**没有爱心**；没有「我的喜欢」入口。

### 1.2 方案
1. 顶部「+」→ 改为「⭐ 收藏/喜欢」按钮，样式沿用现有按钮（不改布局）。
2. 点击弹出**底部抽屉式弹窗**（手机上比居中弹窗好用）：
   - 顶部两个 tab：我的收藏 / 我的喜欢（与 PC 一致）
   - 列表项：标题（带标题色）+ ❤数 + ⭐数，点击进详情
   - 空态：还没有收藏/喜欢的帖子
3. 帖子卡底部：把 `★收藏数` 拆成 **♡/❤（喜欢）+ ★（收藏）** 两个可点按钮（与 PC 语义一致）。
4. 发帖入口保留右下角 FAB（截图里铅笔图标那个），并在弹窗关闭后不消失。

### 1.3 风险
- 顶部「+」被替换后，**必须确认 FAB 发帖仍可用**（截图显示右下有两个 FAB：铅笔 + 加号，需在真机确认加号那个是否也是发帖）。
- 若 FAB 也失效，需保留「+」并把「收藏/喜欢」放到「我的」页入口。

## §2 教师端评论输入框对齐（第 2 条）

统一为 **一行 40px**：

```css
.tf-comment-input { display:flex; align-items:center; gap:8px; }
.tf-comment-textarea { flex:1 1 auto; min-height:40px; height:40px; resize:vertical; }
.tf-icon-btn { width:40px; height:40px; }
.tf-comment-input .tf-btn { height:40px; }
.tf-comment-input :deep(.fu-add) {
  width:36px; height:36px; padding:0; border-radius:50%; font-size:0;
}
.tf-comment-input :deep(.fu-add::before) { content:'+'; font-size:18px; }
```

与 PC 学生端评论区已经验证过的写法一致（v1.2 方案），不新造样式语言。

## §4 教师端「我的收藏 / 我的喜欢」+ 点赞收藏（第 3 条后半 + 第 4 条）

| 项 | 方案 |
|---|---|
| 入口 | 头部「发布新帖」左侧加两个同尺寸按钮（与 PC 学生端一致） |
| 弹窗 | 复用学生端的两个 tab 结构（收藏/喜欢），数据来自 `/api/forum/my-favorites`、`/api/forum/my-likes` |
| 卡片交互 | `.tf-actions` 左侧加 ❤（喜欢）与 ⭐（收藏）；点击调 `/like`、`/favorite`，即时更新计数与高亮 |
| 权限 | 两个接口都是"本人操作"，教师 token 可直接用，无需新后端 |

**注意**：教师端卡片是"管理视角"，点 ❤/⭐ 不应触发展开详情 → 按钮必须 `.stop`（与本轮整卡点击改动配套）。

| 8 | 教师：「我的收藏/我的喜欢」弹窗能列出刚收藏/点赞的帖子 |
| 9 | 基线：typecheck 63/9；vitest 28/362；forum pytest 全绿 |
