# 资料内容格式与分类规范 v2（卡片 / 讲义 / 试卷三类）

> 日期：2026-11-05　｜　状态：✅ **已冻结（T0.1，2026-11-05 批准）**（当前仓库里只有「卡片」一类有规范，讲义与试卷是空白）
> 回答你的问题：**卡片这条已严格闭环；讲义/试卷两类此前没有任何格式规范，分类机制也只对卡片有效**。本文把它们补齐，作为 P0 的前置任务 T0。
> 前身：`备考资料_上传格式规范_v1.md`（只覆盖 Excel 卡片）、`专利交底书A_文档格式规范化与分类机制_v1.md`

## 0. 现状对照（必须先承认的缺口）

| 资源 | 有没有"严格格式规范" | 有没有"可机检校验" | 有没有"分类机制" |
|---|---|---|---|
| 资料卡片（xlsx） | ✅ v1 规范：5 列表头 + E001–E010 | ✅ `material_format_validator.py`（blocking / row 两级） | ✅ 110 条规则 + 两轮自动分类（30 样本回归：考点 100% / 子类 93%） |
| 讲义 / 笔记（pdf/docx） | ❌ **无** | ❌ 无（只做魔数与大小校验） | ❌ 无（讲义不参与分类，只靠 confirm 时人工选科目） |
| 试卷 / 真题（pdf/docx） | ❌ **无** | ❌ 无 | ❌ 无（无年份/地区/题型元数据） |

> 也就是说：**"上传备考资料的文档内容格式和系统分类机制"目前只在卡片这一类上是健全的**；讲义与试卷一旦放进来，系统只能"能解析"，但没有"合格线"。

## 1. 总则（三类通用）

| 项 | 规定 |
|---|---|
| 命名 | `{科目}_{主题}_{来源/年份}`，如 `公专_行政执法程序_2027桐哥`；禁止 `新建文件夹(2)`、`未命名`、纯数字 |
| 元数据必填 | 科目、类型（card/article/paper）、来源（原创/机构/网课/真题）、年份（试卷必填） |
| 来源可溯 | 每条资料记录 `source` 文本；讲义须写原始出处；试卷须写考试名称（如「2024年国考《公安专业科目》」） |
| 内容底线 | 不得含 `script/iframe/on*` 等标签；不得含未脱敏个人信息；法条引用必须带法律名与条号 |
| 编码 | 文件 UTF-8（Word 内部 xml 不限）；PDF 用文字版优先 |
| 体积 | 卡片 xlsx ≤10 MB；讲义 docx/pdf ≤50 MB；**试卷/扫描件 ≤250 MB**（P0 已放宽） |
| 重复 | `content_hash` 判重；同一来源重复上传 → 提示"疑似重复，是否覆盖" |

## 2. 资料卡片（xlsx）——沿用 v1，补 4 条

### 2.1 表头契约（不变）

| 列 | 必填 | 上限 | 说明 |
|---|---|---|---|
| 正面 | ✅ | 120 字 | 问题/概念/题干 |
| 背面 | ✅ | 600 字 | 答案/解析/要点 |
| 分类 | ⬜ | — | 子类名（须在 `sub_categories` 词表内） |
| 考点 | ⬜ | — | `knowledge_point` 名称 |
| 封面 | ⬜ | — | 图片 URL 或留空 |

**别名表（新增）**：`正面=front=问题=题目=问`；`背面=back=答案=解析=答`；`分类=子类=category`；`考点=知识点=point`；`封面=配图=cover`。用于吸收不同老师自制表的表头写法。

### 2.2 新增 4 条硬规则

| # | 规则 | 机检 | 错误码 |
|---|---|---|---|
| C1 | **多 sheet**：仅"表头含 正面+背面"的 sheet 视为卡片表；其余 sheet 记为文档附件（如「合法分类」词表页） | 自动识别 | `W101`（提示"已跳过非卡片 sheet：xxx"） |
| C2 | **单表行数**：>500 行自动分批（每 500 行一份资料），不再"超限全量入库" | 自动 | `W102`（提示"已拆为 N 份"） |
| C3 | **单文件行数上限**：≤2000 行（超过请拆分文件） | 阻断 | `E004`（沿用，阈值 200→2000） |
| C4 | **危险标签**：`<script>/<iframe>/on\w+=` 一律阻断 | 阻断 | `E008`（沿用） |

### 2.3 分类（两轮，不变）

1. 第一轮：用「分类」列做子类匹配；命中即用。
2. 第二轮：未命中 → 按正面+背面文本走 `_auto_classify`（110 条规则），产出子类 + 考点候选；
3. 两轮都未命中 → 落 `未分类`，并在管理端列「待分类」队列（人工补）。

## 3. 讲义 / 笔记（docx 优先，pdf 次之）——**新增**

### 3.1 Word 结构规范（决定"章节"能不能自动切出来）

| 元素 | 规定 | 机检 |
|---|---|---|
| 标题层级 | 用 **Heading 1/2/3**（或「标题 1/2/3」）样式；**禁止**用加粗大字充当标题 | 统计 Heading 段落数；为 0 → `W201` |
| 一级标题 | = 章（如「第一章 管辖」），一节一张卡/一页 | — |
| 正文段落 | 单段 ≤ 500 字；段落样式用「正文」 | 超长 → `W202` |
| 表格 | ≤ 8 列；必须首行表头；合并单元格 ≤ 2 层 | 超限 → `W203` |
| 图片 | 每篇 ≤ 20 张，单张 ≤ 2 MB，且**必须紧跟正文说明**（图下 1 行文字） | 超限 → `W204` |
| 星级/标签 | 允许「（高频考点★★）」这类标签，解析为 `tags` | — |
| 法条引用 | 统一格式 `《中华人民共和国治安管理处罚法》第五十条` | 正则抽检 → `W205` |
| 页眉页脚 | 允许（解析时忽略） | — |

### 3.2 PDF 结构规范

| 项 | 规定 |
|---|---|
| 优先文字版 | 由 Word/LaTeX 导出的文字版；**扫描件须 ≥300 dpi、正向、无遮挡**（覆盖文字的印章/水印会导致 OCR 错字） |
| 章节识别 | 按「第X章/第X节/一、二、三」标题切分；识别不出则整篇为一章（`W206` 提示） |
| 表格/公式 | 表格允许；公式以图片或文本均可（MinerU 会转 HTML） |
| 页数 | ≤ 300 页/文件（1024 页以上请拆分） |

### 3.3 讲义分类规则（新增，与卡片不同）

| 步骤 | 规则 |
|---|---|
| 1 | 科目：来自上传时选择（必须选） |
| 2 | 章节 → 子类：用章节标题与 `sub_categories.name` 做**包含匹配**（如「管辖」→ 行测/公专对应子类） |
| 3 | 章节 → 考点：标题命中 `knowledge_point` 名称（≥2 字重叠）→ 候选；**只呈现候选，人工确认后落库**（讲义易误判，不自动落） |
| 4 | 未命中 | 落"未分类章节"，管理端「待分类」队列 |

## 4. 试卷 / 真题（pdf/docx）——**新增**

### 4.1 元数据（必填，缺一项不允许入库）

| 字段 | 示例 | 说明 |
|---|---|---|
| 科目 | 行测 / 申论 / 公专 | 三选一 |
| 年份 | 2024 | 4 位数字 |
| 地区/范围 | 国考 / 江苏省考 / 多省联考 | 枚举 + 其他 |
| 类型 | 题本 / 答案解析 | 成对上传（见 4.3） |
| 考试名称 | 2024年国家公务员考试《公安专业科目》 | 原样保留 |
| 来源 | 真题 / 模拟 / 回忆版 | 回忆版必须标注 |
| 页数 | 自动读 | — |

### 4.2 命名规范

`{科目}_{年份}_{地区}_{类型}.pdf`，例：`公专_2024_国考_题本.pdf`、`公专_2024_国考_答案.pdf`。

### 4.3 成对与校验

- 同一「科目+年份+地区」的题本与答案**建议成对上传**；缺一方 → `W301`（可入库但标"缺答案"）。
- 题本必须含题号序列（`1.`/`一、`）；抽检前 20 题，题意段落为空 → `W302`。
- 答案文件必须含"答案"或"解析"字样于前 2 页 → 否则 `W303`（防止把题本当答案传）。

### 4.4 分类

- 试卷**不参与**卡片的两轮分类；只按元数据（科目/年份/地区/类型）建索引，供"按年份/地区筛选"与后续题目导入使用。
- 若试卷正文含"考点"标注，抽取为 `tags`（可选）。

## 5. 分类机制总览（三类统一口径）

```text
科目（3） → 子类（16，sub_categories） → 考点（94，knowledge_point）
   ↑              ↑                          ↑
 人工必选      卡片:两轮自动+兜底        卡片:第二轮回填+人工
              讲义:章节标题匹配+人工确认
              试卷:不参与（按元数据索引）
```

**规则库现状**：`material_classification_rules` 110 条，全部启用；卡片 30 样本回归：**考点 100% / 子类 93%**。
**需要补的**：①讲义章节映射规则（新增 `rule_type='chapter'`）；②试卷元数据枚举（年份/地区词表）；③「未分类」队列与人工补录入口（管理端列表加筛选项）。

## 6. 机检规则与错误码（前端可标红到单元格/段落）

| 码 | 级别 | 含义 | 适用 |
|---|---|---|---|
| E001–E003 | 阻断/行级 | 缺列 / 必填空 / 超长 | 卡片 |
| E004 | 阻断 | 行数超上限（2000） | 卡片 |
| E005 | 行级 | 文件内重复行 | 卡片 |
| E006/E007 | 行级 | 子类/考点不在词表 | 卡片 |
| E008 | 阻断 | 危险标签 | 全类 |
| E009/E010 | 阻断 | 扩展名不支持 / 超体积 | 全类 |
| W101–W102 | 提示 | 跳过非卡片 sheet / 已自动分批 | 卡片 |
| W201–W206 | 提示 | 无 Heading / 段落超长 / 表格超限 / 图片超限 / 法条格式 / 章节不可切分 | 讲义 |
| W301–W303 | 提示 | 缺答案 / 题本无题号 / 答案文件可疑 | 试卷 |

> 阻断码 = 不允许确认入库；提示码 = 允许入库但记录在 `parse_result.warnings`，管理端可见。

## 11. 冻结后的补充：预检豁免规则（T0.3 首轮实测得出）

首轮预检跑出 4 个"阻断"，全部落在 `_模板` 与 `_测试文件` 目录（模板本身是空行占位结构，测试文件是故意造错的），
说明预检器需要**目录与意图豁免**，否则会把"不是素材的文件"误判成素材。

| # | 豁免规则 | 理由 |
|---|---|---|
| X1 | 默认跳过目录名以 `_` 开头的（`_模板`、`_测试文件`、`_待归档`…）；需要时用 `--include-nonprod` 强制检查 | 下划线前缀在本库已约定为"非正式素材" |
| X2 | PDF 页数 ≤ 3 或文件名含「总图 / 清单 / 速查 / 口诀」→ **不要求章节结构**（`W206` 降为 `INFO`） | 单页思维导图、口诀清单本来没有章节 |
| X3 | Word 无 Heading 时，若正文段落 > 50 → `W201` 仍提示，但**允许入库**并按兜底规则切章（按「（高频考点★★）」星级、编号、短行） | 现有 `公安基础知识.docx`（149 段）就是这种；不允许入库会挡掉真实素材 |
| X4 | 模板/测试目录里的 `E002/E005` 不计入阻断 | 模板是空行占位，重复是测试造例 |

**首轮实测结论**：按 X1 豁免后，52 个正式素材 **0 阻断**、14 条提示（10 条混合型 PDF、7 条 INFO、各 1 条 W201/W205/W206/W207）。
