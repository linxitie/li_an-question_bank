### A4b 删除 / 回收站 / 恢复（本轮新增，重点）

| # | 操作 | 预期 |
|---|---|---|
| A4b-1 | 任一行点「删除」 | 弹窗标题**「移入回收站」**、按钮「取消 / 移入回收站」→ 点取消无任何变化 |
| A4b-2 | 状态下拉选「回收站（已删除）」 | 顶部提示「回收站：只看已删除资料，点「恢复」可还原」；列表 5 行；状态列橙色「已删除」；**没有上架开关** |
| A4b-3 | 回收站里某行点「恢复」 | 弹窗说明「恢复后为『未上架』状态，学生仍不可见；需要再点『上架（=审批通过）』才可见」→ **建议先点取消**（不点确认就不会动数据） |
| A4b-4 | **完整闭环（推荐做一次）**：① 记一条已上架卡片的 ID ② 删除它 ③ 回收站里找到它 ④ 恢复 ⑤ 回默认视图确认它是「未通过」 ⑥ 再点「上架」 | ⑤ 恢复后是**未上架**（不会自动恢复成已上架）；⑥ 上架后回到验收前状态，数据完全复原（我已实测过这条链路可逆） |
| A4b-5 | 学生端核对 | 用 `202516001 / test123456` 登学生端看资料列表：被删除的那条**不出现**；恢复但未上架时**仍不出现**；上架后才出现 |

> **回收站不是一个独立菜单页**：它就是资料管理页（`#/admin/materials`）**第 3 个下拉「状态」**里的
> 「回收站（已删除）」选项（也可以直接开 `#/admin/materials?status=-1`）。
> 旧版（临时）页 `#/admin/materials/legacy` **没有**这个选项，所以已删除资料只在**新页**能看到。

> **回收站里那 5 条是历史遗留数据**（学生端软删的旧卡片）。在 A4b-3 里点「恢复」会真的把它们放回默认列表（未上架状态）。只想验文案就点取消。
