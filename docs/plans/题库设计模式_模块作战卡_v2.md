## 0 开工三步

```
1) 定位模块（三件套，都是现成脚本/命令）
   # 端点：从契约基线里筛模块名
   python -c "import json;d=json.load(open('backend/data/refactor_baseline/api_surface.json',encoding='utf-8'));print(json.dumps({k:v.get('prefix') for k,v in d.items() if 'KEY' in k},ensure_ascii=False,indent=1))"
   # 页面：路由里筛
   grep -n "KEY" src/router/index.ts
   # 测试：文件名筛
   glob backend/tests/test_*KEY*.py
2) 填声明头（角色卡 §0），预算按影响面选 T1/T2/T3
3) 答 D1–D10；答不出就回 Q2，不写码
```

## 1 设计 D1–D10（Q2 放行闸）

| # | 检查 | 证据 |

## 2 优化 O1–O8（先量后改）

| # | 优化 | 先量什么 | 达标 |
|---|---|---|---|
| O1 | 列表/查询性能 | P95、SQL 条数 | 有数字改善、无 N+1 |
| O2 | 三端计数一致 | 同一口径的查询 | 差异 = 0 |
| O3 | 三态体验 | 空/错态可达性 | 三态齐全 |
| O4 | 安全 | 越权/IDOR/注入面 | SEC 五问通过 |
| O5 | 事件幂等 | 重复提交 | 重复 = 0 |
| O6 | 冗余 | 重复校验/重复请求 | 有删除 diff |
| O7 | 三端复用 | 是否复制页 | 无新增副本（R12） |
| O8 | 可维护 | 行数/函数长度 | ≤800 行 / ≤60 行 |

**没基线就不叫优化**（v4 A20）：优化前贴数字，改完同一命令复量。

## 3 测试 T1–T8（分层，不许一层冒充全部）

| 层 | 命令（真实路径） | 通过标准 |
|---|---|---|
| T1 契约 | `python backend/scripts/gates/gate_l4_api_contract.py` | PASS，条目 343（或已批准增量） |
| T2 边界 | `python backend/scripts/gates/check_module_boundary.py` | PASS |
| T3 数据 | `db_tables.json` 差异 / 迁移 dry-run | 可解释 + 回滚 SQL |
| T4 域测 | `cd backend; python -m pytest tests -q -k "<关键字>"` | 全 PASS |
| T5 前端 | `npx vitest run <spec 路径>` | PASS（注意：命令是 `test:unit` 不是 `test`） |
| T6 页面 | `python backend/scripts/gates/gate_l5_frontend_contract.py` + `vtj_check_consistency`（**只查版本，不同步**） | `versionMatch=true` |
| T7 三端 | `/#/forum`、`/#/mobile/...`、`/#/tablet/...`、`/#/teacher/...` 逐项 | 有 URL + 断言记录 |
| T8 回归 | 事件重放 + 计数一致性 | 重复 0、差异 0 |

全量 `pytest tests` 在本机会挂起 → 分批或 `--timeout=90`，并在报告里标 HANG（v4 §8）。

## 4 模块层五条硬约束

1. 跨模块只走契约与事件，不 `import` 别的 api 域（A14）。
2. 平板复用手机页，不复制（R12 / A15）。
3. 事件 `trigger_type` 只增不改（A19）。
4. 未开发模块（⑰ 签到 / ⑱ 小智 / ⑲ 机考 / ⑳ 小模考）过准入才建分支（A18）。
5. 失败报失败，未测标「未验证」（P7）。
