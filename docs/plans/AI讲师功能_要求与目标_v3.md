## 1. 一句话定义

**AI 讲师 = 一套「讲稿驱动」的网页交互式微课**：编辑写（或系统生成）一份讲稿 JSON，播放器就按它渲染出「讲师 + 板书 + 场景动画 + 检查点题目」的完整讲解课，学生能看、能答题、能重播；同一份讲稿换数据源即可批量扩到题目与资料卡。

**它不是什么**（防误解，见 §5）：不是数字人视频、不是真人录屏、不是把长视频切片播放、不是 LLM 现场对话。

## 2. 需求来源（4 层，逐条可追溯）

| 层 | 来源 | 内容 |
|---|---|---|
| **L0 业务需求** | 备考资料 6 项需求之 ④ | 「AI 讲师 / AI 视频」**标注【专利】**，即交付物必须包含可申请专利的技术方案材料 |
| **L1 口述要求（4 条）** | 你在 2026-11-04 提出的 4 条 | ①先做预写知识点清单的样板、**不做**按题/按卡全自动，但**必须预留底座**；②学真人讲解的**风格/逻辑/肢体动作**，讲解中可**跳转场景**（法条→执法现场、计算→公式动画），画风**卡通与正式并存**；③研究真人**怎么把知识拆开讲**，总结成可复用的结构与分镜规则，**参考不照抄**；④讲解中**弹选择题（数量不限）**，答对继续、答错给解析，正误各有**小动画** |
| **L2 视觉依据** | 你给的 3 张截图 | 左 2/3 讲解区（讲师 + 气泡字幕 + 场景道具 + 章节时间轴 + 重播）、右 1/3 题目面板（题干 + 胶囊选项）、答对（绿 + 大对勾 + 烟花）、答错（橙红 + 答案解析块 + 继续） |
| **L3 后续决策** | 你的 4 次拍板/追加 | ①**方案 A**：网页交互播放器（不做数字人）；②知识点清单来源 → 由**知识库**提供（87 知识点 / 403 考点 / 12 个试点），不再等你手写；③**形象另定**（先参数化 SVG 草案）；④先做**知识供给适配器**再进播放器 |

## 3. 要求（R1–R13，逐条可验收）

> 编号规则：R1–R4 对应你的 4 条口述；R5–R6 对应业务/合规；R7–R13 是工程与非功能要求。**每条都给了验收方式**，没有验收方式的不算要求。

### 3.1 内容与讲解（R1–R4）

| # | 要求 | 细化到可验收 | 验收方式 |
|---|---|---|---|
| **R1** | 样板优先 + 底座预留 | 首期只做 **3 个**知识点（不是全量自动）；同时交付「讲稿 DSL + 播放器 + 供给适配器」三件底座，使「按题目/按资料卡生成」只需换数据源 | 换一份 `lecture_script.json` 不改播放器代码即可播放；适配器产物能被播放器直接消费 |
| **R2** | 学真人讲解：风格 / 逻辑 / 动作 / 场景跳转 / 画风 | ①讲稿按 7 段式组织结构（引入-概念-拆解-示范-场景-检查点-小结）；②讲师动作由语义标签触发（`gesture`/`expression` 七类以上）；③场景至少 4 类（板书/公式/执法现场/自定义），**段落间可切换**；④画风「讲师圆润卡通、场景克制正式」，同屏 ≤3 色 | 3 个样板里至少 2 个出现场景切换；动作标签命中率 100%（讲稿里写了就必须演出来） |
| **R3** | 拆解逻辑模板化 | 沉淀「分镜/拆解规则」：一句话一个镜头、一要点一段、每 20–40 秒一个视觉变化、每 3–5 分钟一个检查点；规则写成文档 + 可由脚本校验（段落时长/要点数上限） | 用规则校验器跑 3 份讲稿，0 违规；规则文档可被第三人照着写出新讲稿 |
| **R4** | 检查点与正误反馈 | 检查点数量不限、可插在任意段末；答对→绿色 + 大对勾 + 烟花 + 2 秒后继续；答错→选项橙红 + **展示正确答案与解析** + 「继续」手动推进；反馈动画是**独立可复用组件**，且尊重 `prefers-reduced-motion`（降级为静态） | 3 个样板每节 ≥1 检查点；正误两条路径都录屏/截图证明；关动效后页面仍完整可读 |

### 3.2 业务与合规（R5–R6）

| # | 要求 | 细化 | 验收方式 |
|---|---|---|---|
| **R5** | **专利材料**（需求 ④ 的【专利】标记） | 交付《专利交底书 B》，至少覆盖 3 组权利要求：①基于讲稿 DSL 的分段讲解与**场景跳转**驱动方法；②讲稿内**检查点注入**与正误反馈动画的触发方法；③**语义标签 → 讲师动作/表情**的映射方法。与已交付的《专利交底书 A（文档格式规范化与分类机制）》体例一致 | 交底书评审通过（技术方案清楚、权利要求可撰写、有对比现有技术的区别点） |
| **R6** | 版权与内容合规 | ①网课视频**只作内部风格参考**，不得复用台词/画面/讲师形象；②法条原文必须来自可核来源（`flk.npc.gov.cn` 等公开库），LLM **不得生成法条**；③LLM 生成内容必须经审核（`approved`）才可上线；④禁 `v-html`，讲稿文本按纯文本渲染 | 讲稿里每条法条带 `law_ref`（法律名+条号+来源）；上线内容 100% 有审核状态；代码中 `v-html` 命中 0 |

### 3.3 工程与非功能（R7–R13）

| # | 要求 | 细化 | 验收方式 |
|---|---|---|---|
| **R7** | 三端适配 | PC（≥1280）、平板横竖屏（768/1024/1366）、手机（390）均可播；讲师与板书按安全边距缩放；触控目标 ≥44px | 三端截图各 1 组；`<44px` 可点元素 = 0；横向溢出 = 0 |
| **R8** | 视觉规范 | 按库内《教学画面渲染规范》：1920×1080 设计 + 四周 96px 安全边距、标题 56–72 / 正文 40–48 / 注释 ≥32、≤3 色、页脚「模块名 · 考点 ID · 页码」、动效 200–400ms 且同屏 ≤2 元素 | 规范自检项逐条打勾；抽帧测量安全边距与字号 |
| **R9** | 数据可追溯 | 每节讲稿记录来源：`point_id` / `topic_id` / `exam_point_id` / 试点集号；内容变更可 diff；产物带 `schema_version` 与输入 `sha256` | 任一节可反查「哪个知识点、哪个考点、哪集视频、哪版讲稿」 |
| **R10** | 性能 | 单节首屏可交互 < 2s（本机）；讲稿 JSON < 200KB；播放动画 ≥ 50fps；切段无白屏 | 本机 Lighthouse/自制计时脚本取证 |
| **R11** | 工程红线 | 不动 `.vtj/`（R1/R3）；不新增后端端点（P1 零后端）；页面路由 104→105 需同步 L6/L7 双改点；VTJ 版本一致性 `--check` 保持 69/0 | `gate_all 10/10`、`vtj_version_sync.py --check` 通过、`vue-tsc` 0 error |
| **R12** | 可维护性 | 讲稿与播放器解耦（播放器只认 DSL）；新增场景/动作不改播放器主流程；供给数据由脚本生成、禁止手改（`--check` 抓漂移） | 新增 1 个场景 = 只加 1 个组件 + 1 个枚举值；`--check` 通过 |
| **R13** | 可观测与降级 | 埋点：进入/开始播/段完成/检查点作答/完成；异常时降级为「静态图文版讲稿」（无动画也能学） | 埋点事件可在本地日志看到；断网/无 JS 动画时仍能读到文字版 |

## 4. 目标（G1–G6，分层且可度量）

| # | 目标 | 度量（本期 → 达标线） | 归属 |
|---|---|---|---|
| **G1 教学效果** | 学生「看完能答对」而不是「看完就算」 | 3 个样板各配 ≥1 检查点；检查点作答率 ≥ 70%（样板期人工验证 3 人×3 节） | P1 |
| **G2 生产效率** | 知识库里的知识点 → 可播微课的**边际成本**要低 | 单个知识点从「零」到「可播」≤ **30 分钟**（供给适配器 + 规则讲稿 + 人工润色）；P2 接 LLM 后目标 ≤ 10 分钟 | P1→P2 |
| **G3 可扩展性** | 同一播放器能接三种来源 | 讲稿来源至少 3 种（知识点清单 / 题目 / 资料卡）都能生成可播 DSL；**切换来源不动播放器** | P2 |
| **G4 专利价值** | 交付可申请的技术方案，而不是"用了某某平台" | 交底书 B 覆盖 3 组权利要求、区别点 ≥ 3 条、与现有 AI 视频方案（数字人播报/Sora 类生成）**技术路线明显不同** | P1 文档，P2 提交 |
| **G5 工程质量** | 不破坏现有系统 | `gate_all 10/10`、三端 0 溢出、`vue-tsc` 0、VTJ 一致；新增代码全部手写页，零 `.vtj` 改动 | P1 |
| **G6 可演进** | 不为 P1 埋死路 | P1 的 DSL 字段能容纳 P2 的 TTS/音轨与 P3 的录屏导出（预留字段，不实现） | P1 |

## 11. 一页纸摘要

- **是什么**：讲稿 JSON → 网页交互微课（讲师 + 板书 + 场景 + 检查点）。
- **为谁**：备考学生（碎片时间看 6–10 分钟一节，看完能答对）。
- **4 条硬要求**：样板 + 底座｜学讲解风格与场景跳转｜拆解逻辑模板化｜检查点 + 正误动画。
- **3 条硬约束**：专利交底书 B｜版权与法条可核｜不动 `.vtj`、P1 零后端。
- **P1 完成的标志**：3 节能在 PC/平板/手机播完、有检查点、三端不溢出、门禁全绿、可反查来源。
- **明确不做**：数字人、现场对话、全自动批量、TTS、导出 mp4、切片真人课、模仿具体老师。
