## 6. 排障

| 症状 | 先查什么 |
|---|---|
| **① 下架后学生端没变化** | ① 学生页是否强刷（Ctrl+F5）；② 跑 A 组探针看后端是否已加载新代码（`/health` 的 `revision` 应为 `d4eaca6` 之后的提交）；③ 后台日志 `_run\uvicorn_8001.log` 有无 500 |
| ② 上/下架报 500 | 看 `_run\uvicorn_8001.log`；临时可设 `MATERIAL_PAPER_SYNC=false` 重启后端（回到旧行为），再把日志发我 |
| ③ 统计卡数字和本文不一致 | 以你当前页面数字为基线，"下架 → 已上架 -1 / 未上架 +1"即可；不必和文档里的 105/14 完全一致 |
| ④ 学生端登录后空白 | 学生页有返回拦截，直接从地址栏进 `#/student/papers`；不要点侧栏"题库"再返回 |
| ⑤ 探针报 `login failed` | 后端不在 8001 或账号密码被改；用 `--base http://127.0.0.1:8001` 显式指定 |
