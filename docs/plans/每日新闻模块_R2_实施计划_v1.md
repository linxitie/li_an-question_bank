# 每日新闻模块 R2.0 实施计划 v1

> 状态：已批准实施（2026-11-01）
> 分支：`feat/news/r2-foundation`
> 上游方案：`docs/plans/每日新闻模块总体设计方案_v1.md`
> 范围：只做数据/检索底座，不接爬虫/AI/外部库

## 1. 目标

1. 新闻分类字典与来源注册表落地（表 + 种子 + 可扩展）。
2. `news_article` 增加 R2 所需最小列：`category_code/content_hash/review_status/event_date/region_code/source_id/deleted_at`。
3. SQLite FTS5 trigram 索引 + 触发器；短词/特殊字符回退 LIKE。
4. `/api/news` 保留 q/page/page_size/category/source/limit 兼容，分类接口返回计数。
5. 真实库迁移前备份，迁移后 FTS 回填，二次执行幂等。

## 2. 任务

| ID | 任务 | 主要文件 | 验收 |
|---|---|---|---|
| R2.0-A | 模型：NewsCategory/NewsSource；NewsArticle 扩列 | `models.py` | 模型导入通过；create_all 新表 |
| R2.0-B | Schema Guard：补列、种子分类、映射现有 category、FTS/触发器/rebuild | `app/core/news_schema.py` | 旧库空表/有数据均可升级；二次幂等 |
| R2.0-C | 检索服务：FTS + LIKE 回退；分类计数 | `app/services/news_search_service.py` | 中文 2/3/多字查询、特殊字符不 500 |
| R2.0-D | API 接线：q/category/source/page/page_size/limit | `api/v1/content/news.py` | 旧请求兼容；total 正确 |
| R2.0-E | 启动接线与真实库迁移 | `main.py`、脚本/命令 | 启动不因 FTS 失败；真实库备份后执行 |
| R2.0-F | 测试与门禁 | `tests/test_news_schema.py`、`test_news_r2.py` | 新测试通过；L0 7/7 |

## 3. 非目标

- 不接新华网/公安部/省厅爬虫，不改 scheduler 08/18。
- 不接 LLM 摘要/考点/实体/图片描述。
- 不启用 Mongo/MinIO/Neo4j/Milvus 生产实例。
- 不做新闻审核看板与自动发布。

## 4. 验收

- FTS 表存在且行列数 = `news_article` 行数；`news_fts` 查询中文片段命中。
- `q` 为空/短词/特殊字符走 LIKE 不报错。
- `GET /api/news?q=枫桥&page=1&page_size=1` 返回 total/page/has_more。
- `GET /api/news/categories` 返回分类计数。
- 真实库迁移前后 `news_article` 行数不变；备份 integrity ok。
- `pytest tests/test_news_schema.py tests/test_news_r2.py` 通过；L0 7/7。

## 5. 回滚

- Schema Guard 只加表/加列/加触发器；回滚保留新列与新表，不删数据。
- 关闭 FTS 查询由服务层自动回退 LIKE；无需回滚数据库。
