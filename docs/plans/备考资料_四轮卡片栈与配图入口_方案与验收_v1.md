# 备考资料 · 四轮：卡片配图入口与卡片栈 3D（方案与验收）

> 版本：v1（2026-11-02）｜分支 `feat/Study-Material-Management-r4`（父 `-r3@e9a3456`，`main` 未动）
> 范围：①「查看配图」入口从列表移到卡片上　②去掉翻页时的白色背景框与卡片白边，翻转做成真 3D

---

## 1. 需求与结论

| # | 你的原话 | 根因（实测） | 处理 |
|---|---|---|---|
| 1 | 手机端「查看上传图片」的按钮移到卡片上，别让人去下面列表里找 | 配图只能在列表行的「查看详情」里打开；卡片本身没有任何入口 | 卡片正面/背面底部新增「查看配图（N）」按钮（无图时显示「查看详情」），点开直接全屏看图 |
| 2 | 翻页时有一个白色背景框留在原地；去掉白框，去掉没翻页时的白边，翻页要更好的 3D | ①卡片栈是 **5 张完整白卡** 叠加（`lv1–lv4` 各自 `background:#fff` + `1px` 边框），顶层飞出时底层白卡原地不动 → 白框；②`perspective` 挂在 `.stack` 上，真正旋转的是孙级 `.card-inner`，透视没生效 → 翻转是「平的」 | ①背景改成 **3 片渐变纸片**（只露一条边，不画白卡），卡片去掉边框；②`perspective` 移到 `.stack-card`，背面加 `translateZ(1px)` 避免零厚度重影；③翻页动画期间纸片整体淡出 |

## 2. 关键实现

```
.stack            纸片容器（不再承载透视）
  .stack-slab ×3  渐变竖条：top 21/12/3px、左右各内缩 6+5n px、opacity 0.58/0.38/0.18
  .stack-card     唯一真卡：无 border、圆角 16、阴影 0 10px 24px、perspective:900px
    .card-inner   transform-style:preserve-3d，翻转 0.5s cubic-bezier
      .card-face.front
      .card-face.back  rotateY(180deg) translateZ(1px)
```

- 卡片底部：`.card-foot` 改为 flex，左侧「点击卡片翻转看要点」，右侧 `.card-act` 按钮。
- 按钮点击 `@click.stop`（不触发翻转）：有图 → 打开 `ImageLightbox`（复用电脑端组件，支持缩放/切图/Esc）；
  无图 → 回退到原有详情弹层（文章类资料仍然走列表）。
- 翻页：`.is-leaving/.is-entering` 时 `.stack-slab { opacity: 0 }`，配合卡片 0.2s 飞出/进入。

## 3. 验收

`scripts/verify/mobile_card_stack_shots.mjs`（手机视口 390×844，真实登录态）**9/9 断言通过**：

| 断言 | 实测值 |
|---|---|
| 栈顶是要看的那张卡 | 演示卡标题命中 |
| 背景只剩 3 片渐变纸片 | `slabs=3`，`background-image=linear-gradient(...)` |
| 卡片无白边 | `border-top-width = 0px` |
| 卡片上有「查看配图」 | 按钮文案 `查看配图（2）` |
| 翻转进入 3D | `matrix3d(-1, 0, 0, 0, …)` |
| 卡片按钮直接开全图 | 计数 `1 / 2` |
| 翻页期间纸片淡出 | `opacity 0.086`、`is-leaving=true` |
| 翻页后切到下一张 | 标题变化 |

效果图：`docs/plans/assets/备考资料_四轮验收/01~06.png`
（默认态 / 翻转中 3D / 背面 / 全图 / 翻页中无白框 / 翻页后）。

## 4. 顺带说明

- 列表行的「查看详情」保留（文章类资料没有卡片，仍需从列表进）；卡片类资料从此不用再往下翻。
- 无图卡片按钮文案自动变「查看详情」，行为与原来一致。
- 演示数据已清理：当前已公开 100 篇 = 97 卡片（含你自己建的 3 张：`1`、`2`、`老表`）+ 3 篇文章。

## 5. 已知不足

1. 翻转到 90° 附近仍能看到一点“卡片厚度”白边（背面 `translateZ(1px)` 造成），属双面卡片的正常投影，静止时不可见。
2. 纸片数量固定 3 片，不随剩余卡片数变化（纯装饰）。
3. 全图查看器仍未做拖拽平移/双指缩放。
