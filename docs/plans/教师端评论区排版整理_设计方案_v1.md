## §1 现象（截图 + 代码对照）

截图里能定位到 3 个具体问题：

| # | 现象 | 代码根因 |
|---|---|---|
| 1 | **输入框被压成一条细竖条**，旁边挤着 😊、图片缩略图、两个文件 chip、"+ 图片 / 文件"大方框 | `.tf-comment-input { display:flex; align-items:flex-end; }` —— 所有子元素挤在**一行**；`FileUploader` 默认 `.fu-add` 是 **76×76 大方框**，把 `textarea` 的 `flex:1` 挤没了 |
| 2 | **「隐藏评论」孤零零飘在右侧**，和评论内容对不齐 | 它是评论块里的最后一个按钮，没有归入评论头部/操作区 |
| 3 | 评论块内**正文/图片/附件上下错位**，图片单独居中、附件另起一行 | `.tf-comment` 是 flex 行布局（P1 改的），图片与附件 chip 没有统一的行容器 |

## §2 目标版式（与学生端 v1.2/v1.3 已定型的那套对齐）

```
┌─ 帖子详情 ───────────────────────────────┐
│ [头像] 昵称 · 班级                  [×] │
│ 标题 / 正文 / 附件                       │
├──────────────────────────────────────────┤
│ 评论（21）                               │
│ ┌ [头像] 昵称 班级 ──────── [隐藏评论] ┐ │
│ │ 正文（左对齐，两端对齐不居中）        │ │
│ │ [附件 chip][附件 chip]                │ │
│ └───────────────────────────────────────┘ │
├──────────────────────────────────────────┤
│ ┌──────────────────────────────────────┐ │  ← 第 1 行：输入框独占整行
│ │ 写下你的评论…                        │ │
│ └──────────────────────────────────────┘ │
│ [😊] [＋] [缩略图×][文件×]        [发送] │  ← 第 2 行：工具贴左、发送贴右
└──────────────────────────────────────────┘
```

关键点：
- 输入框**独占一行**（`flex: 1 0 100%`），不再和按钮抢空间；
- 工具行里 `.fu-add` 缩成 **36×36 圆形「＋」**（`:deep()` 穿透，沿用 PC 评论区的既有做法）；
- 已选附件以 **40px 缩略图 / 文件 chip** 平铺在工具行；
- 「隐藏评论」移到评论**头部右侧**（与昵称同一行）。

## §3 改动清单（全部在 `teacher_forum.vue`，手写 SFC）

| # | 位置 | 改动 |
|---|---|---|
| 1 | `.tf-comment-input` | `flex-wrap: wrap`；`textarea` 加 `flex: 1 0 100%` + `min-height: 44px` |
| 2 | 同文件 `:deep(.fu-add)` | `width/height: 36px; border-radius: 50%; font-size: 0` + `::before { content: '+' }`（照搬 PC 评论区的既有写法） |
| 3 | `.tf-comment` | 头部（头像/昵称/班级/隐藏按钮）与正文分两行；正文 `text-align: left`；附件 chip 统一 `display:flex; gap:8px; flex-wrap:wrap` |
| 4 | 「隐藏评论」按钮 | 移入评论头部右侧（`.tf-comment-head-right`） |
| 5 | 图片渲染 | `ImageGrid` / `<img>` 统一 `max-width: 220px; border-radius: 10px`，不再居中 |

**不做什么**：不改后端、不改接口、不动学生端与平板端。

## §4 验收

| # | 断言 |
|---|---|
| 1 | 输入框宽度 = 弹窗内容宽度（≥ 560px @ 1440 视口） |
| 2 | 工具行内 `.fu-add` 尺寸 = 36×36、圆角 50% |
| 3 | 输入框 top < 工具行 top（确实分成两行） |
| 4 | 「隐藏评论」与昵称同一水平线（top 差 ≤ 6px） |
| 5 | 附件 chip 不换行溢出（容器内 `flex-wrap`） |
| 6 | `npm run typecheck` 63/9、`vitest` 28/362 不劣化 |

## §5 风险与回滚

| 风险 | 对策 |
|---|---|
| `:deep(.fu-add)` 依赖子组件类名 | 与 PC 评论区同一依赖，已在 `FileUploader.vue` 注释登记 |
| 改 flex 后详情弹窗高度变化 | 只改评论区内部，弹窗外层 flex（上一轮已改）不变 |
| 与"输入框吸底"冲突 | 吸底靠外层 flex 布局，内层改 wrap 不影响 |

回滚：`git revert` 单提交（纯 CSS + 少量模板）。
