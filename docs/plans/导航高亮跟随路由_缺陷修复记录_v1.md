# PC 导航高亮跟随路由 · 缺陷修复记录 v1

> 你 2026-11-11 反馈：点顶部「题库 / 关于砺安题库 / 论坛」后，**小红线和浅色小方块仍停在「首页」**。
> 分支 `feat/material-multi-format-import`，**未碰 main**。

---

## 1. 根因

导航栏是共用的 `.vtj/vue/navbar.vue`，它把"当前选中项"存在**组件内部 state** 里：

```js
const state = reactive({ activeMenu: 'home_page', ... });   // 初始值写死首页
...
handleMenuClick(id) { this.state.activeMenu = id; this.navigateTo(id); }  // 只在点击时改
```

而**每个页面各自内嵌一份 `<NavBar>`**（`about / answer_page / daily_news / download_client / favorites / question_bank / …` 都 `<NavBar></NavBar>`）。
换页时组件**重新挂载**，`activeMenu` 又回到初始值 `'home_page'` —— 于是无论你点哪个菜单，落地页的高亮永远显示"首页"。

> 另一套导航组件 `app_navigation.vue` 没这个问题，它本来就是 `currentRoute === item.route` 的写法；
> `navbar.vue` 是唯一"只看点击、不看路由"的一份。

## 2. 修法（只改 `<script>`，守 R3）

`.vtj` 页面的 `<template>` 不能动，所以不改 `:class` 绑定，改为**挂载时按路由把 `state.activeMenu` 对齐**：

```js
menuIdFromRoute(path) {           // 路由 → 菜单 id，唯一定义
  '/page/home_page' | '/'        → home_page
  '/page/question_bank'          → question_bank
  '/news' | '/news/*'            → news
  '/page/about'                  → about
  '/forum' | '/forum/*' | '/page/forum' → forum
  其它（下载客户端 / 答题 / 收藏…）→ ''（不高亮任何一项）
}
syncActiveFromRoute() { this.state.activeMenu = this.menuIdFromRoute(this.$route.path) }

mounted() { this.updateLoginState(); this.syncActiveFromRoute(); }
watch: { '$route.path'() { this.syncActiveFromRoute(); } }
```

设计取舍：
- **点击即时反馈**保留（`handleMenuClick` 先设一次），路由变化后 `syncActiveFromRoute` 再对齐一次，两处同一口径；
- 菜单里没有的页面（如「下载客户端」）**不高亮任何一项**，而不是错误地停在"首页"；
- 浏览器地址栏直达 / 前进后退 也正确（不只是点击）。

## 4. 一个需要你知道的现状（不是这次改坏的）

点「新闻」会进入 `/#/news`（`src/views/student/shared/news_timeline.vue`）—— 这一页**本身没有全局导航栏**，
它自带一个「← 返回」的页内头。所以在新闻页看不到高亮不是 bug，而是它压根没渲染 NavBar。

如果你希望新闻页也显示全局导航（那样"新闻"也能高亮），需要给这个手写页加一行 `<NavBar />`
（`src/` 下的页面不受 R3 限制，可以直接改）—— 要不要加，你说一声。

## 5. 回滚

`navbar.vue` 单文件：删掉 `menuIdFromRoute / syncActiveFromRoute / watch` 与 `mounted` 里那一行即可回到旧行为。
