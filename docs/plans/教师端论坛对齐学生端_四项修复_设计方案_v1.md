## §2 方案（4 处，全部在 `teacher_forum.vue`，手写 SFC 不受 R3 限制）

### 2.1 整卡点击打开详情

```html
<article class="tf-card" @click="openPost(post)">
  ...
  <div class="tf-actions">
    <button class="tf-link" @click.stop="openPost(post)">查看评论</button>
    <button v-if="post.canDelete" class="tf-danger" @click.stop="askHidePost(post)">隐藏帖子</button>
  </div>
</article>
```

要点：**内部所有按钮都加 `.stop`**（隐藏/查看评论/附件下载），否则会"点隐藏也开详情"。
`UserBadge`、`AttachmentList` 等子组件的点击也需 `@click.stop`（若无则用包裹 div 拦截）。

### 2.2 评论输入区固定在弹窗底部

`.tf-modal-card` 从"整卡滚动"改为**三段式 flex**：

```css
.tf-modal-card { display: flex; flex-direction: column; max-height: 86vh; overflow: hidden; }
.tf-modal-scroll { flex: 1 1 auto; overflow-y: auto; min-height: 0; }   /* 标题+正文+评论列表 */
.tf-comment-input { flex: 0 0 auto; border-top: 1px solid #eef1f6; }     /* 永远贴底 */
```

模板上把"标题/正文/评论列表"包进 `.tf-modal-scroll`，输入区留在外面。

> **为什么不用 `position: sticky`**：项目已实测过（`docs/plans/三端论坛评论输入区统一_设计方案_v1.3.md`）——VTJ 外层 `.x-container` 是 `overflow:auto` 的滚动祖先，sticky 会绑到它而非弹窗，导致"看起来没吸底"。**flex 布局不依赖滚动容器，最稳**。

### 2.3 教师发帖支持附件

- 复用 `@/components/forum/ImageUploader.vue`（图片）+ `FileUploader.vue`（文件）
- 提交时把附件数组序列化进 `attachments` 字段（后端 `create_post` 已支持 `attachments` JSON）
- `createForumPostWithVisibility` 增加 `attachments` 参数
- accept 用全量白名单；前端预校验大小 ≤20MB，超限直接提示不发请求

### 2.4 教师评论与学生端一致（除删除）

| 能力 | 学生端有 | 教师端加 |
|---|---|---|
| 文字 | ✅ | ✅（已有） |
| 附件（12 种格式，≤20MB） | ✅ | ➕ 加 `FileUploader` |
| 表情 / 表情包 | ✅ | ➕ 加 `EmojiStickerPicker` |
| 删除评论 | ✅ | **不加**（按你的要求） |

接口不变：`POST /api/forum/posts/{id}/comments` 已接受 `attachments` 字段。

## §3 安全与权限

| 项 | 处理 |
|---|---|
| 上传校验 | 完全复用后端白名单 + MIME/文件头 + 20MB 限制，前端不做"唯一防线" |
| 越权 | 评论接口走 `get_current_user`；教师只能对自己可见的帖子评论（沿用现有过滤） |
| XSS | 附件只回显文件名与链接，不内联渲染 |

## §4 验收

| # | 断言 |
|---|---|
| 1 | 点卡片正文任意处 → 详情弹窗打开 |
| 2 | 点「隐藏帖子」→ 只弹确认框，**不**同时打开详情 |

| 6 | 教师评论带附件 → 发送成功并显示 |

## §5 风险与回滚

| 风险 | 对策 |
|---|---|
| 整卡点击误触（选择文字也弹窗） | 按钮/附件区 `.stop`；正文用 `cursor:pointer` 明确可点 |
| flex 改造导致弹窗布局塌 | 只改 container 的 display/flex 与新增 `.tf-modal-scroll`，不改内部元素样式 |
| 附件上传撑大存储 | 沿用 20MB 上限；教师端再加"每次最多 5 个"前端限制（可调） |

回滚：`git revert` 单提交（纯前端 + 1 处 api.ts 参数）。
