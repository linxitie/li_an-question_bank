# 每日新闻模块 R2.5 前端时间线/日报对接计划 v1

> 状态：实施（2026-11-02）
> 上游：R2.4 时间线 `/api/news/timeline`、日报 `/api/news/digest`

## 1. 现状

- PC 端没有新闻入口路由；
- 平板/手机复用 `src/views/student/mobile/mobile_news.vue`，只有列表/详情；
- 后端时间线/日报 API 已通，但前端未消费；
- `.vtj/vue/daily_news.vue` 存在但未挂路由，属于 VTJ 页面，不直接改模板。

## 2. 方案

- 新增 raw 页面 `src/views/student/shared/news_timeline.vue`：
  - 时间线 tab：按日期分组展示已发布新闻；
  - 日报 tab：日期选择 + 分类计数 + 当日条目；
  - 加载态/空态/错误态；
  - 原文链接新窗口打开，不伪造详情路由。
- 路由：
  - `/news`（PC）
  - `/tablet/news/timeline`（平板）
  - `/mobile/news/timeline`（手机）
  - 三端复用同一组件，不复制页面。
- API 模块新增 `fetchNewsTimeline` / `fetchNewsDigest`。

## 3. 不做什么

- 不改 `.vtj/vue` 模板；
- 不改现有手机/平板新闻详情页；
- 不新增详情接口或自动发布；
- 不引入 UI 库。

## 4. 验收

- 三个路由均可加载；
- 时间线按日期分组；
- 日报可选日期并显示分类计数；
- 接口失败显示错误态，不白屏；
- `npx cross-env ENV_TYPE=live vite build`：通过（2026-11-02）；
- `npm run typecheck`：存在仓库既有 @vtj/icons/wangeditor 类型声明错误，本次新增文件无报错；
- `npm run build`：被既有项目健康度孤儿/漂移检查阻断，非本次改动导致。
