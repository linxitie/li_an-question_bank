## 6. 关键设计决策（复盘）

1. **科目说明复用 `study_material` 的 `type='article'`**（零新表），而不是单独建内容表。
2. **分类规则入库**（`material_classification_rules`）而非前端硬编码 → 运营可改、可审计，也是专利主张③的落点。
3. **三端差异用「同页适配 + redirect」**，不复制页面（守 R12）；平板直接复用电脑页，手机保留卡片栈。
4. **`.vtj` 页面不改 template**（守 R3）：PC 建卡入口、平板首页入口都用运行时 DOM 注入（`materialsCreateEntry` / `tabletMaterialsEntry`，含纯函数判定 + 单测）。
5. **翻卡 3D 的真根因**是 `perspective` 挂错层级（旋转元素是孙级），修在 `.stack-card` 才对；翻页白框根因是容器 `background:#fff`，不是背景纸片。
6. **平板同版必须用 `#app` 前缀**才能压过 `.vtj` 页面的 scoped 样式（同权重时后注入的全局样式会被覆盖）。
