## 0. 结论先行

1. **T6/T7 不是"只加一个 `:style`"**：手机/平板列表页先把接口数据映射成视图模型，映射里**根本没有 `titleColor` 字段**（`mobile_forum.vue:197-214`、`tablet_forum.vue:346-362`）。只改 template 拿不到值，必须同时补映射与 import，共 **2 文件 / 8 处**。
2. **后端无需改动**：`_serialize_post` 已返回 `titleColor`（`forum.py:158`），列表接口 `GET /api/forum/posts` 走的就是它（`:335`）。PC 端早已用同一条链路（`forum.vue:42`）。
3. **T8 复用现成基座**：`.forum-header` 已是 `display:flex; justify-content:space-between`（`forum.vue:1200-1211`），加一个 `.forum-header-actions` 包裹层即可；弹窗外壳照抄「我的帖子」弹窗结构（`forum.vue:457-490`），复用 `.modal-overlay`/`.modal-card`，**不新增全局类、不改共享 `.modal-actions`**。
4. 拆 **2 个提交**：`P2-1` 标题色、`P2-2` 三按钮 + 空态弹窗。两段各自可独立回滚、独立验收。

      {{ state.favoriteTab === 'favorites' ? '还没有收藏的帖子' : '还没有喜欢的帖子' }}
    </div>
    <div class="modal-actions">
      <button class="cancel-btn" @click="closeFavorites">关闭</button>
    </div>

</div>
