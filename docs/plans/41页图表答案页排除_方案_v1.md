## 1. 现象

41 页真卷（`题库/公安题目（打印）/2025多省联考公安《公安专业》.pdf`）导题后 114 条候选里混着：

- **图表页 p11**：61 行里有 **47 行是短标签、32 行是纯数字/百分比**（`800`、`125.60%`），
  被 OCR 认成 **16 个"题号"** → 造出一堆假题，还带出 **题号 125** 这种（其实是 "125.60%"）；
- **答案页 p41**：121 行里 **104 行是短标签、50 行是纯数字**（`C.召开…` 这种答案短句）；
- **图表页 p16 / p19 / p25**：`n=56/47/57`，短行 33/40/35，长行只有 6/5/5（还含 2 行页眉广告）；
- 其它已知垃圾：p32 重复 79/80、p12–p13 的图表标签零星进正文（但 p13 里有**真题 41**，不能整页丢）。

## 3. 方案（F1–F4，≈0.8d）

### F1 答案页整页丢弃

判据（同时满足）：
- 行数 `n ≥ 20`；
- `short_ratio ≥ 0.7`（≤6 字的行占比）**且** `numeric_ratio ≥ 0.2`（纯数字/百分比行占比）；
- `题号行 ≤ 4`（真答案页不会成片出现"12."这种题号，p11 那 16 个假题号因此不会被判成答案页）。

→ p41 命中（104/121 短行、50/121 数字行、3 个题号）。

### F2 图表页整页丢弃

判据（满足其一）：
- (a) `n ≥ 20` 且 `short_ratio ≥ 0.55` 且 **正文长行**（≥30 字、且不是页眉/广告）`≤ 4` 且 `题号行 ≤ 1`；
- (b) `n ≥ 20` 且 `numeric_ratio ≥ 0.2` 且 `正文长行 ≤ 4`（p11 那种整页数字/百分比的图表）。

→ (a) 命中 p16（0.59 / 4 / 0）、p19（0.85 / 3 / 1）、p25（0.61 / 3 / 1）；
(b) 命中 p11（数字行 0.52、正文长行 3）；
p38（0.45）与 p12（0.38）、p13（0.43）**都不命中**（它们是"短选项/图表混排"的正常页）。

#### F2b 为什么**不**把"表格页"也整页丢（首版实测后改的）

首版把 p16/p19/p25 也整页丢，结果题号 **39 / 47 / 50 / 66** 跟着消失 —— 这几页是
"表格 + 夹着真题"（真题的题干/选项就排在表格旁边）。所以最终只整页丢**两类**：

| 类 | 判据 | 处置 | 实测命中 |
|---|---|---|---|
| 答案页 | 短行 ≥0.7 且 数字行 ≥0.2 且 题号 ≤4 | 整页丢 | p41 |
| 数字图表页 | 数字行 ≥0.2 且 正文长行 ≤4 | 整页丢 | p11 |
| 表格页（短行多但没数字）| 不满足上面两条 | **一页不动**，零星标签交给 F3 按题兜底 | p16/p19/p25（保留）|
### F3 垃圾题丢弃（页内兜底）

即使整页保留，个别行仍可能是图表标签。按题丢弃（不猜内容，只做安全判定）：
- 题干 `strip` 后**不含任何中文**（纯数字/符号/英文）→ 丢；
- 题干 < 6 字 → 丢；
- 四个选项全空 → 丢。

丢弃数量写进 `meta.ocr_pages.dropped_items` 与草稿体检。

### F4 观测

- `meta.ocr_pages = {dropped_pages: [...], reasons: {p11: "chart", p41: "answer"}, dropped_items: N}`；
- 草稿体检新增一条：`已跳过 5 页图表/答案页（p11、p16、p19、p25、p41）`；
- 开关：`PAPER_OCR_PAGE_FILTER=0` 可关（默认开）。

## 4. 参数与边界

| 参数 | 取值 | 依据 |
|---|---|---|
| 页判定最少行数 | 20 | 太少的页（承上启下）不判，避免误伤 |
| 短行阈值 | ≤6 字 | 实测图表标签 2–6 字；正文选项多为 ≥8 字 |
| 长行阈值 | ≥30 字 | 正文题干/选项的基本长度 |
| 答案页 short/numeric | 0.7 / 0.2 | p41 = 0.86 / 0.41 |
| 图表页 short / 长行 / 题号 | 0.55 / ≤4 / ≤1 | 命中 p11/16/19/25，放过 p38(0.45)、p12(0.38)、p13(0.43) |
| 垃圾题 | 无中文 / <6 字 / 选项全空 | 只做安全判定，不清洗正文 |

## 5. 影响面与风险

| 项 | 判断 |
|---|---|
| 5 页探针（T5/T6 已验证）| 每页 24–34 行、短行 0–7 → **不命中任何页规则**，行为不变 |

## 9. 回归修正（2026-11-15 晚，P1 交付时发现并已修）

> **这一节是给文档纠错**：§8.2 里"96 题 / 缺号 8 个"的那一版，**把第 39 题一起丢了**。
> 旧数字保留在上面（不篡改历史实测），这里写清楚错在哪、怎么修的、现在是多少。

**错在哪**：v1 把 p11 判成 `chart` 整页丢弃。但 p11 **不是纯图表页** —— 页上有
「**39.**公安机关的人民警察为了维护社会治安秩序…」这一整道题（原图见
`assets/备考资料缺陷排查/18_证据_P1_根因4处原图.png` 的 ①）。
也就是说 v1 为了让"题号 125 消失"而整页丢，代价是**真丢了一道真题**。

**怎么修（P1-1）**：`page_kind()` 判 `chart` 之前，先看这一页有没有"像真题的题号行"
（行首题号 + 题号后 ≥6 字符 + ≥3 个汉字）。有就按正文页保留，图里的假题号
（`125.60%` / `1.12-2` 这类）交给**行级题号自洽**去挡 —— 这样既保住 39，也不让 125 复活。

**修完实测（同机同参数，41 页真卷）**：

| 指标 | v1（§8.2） | v2（P1 交付后） | 说明 |
|---|---|---|---|
| 跳过的页 | p11、p41 | **只有 p41（答案页）** | p11 改为保留 |
| 第 39 题 | ❌ 被丢 | ✅ **回来了** | 页过滤回归修好 |
| 题号 125 | 无 | **无** | 改由题号自洽挡掉（`rejected` 里有 `125.60%`）|
| 候选题目 | 96 | **96** | 清掉假题 2 条 + 重复页题 2 条 + 折行合并 1 条，同时补回 5 条（39/27/45/47/87）|
| 不同题号 | 91 | **96（重号 0）** | 这才是"能用"的口径 |
| 重复题号组 | 5 组 | **0 组** | 假题号 + 影印重复页 + 折行重复全部清掉 |
| 题号缺号 | `[27,39,45,46,47,86,87,92]` | **`[46,86,92]`** | 39 页过滤、27/45 无分隔符题号、47/87 条带回收 |
| 四选项齐全 | 87 / 96（90.6%） | **88 / 96（91.7%）** | 不下滑 |

**新增的"已知不足"（如实）**：39、47、87 三道题**题号回来了，但选项没跟着回来**
（39 的选项原卷画在流程图里；47/87 的 300dpi 条带只捞回题号那一行），
所以草稿里会看到「选项不全(39/47/87)」的标记 —— 这是**真实缺口**，不是这次改动引入的噪声。

详见 `plans/P1题号缺号重号治理_方案_v1.md` §6。
