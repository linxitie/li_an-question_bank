## 1. 本规范要解决的问题

科目说明是**结构化内容**而非自由作文：它要（a）能被 `sanitize_html` 白名单完整保留，（b）Top-10 考点能被脚本逐字校验，（c）三篇同构、便于批量维护与后续 AI 讲评复用（总方案 §6 的讲稿也以此为基础）。

## 2. 落库字段（唯一写法，不得自创）

| 字段 | 取值 | 依据 |

| `subject` | `xingce` / `shenlun` / `gongzhuan` | `materials.py:26 SUBJECTS` |

## 3. HTML 白名单（超出即被剥除，写之前先对照）

**允许**：`p br strong em u blockquote h2 h3 h4 ul ol li img a table thead tbody tr th td span`
**属性**：`img` 仅 `src`/`alt`；`a` 仅 `href`（http/https，自动补 rel）
**禁止**（会被 bleach 直接剥离或替换）：

| 禁止项 | 后果 |
|---|---|
| `div` / `section` / `style` / `script` / `iframe` | 标签被剥，只剩文字，版式全丢 |
| `class` / 内联 `style` / `id` | 属性被剥 |
| `<img src="https://…">` 外链 | `src` 被替换为 `""`（站内图片白名单） |
| `span` 之外的容器嵌套 | 依赖 `div` 的复杂卡片布局不可用 |

> 因此正文只做"文档流"表达（标题/段落/列表/表格/引用/加粗），**不做多栏卡片**。

## 4. 正文模板（5 节固定顺序，便于脚本校验）

```html
<h2>一、考试定位</h2>
<p>…该科目在笔试中的位置、考查目标、与另两科的关系，3–5 句…</p>

<h2>二、题型与配比</h2>
<table>
  <thead><tr><th>题型</th><th>题量</th><th>建议用时</th><th>备注</th></tr></thead>
  <tbody>
    <tr><td>…</td><td>…</td><td>…</td><td>…</td></tr>
  </tbody>
</table>
<p><em>注：题量/用时为区间估算，以当年考试公告与真题为准。</em></p>

<h2>三、高频考点（Top-10）</h2>
<ul>
  <li><strong>考点名（逐字取自 knowledge_point）</strong>：为什么高频 + 一句话要点</li>
  <!-- 共 10 条 -->
</ul>

<h2>四、备考路径</h2>
<ul>
  <li><strong>基础期（第 1–2 周）</strong>：…</li>
  <li><strong>专项期（第 3–4 周）</strong>：…</li>
  <li><strong>冲刺期（考前 10 天）</strong>：…</li>
</ul>

<h2>五、常见误区</h2>
<blockquote>…3–5 条，每条一句，用 <br> 分隔…</blockquote>
```

**结构断言（脚本校验）**：`h2` 恰好 5 个且顺序固定；`table` ≥1；`ul` ≥2；`li` ≥13（10 考点 + 3 路径）；`content` 中文 900–1800 字。

## 6. 起草与校验流水线（T-03）

```
1) 生成草稿（_run/drafts/<subject>.html，不入库）
2) 本地过一遍 material_sanitizer.sanitize_html，比对输入/输出：
   - 长度差 ≤ 2%   - 无 "div|class=|style=" 残留
3) 结构断言（h2=5 / table≥1 / ul≥2 / li≥13）
4) 考点断言：提取 <strong> 内容，与 knowledge_point 精确比对，要求 10/10 命中
5) 字数断言：中文 900–1800；read_time = ceil(中文字数/300)
6) 全部通过 → 才进入 T-04 入库
```

任一步失败 → 改草稿重跑，**不带着失败入库**。
