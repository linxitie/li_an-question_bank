## 3. 这些"看不到"是正常的

| 现象 | 原因 |
|---|---|
| 只有 121 有原件，别的资料没有 | B1 之前导入的源文件已被流程清理；从 B1 起的新导入都会自动留档 |
| 学生端界面上没有下载入口 | 本批只做了接口与**管理员**抽屉；学生端原件下载入口随 C 批（讲义/试卷展示）一起做 |
| 「上传时间」和原件时间可能差几分钟 | 抽屉顶部的「上传时间」取的是**资料入库时间**（A2 契约），不是文件时间；文件级时间回填随 B2 |
| 导入 xlsx 卡片后没有原件 | 一张表转 N 张卡，源表与单卡不是一对一；B2 批量导入会按"批次"留档 |
