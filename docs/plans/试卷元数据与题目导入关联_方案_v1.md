# 试卷元数据 ↔ 题目导入 的关联方案 v1

> 日期：2026-11-05　｜　状态：📋 待确认（**本轮先不动**，属题目导入线 / P2；本文只回答"怎么关联"）
> 关联：`资料内容格式与分类规范_v2.md`（模板 3 试卷元数据）、`资料上传_管理员端全员可见_方案_v2.md`（D12：试卷先作为 paper 资料）

---

## 0. 一句话

**用 `exam_paper.paper_code` 做唯一关联键**：试卷元数据（模板 3）先落成一张"空试卷"（`exam_paper` + `exam_paper_tag`），题目导入时把这个 `paper_code`/`paper_id` 传进去，题目就通过 `paper_question_relation` 挂到这张试卷上。
——**这条链路的数据结构已经存在，缺的是"元数据入库这一步"和"导入时按 code 而不是按名字猜"**。

---

## 1. 现有数据结构（实测，不是设计）

| 表 | 关键列 | 现状 |
|---|---|---|
| `exam_paper` | `paper_id`、`paper_name`、**`paper_code`（UNIQUE NOT NULL）**、`subject_id`、`exam_type`、`paper_type`、`question_count`、`composition_method`（MANUAL/IMPORT） | **3 行**：1 条测试（`paper_name='1'`）、2 条真实（2019 北京公专、2017 江苏公专），`paper_code` 是随机串（`PAPER-20261026192854-A17F99B4`） |
| `exam_paper_tag` | `paper_id`、`exam_year`、`exam_province`、`exam_type`、`subject_category`、`is_complete` | **2 行**：年份/类型/科目有值，**地区为空**（`exam_province` 全 NULL）→ 说明是自动猜的，不是填的 |
| `paper_question_relation` | `paper_id`、`question_id`、`question_order`、`question_score` | **200 行**（题目已能挂到卷上，且有 UNIQUE(paper_id,question_id) 保护） |
| `question_bank` | `question_content`、`options`、`answer`、`answer_analysis`、`point_id`、`year`、`source` | **200 题**，`point_id` **全 NULL** |

**题目导入现有能力**（`/api/questions/import/*`）：
- `/upload`（异步解析，docx/pdf/xlsx/xls/csv）、`/records/{id}/status`（进度）、`/confirm`、`/batch-parsed`、`/batch-answers`、`/separate-match`；
- `/batch-parsed` 会**自动创建/复用 ExamPaper(DRAFT)** 并批量建 `PaperQuestionRelation`，返回 `paper_id`；
- 试卷名从文件名/首行用 `_extract_paper_name` 抽，年份/类型/科目用 `_auto_detect_tags` 猜（**地区猜不出来**）。

## 2. 目标关联链路

```text
① 上传「模板_试卷元数据.xlsx」（7 列）
        │  解析 → upsert
        ▼
② exam_paper（paper_code = 规则码，如 GZ-2024-GK-Q）
   exam_paper_tag（年份 / 地区 / 类型 / 科目 / is_complete=0）
        │
        │  ← 同一次上传可附带原卷 PDF/docx（study_material type='paper'，记同一 paper_code）
        ▼
③ 上传考题（Excel 一题一行，或整卷 docx/pdf 自动拆题）
        │  前端选择「归属试卷」（下拉来自 ②，显示 科目·年份·地区·类型）
        │  或按文件名/paper_code 自动匹配
        ▼
④ POST /api/questions/import/confirm { paper_id 或 paper_code, questions[] }
        ▼
⑤ question_bank（题目）+ paper_question_relation（题序/分值）
   exam_paper.question_count 回写；exam_paper_tag.is_complete=1（题本+答案齐）
```

---

## 3. 字段映射：模板 3 → 落库

| 模板 3 列 | 落到 | 说明 |
|---|---|---|
| 科目 | `exam_paper.subject_id` + `tag.subject_category` | 行测 1 / 申论 2 / 公专 3 |
| 年份 | `tag.exam_year` | 4 位数字 |
| 地区/范围 | `tag.exam_province` | 国考 / 江苏省考 / 多省联考…（**当前全 NULL，这是要补的**） |
| 类型 | `tag.exam_type` | 题本 / 答案解析 |
| 考试名称 | `exam_paper.paper_name` + `original_title` | 原样保留 |
| 来源 | `tag` 无对应列 → 放 `exam_paper.description` 或 `question_bank.source` | 建议 `description` |
| 页数 | `exam_paper` 无对应列 → 记 `description` 或忽略 | 系统自动读 |
| 文件名 | **`paper_code` 的生成依据** + 原卷资料的关联键 | 见 §4 |

## 4. `paper_code` 规则（建议）

| 方案 | 规则 | 优点 | 缺点 |
|---|---|---|---|
| A（推荐） | `{科目码}-{年份}-{地区码}-{类型码}`，如 `GZ-2024-GK-Q`（公专/2024/国考/题本） | 人可读、可从文件名反推、天然幂等（同卷重复上传不新建） | 需要地区码词表（~30 个） |
| B | 继续用系统随机码（`PAPER-日期-随机`） | 零改动 | 无法从文件名/元数据反推，重复导入会新建卷 |

> 注意 `paper_code` 现有 `unique=True`，A 方案正好利用它做幂等：**同一份试卷重复上传 → 命中已有 code → 复用而不是新建**。

## 5. 与"原卷资料"的关联（学生端看原卷 ↔ 练题目）

| 项 | 做法 |
|---|---|
| 原卷资料 | `study_material(type='paper')`，新增 `source` 字段写 `paper_code`（不加列，复用现有 `source` 文本列） |
| 关联展示 | 学生端试卷详情页：`source` 命中 `paper_code` → 显示「开始做题」按钮 |
| 反向 | 题库试卷详情 → 显示「查看原卷」，指向 `study_material` 详情 |

> 这样**一份卷子只有一份原文件**（不会资料库、题库各存一份），符合"媒体/文件不入两处"的既有约定。

## 7. 现状的三个坑（必须先知道）

| # | 坑 | 后果 |
|---|---|---|
| P1 | `exam_paper_tag.exam_province` **全 NULL** | 试卷无法按地区筛，"国考/省考"这类分类缺失 |
| P2 | 试卷名靠**文件名/首行猜**（`_extract_paper_name`） | 文件名不规范就会造出"新建文件夹2"这种试卷 |
| P3 | `question_bank.point_id` **200/200 全 NULL** | 题目挂不到考点，练习无法按考点统计/推荐 |
