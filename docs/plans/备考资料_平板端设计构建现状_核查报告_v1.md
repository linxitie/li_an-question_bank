# 备考资料 · 平板端设计构建现状核查报告

> 版本：v1（2026-11-02）｜分支 `feat/Study-Material-Management-r4`（`main` 未动）
> 核查方式：静态读码（路由/样式/平台判断）＋ 真实浏览器实测（iPad UA、768×1024 与 1024×768、触屏模拟、真实学生登录态）
> 脚本：`scripts/verify/tablet_audit_shots.mjs` → 11 张截图 + `docs/plans/assets/备考资料_平板端验收/_audit.json`

---

## 1. 一句话结论

**平板端是「复用手机页 + 零适配代码」，不是「设计过的第三端」**：功能一条不缺（能看卡、能翻页、能建卡、能传 Excel、能看徽章），
但版式是手机版按比例拉宽——卡片在 768 宽下变成 735×226（宽高比 3.25，手机是 1.58），横屏 1024 下变成 991×226（4.39），
触控目标最小只有 28px 高；而且**平板首页没有备考资料入口**，唯一入口藏在「我的 → 离线下载」。

## 2. 家底（实测）

### 2.1 路由：21 条平板路由 = 7 平板原生 + 14 复用手机页

| 类型 | 条数 | 例子 |
|---|---|---|
| 平板原生（`$vtj/vue/tablet_*.vue`） | 7 | `/tablet/home`、`/tablet/login`、`/tablet/practice`、`/tablet/forum`、`/tablet/profile`、`/tablet/question-bank`、`/tablet/gold-purchase` |
| 复用手机页（`@/views/student/mobile/*`） | 14 | `/tablet/materials`→`mobile_materials.vue`、`/tablet/news`、`/tablet/favorites`、`/tablet/calendar`、`/tablet/answer`、`/tablet/notes` … |

复用比例 **14 / 21 = 67%**，符合项目红线 R12（禁止为平板复制手机页）。

### 2.2 备考资料相关的三条路由

| 能力 | 平板走的路由 | 组件 | 是否平板专属 |
|---|---|---|---|
| 资料列表 / 卡片栈 / 翻转 / 配图 / 翻页 / 建卡弹层 | `/tablet/materials` | `src/views/student/mobile/mobile_materials.vue` | 否，复用手机页 |
| 徽章墙 / 精选 | **无平板路由**，走 PC 的 `/badges` | `src/views/student/badges.vue` | 否 |
| 逐张创建 + Excel 批量 | `/materials/upload?tab=excel`（**无平台前缀**） | `src/views/student/material_upload.vue` | 否 |

### 2.3 关键代码事实

| 事实 | 证据 |
|---|---|
| **`src/` 里 0 处按平台分支**（`isTablet`、`meta.platform === 'tablet'` 均无命中） | `grep -r "isTablet\|platform === 'tablet'\|meta\.platform" src` → 0 命中；`meta.platform` 只在 `src/router/index.ts` 里**声明**，没有消费方 |
| 设备判定：768–1024 宽 + 有触摸 → `tablet` | `src/utils/device.ts:21-26` |
| **PC→设备路径映射表没有备考资料** | `src/utils/device.ts:109-128` 只映射 `/`、`/home`、`/login`、`/question-bank`、`/forum`、`/practice`、`/profile`；`/materials`、`/badges`、`/materials/upload` 均无映射 → 不会自动跳转 |
| 平板唯一的备考资料入口 | `src/views/student/tablet_profile.vue`：`goToDownloads = () => router.push('/tablet/materials')`，按钮文案「离线下载」 |
| 平板首页没有备考资料/徽章入口 | `.vtj/vue/tablet_home.vue` 中 `materials`、`badge`、`备考`、`徽章` 全部 0 命中（只有「公安联考备考学员」一句文案） |
| 卡片尺寸是手机量：**宽 100%、高固定 226px** | `mobile_materials.vue:624-640`：`.stack{height:256px}`、`.stack-card{left:0;right:0;height:226px}`，无 `max-width`、无 `@media` 断点（该文件只有 `prefers-reduced-motion` 一条媒体查询） |
| 建卡弹层全屏、无最大宽 | `mobile_materials.vue:523-532` `.modal{max-width:560px}` 是详情弹层；建卡用 `.cc-*`，实测 768×1024 满屏 |

## 4. 问题清单（按严重度）

| 级别 | 问题 | 影响 |
|---|---|---|
| **P1** | 卡片固定 226px 高、宽度吃满 → 768 下 3.25、1024 下 4.39 的宽高比，正文区域大片留白 | 平板观感像「拉宽的手机」，与「三端适配」的承诺有差距 |
| **P1** | 平板首页无备考资料/徽章入口，唯一入口文案叫「离线下载」 | 老师/学生拿到平板找不到资料模块 |
| **P1** | 交互元素高度 28–34px（<44px） | 触屏误触、点不着 |
| **P2** | 徽章无平板路由（走 PC 页），`/materials/upload` 无平台前缀 | 路由层没有「平板语义」，将来加分页/左右栏没地方挂 |
| **P2** | PC 与平板两套路由同时可打开（`/materials/shenlun` 在 768 下也能开，卡片高 1340px） | 同一功能两套界面并存，样式债 |
| **P3** | `DEVICE_ROUTE_MAP` 未映射备考资料 → 平板访问 PC 链接不会自动转平板版 | 需要用户手动改地址 |

> 说明：建卡弹层一开始被我误判为「满屏无最大宽」——那是量到了遮罩 `.cc-mask`（本来就要铺满）；
> 复核 `.cc-panel` 后是 520×440，有 `max-width:520px`，**不是缺陷**，已从问题清单移除。

## 5. 建议方案（**待你批准后再动手**）

### A 档 · 最小改动（约 0.5–1 天，改动 3 个文件，不动 `.vtj` 模板）

1. `mobile_materials.vue` 增加 `@media (min-width: 700px)`：`.stack{height:auto}`、`.stack-card{height:clamp(240px, 34vw, 320px); max-width:640px; margin:0 auto}`、底部按钮 `min-height:44px`、建卡弹层 `max-width:640px`。
2. `src/router/index.ts` 增加 `/tablet/badges`（复用 `badges.vue`），`DEVICE_ROUTE_MAP.tablet` 补 `/materials`、`/badges`、`/materials/upload`。
3. 平板首页入口：**受红线 R3 限制，`.vtj/vue/tablet_home.vue` 的模板必须你在设计器里拖**（我只能改 `<script>`），或先用 DOM 注入方案（与 PC 三轮同法）临时放一个「备考资料」入口。

### B 档 · 组件化（约 2–3 天）

把卡片栈抽成 `src/components/materials/CardStack.vue`，`mobile_materials.vue` 与（将来的）平板页都用它，用 `props.platform` 控制高度/栏宽/按钮尺寸；徽章墙同理抽 `BadgeWall`。

### C 档 · 平板专属布局（约 1 周）

按 R12「不复制页面、用 platform 区分」：`/tablet/materials` 走双栏（左列表 320px + 右卡片区），卡片恢复近 3:4 比例，触控目标 44px 起；配套 `tablet_audit_shots.mjs` 断言扩到 15–20 条（含双栏断点、44px、无溢出）。

## 7. 已知不足（本报告自身）

1. 翻转/翻页的「中间帧」受 Chrome 遮挡不产帧影响，只能验状态类与终态尺寸，不能截图留证动画过程（与四轮同因）。
2. 未在真机（iPad / 安卓平板）上验证，用的是 Chrome 设备模拟 + iPad UA + 触屏模拟；真机的安全区、字体回退、滚动惯性可能有差异。
3. 没有覆盖管理端/教师端在平板上的表现（本轮只核学生端备考资料链路）。
4. 「离线下载」按钮实际跳的是备考资料，文案与行为不一致，这条是既有实现，未在本轮改动。
5. 本报告初稿曾把遮罩 `.cc-mask` 当弹层面板，误记「建卡弹层满屏」；复测 `.cc-panel` = 520×440 后已更正并在第 4 节留痕。
