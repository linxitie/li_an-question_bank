## 3. 环境与坑（踩过的，别再踩）

| 坑 | 现象 | 解法 |
|---|---|---|
| 后端无 `--reload` | 改后端不生效 | 每次改完后端**必须重启 8000** |
| 9527 是 dev server | 页面里是 `/@vite/client`、`/src/main.ts`；`main.*.js` 是旧标签页残留 | 改代码后普通刷新即可，**不需要 build**；`dist/` 只在需要时构建 |
| 媒体缓存 `immutable` | 修好后仍下载到旧 HTML | 已加 `_t` 时间戳 + `no-store` |
| PowerShell 引号 | `node -e`/`python -c` 带引号被吃坏 | 一律写 `.py`/`.mjs` 文件再执行 |
| 文件 EOL | 锚点 `\n` 匹配不到 CRLF 文件 | 补丁脚本先用 `E = "\r\n" if "\r\n" in t else "\n"` |
| passlib+bcrypt | `module 'bcrypt' has no attribute '__about__'` | 直接 `bcrypt.hashpw` |
| 控制台 GBK | pytest 打印 emoji 崩溃 | `$env:PYTHONIOENCODING="utf-8"` |
| 教师端登录时序 | 登录后立刻 goto → 停在 dashboard | 等 4–5s 或轮询等 `.tf-card` |
| 手机/平板路由鉴权 | 教师账号访问 `/mobile/*` 被拦 | 必须用**学生**账号验证 |
| 整份 `--theirs` | 合并时丢掉本分支全部改动 | 冲突只能**逐块**解 |
