## 1. 逐项证据

### 1.1 退出登录无效

```js
// TeacherNavHeader.vue:373
function handleLogout() {
  showUserMenu.value = false;
  emit('logout');          // 只有这一句
}
```

`teacher_forum.vue:3` 是 `<TeacherNavHeader active-nav="forum" />`，**没有 `@logout`**。其它教师页可能各自处理，这里没人处理 → 点击无反应。

**修法（只改 script，R3 允许）**：

```js
function handleLogout() {
  showUserMenu.value = false;
  const auth = (window as any).__VTJ_AUTH__;
  auth?.logout?.();
  try { localStorage.removeItem('__VTJ_AUTH_STATE__'); } catch {}
  emit('logout');                 // 保留，兼容现有父页面
  router.push('/login');          // 组件内自兜底
}
```

> 为什么在组件内兜底而不是每页加 `@logout`：教师端页面有 8 个，逐个加监听会遗漏；组件内自兜底一次解决。

### 1.2 右栏固定 + 回到顶部

实测（1440×900）：`.forum-right` 高度 **2552px**，与 `.forum-body` 等高；滚动 600px 后 `top` 变为 -444。

```css
/* forum.vue:1226 */
.forum-body { display: grid; grid-template-columns: 1fr 300px; }
```

grid 子项默认 `align-self: stretch` → 右栏被拉满整列 → sticky 无空间。

「发布新帖」在 `.forum-header`（`forum.vue:11`），不在右栏内，需要单独 sticky。

**回到顶部**：PC 论坛是 VTJ raw 页，直接加按钮要改 template（R3）。改为**全局组件**挂在 `src/App.vue`（手写文件），按路由白名单显示——三端都能用，完全不碰 VTJ 模板。

### 1.3 手机端标题颜色不生效

链路已完整：

```
手机发帖 mobile_forum_create.vue:108  titleColor: titleColor.value
API    src/modules/community/api.ts:321 title_color: payload.titleColor
后端   forum.py:395 接收 → :445 校验 → :454 写库
返回   forum.py:158 "titleColor": post.title_color or "default"
PC     forum.vue:42（列表）:280（详情）  titleColorValue(post.titleColor)  ✅
平板   tablet_forum_detail.vue:21        titleColorValue(post.titleColor)  ✅
手机   mobile_forum.vue（列表）          未使用  ❌
手机   mobile_forum_detail.vue（详情）   未使用  ❌
平板   tablet_forum.vue（列表）          未使用  ❌
```

**修法**：三处加上 `:style="{ color: titleColorValue(post.titleColor) }"`。
- 手机详情、平板详情/列表若为手写页可直接改；**手机列表 `mobile_forum.vue` 是 raw 页，改 template 需你授权**。
- 平板列表 `tablet_forum.vue` 同为 raw 页。

### 1.4 教师端标题颜色

`forum_moderation.py:_post_item` 直接 `_serialize_post(...)` 再合并字段（`:85-100`），因此 **titleColor 已经在响应里**。教师端模板没用。

**修法**：`teacher_forum.vue` 两处标题加 `:style`（手写页）。

### 1.5 教师端侧栏 + 发帖

- 侧栏三卡的数据源已存在：`/api/forum/stats`（`:1208`）、热门帖子（`/api/forum/posts?sort=likes`）、`/api/forum/my-posts`（`:1166`）。
- 发帖：`/api/forum/posts` 的 `create_post` 只依赖 `get_current_user`，**教师可直接调**，无需改后端。
- 教师端是手写 SFC，新增侧栏与发帖弹窗不受 R3 限制。

### 1.6 / 1.7 收藏与喜欢

现状：
- `forum_like`（`models.py:1119`）已有 `reaction_code`（like/love/haha/wow/sad/angry），唯一约束 `(post_id, user_id)` —— **一个用户对一篇帖子只能有一种反应**。
- **没有帖子收藏表**（`FavoriteQuestion`/`NewsFavorite`/`QuoteFavorite` 都是别的业务）。
- 因此「我的收藏」必须新建表；「我的喜欢」可复用 `forum_like`。

### 阶段 P3 — 后端新表 + 收藏/喜欢功能

**3.1 数据模型**

```python
class ForumFavorite(Base):
    __tablename__ = "forum_favorite"
    favorite_id = Column(Integer, primary_key=True, autoincrement=True)
    post_id = Column(BigInteger, ForeignKey("forum_post.post_id"), nullable=False)
    user_id = Column(BigInteger, ForeignKey("sys_user.user_id"), nullable=False)
    create_time = Column(DateTime, default=datetime.now)
    __table_args__ = (UniqueConstraint("post_id", "user_id", name="uk_post_user_favorite"),)
```

**3.2 新增接口（全部 `/api/forum/...`，遵循 R11 不新增 `/api/v1`）**

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/forum/posts/{id}/favorite` | 收藏 / 取消（toggle），返回 `{favorited, favoriteCount}` |
| GET | `/api/forum/my-favorites` | 我的收藏列表（分页，含帖子摘要与作者） |
| GET | `/api/forum/my-likes` | 我点赞过的帖子（基于 `forum_like.reaction_code='like'`） |
| GET | `/api/forum/posts`（扩展） | 返回项补 `favorited`、`favoriteCount` |

**3.3 迁移与备份**

按 **R10**：迁移前用 `sqlite3.backup()` 备份到 `backend/data/example_db.bak_pre_favorite_YYYYMMDD.sqlite`；建表用 `Base.metadata.create_all` 增量（项目现有做法），不删列不改列。

**3.4 前端**

- PC：发帖按钮左侧两个入口 → 打开「我的收藏 / 我的喜欢」弹窗（列表 + 分页 + 跳转帖子）。
- 手机上「我的」页已有收藏入口（`favorites` 页），论坛收藏需要新入口或复用；**本期先做 PC + 教师端，手机/平板入口列 P4**。
- 点赞按钮已有；补充「已赞」态与取消逻辑校验。

**3.5 安全**

- 收藏/取消都走 `get_current_user`，只操作自己的记录。
- 列表接口只返回本人收藏，禁止传入他人 `user_id`。
- 帖子被删除/隐藏时，列表需过滤 `status='NORMAL'`。

## 4. 验收标准（分阶段）

**P1**
- 教师端点「退出登录」→ 跳回 `/login`，`localStorage.__VTJ_AUTH_STATE__` 被清除
- PC 论坛滚动 600px：右栏三卡仍在视口内；「发布新帖」仍在顶部
- 三端滚动 > 400px 出现「回到顶部」，点击回到顶部（平滑滚动）
- 手机详情打开带颜色的帖子 → 标题为对应颜色
- 教师端列表/详情 → 标题颜色与发帖时一致
- 教师端评论三列排版（头像 / 内容 / 操作），附件左对齐

**P2**
- 手机列表、平板列表标题颜色正确
- PC 三个按钮（我的收藏 / 我的喜欢 / 发布新帖）同高同风格

**P3**
- 收藏 → 帖子出现在「我的收藏」；再点取消 → 消失；刷新后状态保持
- 「我的喜欢」只列出被点赞的帖子
- 他人的收藏不可见（接口层校验）
- 迁移前有备份文件，迁移后 `db_tables.json` 多出 `forum_favorite`

## 5. 风险

| # | 风险 | 对策 |
|---|---|---|
| 1 | 组件内兜底 logout 与父页面 `@logout` 重复执行 | 幂等：logout 可重复调用；先检测 token 是否存在 |
| 2 | `.forum-header` sticky 后遮挡分类栏 | 右栏 `top` 与 header 高度联动（60px），滚动时验证不重叠 |
| 3 | 全局 BackToTop 出现在不该出现的页面 | 路由白名单 + `scrollY > 400` 双条件 |
| 4 | 新表迁移影响现有数据 | 只建新表；R10 备份；迁移脚本幂等（`CREATE TABLE IF NOT EXISTS` 语义） |
| 5 | 收藏与点赞语义混淆 | UI 文案明确：收藏=收进个人清单，点赞=公开展示热度 |
