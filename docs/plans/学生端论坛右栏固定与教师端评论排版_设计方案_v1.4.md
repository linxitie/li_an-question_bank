# 学生端论坛右栏固定 + 教师端评论排版修复 — 设计方案 v1.4

> 状态：**待批准**，本文只做设计，不含代码改动。
> 日期：2026-10-26
> 涉及文件：`.vtj/vue/forum.vue`（学生端 PC 论坛，**raw 页，只改 `<style>`**）、`src/views/teacher/teacher_forum.vue`（教师端，**手写 SFC**）

---

## 0. 结论先行

1. **学生端右栏没固定，是因为它被 grid 拉伸成了整列高度**：实测 `.forum-right` 高 2552px，与左侧帖子列表等高（`.forum-body` 也是 2552），`position: static`。grid 的子项默认 `align-self: stretch`，所以即使加了 `sticky` 也没有可粘的余量。修法 = `align-self: start` + `position: sticky`（纯 CSS）。
2. **教师端评论乱，是因为每条评论没有任何布局容器**：`UserBadge`、班级标签、正文 `<p>`、附件、隐藏按钮五个元素按 inline 顺序直接堆在一个 `div` 里（`teacher_forum.vue:61-81`），`.tf-comment` 只有一条 `border-top`。修法 = 给 `.tf-comment` 一个三列 grid（头像 / 内容 / 操作），纯 CSS。
3. 两处都不改后端、不执行 DSL 同步；学生端不碰 template，教师端也不需要改 template。

## 1. 问题一：学生端右栏跟随滚动

### 实测（1440×900，`/#/forum`）

| 元素 | position | top（滚动前） | top（scrollY=600） | 高度 |
|---|---|---|---|---|
| `nav` | static | 0 | -600 | 64 |
| `.forum-header`（含「发布新帖」） | static | 88 | -512 | 44 |
| `.forum-right` | static | 156 | -444 | **2552** |
| `.forum-body` | static | 156 | -444 | 2552 |

页面用 window 滚动（`docH 2748`，`scrollY 600` 生效），顶部导航本身也会滚走。

**根因**：`.forum-body { display: grid; grid-template-columns: 1fr 300px; }`（`forum.vue:1226`），右栏作为 grid item 默认 `align-self: stretch`，被拉成与左栏同高 2552px —— 没有"剩余滚动空间"，`sticky` 无从生效。

### 方案

```css
.forum-right {
  position: sticky;
  top: 24px;              /* 顶部导航会滚走，所以只需留 24px 间距 */
  align-self: start;      /* 关键：取消 grid 拉伸，否则 sticky 无效 */
  max-height: calc(100vh - 48px);
  overflow-y: auto;       /* 侧栏自身内容超过视口时可内部滚动 */
}
```

### 待你选：要不要连「发布新帖」一起固定

`screenshot` 里你圈的区域包含顶部的「发布新帖」按钮，但它在 `.forum-header` 里，不在右栏内。

| 选项 | 做法 | 效果 |
|---|---|---|
| **A（推荐）** | 只固定右栏卡片 | 「发布新帖」随页面滚走，三张卡片常驻 |
| B | 同时把 `.forum-header` 设为 `sticky; top: 0`，右栏 `top: 60px` | 标题 + 发布按钮 + 右栏都常驻 |

选 B 的话页面顶部会一直有一条「备考论坛」标题栏，视觉上更稳，但也更占高度。

## 2. 问题二：教师端评论排版

### 现状结构（`teacher_forum.vue:61-81`）

```html
<div class="tf-comment">
  <UserBadge size="sm" ... />                     <!-- inline -->
  <span class="tf-meta">{{ className }}</span>    <!-- inline，紧贴头像 -->
  <p><ForumContent :content="c.content" /></p>    <!-- 默认 <p> 上下 margin -->
  <AttachmentList ... />                          <!-- 独占一行，无间距控制 -->
  <button class="tf-danger small">隐藏评论</button> <!-- 跟在附件后面 -->
</div>
```

CSS 只有一行：`.tf-comment { border-top: 1px solid #eef1f7; padding-top: 8px; margin-top: 8px; }`

于是：头像和「测试班」挤在一起、正文与附件之间间距由浏览器默认 margin 决定、「隐藏评论」孤零零挂在附件下方、多条评论之间节奏不一致——就是你截图里的样子。

### 方案：三列 grid

```
┌─────┬──────────────────────────────┬──────────┐
│ 头像 │ 昵称 · 班级标签               │ 隐藏评论 │
│     │ 评论正文                      │          │
│     │ [附件]                        │          │
└─────┴──────────────────────────────┴──────────┘
```

```css
.tf-comment {
  display: grid;
  grid-template-columns: auto 1fr auto;
  column-gap: 10px;
  row-gap: 6px;
  align-items: start;
  border-top: 1px solid #eef1f7;
  padding: 14px 0;
}

.tf-comment :deep(.user-badge) { grid-row: 1; grid-column: 1; }
.tf-comment > .tf-meta { grid-row: 1; grid-column: 2; align-self: center; }
.tf-comment > .tf-danger { grid-row: 1; grid-column: 3; align-self: center; }
.tf-comment > p { grid-row: 2; grid-column: 2 / 4; margin: 0; line-height: 1.6; }
.tf-comment :deep(.attachment-list) { grid-row: 3; grid-column: 2 / 4; }
```

配套微调：

```css
.tf-modal-card h3 { margin: 20px 0 4px; font-size: 15px; color: #1a2b5f; }  /* 评论标题 */
.tf-modal-card > h2 { margin: 0 0 6px; }
```

### 为什么用 grid 而不是 flex

- 三列（头像 / 内容 / 操作）是固定结构，grid 用 `grid-row/column` 精确落位，不依赖 DOM 顺序；
- 附件是 `v-if` 渲染的，用 `nth-child` 会错位，grid 按类名定位不受影响；
- 后续若加"点赞/回复"按钮，直接塞进第 3 列，不用重排。

## 3. 安全与运维

| 关注点 | 结论 |
|---|---|
| 影响面 | 学生端只动 `.forum-right` 一条规则；教师端只动 `.tf-comment` 与两条标题规则 |
| R3/R2 | 学生端只改 `<style>`；教师端是手写 SFC，且同样只改 `<style>` |
| 后端 | 零改动（两个问题的数据都已正确返回） |
| 回滚 | 单提交可回滚 |
| 兼容性 | `sticky` 与 `grid` 均为现代浏览器标准；VTJ 外层若产生新的滚动容器导致 sticky 失效，用验收 #1 立即暴露 |
| 可维护性 | 每条规则带注释说明"为什么 align-self: start"、"为什么用 grid 定位" |

## 5. 风险

| # | 风险 | 对策 |
|---|---|---|
| 1 | VTJ 外层容器导致 `sticky` 不生效 | 验收 #1/#2 先跑；失败则改为「右栏独立滚动容器 + 页面不滚」方案（需 template） |
| 2 | 右栏 `max-height + overflow` 在小屏出现双滚动条 | 仅在内容超视口时出现，且 `overscroll-behavior: contain` 可抑制滚动穿透 |
| 3 | 教师端 `:deep(.user-badge)` 依赖组件类名 | 与既有做法一致，组件改版需同步 |
| 4 | 评论为空时的样式 | `.tf-empty` 不受影响 |
