## 1. 解决了什么

**实测缺陷**（诊断见 [试卷上传到学生开考_现状链路_v1.md](试卷上传到学生开考_现状链路_v1.md)）：上传试卷只落
`study_material(status=0)` + 原件 + `paper_code`，**不建 `exam_paper`** → 学生端永远看不到上传的真题。
#127「2024国考·公专题本」（`GZ-2024-GK-T`）上传 3 天仍是"有资料无卷"。

本批补上「资料 → 卷」这一步：

```
资料管理页 ──「建卷」──▶ POST /api/materials/admin/{id}/ensure-paper
                              └─ services/material_paper_link.ensure_paper_for_material()
                                  · 用 paper_code（回落 badge）建 exam_paper(DRAFT)
                                  · 元数据：人工订正 > 文件名解析；缺省 120 分钟 / 100 分
                                  · 幂等：同编号已存在则复用，绝不覆盖状态/题目
                          ──▶ 卷就绪（0 题）
                                  · 导入题目（下一步）
                                  · 资料「上架」──P5──▶ 卷自动 PUBLISHED ──▶ 学生可考
```

## 3. 关键行为

| 场景 | 行为 |
|---|---|
| 正常建卷 | 用 `paper_code` 建 `exam_paper`：`composition_method=IMPORT`、**`paper_type=DRAFT`**、`question_count=0`、时长/总分取订正或解析（缺省 120/100）、科目按 `xingce/shenlun/gongzhuan` 映射 |
| 同编号已存在（含 PUBLISHED） | 返回 `created=false` + 已有卷信息，**不覆盖状态、不动题目** |
| 非试卷资料 | 400「只有「试卷」类资料才能生成可作答卷」 |
| 试卷资料但没编号 | 400「没有试卷编号（paper_code）… 请先在「改信息」里补编号」 |
| 非管理员 | 403 |
| 与新卷可考性 | 新卷是 DRAFT → 学生看不到；**资料上架后由 P5 自动 PUBLISHED**（已实测串联） |
