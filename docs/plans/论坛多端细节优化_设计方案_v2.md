## §1 逐项方案

### #1 详情标题不越界

```scss
/* src/style/index.scss */
.forum-page .detail-title,
.forum-page .post-detail-card h3,
.tablet-forum-page .post-title,
.mobile-forum-page .detail-title,
.tf-page .tf-modal-card h2,
.tf-page .tf-modal-card h3 {
  overflow-wrap: anywhere;
  word-break: break-word;
}
.forum-page .post-detail-card,
.tf-page .tf-modal-card { min-width: 0; }
```

放全局而不是 raw 页 `<style>`：R3 只允许改 `<script>`，全局样式零模板风险、可独立回滚。
验收：造一条连写数字标题 → 断言 `.detail-title` 的 `scrollWidth <= clientWidth`。

### #2 点赞 / 收藏微动效

- 点赞：爱心 `transform: scale(1) → 1.35 → 0.95 → 1`（240ms spring）+ 一个 `❤` 上浮淡出（400ms，伪元素实现）。
- 收藏：五角星 `rotate(0 → 18deg → -12deg → 0)` + 轻微放大。
- 纯 CSS：仅在 `.heart-icon.active` / `.star-icon.active` 上挂 `animation`，类切换即播放，零 JS、零 DOM 改动。
- `prefers-reduced-motion: reduce` 时全部关闭（无障碍）。

### #3 手机端热门回退近 7 日

```ts
// mobile_forum.vue: hot 分支
// 1) 先查当天；2) 结果为空 → 改查 today-6 .. today，并标记 hotRange='week'
```

- 页签文案：`今日热门`（当天有帖）/ `今日热门 · 近 7 天`（回退后）/ 仍为空则不标注。
- 与 PC 端 `state.hotIsWeek` 语义保持一致。
- 只在「当天为空」时才发第二次请求，正常路径零额外请求。

### #4 查看更多弹窗补正文摘要

| 位置 | 现在 | 改为 |
|---|---|---|
| 热门「查看更多」弹窗（`showHotAll`） | 排名 + 标题 + 统计 | 补 `.list-excerpt`（2 行） |
| 我的帖子弹窗（`showMyPosts`） | 摘要被 flex 挤没 | `.my-post-item` 加 `flex-wrap:wrap`，摘要 `flex:0 0 100%` |
| 收藏/喜欢弹窗（`.fav-item`） | 同上 | 同上 |

用 `flex-wrap` 而不是改 grid：任意子元素数量都能正确换行，侵入更小。

### #5 去掉点赞旁的大拇指

- `post.likeCount = String(reactionCount ?? 0)`（纯数字）；
- `formatReactionSummary()` 的结果（`👍1`）移到 `title` 属性，悬停可见；
- 保留 `reactions` 数据与接口，本轮只改显示，不改协议。


新增 4 条 e2e：

1. `#4 查看更多弹窗显示正文摘要`：断言 `.list-excerpt` 非空 **且宽度 > 80px**（专治「被 flex 挤没」）。
2. `#5 点赞计数是纯数字`：断言按钮文本不含 `👍`，去掉爱心/空白后只剩数字。
3. `#1 详情里的超长标题不越界`：取标题最长那条，断言标题与详情卡片 `scrollWidth - clientWidth <= 1`。
4. `#3 手机端热门回退（网络拦截造数据）`：当天区间返回空、近 7 天区间返回 1 条，
   断言页签变成「今日热门 · 近 7 天」、两个区间都请求过、列表渲染出样例帖。

> 单独重跑该文件 6 passed，第二次全量 13 passed。该页面本轮未改动。

## §4 风险与回滚

| 风险 | 对策 |
|---|---|
| 全局样式影响其它页面 | 每条规则都带真实根类前缀（`.forum-page` / `.tablet-forum-page` / `.mobile-forum-page` / `.tf-page`） |
| 动效影响晕动症用户 | 仅 transform/opacity，且 `prefers-reduced-motion` 关闭 |
| 手机端回退多打一次请求 | 只在「当天为空」时触发 |
| 改 raw 页 | 沿用 v1 的显式授权，改前照例备份 |
