## 1. 先看四个按钮（管理端资料页右上角）

|---|---|---|
| **＋ 上传试卷** | 传真题原卷（可自动建卷） | 「上传试卷（原件留档）」批量对话框（类型预置=试卷） |

## 2. 现在能上传的 5 类文件 + 1 类答案

| # | 类型 | 入口 | 接受格式 | 限额 | 上传后是什么 |
|---|---|---|---|---|---|
| 1 | **试卷（真题原卷）** | ＋ 上传试卷 | `docx / doc / pdf / xlsx / xls` | 单个 **≤20MB**；一次 **≤50 个**、合计 **≤2GB**；同名 docx+pdf 合成一条（docx 主、pdf 附件） | 建一条**未上架**试卷资料 + 原件留档；文件名能解析出年份/地区时**自动建 0 题草稿卷**（投放位=考试页/都投才建） |
| 2 | **讲义** | 批量导入（类型=讲义） | 同上 | 同上 | 建未上架讲义 + 原件留档 + docx 抽章节大纲；**正文不入库**（学生端在线阅读为空） |
| 3 | **文章** | 批量上传文章 | `docx / pdf` | 一次 ≤50 个、合计 ≤2GB | 解析正文 HTML 入库（可在线阅读）；默认未上架，可勾「立即上架」 |
| 4 | **卡片（批量）** | 旧版 → 智能导入 | `xlsx`（正面/背面/分类/考点/封面列映射） | xlsx **≤5MB**；单次 **≤500 行** | 批量建卡（默认未上架），可去列表批量上架 |
| 5 | **卡片（单条）** | 学生端 `/materials/upload`（学生/教师/管理员都可用） | 表单 + 可选配图 | 按表单限制 | 建一张卡（自己的库） |
| 6 | **视频** | ❌ 当前无可用入口 | — | — | 类型白名单里有，但全库 0 条；旧版里的分片上传不建议再用 |
| 7 | **答案**（写题库，不是资料） | 试卷行「补答案」 | `pdf / docx / xlsx / xls / txt / csv` | **≤30MB** | 解析成草稿 → 逐题核对 → **只写** `question_bank.answer` + `answer_analysis` |

> **扫描件（2026-11-13 更新）**：PDF 里没有文字层（整页是图片）时，各通道待遇：
> · **答案 PDF**（「补答案」）→ **已支持**：自动走本地 OCR（约 8.6–17s/页），草稿会写明「扫描件已 OCR 3/3 页（28.1s，200dpi），识别文字请逐题核对」；
> · **文章 / 讲义**（「批量上传文章」/「批量导入」）→ **已支持（P2）**：自动 OCR 成**段落文本**；界面显示「OCR 12/24 页 · 已用 1:36」，完成后显示「已 OCR 24/24 页」，>60 页只识别前 60 页会明确提示；
> · **试卷原件**（「＋ 上传试卷」）→ **仍不支持**，还是那句「该 PDF 为扫描图片版且系统 OCR 组件未就绪」（导题链路 P3 未接）。
> 代价提醒：OCR 是**纯文本**，表格/双栏会按阅读顺序拆散，错字需人工校对；入库默认**未上架**，请先预览再上架。

## 3. 三条标准流程（照着点即可）

### A. 传试卷（并让它变成"可考卷"）

1. 「＋ 上传试卷」→ 选 **科目**（必填）、**类型=试卷**、分类（可选，如"基础知识"）、**投放位**（仅考试页 / 仅资料页 / 都投）、是否「立即上架」；
2. 选文件（可多选）→ 队列逐条上传，右侧显示"成功 / 重复 / 失败 + 原因"；
3. 看每行提示：
   - 「已自动建卷 `GZ-2019-BJ-T`（0 题，导题后学生才能考）」→ 编号已生成；
   - 「未自动建卷：编号解析失败」→ 去「改信息」补编号，或点「建卷」；
4. 列表点**上架**（=审批通过）→ 学生能看到原卷，卷同步变 PUBLISHED；
5. 再走：**导题**（原件拆题→逐题确认→入库）→ **补答案**（答案 PDF → 核对 → 写入）→ **考试开关/定时** → 学生可考。

**文件名建议**：`年份 + 地区 + 卷别`，例如 `2019年北京市公务员考试《公安专业科目》真题.pdf`。
实测 517 份真文件：科目 100%、年份 100%、地区 99.4%、题本/答案 99.8%、四要素齐 99.2%。

### B. 传文章（带正文，可在线阅读）

「批量上传文章」→ 选科目 → 决定是否勾「立即上架」→ 选 docx/pdf → 逐条"上传 → 解析 → 入库"。
不勾上架：到列表里逐条/批量上架；勾了：入库即上架（学生立刻可见）。
扫描版 PDF 的**文章/讲义**现已支持（自动 OCR，页级进度，约 10–20 秒/页）；试卷原件仍不支持（P3 待接）。

### C. 传讲义

「批量导入」→ 类型=讲义 → 选文件 → 上传（**只留档 + 抽大纲**）→ 上架。
**注意**：讲义正文没有入库，学生端点开是空的；要让讲义可读，需要走"解析导入"的讲义分支（`import/upload` + `confirm type=lecture`），**当前 UI 还没接**——这是已知缺口。

## 4. 传完之后：上架 = 审批

- 所有上传默认 **未上架（status=0）**，学生看不到；
- 列表点「上架」= 审批通过 → 学生可见；试卷还会联动 `exam_paper` 变 `PUBLISHED`（P5 联动）；
- 批量：列表勾选 → 「批量上架 / 批量下架」；
- 「立即上架」只影响**本次上传**那一批，不是全局开关。

## 5. 限额与格式（速查）

| 项 | 值 |
|---|---|
| 原件类单文件 | **20MB**（docx/doc/pdf/xlsx/xls；后端校验扩展名 + 文件头） |
| 一次批量 | **50 个文件 / 2GB**（前端队列把关，服务端逐个收） |
| 解析导入（文章）单文件 | docx/pdf ≤20MB；xlsx ≤5MB |
| xlsx 卡片 | ≤5MB、≤500 行 |
| 答案文件 | ≤30MB，pdf/docx/xlsx/xls/txt/csv |
| 双格式配对 | 同名 docx + pdf → 一条资料（docx 主文件、pdf 附件） |
| 去重 | 同一文件（名+大小+sha256）跳过并回已有 id；同内容入库时 409（接口可 `force=true`） |

## 6. 常见报错与处理

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 红字「该 PDF 为扫描图片版且系统 OCR 组件未就绪」 | 走的是**试卷原件**通道（导题链路还没接 OCR） | 文章/讲义请改用「批量上传文章」（已支持扫描件）；试卷先转文字版 |
| 「编号解析失败 / 未自动建卷」 | 文件名里缺年份/地区/卷别 | 「改信息」补编号，或点「建卷」 |
| 「重复」 | 同文件已传过（sha256 相同） | 直接去列表找已有资料；确需再存一份走接口 `force` |
| 「文件超过 20MB 上限」 | 单文件过大 | 拆分/压缩；答案文件上限 30MB |
| 「仅支持 docx / doc / pdf / xlsx / xls 原件」 | 扩展名不在白名单 | 转格式后再传 |
| 「文件实际格式与扩展名不符」 | 改了扩展名但内容不是该格式 | 用原格式重新导出 |
| 上传成功但学生看不到 | 还是**未上架** | 列表点「上架」 |
| 讲义点开是空白 | 讲义只留档、正文未入库 | 已知缺口（见 3C） |
