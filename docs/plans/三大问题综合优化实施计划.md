---

## 一、实施总原则

1. **逐任务独立提交**：每个任务 = 一次代码提交 + 一次状态更新，可独立回滚。
2. **任务间无共享依赖**：任务按依赖顺序排列，每完成一个立即验证。
3. **VTJ 规范**：只改 `.vue` 的 `<script>`；改动后立即 `vtj_sync_vue_to_dsl` + 版本号一致核对。
4. **数据迁移五件套**：dry-run 默认 / 备份 / JSONL 审计 / 幂等 / 回滚。
5. **灰度开关**：新逻辑带 config 开关，默认开启但可一键回退。

## 二、任务分解（P0 → P1 → P2）

### P0（无前置依赖，最先做）

#### 任务 P0-1：图片统一 URL 规范 + 后端映射修复
- **目标**：修复"占位符 `[IMAGE:uuid_qn_seq]` 与磁盘名 `img_docx_{idx}_{md5}` 无映射"的核心矛盾。
- **文件**：
  - `backend/app/services/option_utils.py`：`render_image_placeholder` 改为带映射解析（不再盲拼 `/static/questions/{marker}.png`），透传已规范的 `<img>`，占位符经 QuestionImage 表 + 子目录反查真实文件名，全失败用占位图。
  - `backend/app/services/image_service.py`：`_extract_marker_from_src` 正则放宽兼容 `img_docx_{idx}_{md5}` 命名；`sanitize_content_images` 兜底逻辑对齐。
  - `backend/app/api/v1/question_import.py`：`_extract_and_save_images` 记录 `marker → 最终文件名` 映射（写 QuestionImage 表）。
- **验证**：导入含图 docx → `curl /api/questions/random` 返回规范 `<img src="/static/questions/{qid}/img_docx_xxx.png">`；浏览器图片正常渲染。
- **提交**：`fix(images): 统一图片URL规范+占位符映射修复`

#### 任务 P0-2：前端统一渲染函数 + 替换 10+ 页面
- **目标**：前端放弃各自正则替换，统一 v-html 渲染后端规范输出。
- **文件**：
  - 新增 `src/utils/questionRender.ts`：`renderQuestionContent(content)`（白名单标签过滤 + onerror 兜底 + XSS 防护）。
  - 替换页面（改 script 逻辑 + 渲染绑定）：`answer_page.vue`、`paper_answer.vue`、`wrong_questions.vue`、`smart_answer.vue`、`smart_exam.vue`、`favorites.vue`、`notes.vue`、`question_preview_list.vue`、`score_analysis.vue`、`teacher_papers.vue`、`teacher_analytics.vue`、`paper_approval.vue`、`student_papers.vue`。
  - 逐页同步 `.vtj/files/*.json`。
- **验证**：各页面题目图片正常渲染，无裂图、无路径字符串。
- **提交**：每页或每 2-3 页一个 commit（`fix(frontend): 页面X统一图片渲染`）。

#### 任务 P0-3：异常题结构化返回 + 前端异常题清单定位面板
- **目标**：解决"异常题只闪几秒无法定位"。
- **文件**：
  - `backend/app/api/v1/question_import.py`：`failed_items` 补 `question_number`；新增 `need_confirm_items`（含 index/question_number/reason）；保持旧字段兼容。
  - `.vtj/vue/question_import.vue`：新增 `abnormalItems` state；导入完成弹窗新增"异常题清单"面板；点击行 scrollIntoView 定位 + 高亮；就地修正重校验。
- **验证**：导入异常题 → 清单列出题号+类型+原因，点击可定位。
- **提交**：`feat(import): 异常题结构化返回+前端定位面板`

#### 任务 P0-4：复合题规则引擎扩展（层1）
- **目标**：扩展单一正则 → 规则集（题号范围/材料标识/情境标识/文章标识）。
- **文件**：
  - 新增 `backend/app/services/composite_matcher.py`：`detect_composite_groups`（层1 规则集 + 层2 占位 + 层3 疑似标记骨架）。
  - `backend/app/api/v1/question_import.py`：`_detect_and_link_composite_groups` 改为调用 `composite_matcher`。
- **验证**：显式标识复合题（回答X-Y题）正确挂组。
- **提交**：`feat(composite): 复合题规则引擎扩展(层1)`

### P1（依赖 P0）

#### 任务 P1-1：复合题语义增强兜底（层2）
- **目标**：落实方案 v1.1 §4.3（上下文继承/序列挖掘/选项一致性/TF-IDF 相似度/共享内容推测）。

- **提交**：按端拆分 commit。

#### 任务 P1-3：MinerU 接入修复
- **目标**：MinerU 主 + PaddleOCR 辅，三级回退链接通。

  - `backend/app/services/mineru_service.py`：CLI 调用对齐实际部署，env 带 `MINERU_MODEL_SOURCE=modelscope`。

- **提交**：`fix(mineru): 接入修复(主)+PaddleOCR兜底`

### P2（依赖 P1）

- **提交**：`feat(scripts): 存量图片+复合题重组脚本`

## 四、风险控制

| 风险 | 控制 |
|------|------|
| 前端 v-html 违反 VTJ 规范 | 仅改 script；复杂 UI 变更走设计器；逐页 DSL 同步 |
| 图片映射误删 | 恢复优先，失败用占位图不删除；迁移 dry-run+备份 |
| 复合题误合并 | 评测集校准阈值；疑似入人工审核 |
| MinerU 拖慢导入 | 仅扫描件走 MinerU；三级回退+超时熔断+异步 |
