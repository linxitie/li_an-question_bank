# P1：学生个性化 + 反馈入口 + 图片/折叠 实施计划 v1

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让学生在三端真正感知到「头像/身份、文字样式、图片、评论区、反馈入口」的变化，并把 P0 的数据底座接到页面上。

**Architecture:** 后端补图片上传与帖子/评论增量字段；前端抽 5 个共享组件（`UserBadge`、`UserCard`、`ImageUploader`、`ImageGrid`、`TitleColorPicker`），学生端三处列表/详情/发帖页复用同一套渲染规则；反馈入口复用 P0 的工单接口。

**Tech Stack:** FastAPI / SQLAlchemy / Pillow / Vue 3.5 / Pinia / vitest / pytest

**Spec:** `docs/plans/论坛个性化与练习管理员及三端论坛管理_设计方案_v1.3.md`
**Depends on:** P0（`feature/forum-personalization` 已完成，提交 `2205e9d`~`a61fbb9`）

## Global Constraints

- 分支：`feature/forum-personalization`（父分支 `feature/forum`）。
- 不改 `/api/v1/...` 既有路径（R11）；只新增端点/字段。
- 新列必须补进 `backend/app/main.py` 自动迁移清单；迁移前 `sqlite3.backup()`（R10）。
- `.vtj/vue/*.vue` 只做增量修改，改前备份 `*.bak_<日期>`。
- 图片：发帖/评论**不限张数**；单张 ≤5MB；单次 ≤20；每人每天 ≤500；单帖/单评论总体积 ≤200MB。
- 评论图片 **≥3 张折叠**；发帖图片 >9 张显示 9 张 + “+N”。
- 反馈工单截图 ≤5 张。
- 标题颜色只接受 token：`default/red/gold/blue/green/purple`。
- 只存纯文本 + token，不存 HTML。

## Review Focus

- 上传 0 字节/伪造扩展名/超大图片：必须拒绝且不留垃圾文件。
- 评论 3 张图：折叠态只显示 1 张 + 计数；展开后全部可见；刷新后状态不持久化（默认折叠）。
- 发帖 10 张图：先显示 9 张 + “+N”，点击看全部。
- 无权用户编辑他人帖子、置顶他人评论：403。
- 反馈入口从做题页带入题目 ID；提交后“我的反馈”能看到工单号。
- 手机端无头像用户：回退中文首字；纯数字学号回退「友」。

```python
def test_upload_png_returns_url(client, auth_headers):
    files = {"file": ("a.png", PNG_BYTES, "image/png")}
    resp = client.post("/api/media/image", headers=auth_headers, files=files)
    assert resp.status_code == 200
    body = resp.json()
    assert body["url"].startswith("/uploads/forum/")
    assert body["type"] == "image/png"


def test_reject_fake_extension(client, auth_headers):
    files = {"file": ("a.png", b"not-an-image", "image/png")}
    assert client.post("/api/media/image", headers=auth_headers, files=files).status_code == 400


def test_reject_oversize(client, auth_headers):
    big = b"\x89PNG\r\n\x1a\n" + b"0" * (5 * 1024 * 1024 + 1)
    files = {"file": ("big.png", big, "image/png")}
    assert client.post("/api/media/image", headers=auth_headers, files=files).status_code == 413
```

- [ ] **Step 2: 运行并确认失败**

Run: `python -m pytest tests/test_image_media.py -v`（workdir=`backend`）
Expected: FAIL（404）

- [ ] **Step 3: 实现**

- 扩展名白名单：`.jpg/.jpeg/.png/.gif/.webp`。
- 用 Pillow `Image.open()` 验证真实图片；`verify()` 后重开。
- 超过 5MB → 413；非图片 → 400。
- 重编码：JPEG/PNG/WebP 去掉 EXIF；GIF 保留动图（仅校验）。
- UUID 文件名；按年月分目录。
- 注册路由。

- [ ] **Step 4: 运行测试**

Run: `python -m pytest tests/test_image_media.py -v`
Expected: PASS
