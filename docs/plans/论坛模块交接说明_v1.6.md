## 5. 环境与验证的坑（血泪）

| 坑 | 现象 | 解法 |
|---|---|---|
| 后端未带 `--reload` | 改了后端参数，接口不生效（如 T3 日期筛选首验失败） | **改完后端必须重启 8000 进程** |
| 教师端登录时序 | 登录后立刻 `goto` 论坛页 → 停在 dashboard，`.tf-card` 等待超时，误判功能坏了 | 登录后等 4–5s，或轮询等 `.tf-card` 出现 |
| 手机端登录页 | 是 `/#/mobile/login`，与 PC 选择器不同 | 桌面上下文登录 → `storage_state` 复用给手机上下文 |
| 教师账号无手机端权限 | 手机论坛守卫返回 `/unauthorized?reason=mobile_student_only` | 必须用**学生**账号验证手机端 |
| PowerShell 引号 | `node -e` / `python -c` 里带引号会被吃坏 | **一律写成 `.py` / `.mjs` 文件再执行** |
| passlib + bcrypt 版本 | `module 'bcrypt' has no attribute '__about__'` | 直接用 `bcrypt.hashpw`，不走 passlib |
| GBK 控制台 | pytest 打印 emoji 崩 | `$env:PYTHONIOENCODING="utf-8"` |
