## 2. 改了什么

### 2.1 手机端断点续答 + 倒计时（`src/views/student/mobile/mobile_answer.vue`）

| 能力 | 实现 |
|---|---|
| 拉历史答案 | 开考后先打 `GET /api/exams/records/{record_id}/resume`：返回 `questions` + `saved_answers` + `remaining_seconds`；取不到再退回 `GET /{paper_id}/questions` |
| 回填选择 | `saved_answer` 形如 `"A"` / `"A,C"` → 字母转选项下标写回 `answersRecord`；主观题文本写回 `subjectiveAnswers` |
| 定位 | 自动跳到**第一道未作答**（续答不用自己翻 97 题） |
| 自动保存 | 监听 `answersRecord` / `subjectiveAnswers`，**防抖 1.2s** 调 `PUT /api/exams/{id}/progress`；失败只告警不打断答题 |
| 倒计时 | `remaining_seconds` 每秒递减，顶栏显示 `mm:ss`（≥1 小时显示 `h:mm:ss`）；最后 5 分钟变红 + 呼吸动画 |
| 到点 | 归零后**不再弹确认**，直接交卷（继续拖只会被后端判迟交） |
| 清理 | `onUnmounted` 停表 + 清防抖定时器（否则退出页面后定时器仍在跑，还会触发一次交卷） |

### 2.2 PC 列表显示未开放

| 层 | 改动 |
|---|---|
| `catalog/paper_generation.py` | 删掉对学生会话的 `exam_gate.open_conditions()` 过滤；取回后逐行 `setattr` 挂 `exam` / `answerable` / `exam_hint` |
| `services/exam_gate.py` | 新增 `paper_state(db, paper)` / `paper_hint(db, paper)`（catalog 走服务层，避免 catalog → exam 的跨域 import） |
| `schemas.py::PaperDetailResponse` | 新增 3 个可选字段（老调用方无感） |
| `.vtj/vue/student_papers.vue`（只改 `<script>` + `<style>`，守 R3） | `getPaperStatus()` 增加"不可考"优先级 → 「未开放」琥珀标；`startExam()` 先拦并 `ElMessage.warning(exam_hint)`；新增 `.status-off` 样式 |
| `src/modules/papers/api.ts` | `PaperItem` 增 `exam` / `answerable` / `exam_hint` |

**状态优先级**：`不可考` > `已完成` > `进行中` > `可考`（"现在考不了"是学生最需要先知道的，哪怕他考过一次）。

### 2.3 测试口径同步更新（这是**行为变更**，必须改断言）

`backend/tests/test_exam_p2_gate.py` 三条从"隐藏"改成"显示 + 原因"：

| 原用例 | 现用例 |

| `test_student_list_hides_closed_paper` | `test_student_list_shows_closed_paper_with_reason`（在列表里、`answerable=False`、`reason=closed`、文案含「已关闭」） |
| `test_student_list_hides_zero_question_paper` | `test_student_list_shows_zero_question_paper_with_reason`（`reason=no_questions`，文案含「还没有题目」） |

## 5. 已知边界

| # | 边界 | 说明 |
|---|---|---|
| 1 | 倒计时以**进入页面时**后端给的剩余秒数为准 | 中途电脑休眠/切后台，本地计时会偏慢；交卷时后端仍按 `start_time` 真实判定，不会因此少算时间 |
| 2 | 自动保存只存**已作答**的题 | 清空某题（取消选择）不会删掉服务端旧记录 —— 交卷时以"本次提交的全量答案"为准，所以不影响成绩 |
| 3 | PC「未开放」只改列表页 | 资料页卡片早已有「暂不可考 + 原因」（P2），两处现在口径一致 |
| 4 | 教师端试卷列表未加状态标 | 教师能看到全部卷，状态由他自己开合，暂不加 |

**回滚**：①删 `mobile_answer.vue` 里 resume/倒计时/watch 三块；②`paper_generation.py` 恢复 gate 过滤 + 删 setattr；`getPaperStatus` 去掉 `answerable` 分支；测试三条改回隐藏断言。
