### 1.3 现网画风的具体毛病（来自 11 张真机截图走查，非印象）

1. **emoji 当图标**：👥📚📝📈📄 在 Windows/Mac/不同字号下渲染不一致，无法统一着色；
2. **标题重复**：顶栏面包屑写"系统总览"，页面里又写一遍「📊 系统总览」；

## 3. 三层落地架构

### 3.1 目录规划（全部新增，不动旧文件）

```text
src/styles/
  tokens.scss            ← 令牌（CSS 变量 + scss 变量），供手写页 import
  admin-theme.scss       ← 覆盖层：只在 .admin-layout 作用域内生效（见 3.3）
src/components/admin/
  AdminStatCard.vue / AdminToolbar.vue / AdminTable.vue
  AdminTag.vue / AdminPageHeader.vue / AdminFormItem.vue
src/views/admin/         ← 手写页（已有 admin_forum.vue / material_rules.vue / pc/AdminUsersWorkspace.vue）
  materials.vue          ← A4 新资料页（第一个样板页）
```

**为什么用 CSS 变量**：`.vtj` 页的 scoped 样式改不了，但覆盖层可以用 `var(--adm-primary)` 取值；将来换主题只改一处。

### 3.2 令牌怎么进页面

- **手写页**：`@use '@/styles/tokens.scss'`，`color: $adm-primary`；
- **覆盖层与 `.vtj` 页**：`:root` 上挂 `--adm-*`，覆盖层用 `var(--adm-*)`；`.vtj` 页本身仍用旧字面量（不冲突）。

### 3.3 9 个 `.vtj` 页怎么换画风（关键技术约束）

`.vtj` 页的 `<style scoped>` 会被编译成 `[data-v-xxx] .cls`，特异性 = 2 个选择器；如果我在 `admin-theme.scss` 里只写 `.cls`（特异性 1），**盖不住**。三种做法：

| 做法 | 特异性 | 风险 | 结论 |
|---|---|---|---|
| A 高特异性后代选择器 `.admin-layout .cls`（2 个类，源码顺序靠后即可胜出） | 2 | 需逐页摸清 13 个 class 名 | **采用**（主手段） |
| B 裸元素 + `!important`（`table th {…!important}`） | 低但强制 | 会打到弹窗内部所有同类元素 | **仅用于表格/输入框这类"全局一致"元素**，逐条评审 |
| C 逐页手写替换 | — | 13 页 × 0.5–1 天 | 长期终局，不在本轮 |

> **诚实结论**：覆盖层能做到"**观感统一**"（背景、卡片、表格、按钮、徽标、字号），**做不到像素级统一**（每页内部间距、局部结构仍会有差异）。要像素级只能逐页替换（+5 天），见 **E1**。

> ⚠️ 另注：VTJ 设计器预览是独立 iframe 渲染 `.vtj` 页，**不带 `.admin-layout`** → 设计器里看不到新画风，属预期行为，需在文档标注免得后人以为改造没生效。

## 5. 风险与对策

| # | 风险 | 对策 |
|---|---|---|
| 1 | 覆盖层与 scoped CSS 打特异性战争，出现"有的页变了有的没变" | 用「页面 → class 清单 → 覆盖规则」三列表逐页核对；E3 走查逐页截图对比，不留"半变"页 |
| 2 | `!important` 误伤弹窗/抽屉内部 | 只对 `table/th/td/input/select/button` 这类元素用，且限定 `.admin-layout` 内；逐条评审后入库 |
| 3 | 覆盖层泄漏到学生端 | 所有规则前缀 `.admin-layout`；学生端路由不带该容器（实测 layout 仅 `/admin` 用） |
| 4 | users(1214 行) 改造引入功能回归 | E2 先做 users 的**外层壳**（页头/工具栏/表格/分页），内部逻辑零改动；改前改后各跑一次相关用例 + 手工点 6 条主流程 |
| 5 | 设计器预览"看不到新画风"被误判为失败 | 文档标注 + 在设计器页顶部提示；验收只认浏览器实际渲染 |
| 6 | 画风工作拖慢 B/C 批（真实业务价值） | E 批排在 A 批之后、B 批之前**可整体延后**；A0/A4/A5 是"必须"（A4 反正要做，A5 是你要的侧栏冻结），E1/E2 是"可以晚点" |
