**共同点**：封面承载"归属感"（科目/分类），进度环承载"完成感"，Footer 承载"下一步动作"。三者齐了才不会像"白板贴文字"。

## 2. 卡片解剖（三端一致，只改尺寸）

```
┌─────────────────────────────┐
│ 封面区  (渐变 + 科目角标 + 进度环)  │ ← Header，高度 34%~42%
├─────────────────────────────┤
│ 标题（2 行截断）                  │
│ 正文要点（正面=提示 / 背面=解释）      │ ← Body，行高 1.55，最多 5 行
│                             │
├─────────────────────────────┤
│ [方法技巧] [中等]      点击翻转     │ ← Footer，chips + 动作
└─────────────────────────────┘
```

### 2.1 设计令牌（可直接写进 CSS 变量）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--card-radius` | `16px`（PC/平板）/ `14px`（手机） | 圆角 |
| `--card-border` | `1px solid #eef1f6` | 描边 |
| `--card-shadow` | `0 6px 18px rgba(26,42,74,.06)` | 静置 |
| `--card-shadow-hover` | `0 14px 28px rgba(26,42,74,.12)` | hover/抬起 |
| `--card-cover` | `linear-gradient(160deg,#3b82f6 0%,#9cc4ff 55%,#ffffff 100%)` | 封面 |
| `--chip-bg / --chip-fg` | `#eef4ff / #3b82f6` | 分类 chip |
| `--chip-ok-bg / --chip-ok-fg` | `#e9f7ef / #0f9d58` | 难度 chip |
| `--ring-track / --ring-fill` | `#e8eef8 / #3b82f6` | 进度环 |
| `--flip-ms` | `560ms` | 翻转时长 |
| `--flip-ease` | `cubic-bezier(.2,.8,.2,1)` | 翻转曲线 |

### 2.2 三端尺寸

| 端 | 栅格 | 卡宽 | 封面高 | 触控目标 | 特殊 |
|---|---|---|---|---|---|
| **PC** | 3 列（`≥1280px`）/ 2 列（`960–1279`） | `~430px` | `42%` | 32px | hover 抬起 `translateY(-8px)` |
| **平板** | 2 列（`768–1279`），横屏可 3 列 | `~440px` | `40%` | **≥44px** | 左侧窄导航常驻 |
| **手机** | 1 列 | `100% - 32px` | `34%` | **≥44px** | 底部三段操作条（上一张/翻转/下一张） |

## 4. 动效与降级（全部 CSS 可实现，无 WebGL）

| 效果 | 实现 | 降级 |
|---|---|---|
| 翻转 | `perspective:1200px` + `rotateY(0→180deg)` + `backface-visibility:hidden` | `prefers-reduced-motion` → 直接切显隐 |
| hover 抬起 | `translateY(-8px)` + 阴影加深，200ms | 触屏无 hover → 按压缩放 `scale(.98)` |
| 翻页 | 叠层 `translateX` + 阻尼回弹 | 键盘 `←/→` 等价 |
| 进度环 | `conic-gradient` 或 SVG circle | 低端机降为纯文字 `40%` |
| 性能预算 | 只动 `transform/opacity`；单卡 DOM ≤ 40 节点；首屏 ≤ 20 张 | `hardwareConcurrency ≤ 4` 或 `deviceMemory ≤ 2` → 关阴影/视差 |
