# 人民警察法 · 履职要点

> 备考要点整理，**具体条文以现行有效法条为准**。

## 一、职责边界（高频考）

- 维护社会治安秩序，制止危害社会治安秩序的行为。
- 预防、制止和侦查违法犯罪活动。
- 维护交通安全和交通秩序，处理交通事故。
- 组织、实施消防工作，实行消防监督。
- 管理枪支弹药、管制刀具和易燃易爆等危险物品。
- 警卫、守卫、管理集会游行示威。
- 监督管理计算机信息系统的安全保护工作。
- 法律、法规规定的其他职责。

## 二、执法保护与限制

- 拒绝执行：对超越法定职责、违反法定程序的指令，有权拒绝执行。
- 回避：办理案件遇利害关系应回避。
- 着装与证件：依法执行职务时应出示证件（特定情形）。

## 三、情景题常考点

- "警察有权不管吗" → 看是否属于法定职责。
- "上级指令违法怎么办" → 拒绝执行并报告。
- "公民求助" → 紧急求助应救助，不属职责的应告知渠道。
