# 治安管理处罚法 · 核心条款速览

> 备考要点整理，**具体条文以现行有效法条为准**，请核对最新修正文本。

## 一、处罚种类

- 警告
- 罚款
- 行政拘留
- 吊销公安机关发放的许可证
- 限期出境 / 驱逐出境（对违反治安管理的外国人）

## 二、常见行为与要点

| 行为类型 | 记忆要点 |
| :--- | :--- |
| 殴打他人 / 故意伤害 | 轻微伤以下按治安处罚；情节较轻可调解 |
| 寻衅滋事 | 注意与刑法寻衅滋事罪的界限（情节/后果） |
| 盗窃 | 数额不大、不够刑事追诉标准的按治安处罚 |
| 阻碍执行职务 | 注意与妨害公务罪界限；袭警行为按规定处理 |
| 散布谣言 | 谎报警情/扰乱公共秩序 |
| 赌博 | 以营利为目的、赌资较大 |

## 三、办案程序要点

- 传唤：口头/书面传唤，询问时间一般不超过 8 小时，情况复杂可延至 24 小时（依现行规定）。
- 调解：因民间纠纷引起的打架斗殴等，情节较轻的可以调解，调解成功不再处罚。
- 处罚决定：告知 → 陈述申辩 → 决定 → 送达。
- 拘留执行：通知家属；暂缓执行需符合条件的担保。

## 四、情景题常用判断链

1. 行为性质？（违法 vs 犯罪）
2. 该由公安处理吗？（管辖）
3. 情节轻重？（处罚档次）
4. 程序对不对？（传唤/告知/时限）
5. 要不要调解或移交？
