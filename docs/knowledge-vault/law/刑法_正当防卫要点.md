# 刑法·正当防卫要点

《中华人民共和国刑法》第二十条：为了使国家、公共利益、本人或者他人的人身、财产和其他权利免受正在进行的不法侵害，而采取的制止不法侵害的行为，对不法侵害人造成损害的，属于正当防卫，不负刑事责任。

## 核心要点（以现行有效法条为准）
- 起因条件：存在现实的不法侵害（不能是假想防卫）
- 时间条件：不法侵害正在进行（不能是事前/事后防卫）
- 限度条件：未明显超过必要限度造成重大损害（明显超过并造成重大损害的，应负刑责，但应当减轻或免除处罚）
- 特殊防卫：对正在进行行凶、杀人、抢劫、强奸、绑架以及其他严重危及人身安全的暴力犯罪，采取防卫行为造成不法侵害人伤亡的，不属于防卫过当，不负刑事责任

## 高频考点
- 防卫过当不是独立罪名，按触犯罪名定罪但减轻/免除处罚
- 相互斗殴一般互不构成正当防卫（一方停止或放弃除外）
- 公专情景题常考：时间与限度的判断
