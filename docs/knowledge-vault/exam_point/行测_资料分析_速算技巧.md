# 行测 · 资料分析速算技巧

> 高频考点：资料分析占行测比重高，比的是"准 + 快"。

## 一、先读题再读材料

- 先看题目问什么（现期/基期/增长量/增长率/比重/平均数），再回材料找数。
- 单位、时间、口径先核对，避免"坑"。

## 二、速算三件套

1. **截位直除**：选项差距大时截 2-3 位估算；差距小才精算。
2. **首数法**：先看商的首位，快速排除。
3. **特征数字法**：百分数化分数（1/8=12.5%、1/6≈16.7%），乘法变除法。

## 三、增长率相关公式

- 增长率 = (现期 − 基期) / 基期
- 基期 = 现期 / (1 + 增长率)
- 间隔增长率 = r1 + r2 + r1×r2
- 混合增长率：总体增长率介于两部分之间，偏向基期大的一方

## 四、易错点

- 增长量 vs 增长率（绝对量 vs 相对量）。
- "比上年同期" = 同比；"比上月" = 环比。
- 百分点 vs 百分比（不是一回事）。

## 五、练习口诀

"先圈问法、再找数据、三看单位、四估答案、五验首位"
