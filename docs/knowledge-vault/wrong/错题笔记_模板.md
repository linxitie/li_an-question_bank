# 错题笔记 · 模板

> 按此模板记录错题，复盘一次顶三次。

```markdown
# 错题：<题目一句话摘要>

## 题干摘要
<把关键信息压缩到 2-3 行>

## 我当时选的
<错误答案>

## 为什么错
- [ ] 知识点没记住
- [ ] 审题失误（没看到 XX 条件）
- [ ] 时间不够 / 计算失误
- [ ] 陷阱（单位/口径/程度词）

## 正确思路
<一句话解题路径，最好配口诀>

## 同类题会怎么考
<变形方向预测 1-2 条>

## 下次怎么做
<对自己的 1 条行动指令>
```

## 示例：资料分析"单位坑"

- 题干摘要：某省粮食产量 1.2 亿吨，问万吨。
- 当时选：直接按亿吨算，漏了 10^4 换算。
- 为什么错：单位换算漏看。
- 正确思路：先统一单位再算，看到"亿/万"立刻停 1 秒。
- 同类会怎么考：同比增速的百分点 vs %。
- 下次：做题前在草稿上先写单位。
