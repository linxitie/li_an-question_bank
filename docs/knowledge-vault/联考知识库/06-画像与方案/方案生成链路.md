# 方案生成链路

```
画像问卷(profile_quiz)
  → POST /api/profile/upsert           落 UserProfile
  → POST /api/plan/generate            调 LLM 出阶段与任务
  → GET  /api/plan/current             前端读取
  → 首页 / 我的 的 StudyPlanCard 展示
  → GET  /api/plan/today               今日任务
```
