# 画像维度说明

画像问卷共 6 维，每维 1–2 题，问法每次轮换（模块4 P1 已实现）。

| 维度 | 字段 | 用途 |
|---|---|---|
| basic | grade, target_region | 定基础档位与地区 |
| target | exam_date, target_score, target_post | 定时间窗与目标 |
| level | self_level | 定起点难度 |
| weakness | subject_weaknesses / subject_strengths | 定资源分配 |
| habit | daily_hours | 定每日任务量 |
| self | self_intro | 自由自述，喂给 LLM 做个性化 |

## 自述怎么用

`self_intro` 是自由文本，进 `PlanAgent` 的 prompt 上下文。
不要做关键词抽取后丢弃原文——原文里的语气和具体困境是排计划的关键信息。
