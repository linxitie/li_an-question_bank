# 命名与同步规则

## 同步方向（单向，禁止回写）

```
SQLite（事实源） --导出脚本--> 联考知识库（投影）
```

禁止从 vault 回写数据库。人工批注只改 vault 里的非生成区。

## 生成区与人工区

页面分两段：

```markdown
---
title: 行测-判断-图形推理
generated: true
question_ids: [1024, 1025]
---

<!-- GENERATED:BEGIN -->
（脚本生成，勿手改）
<!-- GENERATED:END -->

## 我的批注

（人工自由写）
```

脚本只重写 `GENERATED` 段，保留批注段。

## 考点卡片三要素

1. **定义**：这是什么，一句话
2. **样例**：至少 1 道真题（带 question_id）
3. **易错点**：至少 1 条真实踩坑
