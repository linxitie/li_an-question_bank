# 知识图谱模型

## 节点（Node）

| 类型 | 主键 | 来源 |
|---|---|---|
| 科目 subject | subject_id | `question_subject` |
| 章节 chapter | chapter_id | `question_bank.chapter` |
| 考点 point | point_id | 知识点表 / 从题目标签聚合 |
| 题目 question | question_id | `question_bank` |

## 边（Edge）

| 类型 | 语义 | 例子 |
|---|---|---|
| `contains` | 上级包含下级 | 科目 → 章节 → 考点 |
| `tests` | 考点被哪些题考 | 考点 → 题目 |
| `prereq` | 前置依赖 | 资料分析·增长率 → 基期量 |
| `confusable` | 易混 | 均值 vs 中位数 |
| `weak_of` | 用户薄弱 | 用户 → 考点（带错误率） |

## 实现约定

- 存储：`content/kg.py` 已有骨架，节点/边落表，不在内存临时算
- 查询：按 `subject_id` + `chapter_id` 下钻，禁止全图遍历
- 前端：`KnowledgeGraphPanel.vue` 渲染，节点数 > 200 时按章节折叠
- 用户维度：`weak_of` 边由错题统计生成，**不落库**，查询时实时算

## 与遗忘曲线的衔接

考点级掌握度 = 该考点下题目 `review_ease` 与 `error_count` 的加权。
掌握度 < 0.5 的考点在图谱上标红，并进入错题复习队列。
