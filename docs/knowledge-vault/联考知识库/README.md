# 联考知识库（自生长）

> 本库是**可重建投影**，不是事实源。事实源是 SQLite（题目、错题、画像）。
> 这里只放：结构、方法、索引、人工批注。丢了可以从库里重建。

## 目录

| 目录 | 放什么 | 谁写 |
|---|---|---|
| `01-科目/` | 行测 / 申论 / 公安专业科目总览 | 人 + AI 草稿 |
| `02-考点/` | 考点卡片：定义、真题样例、易错点 | AI 生成 + 人工审 |
| `03-真题/` | 按年份归集的真题索引（链接到题库 id） | 脚本导出 |
| `04-错题/` | 错题归因笔记（不是错题本身） | 学员 |
| `05-方法/` | 解题方法、速算技巧、模板 | 人 |
| `06-画像与方案/` | 画像结论与备考方案的过程记录 | AI + 人 |
| `99-系统/` | 命名规范、同步规则、健康度 | 维护者 |

## 命名规范

```
02-考点/行测-言语-成语辨析.md
02-考点/申论-归纳概括-要点合并.md
03-真题/2025-行测-第31题.md
04-错题/2026-11-14-资料分析-基期量.md
```

- 文件名：`<科目>-<章节>-<知识点>.md`，用连字符，不用空格
- 每个页面必须有 frontmatter：`title / subject / chapter / tags / question_ids`
- `question_ids` 写题库里的真实 id，用于双向跳转

## 三条硬规矩

1. **不手改生成区**：带 `generated: true` 的页面由脚本重写，手改会被覆盖
2. **双链必须有效**：写脚本检查断链，断链数纳入健康度
3. **先建考点、再挂真题**：不允许孤儿真题页

## 健康度指标

- 考点覆盖：题库中每个知识点是否有对应卡片
- 卡片完整度：定义 / 样例 / 易错点 三要素齐全率
- 断链数：必须为 0
- 孤儿页：无入链的页面数量
