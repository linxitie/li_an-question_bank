# 公安联考 · 报考信息时间线

> 通用备考信息，**以当年官方招录公告为准**（公安部 / 各省人事考试网 / 院校就业指导）。

## 一、考试科目

| 科目 | 考试时长 | 常见题量（参考） |
| :--- | :--- | :--- |
| 行政职业能力测验（行测） | 约 120 分钟 | 约 130-140 题 |
| 申论 | 约 150 分钟 | 若干材料题 + 大作文 |
| 公安专业科目（公专） | 约 120 分钟 | 单选/多选/情景题 |

## 二、常见时间节点（以当年公告为准）

- 公告发布：一般为前一年年底至当年年初。
- 报名：公告后 1-2 周左右开放。
- 笔试：公告后 1-2 个月内。
- 面试：笔试成绩公布后约 1-2 个月。
- 体测/体检/政审：面试后陆续进行。

## 三、报考条件要点

- 学历与专业：以岗位表为准（部分岗位限专业）。
- 年龄：一般有上限要求。
- 身体条件：视力/身高/体能等按招录规定。
- 政治条件：政审合格，本人及家庭主要成员政治背景审查。

## 四、选岗建议

1. 先筛条件（专业/地区/性别/生源地）→ 剩可选岗。
2. 看竞争比与历年分数线。
3. 结合自身画像（模块4 档案）与备考水平做选择。
