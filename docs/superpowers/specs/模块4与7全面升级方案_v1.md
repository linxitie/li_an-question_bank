## 2. 目标与差距

一句话：**把「问画像 → 出方案 → 能查看 → 能执行 → 能复习」这条链打通，并把小智与知识库接进这条链。**

| # | 用户诉求 | 目标 |
|---|---|---|
| 1(1) | 询问页样式单调，要动画过渡 | 分步问答 + 卡片进出场动画（参考多邻国/不背单词的节奏感） |
| 1(2) | 问题单一，要动态变换 + 用户自述 | 问题池扩到 30+ 分 6 维；每步动态抽题；末段自由自述写入画像 |
| 1(3) | 方案不能在首页/我的查看 | 首页 + 我的各加一张方案卡，点击进 `/study-plan` |
| 1(4) | 3D 学习日历进「每日签到」 | 签到页嵌入 3D 翻转日历，点亮当日 |
| 1(5) | 番茄钟进首页（小弹窗） | 首页浮动小窗 + 专注计时 + 结束后写签到/积分 |
| 1(6) | 遗忘曲线复习提醒（错题集） | 错题按 SM-2 简化算法排下次复习日，错题集出提醒入口 |
| 1(7) | 手机/平板缺失 | 三端同源，按 R12 复用 mobile 页 + `meta.platform` |
| 2(1) | Obsidian 自生长知识库 | 建 vault 骨架 + 采集/审核/发布流程，与画像、小智打通 |
| 2(2) | 知识图谱框架 | 定义节点/边模型 + 落库 + 图谱页可交互 |
| 2(3) | 小智手机/平板缺失 | 复用 `ai_chat.vue` 的数据契约，新增 mobile/tablet 入口 |

## 3. 分阶段实施

### P0 · 基线与断点修复（0.5 天）
- 跑门禁确认基线：`python backend/scripts/gates/gate_all.py --quick`
- 快照当前 343 端点：`backend/data/refactor_baseline/api_surface.json` 比对
- 修 1(3) 断层的最小版本：首页 + 我的各加一个方案卡（只读，不改后端）

### P1 · 画像询问页（3 天）
- 问题池：`src/modules/profile-quiz/questions.ts`（6 维 × 5 条 = 30 条）
- 动态抽题：沿用 `suggestions.ts` 的环形 + 排除集算法，`nextQuestions({answered, dimension, size})`
- 用户自述：末步加自由文本框，写入 `UserProfile.self_description`
- 动画：**由航少在设计器完成 `<template>` 与样式**（R3）；本方案只交付 `<script>` 数据层 + 动画 CSS 片段供粘贴
- 后端：`growth/profile.py` 已存在，仅补字段（不改路径）

### P2 · 方案回流（1.5 天）
- 首页卡：读 `/api/v1/growth/study-plan/current`（若不存在则用现有列表端点）
- 我的卡：同源组件复用
- 空态：未生成方案时引导去画像页

### P3 · 签到 3D 日历 + 番茄钟（3 天）
- 3D 日历：纯 CSS `transform: rotateY()` 翻转，数据取 `checkin` 连续签到与热度
- 番茄钟：新组件 `src/components/focus/PomodoroWidget.vue`
  - 纯前端计时（25/5），localStorage 断点续
  - 结束事件写签到（已有端点）+ 可选专注时长记录（**需新增端点，见未决 4**）
- 首页挂载：`home_page.vue` 的 `<script>` 引入，模板由航少拖入

### P4 · 遗忘曲线复习（3 天）
- 算法：SM-2 简化（间隔 1/2/4/7/15/30 天，答错回退）
- 存储：错题表加 `next_review_at`、`ease`、`repetitions`（迁移脚本 + 备份，R10）
- 入口：错题集顶部「今日待复习 N 题」；手机端复用 `mobile_wrong_review.vue`
- 提醒：先用站内通知（`platform/notifications.py` 已有），不做推送

### P5 · 三端补齐（4 天）
- 按 R12：不复制手机页；tablet 路由复用 mobile 组件 + `meta.platform`
- 新增路由组：`/m/profile-quiz`、`/m/study-plan`、`/m/ai-chat`、`/m/signin`、`/m/knowledge-graph`
- 平板：`/tablet/` 同名路由指向同组件
- `src/utils/device.ts` 与 `resolveDevicePath()` **一字不动**

### P6 · 知识库 + 知识图谱（5 天）
- Obsidian vault：`docs/knowledge-vault/联考知识库/`，骨架 6 目录（科目/考点/错题/真题/方法/索引）
  - **基础款由航少提供**，本方案先给目录规范与命名约定
- 知识图谱：
  - 节点类型：科目 → 章节 → 考点 → 题目
  - 边类型：包含 / 前置 / 易混 / 同类
  - 落库：`models.py` 已有 kg 模型，先核对是否覆盖上述边类型，缺则补
  - 前端：`KnowledgeGraphPanel.vue` 接入 `knowledge_graph.vue` 页，支持按考点下钻到题目
  - 补齐三端入口

|---|---|

| 三端路由与 `resolveDevicePath` 冲突 | 只加 `meta.platform`，不碰 `device.ts` |
| 错题表被昕蕾侧并发改 | 改动前与她确认字段归属（见未决 3） |
