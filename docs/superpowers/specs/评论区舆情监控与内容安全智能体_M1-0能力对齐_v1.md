> 目的：在动 M1 代码之前，把「远端已上线的 content_guard」与「本分支 M0 的 policy_compiler / knowledge_ops」划清边界，给出唯一裁定。

## 0. 一句话结论

**content_guard 已经是运行态审核闸门 + 知识资产库 + 治理闭环**，在发帖、评论、改资料三处真实生效（默认开启，命中即阻断）；
**本分支 M0 是政策源（Obsidian Markdown）+ 动作梯度 A0–A5 的编译层**，未接线、无表、开关默认 off。

裁定：**执行与留痕归 content_guard，政策源与动作梯度归 policy_compiler**；`cg_policy` 降为编译产物，不再手工维护；**不新建 moderation_* 四表**。

## 3. 三处「同一件事两种做法」的冲突与裁定

**A. 政策源双份**：`cg_policy`（DB 行，改要走 API/提案） vs 政策 Markdown（人可读、可 diff、编译期校验）。
裁定：**Markdown 是唯一源**；`cg_policy` 增加 `source_path` / `source_hash` 映射，启动 `seed_policies()` 降级为「空库兜底」；后台改政策 = 改 Markdown → 编译 → 落 `cg_policy`（写提案 → 审批 → 生效）。

**B. Obsidian 双库**：仓库内 `docs/knowledge-vault/敏感词治理`（机器投影，进 Git） vs 仓库外 `AI舆情审核知识库`（人工运营 + Canvas）。
裁定：**外库=编辑面**（政策/案例/运营，人写）；**内库=投影面**（DB 导出，机器写，可重建，不手改）。
方向单向：外库 →（编译）→ DB →（`export_all`）→ 内库。**禁止双向同步**——两侧都可写时，冲突不可判定。

**C. 台账双份**：`cg_judgment`/`cg_task` vs 计划 `moderation_case`/`decision_log`/`appeal`。
裁定：**复用 cg_***；M1 只为申诉单独加一张 `cg_appeal`（外键 judgment_id），不复制判定与审计。

## 4. A0–A5 ↔ content_guard 四档映射（唯一定义）

| A 档 | 语义 | cg level | cg decision | 用户可见性 | 任务 |
|---|---|---|---|---|---|
| A0 | 放行 | pass | pass | 正常 | 无 |
| A1 | 遮蔽 | masked | mask | 打码后发布 | `auto_masked` |
| A2 | 暂扣 | reviewed | review | 仅作者可见 | `pending`（24h） |
| A3 | 隐藏 | reviewed | review | 他人不可见，需管理员/教师确认 | `pending` + priority 提级 |
| A4 | 拒绝发布 | blocked | block | 400 错误 | `auto_blocked` |
| A5 | 账号级 | — | — | 走 admin 处置 | 写 `cg_audit_event` |

> A2/A3 都落 `review`，差异只在「谁可见 + 优先级」，不动 cg 状态机——这是最小改动落点。

## 5. 目标调用链（M1 之后）

```
发帖/评论/改资料
  → guard_text(db, text, scene, user_id)
    → [L0 归一化 normalizer]
    → [L1 词表 DFA（今日现状，必跑）]
    → 未命中 且 FORUM_AI_RULES=on
        → policy_compiler.score_text() 规则层（A0–A2 上限）
    → 仲裁：取更严动作（block > mask > review > pass）
    → cg_judgment / cg_task / cg_audit_event / cg_edge
  → 返回旧版兼容结构（level / words / masked_text）+ 新增 decision / evidence
```

**硬约束**：规则层默认 off；规则层**不得单独产生 block**（最高 A2）；block 只能来自词表命中或人工。

## 8. 一句话收尾

两套实现不是二选一，而是**上游与下游**：M0 负责「政策怎么写、动作怎么分」，content_guard 负责「怎么判、怎么留痕、怎么治理」。
M1 只做**接线**，不做**重写**——这样任何一步出问题都能一键退回今日已上线行为。
