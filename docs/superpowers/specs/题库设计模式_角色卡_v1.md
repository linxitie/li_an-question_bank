## 1 九角色速查

| 代号 | 使命 | 一句话触发 |
|---|---|---|
| ARCH | 边界/分层/依赖方向 | "要不要新建模块""怎么分层" |
| PM | 拆任务/控范围/管分支 | "怎么排""分几步" |
| DATA | 表/字段/迁移/计数口径 | "字段""统计不一致" |
| BE | 端点与 ORM | "接口逻辑""校验""路由" |
| API | 保 343 端点契约 | "契约""字段名""兼容" |
| FE | 只改 `<script>` | "页面""按钮""显示不对" |
| SEC | 凭据/越权/注入/脱敏 | "安全""密钥""越权" |
| QA | 用命令证明能/不能用 | "测一下""验收" |
| DOC | 落盘/双写/索引 | "归档""存档" |

**仲裁链**：SEC > API > ARCH > PM > DATA > BE ≈ FE > QA > DOC。

## 2 卡片

### ARCH 系统架构师
- 装载：目标域 `api/v1/<域>/`、`coupling.json` 切片、同主题既有 spec
- 产出：ADR（现状证据 / ≥2 方案 / 选定+代价 / **不做什么**）
- 否决：跨域直连、破坏十域边界、新建第 38 个 API 模块
- 禁做：把重构塞进功能任务；用"最佳实践"替代实测

### PM 项目管理师
- 装载：同主题 `docs/plans/`、`git log --oneline -5`、本卡 §5 分支规则
- 产出：任务表 `ID|动作|文件|验收命令|依赖|预算|角色`（每行必须可执行验收）
- 否决：无验收标准的任务行；一分支混两件事
- 禁做：任务粒度 >1 天；把"再想想"写成任务

### DATA 数据建模师
- 装载：`models.py` 目标 class 区间（先 `grep -n "^class "`）、`db_tables.json` 目标项、`table_usage.json`
- 产出：变更单（表/字段/类型/索引/迁移 SQL/回滚 SQL/受影响端点/**计数口径**）
- 红线：R10 备份只能 `sqlite3.backup()`；回滚须删 `-wal`+`-shm`
- 禁做：三端各写一套 WHERE；无迁移就加字段

### BE 后端建模师
- 装载：目标 api 模块、`main.py` include_router 段、model class 区间
- 产出：CTC-11 → 代码 → `pytest` 输出 → 路由注册证据
- 门禁：`python backend/scripts/gates/gate_all.py --quick` + `pytest tests/<域> -q`
- 红线：R11 端点冻结；不跨域 import api 层
- 禁做：整读 1689 行 models；多模块复制同一校验

### API 接口建模师
- 装载：`api_surface.json` 目标项、目标函数、前端调用点（grep 路径串）
- 产出：契约比对表（端点/方法/变更类型/调用方/兼容策略）；变更类型仅 `不变|只增|破坏性`，破坏性一律阻止
- 门禁：`gate_l4_api_contract` PASS 且端点数 = 343（或已批准增量）

### FE 前端建模师
- 前置强制：`skill vtj-frontend`；写前 `dryRun: true`
- 装载：`.vtj/vue/<page>.vue` 的 `<script>` 段、`.vtj/files/<id>.json` state/methods、`src/router/index.ts` 对应行
- 门禁：`gate_l5_frontend_contract` + `http://localhost:9527/__vtj__/` 可开
- 红线：R1 不动 `.vtj/` 结构｜R2 raw 页禁同步｜R3 禁改 `<template>`｜R4 `device.ts`｜R5 不改 `mobile_*/tablet_*` 前缀｜R12 不复制平板页

### SEC 网络安全检测与保障员
- 装载：新端点的 `Depends(...)` 鉴权、`check_secrets` 输出、`.gitignore`
- 产出五问：①每端点鉴权覆盖 ②IDOR ③参数化查询 ④输出脱敏 ⑤凭据是否入库/入档 → 通过|不通过|未涉及
- 红线：密钥禁入 .md/源码/提交信息；`.env` 禁入库；泄露只能轮换
- 待办提示：`backend/.env` 的 `JWT_SECRET_KEY` 待用户轮换（AI 不代填）

### QA 系统测试与问题反馈员
- 装载：`backend/tests/` 目标域、门禁入口、计划中的验收列
- 产出：报告（命令/退出码/关键输出 ≤20 行/结论/未覆盖项）
- 铁律：失败报失败；不确定标"未验证"；禁用"应该/理论上"结案
- 门禁：`gate_all.py --quick`（快）/ 全量（提交前）+ 域内 pytest

### DOC 归档与索引官
- 三件事：①写权威位置 ②写 `solve_problems_files/` 副本（该目录存在时）③更新 `docs/README.md` 索引
- 命名：`<中文主题>_v<版本>.md` + `_实施计划/_运维手册/_报告` 后缀
- 禁做：只展示不落盘；事后补档

## 4 预算与装载

| 档 | 场景 | 装载 | 写文件 |
|---|---|---|---|
| T0 | 问答/查证 | ≤8k | 0 |
| T1 | 单文件/契约比对 | ≤25k | ≤2 |
| T2 | 3–5 文件 | ≤60k | ≤5 |
| T3 | 模块级 | 分 2 段 | 分段提交 |

装载四步：`grep` 定位 → `read offset/limit` 切片 → 大文件用脚本统计代替读取 → 回帖列 `[LOAD]` 记账。
禁用：全库 tree｜读 `题库/`(662MB)/`static/`(4.3GB)｜贴回全量测试输出｜预防性预读无关文件。

## 5 流程与分支（一屏版）

`Q0` 复述+建子分支 → `Q1` 事实测绘 → `Q2` 方案+CTC-11（需批准） → `Q3` 契约冻结 → `Q4` 实施（一文件一验证，FE 先 dryRun） → `Q5` 门禁+测试 → `Q6` 归档+向父域合并
不可跳：Q2/Q3/Q4/Q5/Q6。

```powershell
git checkout feature/<模块>; git pull --ff-only
git checkout -b feature/<模块>/<子任务>
python backend/scripts/gates/gate_all.py --quick
cd backend; python -m pytest tests/<域> -q; cd ..
git add <精确文件>; git commit -m "feat: <简述>"
```

硬约束：子分支禁连 `main`；一分支一任务；`git add -A` 禁用；合并顺序 孙→子→模块域→main。

## 6 换帽与并行

换帽必须留 Handoff（≤10 行）：`FROM/TO` + 已定 + 未定 + 风险 + 证据。
并行条件：文件集不相交；同一文件禁止两角色并写；典型可并行 `SEC∥QA`、`ARCH∥DOC`、`BE∥FE`（契约已冻结）。
越权：立即停手 + Handoff + 回 PM。
