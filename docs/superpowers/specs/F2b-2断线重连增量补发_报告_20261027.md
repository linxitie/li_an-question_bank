## 1. 交付摘要

F2b-2 把 `data-changed` 从「只有 domain/type/id」升级为「带 Outbox 游标 oid」，
并让客户端在 WS 重连时携带 `since` 请求增量补发，服务端按用户/角色可见性回放，
超限、过期、开关关闭或异常时显式返回 `truncated`，客户端退回一次全量同步。

本批只改事件协议、同步链路和 2 个手写页；75 个 VTJ 页面模板零改动，
无新表、无迁移、无新增依赖。

## 2. 协议变更

### 2.1 live data-changed

```json
{
  "v": 2,
  "type": "data-changed",
  "seq": 12,
  "scope": "exam.practice.submit.42",
  "domain": "exam",
  "entity": "practice.submit",
  "id": 42,
  "data": { "oid": 987 }
}
```

- `oid` = `foundation_outbox.id`，全局单调递增，add-only。
- 仅当事件处理器能拿到 outbox id 时才附加；旧路径不带 oid，客户端忽略。

### 2.2 重连补发请求

```json
{ "type": "sync", "data": { "since": 981, "limit": 200 } }
```

- 只在客户端已有游标且处于重连时发送；首次连接不发。
- 服务端回复不走广播 seq，不参与 `acceptSeq`。

### 2.3 补发回复

```json
{
  "v": 2,
  "type": "sync",
  "scope": "sync",
  "data": {
    "reason": "replay",
    "events": [
      { "domain": "exam", "type": "practice.submit", "id": 43, "oid": 988 }
    ],
    "latest_oid": 988,
    "truncated": false
  }
}
```

`reason` 取值：`replay` / `replay-truncated` / `disabled` / `bad-request` / `error`。
回复不含 payload、不含他人 user_id。

### 2.4 截断规则

任一条件成立即 `truncated=true` 且 `events=[]`：

1. `WS_SYNC_REPLAY_ENABLED=false`；
2. `since` 不是正整数；
3. 扫描上限 2000 条内候选超过单次 200 条；
4. `since` 之后存在早于 24 小时的事件；
5. 查询/解析异常（客户端收到 `error`）。

`latest_oid` 始终为 `status!='dead'` 的最大 outbox id。

## 3. 可见性过滤

| 事件 | 可见规则 |
|---|---|
| `user.action.v1` | 事件 owner 本人，或 `route_for(trigger).self_only=false` 且查看者角色在 `route.roles` 内 |
| `catalog.paper.published` | student / teacher / admin 三角色 |
| 其他 event_name | 跳过，不补发 |
| payload 为空/损坏 | 跳过，不抛异常、不 500 |
| `status='dead'` | 不补发，也不计入 `latest_oid` |

## 4. 前端行为

- `src/utils/wsMessage.ts`：新增 `extractOid`、`extractSyncReply`，过滤缺 oid/非正整数/脏事件。
- `src/auth.ts`：新增内存游标 `_lastOutboxId`、2500ms 兜底定时器、`__VTJ_DATA_CHANGED__` 事件；
  - 重连且无游标：旧行为，立即一次 `__VTJ_SYNC__`；
  - 重连且有游标：发 `sync{since}`，2500ms 无回复再全量；
  - `truncated` / `error` / `disabled`：一次全量，不逐条刷新；
  - 正常 replay：先一次 `__VTJ_SYNC__` 兼容旧页，再逐条 `__VTJ_DATA_CHANGED__`；
  - 在线事件：游标只增不回退；
  - 登出/重新登录：清游标与定时器。
- `src/composables/useDataSync.ts`：domain/type 过滤、同事件去重、默认 100ms 防抖、卸载自动清理。
- 接入页面：
  - `src/components/domain/RecentPracticeRecords.vue`：exam + practice.submit / practice.record.created / paper.completed，800ms；
  - `src/views/student/shared/profile.vue`：多域，500ms，并行刷新统计/金币/等级/成就/掌握度。
- `.vtj/vue/` 模板与 DSL 零改动。

## 8. 限制与未覆盖

1. **无真实浏览器矩阵**：9×3 为协议级用例，不是 9 个浏览器；页面视觉与生命周期未做真机验证。
2. **无真实断网/Redis 故障演练**：2500ms 兜底、重连补发用假 WebSocket/假定时器验证。
3. **仅接 2 个手写页**：75 个 VTJ 页仍走 `__VTJ_SYNC__` 全量兼容路径；逐页 typed 接入留待后续批次。
4. **游标为全局 outbox id**：会暴露全局事件总量这一非敏感单调整数；不含事件内容。后续可改 per-user 游标。
5. **Outbox 未清理**：24h 保留期依赖现有数据；未来清理必须同步推进游标策略，否则会出现游标空洞。
6. **4 个 Playwright 未纳入**：与本次无关，仍为环境/端口问题。
7. **L7 唯一 WARN 为既有 L7-10 孤儿库**，与 F2b-2 无关。
