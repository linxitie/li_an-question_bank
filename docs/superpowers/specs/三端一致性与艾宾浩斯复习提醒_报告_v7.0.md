## 2. 版本号单一来源

### 2.1 为什么之前会出现两串 SHA
前端角标取 vite 启动那一刻的提交，后端取进程启动那一刻的提交，两者字面永不相同，用户只能读成「版本不一致」。

### 2.2 现在的实现
| 位置 | 作用 |
|---|---|
| `VERSION`（仓库根，内容 `2.0.0`） | 唯一事实来源 |
| `vite.config.ts` `resolveAppVersion()` | 读 VERSION，经 `buildStamp()` 注入 `__APP_VERSION__` |
| `src/env.d.ts` | 声明 `__APP_VERSION__` 类型 |
| `src/main.ts` `checkVersionConsistency()` | `backendVersion === frontendVersion && != '0.0.0'` 才判定一致，写入 `__APP_BUILD__` |
| `src/components/common/BuildStamp.vue` | 只显示 `v{version}`；真不一致才红底 `#b91c1c`；tooltip 才给 SHA/构建时间/后端 SHA；作答页隐藏（见 §3.3） |
| `backend/app/main.py` `_resolve_app_version()` | 读仓库根 VERSION（异常降级 `0.0.0`），传给 `FastAPI(version=)` 与 `/health` |

### 2.3 实测
`GET http://127.0.0.1:8000/health` → `{"version":"2.0.0","revision":"c03826ce", ...}`；三端页面角标均 `v2.0.0`。

## 5. 手机端答题页布局（本轮新增）

### 5.1 症状
390px 下头部「返回题库 / 公专 / 做题模式 / 背题模式 / 答题卡 / 计时」被压成一列竖排；底部「上一题 / 下一题 / 交卷」中「交卷」被挤出屏幕。

### 5.2 原因
`.ex-header` 为单行 `justify-content: space-between` 且不换行；`.ex-actions` 为固定 padding 的 flex 行且按钮不换行，圆点导航占位。

### 5.3 修法（`src/views/student/shared/exercise.vue` 末尾 `@media (max-width:700px)`）
- `.ex-header` 换行 + `padding: 10px 12px`；`.ex-back-btn span`、`.ex-answer-sheet-btn span` 隐藏（只留图标），保留 `title`/`aria-label` 语义。
- `.ex-header-right` 整宽第二行 `space-between`；模式按钮 `padding 6px 10px / 12px`；计时器 `margin-left:auto`。
- `.ex-question-card` `margin: 0 12px; padding: 16px 14px`；题干 15px/1.85；选项 `padding: 12px`。
- `.ex-actions` 换行 + `margin: 16px 12px 0`；三个按钮 `flex: 1 1 0; white-space: nowrap`；`.ex-dot-nav` 隐藏（改由头部「答题卡」操作）。

### 5.4 顺带处理的两个浮层遮挡
- `ReviewBell`：`route.path.startsWith('/exercise')` 时整体隐藏（答题时不该弹复习面板，且会压住「下一题」）。
- `BuildStamp`：同样在作答页隐藏，但**版本真不一致时仍然显示**（`showStamp = !isAnswering || isMismatch`），排查线索不能被页面类型吞掉。

## 6. 艾宾浩斯复习：算法与入口

| 层 | 实现 |
|---|---|
| 调度表 | `review_schedule`（user_id / question_id / stability / next_due_at / review_order） |
| 回归算法 | `backend/app/services/review_scheduler.py`：SM-2 变体，答对升 stability、答错回落；间隔序列 1/2/4/7/15/30/60 天；已牢固（P<0.3）的题暂停提醒 |
| 接口 | `GET /api/review/due?limit=`（预览队列）、`POST /api/review/{question_id}/grade`（回写）、`POST /api/review/rebuild`（重建）、`GET /api/review/calendar` |
| 入口 | 右下角铃铛 FAB（有到期题显示数字角标）→ 面板列出「科目 / 考点 / 到期日」，点「开始复习（N 题）」进 `/exercise?review=1` |
| 闭环 | 交卷时 `collectWrongAnswers` 之前先 `submitReviewGrades(details)` 逐题回写，答对则下次到期推后，答错则回到短间隔 |

> 认证注意：面板必须走 `window.__VTJ_AUTH__.apiFetch`（`src/auth.ts:573` 暴露），裸 `fetch` 没有 Authorization 会被 401，前端就会只剩「复习队列读取失败」。
