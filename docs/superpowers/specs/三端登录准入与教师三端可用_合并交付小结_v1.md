```
FAIL  L4（模块边界）
      新增违规（须处理或确认纳入基线）：
```

- **影响**：门禁口径上本版**不能称"全绿"**，只能称"9/10，唯一红项为远端既有违规"。

**期间修复的测试环境问题**：合并后 2 个 spec 共 10 例因 jsdom 下 `localStorage.clear/setItem is not a function` 失败，
在测试文件内部无条件下注入最小可用 `localStorage` 后全部通过（只改测试，不动产品代码与全局配置）。
