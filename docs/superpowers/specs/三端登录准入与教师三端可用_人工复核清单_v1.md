## 7. 怎样才算「验收通过」

### 7.1 硬门槛（全过才算通过）

| 门槛 | 判定方式 |
|---|---|
| **G1 登录准入 9 格全对** | A-1 ~ A-9 全部符合预期，尤其 A-8/A-9 管理员必须被拒 |
| **G2 设备错配 0 例** | B-1 ~ B-6 全部正确跳转，电脑绝无平板/手机界面 |
| **G3 教师三端可用** | C-1 ~ C-8 全过，且设备端**无任何写操作入口** |
| **G4 学生三端无「模块加载失败」** | D-1 ~ D-6 全过 |
| **G5 写操作入口可用** | E-1 ~ E-3 全部能打开并能走到关键步骤 |
| **G6 版本一致** | F-1 `revision` = `0d6b81bb` |

### 7.2 出现这些情况**不算**不通过（已知残留，已登记）

| 已知项 | 说明 |
|---|---|
| 判断题（无 A/B/C/D 选项）无法通过「题目批量导入」入库 | 独立缺陷，已在 §17.4 登记，按你口径本轮不修；**单题录入不受影响** |
| 试卷页出现「全部5 / 共4份」两个数字 | `stats.total` 与 `papers.total` 口径不一致，已登记 |
| 资料删除后计数不变 | 软删除，属运营语义 |
| 平板/手机首次进入时短暂显示「正在加载资源…2/4」 | VTJ 页面懒加载提示，等待后消失 |

### 7.3 出现这些情况**必须**判不通过并告诉我

- 任一角色能绕过设备限制（管理员在设备端看到后台内容）；
- 电脑上出现平板/手机界面，或反过来；
- 设备端出现编辑/发布/删除/上传按钮；
- 页面报「模块加载失败」「404」「请求的资源不存在」；
- 登录后掉回登录页、或角色首页串台；
- `revision` 不是 `0d6b81bb`（说明跑的不是这版）。

### 7.4 结论只允许三种

| 结论 | 含义 | 后续动作 |
|---|---|---|
| **通过** | 7.1 六项门槛全过 | 可推送远端（另需你单独批准） |
| **有条件通过** | 六项门槛全过，但发现 7.2 之外的小瑕疵（如文案、样式错位） | 记下来，作为下一版修复项，不阻塞本版 |
| **不通过** | 命中 7.3 任一条 | 我按你写的复现步骤定位修复，修完重新走本清单 |
