# 题库设计模式 · 模块作战卡（热加载版 v1）

> 领到「某个功能模块」的任务时只读这一张（约 4KB）。全文：`题库设计模式_v2.md`；
> 角色切换：`题库设计模式_角色卡_v1.md`；红线唯一出处：`AGENTS.md` R1–R12。

## 0 开工三步

```
1. python scripts/qbdm/qbdm.py module <id>     # 看该模块端点/页面/测试/门禁
2. 填声明头（角色卡 §0）：
   [ROLE] <代号> <角色> v1
   [TASK] QBDM-<日期>-<序号> <一句话>
   [BUDGET] T1|T2|T3
   [LOAD] <域卡>:1-80 | <api 文件>:<行区间> | 台账该模块条目
   [GATE] qbdm module <id> 里列出的门禁
3. 答 D1–D10（下表），答不出就回 Q2，不写码
```

## 1 设计 D1–D10（Q2 放行闸）

| # | 一句话检查 | 证据 |
|---|---|---|
| D1 | 本模块拥有哪些端点/页面/事件 | 台账 + 域卡 |
| D2 | 表/字段/索引/计数口径 | 迁移单或「零迁移」 |
| D3 | 端点只增不改，字段两端对齐 | 契约比对表 |
| D4 | 发/订哪些 trigger_type，幂等键 | 事件清单 |
| D5 | 每端点鉴权 + 角色 + 设备端 | `Depends(...)` |
| D6 | 三端入口与降级，平板复用手机页 | 复用关系 |
| D7 | 空/加载/错误三态 | store 字段或截图 |
| D8 | 事务边界与失败回滚 | 事务范围 |
| D9 | 审计字段/错误码/日志脱敏 | 字段样例 |
| D10 | 不做什么 | 显式排除项 |

## 2 优化 O1–O8（先量后改）

| # | 优化 | 先量 | 达标 |
|---|---|---|---|
| O1 | 列表/查询性能 | P95、SQL 条数 | 有数字改善、无 N+1 |
| O2 | 三端计数一致 | `test_three_end_counts.py` | 差异 = 0 |
| O3 | 三态体验 | 空/错态可达性 | 三态齐全 |
| O4 | 安全 | 越权/IDOR/注入面 | SEC 五问通过 |
| O5 | 事件幂等 | 重复提交 | 重复 = 0 |
| O6 | 冗余 | 重复校验/请求 | 有删除 diff |
| O7 | 三端复用 | 是否复制页 | 无新增副本 |
| O8 | 可维护 | 行数 | ≤800 / ≤60 |

**没基线就不叫优化**（A20）：优化前先贴数字，改完复量。

## 3 测试 T1–T8（分层，不许一层冒充全部）

| 层 | 命令 | 通过 |

| T6 页面 | `gate_l5_frontend_contract.py` + 设计器可开 | PASS |

全量 pytest 会挂起：用 `python scripts/qbdm/test_sweep.py --suite tests --timeout 90` 拿 OK/FAIL/HANG。

## 4 模块层五条硬约束

1. 跨模块只走契约与事件，不 `import` 别的 api 域（A14）。
2. 平板复用手机页，不复制（R12 / A15）。
3. 事件 `trigger_type` 只增不改（A19）。
4. 未开发模块（⑰⑱⑲⑳）过准入才建分支（A18）。
5. 失败报失败，未测标「未验证」（v1 A1/A13）。
