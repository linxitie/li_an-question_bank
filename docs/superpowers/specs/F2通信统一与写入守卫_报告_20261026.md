## 1. 交付范围

F2 只做「通信统一 + 写入守卫 + 路由角色」，不改业务功能、不改 `api/v1` 路径与出入参、不改 `.vtj` 模板与 `static`：

| 层 | 交付 |
|---|---|
| WS 协议 | `app/foundation/ws_protocol.py`：v2 信封统一 `build_envelope`，含 `v/seq/scope/domain/entity/id/data/timestamp`；`SeqAllocator` 优先 Redis `INCR foundation:ws:seq`，不可用时进程内毫秒递增 |
| 跨 worker 中继 | `app/foundation/ws_relay.py`：单 worker 本地扇出；`WS_RELAY=redis` 时发布到 `foundation:ws`，各 worker 订阅后本地定向发送；发布者本地也发一次，订阅端跳过 `origin == 自己`，保证每个 worker 恰好一次 |
| 多 worker 保护 | `validate_worker_config()`：`WEB_CONCURRENCY>1` 且未设 `WS_RELAY=redis` 时启动即失败；Redis 不可达只降级为本地扇出，不让业务不可用 |
| 统一发送出口 | `api/v1/platform/websocket.py` 与 scheduler 统一走 `ws_relay.emit`；心跳 90 s 无消息关闭 4008 |
| 前端消费 | `src/utils/wsMessage.ts`：解析、分类、`deriveScope`、`acceptSeq` 同 scope 去重；`src/auth.ts` 收到 `data-changed` 派发 `__VTJ_SYNC__`，重连清空去重表并派发一次全量 `sync`；`src/modules/papers/events.ts` 桥接试卷事件 |
| 路由角色 | `src/router/index.ts` 92 条页面路由全部声明 `meta.roles`；mobile/tablet 仅 `student`；公共白名单 4 条 |
| 写入守卫 | `app/foundation/validation.py`：R-EMPTY / R-LONG / R-ENUM / R-JSON / R-FK / R-ENCODING 六类；5 个写入口前置 `ensure_valid`，错误返回 422 `detail=[{field,rule,message}]` |
| 门禁 | `scripts/gates/gate_l7_foundation.py` 15 项升级：8/13/14 升 FAIL，15 新增缺失 FAIL、存量 WARN |

不改：`api/v1` 既有 343 端点路径与出入参、`models.py` 既有模型、`.vtj/**` 模板、`static/**`、既有 73 张业务表。无新表、无迁移、无新依赖。

## 5. 未执行 / 明确不宣称

以下项目因环境或阶段边界**未执行**，不得在总结中写成已完成：

1. **真实 2 个 uvicorn worker + 浏览器 WebSocket 端到端**：已用两个独立 WsRelay/ConnectionManager + 真实 Redis 验证中继链路；未启动双 worker 的完整 Web 服务并用真实浏览器观察。
2. **浏览器断网 30 s 恢复**：仅做前端单测（重连、去重、全量 sync）；未在真实浏览器 DevTools offline 下计时验证。
3. **手机/平板真机 4008 心跳关闭与重连**：未执行，需真机环境。
4. **9 组合 × 3 场景自动化**：未执行；当前由单测 + 中继 e2e 覆盖协议层。
5. **F2b 事件迁移**：13 个 `record_user_action`、2 个 `events.publish` 迁 Outbox，Redis Stream 消费者组，按角色/用户定向派生事件——**全部未做**。当前 `data-changed` 只覆盖既有少数调用点，§20.4 的“写路径 → Outbox → dispatcher”仍是目标态。
