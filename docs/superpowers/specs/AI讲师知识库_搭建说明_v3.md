## 4. Canvas 故障：根因与修复

**现象**：截图里所有 Canvas 卡片显示「未找到 xxx.md」，只剩「新建笔记 / 替换内容」按钮。

**根因**：Canvas 的 `file` 字段路径相对 **vault 根**（`D:\Obsidian仓库`），旧值写成 `笔记/视听资源/...`，缺了子库前缀 `AI讲师知识库/`。Obsidian 因此解析到 `D:\Obsidian仓库\笔记\...`，必然不存在。

**修复**：全部 `file` 字段改为 `AI讲师知识库/笔记/...`；同时重排布局（组框 + 竖排连边），避免旧版节点重叠。

| Canvas | 节点 | 边 | 组 | 设计要点 |
|---|---|---|---|---|
| `图谱视图/知识分类概览.canvas` | 19 | 0 | 3 | 3 科目 × 15 模块，模块内列知识点 + 考点数 |
| `图谱视图/资源全景.canvas` | 14 | 0 | 3 | 公专 5 系列卡 / 行测 1 卡 / 申论缺口 + 三入口页脚 |
| `图谱视图/白宁公专-2022八大主题.canvas` | 9 | 8 | 0 | 4 列 × 2 行 + 中心竖线 |
| `图谱视图/行测-资料分析.canvas` | 9 | 8 | 0 | 8 集递进 |
| `图谱视图/桐哥公专-目录.canvas` | 63 | 51 | 10 | 51 集按 10 个模块分组，双列高度贪心平衡（4160 / 3860） |

**规则固化**：`AGENTS.md` 第 12 条要求「Canvas 写全前缀 + 改完必须跑路径校验」。

## 6. 创新设计（12 项摘要）

| # | 创新点 | 一句话 |
|---|---|---|
| 1 | 分类即主键 | 模块 CODE（`GZ-JC` 等）+ 知识点 ID，改名不改 ID |
| 2 | 覆盖矩阵 → 缺口队列 | 生产排期由数据驱动 |
| 3 | 切片台账 | 长视频切 5–8 分钟片段，只进 JSON 不建笔记（避免 600 篇碎片） |
| 4 | 讲师语料指纹 | 语速/句长/举例密度/术语表，把「讲得好」变成阈值 |
| 5 | 三色可视化 | Canvas 管结构、Dataview 管统计、Mermaid 管文本 |
| 6 | changeset 发布协议 | JSON + sha256 + `reviewed_by`，未审只入草稿 |
| 7 | 三层质量门 | 事实门（法条/考点 ID 命中）/ 教学门（5 分钟一交互）/ 合规门 |
| 8 | 知识折旧 | `syllabus_year` + `review_due`，过期自动降级 |
| 9 | 讲师驾驶舱 | 覆盖 / 产能 / 质量 / 告警 四块 |
| 10 | 可审计写入 | REST API 白名单 + 日志留痕，禁止写 `原始语料/` 与 `AGENTS.md` |
| 11 | 双链中心度排期 | 用 backlinks 近似重要度，是 Graph-RAG 的零依赖预演 |
| 12 | AI 视频反向登记 | 系统只写 `产出/报告/生成登记表.md`，库内可查 AI 视频与降级档位 |

反模式 5 条：片段不建目录、媒体不入库、核心不依赖社区插件、AI 不直接改规则与事实源、知识画面不用生成式视频模型。
