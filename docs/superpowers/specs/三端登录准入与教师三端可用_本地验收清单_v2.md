## 5. 怎样才算「三端验收通过」

### 5.1 每端各自的门槛

| 设备 | 必过项 | 数量 |
|---|---|---|
| 电脑 | PC-1 ~ PC-12 | 12 |
| 平板 | T-1 ~ T-12 | 12 |
| 手机 | M-1 ~ M-10 | 10 |
| 跨端 | X-1 ~ X-3 | 3 |

**单端通过 = 该端必过项 0 失败。**
**三端验收通过 = 电脑 0 失败 + 平板 0 失败 + 手机 0 失败 + 跨端 0 失败。**

### 5.2 允许存在、不算失败的已知项

| 已知项 | 说明 |
|---|---|
| 平板/手机首次进入短暂显示「正在加载资源…2/4」 | VTJ 懒加载提示，等待后消失 |
| 试卷页「全部5 / 共4份」两个数字 | `stats.total` 与 `papers.total` 口径不同，已登记 |
| 判断题（无 A/B/C/D）无法通过批量导入入库 | 独立缺陷已登记，单题录入不受影响 |
| 电脑端窗口拖到 <768px 宽时变手机版式 | 这是**有意保留**的兼容（窄到手机宽度才降级），不算错 |

### 5.3 出现即判不通过

- 电脑端（含 880px 窄窗口）出现平板/手机版式；
- 平板/手机上出现电脑版式，或平板出现手机版式（反之亦然）；
- 设备端出现编辑 / 发布 / 删除 / 上传按钮；
- 任何页面报「模块加载失败」「页面未找到 404」「请求的资源不存在」；
- 管理员在平板/手机上成功进入任何后台页面；
- 登录后掉回登录页、或落到别的角色首页；
- `/health` 的 `revision` 不是 `4fc052e5`。
