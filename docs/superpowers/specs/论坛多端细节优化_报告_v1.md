5. **`.vtj/vue/forum.vue` 的 template 改动经用户批准**（D4-A），改前已备份 `.vtj/vue/forum.vue.bak_20261103_modal-layers`（`.vtj/**/*.bak*` 已被 `.gitignore` 忽略，仅本地留档）。

## §6 回归风险提示

- `content_format` 默认 `TEXT`，所有老帖走原路径；但**如果某条历史数据被人工写成 HTML 而格式列仍是 TEXT**，会显示成标签文本。属既有数据卫生问题，未做自动改写（改写风险高于收益）。
- 富文本渲染依赖后端消毒；**若将来有人绕过 `/api/forum/posts` 直接写库**，前端 `ForumContent` 的第二层拦截会把它降级为纯文本（不执行），不会变成 XSS。
