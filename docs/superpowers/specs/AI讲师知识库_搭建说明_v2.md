## 6. frontmatter 契约

- 必填：`id` / `type` / `title` / `status`；契约文件 `config/schema/frontmatter.schema.json`。
- `type` 枚举：`video_resource` `series` `exam_point` `law_article` `error_pattern` `lesson`。
- `status` 状态机：`draft` → `available` → `transcribed` → `mapped` → `archived`；旁支 `incomplete` `duplicate` `audio_only` `missing_video`（后两者为本次实测新增）。
- 单集必含：`series_id` `episode` `teacher` `bvid` `duration_sec` `file_path`（E 盘相对文件名）。

## 7. 可视化
