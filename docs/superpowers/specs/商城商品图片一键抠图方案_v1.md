# 商城商品图片「一键抠图」方案 v1

- 场景：管理员端上架商品，上传商品图后去掉背景，输出透明底 PNG
- 状态：方案（待批准实现）
- 关联分支：`fix/forum-shop-ui-batch3`

## 一、可选路线对比

| 方案 | 实现 | 优点 | 缺点 |
|---|---|---|---|
| A. 浏览器端 AI 抠图 | npm `@imgly/background-removal`（ONNX/WASM，本地推理） | 不占服务器、无 API 费用、图片不出本机 | 首次需下载 ~5–10MB 模型（可随包内置）；低配机器 2–5 秒/张 |
| B. 服务端 AI 抠图 | 后端装 `rembg` + `onnxruntime`，新增 `POST /api/admin/shop/remove-bg` | 前端简单、效果稳定 | 依赖 ~300MB，CPU 推理 1–3 秒/张，需下载 U2Net 模型；离线部署要预置模型 |
| C. 纯前端色键 | Canvas 取背景色，去除相近颜色 + 羽化 | 无依赖、瞬时 | 只适合纯色/白底商品图，复杂背景无效 |

**推荐：A 为主 + C 兜底**
- 管理员点「一键抠图」→ 先走浏览器端 AI（本地推理）
- 模型不可用/离线时自动降级为「白底去除」，并提示"复杂背景建议重试 AI 抠图"

## 二、落地改动（若批准）

1. 依赖：`pnpm add @imgly/background-removal`（仅管理端页面按需动态 import，不增大普通用户包体）
2. 组件：`src/components/admin/ImageCutoutButton.vue`
   - props: `src`；emit: `done(blobUrl)`
   - 内部：`removeBackground(file)` → canvas 兜底 → 输出 PNG
3. 上架页：商品图上传旁加「✂️ 一键抠图」，完成后替换预览图并随表单上传
4. 后端：无需改动；仍走现有图片上传接口
5. 验收：
   - 白底商品图 → 透明底，边缘无明显白边
   - 复杂背景 → AI 可抠出主体
   - 断网 → 降级色键，不报错

## 三、风险与规避

- **模型下载失败**：允许配置本地模型目录（`/public/models`），打包时内置
- **包体**：动态 import，避免进入学生端 bundle
- **效果**：抠图结果允许管理员再上传替换，不强制使用
- **性能**：限制输入图 ≤ 4000px，超出先压缩

## 四、不做的事

- 不引入云端抠图 API（费用/隐私/断网不可用）
- 不改现有商品图存储结构（仍是一张 URL）
