## 3. M1 三层分类：按 drawio 落库

### 3.1 真实层级（实测，纠正早期误判）

```
question_subject（科目 3）
  └─ sub_categories（知识点 16：行测 7 + 科学推理、申论 5、公专 3）
       └─ knowledge_point.level=2（考点，parent_id=0，sub_category_id 指向知识点）
            └─ knowledge_point.level=3（细分，parent_id 指向考点）
```

唯一约束：`UNIQUE(subject_id, sub_category_id, parent_id, point_name)` —— 同名「其他」下沉必然冲突，必须「先合并再改挂」。

### 3.2 解析器（新增 `backend/scripts/taxonomy/drawio_tree.py`）

- 解析 drawio `mxCell` vertex，去 HTML 标签取文字
- 挂父规则：**最近的上方** + **横向包含 ±24px** + **父框宽 ≥ 子框宽 × 1.4**
- 第三条是关键：否则同列堆叠的知识点会互相认父子，层级被压扁
- 输出 `docs/design/taxonomy_drawio_v9.json`：508 节点
  - 行测 7 知识点 / 27 考点 / 129 细分
  - 申论 5 / 25 / 108
  - 公专 3 / 35 / 166
  - 名为「其他」的节点 86 个（drawio 自带，非 DB 脏数据）

### 3.3 落库（`backend/scripts/taxonomy/verify_tree.py --apply`）

- 补建缺失考点/细分；drawio 之外的历史考点**全部下沉为 level=3** 挂到最接近考点；子节点一并改挂
- 结果：`{"knowledge_point":0,"point":7,"detail":152,"demoted":367,"reparented":86,"merged":51,"moved_questions":0}`
- 备份：`backend/data/backups/question_bank_pre_v9tree_20261117_203822.db`
- 复核（三科）：缺考点 0 / DB 独有考点 0 / 「其他」考点 0

### 3.4 前端实证

练习中心「政治理论」展开为：习近平新时代中国特色社会主义思想 0/11、党的二十大精神 0/4、马克思主义基本原理 0/6、党和国家方针政策 0/21 —— **不再有「其他（未细分）」行**。

## 8. M7 内容缺口自动体检（用户 m06061 新增）

### 8.1 六类缺口

| kind | 判定 |
|---|---|
| `missing_image` | `[IMAGE:hash_seq_idx]` 标记 / `<img src>` / `question_image` 表 → 磁盘文件不存在 |
| `missing_blank` | 题干提到「横线/划线/空白处/下划线」但无 `____` 占位 |
| `missing_option` | 选项文本为「（待补充）」「图中的B选项」等占位 |
| `missing_answer` | 正确答案为空 |
| `missing_analysis` | 解析为空 |
| `missing_material` | 有 `group_id` 但材料 < 10 字；或无 `group_id` 却引用「给定资料」 |

### 8.2 接口（`backend/app/api/v1/catalog/content_gaps.py`）

- `GET /api/content-gaps/summary?subject_id=` → `{scanned, gap_questions, by_kind, kind_labels}`
- `GET /api/content-gaps/questions?kind=&subject_id=&page=&page_size=` → 分页明细（含 snippet、年份、缺口、质量分）
- `GET /api/content-gaps/question/{id}`
- `POST /api/content-gaps/scan {question_ids}`（不限角色，学生端自检也用）
- 前三个需 teacher/admin；扫描全库 3763 题约 2.7s，**不建缓存表**避免过期

### 8.3 导入即体检

`question_import.py` 的 `/confirm` 自动对本批新题跑一次 `scan_ids`，返回体新增 `gaps` 字段（失败只 warning，不阻断导入）。

### 8.4 教师端「内容修复中心」

- 页面：`src/views/teacher/pc/ContentRepair.vue`，路由 `/teacher/content-repair`，导航「内容修复」
- 六类统计卡（点击筛选）+ 科目下拉 + 分页列表（缺口徽标 + snippet + 质量分）
- 「定位题目补录」→ `/teacher/questions?question_id=xxx`，`teacher_questions.vue` 的 `onMounted` 补了 query 深链，直接打开该题编辑弹窗

### 8.5 实测（去重后）

扫描 3763 题，待修 **215** 题：配图缺失 73 / 横线缺失 15 / 选项缺失 14 / 答案缺失 0 / 解析缺失 110 / 材料缺失 8（一题可属多类，故各类之和大于 215）。
