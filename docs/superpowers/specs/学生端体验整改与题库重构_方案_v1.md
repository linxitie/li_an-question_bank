## 2. 实施路径（三个选项，需你选一个）

### 路径 A（推荐）：新写 src 页面 + 路由切换 + 运行时补丁；**不改 .vtj 模板**
- 题库 PC/平板：新建手写页 `src/views/student/pc/question_bank_console.vue` / `tablet/question_bank_console.vue`，路由改为新页；原 `.vtj/vue/question_bank.vue`、`tablet_question_bank.vue` 保留不删（R1 合规）。
- 导航壳（铃铛/头像/下载）：`src/App.vue` 增加 `installStudentTopBar()`：在 `.navbar-actions` / 平板 `.nav-right` 上挂载铃铛与头像，移除下载按钮（ResizeObserver 处理路由重挂载）。
- 反馈附件：在 `forum.vue` 的反馈弹窗上注入文件选择器（脚本层 DOM 注入，参考已有“热门前 100 工具栏”做法）。
- 优点：不违反 R3、不产生 DSL 漂移；页面可自由布局、可测试。
- 缺点：题库迁移工作量大；注入层需回归测试。

### 路径 B：你在设计器改模板，AI 改脚本/组件
- 给你逐项“设计器操作清单”（拖哪个节点到哪、加哪些按钮）；AI 负责接口、组件、样式与测试。
- 优点：模板与 DSL 一致，设计器回存不丢。
- 缺点：需要你动手改 4~6 个模板；改完前无法联调。

### 路径 C：授权 AI 直接改 .vtj 模板（R3 例外）
- 只在上述文件上执行，先备份，改完给 diff；但 **设计器回存会覆盖**，后续维护有风险。
- 不推荐，除非你明确接受这个风险。

**推荐 A**：所有 13 项都能在“零模板改动”下落地，且能真正接后端数据。

## 3. 逐项方案（按路径 A）

### 3.1 dev 环境：ECONNREFUSED
- 根因：Vite 启动后立即代理，后端 8 秒后才 ready；Vite 对代理失败无重试。
- 改法：
  - 新增 `scripts/dev.ps1`：先起后端 → 轮询 `/health`（≤60s）→ 再起 `npm run dev`；任一进程退出则统一收尾。
  - `vite.config.ts` 的 proxy 增加 `error` 日志节流（同一 host 10s 内只打一次，不再刷屏）。
  - README/运维文档补“启动顺序”。
- 验收：冷启动执行 `scripts/dev.ps1`，浏览器无 ECONNREFUSED；后端未启动时只提示一次。

### 3.2 论坛反馈：图片 + 视频
- 现状：后端 `UserFeedback.attachments` 已存在（`models.py:2692`），但 `_validate_attachments` 只接受 ≤5 张、无类型/大小约束；上传端点只收文档。
- 后端：
  - 新增 `POST /api/feedback/attachments`（登录用户）：图片 `jpg/png/webp` ≤5MB、最多 5 张；视频 `mp4/webm/mov` ≤50MB、最多 1 个；校验 magic（图片走 `image_magic_ok`，视频校验 `ftyp`）；走 `media_service.store_bytes(kind=`forum/video`)`；返回 `{url,name,size,type,kind}`。
  - 扩展 `_validate_attachments`：总数 ≤6，视频 ≤1，未知 `kind` 拒绝；反馈详情返回 `kind`。
  - 管理端 `admin_feedback.vue` 目前只显示“📎 n 个附件”（`:36,58`）→ 改为缩略图 + `<video controls>`。
- 前端：`forum.vue` 反馈弹窗注入：拖拽/粘贴/选择、缩略图、上传进度、删除；提交时带上 `attachments`。
- 验收：图片/视频各传 1 次、提交后管理员可见可播放；超限/错误类型给出明确提示；单测覆盖大小/类型/数量。

### 3.3 铃铛：右下 → 右上；弹窗 1/2；收件箱补“反馈回复”
- 组件：`ReviewBell.vue`（src）重构：

## 4. 第一性原理专项

### 4.1 错题集：从“仓库”改成“复习决策台”
- 现状问题（证据）：
  1. 筛选「子科目」写死 7 个选项（`wrong_questions.vue:36-48`），与数据库层级不一致，跨科目混排；
  2. 列表标题用 `renderQuestionSummary`（`:695-698`）→ 选项/图片/材料被折叠成摘要，错题“原貌”丢失；
  3. 详情弹窗信息完整（`:295-394`），但必须点开才知道，列表层没有“我的答案 vs 正确答案 / 错因 / 复习状态”；
  4. PC 与手机两套实现（`mobile_wrong_questions.vue`），字段/交互漂移。
- 原则：错题集的用户目标是“今天先复习哪几道 + 为什么错”，不是浏览题库。
- 目标设计：
  - 筛选数据化：科目 → 子科目 → 考点三级下拉（`/api/quick-practice/subjects|sub-categories`），保留时间/熟练度/来源；
  - 卡片 v2：科目标签 + 考点 + 2 行题干（图片保留占位）+ 我的答案/正确答案 + 错误次数 + 最近错日 + 复习 due + 操作（复习/收藏/斩题）；
  - 复合题：材料缩略 + “展开材料”按钮；列表虚拟滚动（>300 条）。
- 验收：筛选项来自接口；列表能直接判断错因；1000 条滚动不卡。

### 4.2 页面显示与排版：先测量再改
- 检查项：横向溢出、文字截断、图片 404、字体 <12px、对比度 <4.5、点击热区 <44px。
- 已知问题：平板题库静态数字（`:382-384`）、假分页（`:225-228`）、导航头像写死、PC 导航缺铃铛、筛选行 6 控件挤压（`wq-filter-bar`）。
- 做法：Playwright 在 1440/1280/1024/390 四个宽度跑同一套断言（`scrollWidth <= innerWidth`、关键块不重叠、图片 `naturalWidth>0`）。

### 4.3 快速练习知识分层：考点之下不允许“其他”
- 现状：后端已隐藏 L2 下的 fallback 子节点（`quick_practice.py:269-322`），并返回子科目级收容块；但前端 `question_bank.vue:674-684` 又把 fallback 合成为“考点”塞进内联树，`:1090/1222-1336` 再特殊处理 → 用户感知“考点之下还有其他”。
- 不变式（写进测试）：
  1. `knowledge_point.level==3` 且 `is_fallback` 的节点不得出现在任何 L2 的 `children`；
  2. “其他（未细分）”只允许出现在子科目级 `fallback`，`drillable=false`；
  3. 前端任何树渲染都不得合成 fallback 节点。
- 数据治理：库内 fallback 节点约 91 个（`WrongHeatPanel.vue:120` 注释）；上线自动归类（题干关键词 + 大纲映射 + 人工抽检），目标：fallback 题占比从当前降至 ≤10%（先量基线）；每周产出“未归类 Top 50”清单给管理员。

### 4.4 错题集题目展示（具体）
- 列表：题干 2 行 + 选项缩略（单选只显示 A/B/C/D 文本前 20 字）+ 图片懒加载；不渲染完整解析；
- 详情：保持现有材料吸顶、图片 marker、解析；增加“错误原因”选择（知识盲区/审题/计算/蒙错）；
- 移动端：与 PC 共用同一数据/字段，布局单列。

## 6. 风险与回滚
- 新页路由切换：保留 `?legacy=1` 或环境变量切回旧 .vtj 页；不删除旧文件。
- 注入层（App.vue 补丁）：特性开关 `STUDENT_SHELL_PATCH=0` 关闭；选择器失效时只告警不抛错。
- 周任务扩容：迁移脚本 dry-run + 备份；可回滚 SQL。
- KG 动效：`prefers-reduced-motion` + 设置里关闭。

## 7. 需要你审批的 6 件事

1. **路径选择**：A（新 src 页 + 路由切换 + 注入，零 .vtj 模板改动，推荐）/ B（你改设计器模板）/ C（授权 AI 改模板，有回存覆盖风险）。
