# 论坛多端细节优化 设计方案 v4（AI 标题开关）— 归档副本

> 权威位置：`docs/plans/论坛多端细节优化_设计方案_v4.md`（含 §8 实施记录，内容更全）
> 状态：**已实施（D1–D6 全按推荐）** / 日期：2026-11-04 / 分支：`feature/forum-multi-device-polish`

## 需求

每个端口的发帖弹窗增加「是否允许 AI 自动总结标题」：

- 不允许 → 按原格式发布（标题空即 `(无标题)`），不调用模型；
- 允许 → 可先看建议、不满意「重新生成」、仍不满意手填。

## 实施摘要

1. `PostComposer` 增加开关（默认开）+「AI 生成标题 / 重新生成」按钮；
   覆盖已有标题前二次确认；单次弹窗最多 5 次；手改标题后不再标记 AI。
2. 手机端 `mobile_forum_create.vue` 同款控件。
3. 新接口 `POST /api/forum/ai-title/suggest`：需登录、每用户每小时 30 次、
   正文有效文字 < 8 直接 `no_content`。
4. 发布接口新增 `ai_title_enabled` / `title_from_ai`；关闭时不投递后台生成任务；
   标题原样来自模型才置 `ai_title=1`。
5. 新列 `forum_post.ai_title_enabled`（记录选择）与 `forum_draft.ai_title_enabled`（草稿恢复）。
6. **框架坑**：这版 FastAPI 把缺省的 bool Form 一律解析成 False（`Form(True)`/`Form(None)` 默认值都不生效），
   会把老客户端误判成「关闭 AI」；改为 `str` 解析 + 显式判定。
