# 智能匹配增强设计方案

## 文档信息

- **文档版本**：v1.0
- **编写日期**：2026年8月21日
- **编写目的**：增强分离导入的智能匹配功能，提高匹配精度，降低匹配率阈值，提供更好的用户体验
- **适用对象**：前后端开发人员

## 一、问题背景

### 1.1 当前问题

1. **匹配率阈值过高**：前端代码硬编码99%阈值，导致无法导入
2. **缺乏试卷自动创建**：分离导入后只导入题库，没有自动创建试卷
3. **缺乏手动匹配界面**：当匹配率不足时，没有用户友好的匹配界面

### 1.2 用户需求

1. **试卷文档检测**：文件名+内容分析结合判断
2. **匹配率阈值**：≥90%自动合并，70%-90%标记待确认，<70%手动匹配
3. **手动匹配界面**：智能推荐匹配+拖拽匹配
4. **关联关系**：关系表+字段冗余结合

## 二、设计目标

### 2.1 核心目标

1. **提高匹配精度**：匹配准确率>95%
2. **降低匹配率阈值**：从99%降低到90%
3. **提供智能匹配界面**：支持智能推荐和拖拽匹配
4. **支持复杂文档格式**：支持多种题号格式和答案格式

### 2.2 技术目标

1. **模块化设计**：各组件独立，易于维护和扩展
2. **可测试性**：每个组件都有明确的输入输出
3. **可扩展性**：支持添加新的匹配策略
4. **性能优化**：匹配过程高效，响应时间<3秒

## 三、系统架构

### 3.1 整体架构

```
┌─────────────────────────────────────────────────────────┐
│                    智能匹配系统                          │
├─────────────────────────────────────────────────────────┤
│  文本预处理 → 题号识别 → 答案提取 → 相似度计算 → 匹配引擎 │
└─────────────────────────────────────────────────────────┘
```

### 3.2 组件关系

```
文本预处理 ──→ 题号识别 ──→ 答案提取 ──→ 相似度计算 ──→ 匹配引擎
    │              │              │              │              │
    ▼              ▼              ▼              ▼              ▼
  清理文本      识别题号      提取答案      计算相似度      智能匹配
```

## 五、匹配策略链

### 5.1 策略优先级

1. **题号分段解析匹配**（主要策略）
   - 按题号分割题目和答案
   - 识别准确率>98%

2. **嵌入式答案提取**
   - 提取"故本题答案为D"等格式的答案
   - 适用于答案嵌入在题目中的情况

3. **连续答案序列匹配**
   - 匹配连续的答案序列
   - 适用于答案按顺序排列的情况

4. **内联答案提取**
   - 从题目文本中提取内联答案
   - 适用于答案在题目末尾的情况

5. **多维度相似度匹配**
   - 使用编辑距离、余弦相似度等算法
   - 适用于题号不明确的情况

6. **结构特征匹配**
   - 利用题目结构特征进行匹配
   - 适用于题目结构相似的情况

7. **位置兜底匹配**
   - 基于位置进行匹配
   - 适用于所有策略都失败的情况

### 5.2 匹配率阈值

- **≥90%**：自动合并
- **70%-90%**：标记待确认
- **<70%**：手动匹配
