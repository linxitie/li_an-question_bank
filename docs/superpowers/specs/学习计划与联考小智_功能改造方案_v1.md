## 1. 智能排课（已实施 · 后端）

**改动**：`backend/app/api/v1/growth/study_plan.py`

- 新增 `_build_schedule()`：按**今日任务 + 画像每日时长 + 待复习错题数**生成三段时段表（上午/下午/晚上），科目按关键词归类（行测/申论/公专/综合），单选题量按 `expected_minutes` 折算，总时长封顶 `daily_hours×60×0.9`；每项带 `goal_id`（可勾选回写）或 `kind=review`。
- 落库：`plan_meta["schedule"]`（**零迁移**），含 `date/sig/version/generated_at/budget_minutes/planned_minutes/slots`。
- 幂等与动态更新：`sig = md5(日期 + 每日时长 + 各任务 id/标题/日期/完成状态)`；`/plan/current` 每次读取比对 sig，**任务或日期一变就重算**；`/plan/task/{id}/toggle` 勾选后重算并返回 `schedule_recomputed`。
- 接口只增字段：`GET /api/plan/current` 增 `schedule`；`GET /api/plan/today` 增 `schedule`。

**证据**：`backend/tests/test_plan_schedule_capability.py` 8 例全绿（含：明天任务不进今日排课、资料分析→上午、申论→晚上、加任务后 sig 变化、勾选后 done=true）。

**待做（前端）**：把 `.vtj/vue/study_plan.vue:143-200` 的静态时段块替换为渲染 `state.plan.schedule.slots`（模板改动 → R3）。

## 5. AI 调整计划落地（P2 待做）

目标（`/plan/adjust`）：LLM 只输出**受限变更指令数组**，服务端事务应用并落 diff：
```json
{"applied":true,"changes":[
  {"op":"add","title":"资料分析 20 题","date":"2026-11-24","minutes":40},
  {"op":"move","goal_id":123,"from":"2026-11-24","to":"2026-11-25"},
  {"op":"modify","goal_id":124,"minutes_from":30,"minutes_to":45},
  {"op":"remove","goal_id":125}],
 "summary":"...","schedule_recomputed":true}
```
约束：单次 ≤10 条变更、总时长不超画像 `daily_hours`、失败整体回滚；`/plan/current` 增 `recent_adjustments[3]`（原因/变更摘要/时间）；支持"撤销最近一次"（反向应用同一 diff，仍写审计记录）。
