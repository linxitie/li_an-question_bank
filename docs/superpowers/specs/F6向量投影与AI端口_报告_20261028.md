## 3. 关键契约

- local 根：`backend/data/foundation/vectors/<collection>.npy|.ids.json|.meta.json`。
- 单条向量维度必须等于 `VECTOR_DIM`；零向量/NaN/Inf/非法集合名拒绝。
- 检索按余弦相似度降序、同分按 id 升序；top_k 上限 `VECTOR_SEARCH_TOP_K_MAX=100`。
- where 只支持 meta 字段等值/IN，多条件 AND。
- Milvus 集合名 = `VECTOR_MILVUS_PREFIX + collection`，默认 `li_an_text_questions`。
- hash 端口用字符 1/2/3-gram + blake2b 有符号哈希 + L2 归一化，`degraded=True`。
- http 端口：POST {BASE_URL}/embeddings，Bearer，batch=32，超时 30s；429/5xx/网络 → Unavailable，400/401/403 → Error。
- 回填默认 dry-run；`--apply` 强制要求 http 端口，避免把 hash 写进生产语义索引；`--verify` 使用临时根。
