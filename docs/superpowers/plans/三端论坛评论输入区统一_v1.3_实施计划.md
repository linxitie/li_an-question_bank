# 三端论坛评论输入区统一 实施计划 v1.3

> 状态：**已执行（2026-10-26，提交 12eb14e）**：三端实测通过；PC 改用 fixed 与弹窗底边对齐。
> Spec：`docs/plans/三端论坛评论输入区统一_设计方案_v1.3.md`

**Goal:** 三端（PC / 平板 / 手机）的论坛评论输入区统一为**一行**「😊 ＋ 输入框 发送」并**吸底**。

**Architecture:** 三处都是样式层调整：
- PC `.vtj/vue/forum.vue`（raw 页，只改 `<style>`，R3 安全）
- 平板 `src/views/student/tablet/tablet_forum_detail.vue`（手写 SFC，已 fixed）
- 手机 `src/views/student/mobile/mobile_forum_detail.vue`（手写 SFC，`relative → fixed`）

## Global Constraints

- PC 端仍只改 `<style>`，不碰 template、不执行 DSL 同步。
- 手机端 `.page` 必须补 `padding-bottom`，否则 fixed 底栏遮住最后一条评论。
- iOS 安全区保留：`padding-bottom: calc(10px + env(safe-area-inset-bottom))`。
- 上传按钮统一 36×36 圆形「＋」，原文字视觉隐藏保留给读屏。
- 表情面板都必须浮在输入区上方，且不改变输入区高度。
