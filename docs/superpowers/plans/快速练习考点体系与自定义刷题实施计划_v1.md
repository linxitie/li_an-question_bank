## 3. P1 API `display_points` + `filters`

### 3.1 后端改动

文件：`backend/app/api/v1/exam/quick_practice.py`

1. 新增内部 helper：
   - `_is_canonical_other(point)`：`point.level == 3 and point.point_name == '其他'`。
   - `_scope_payload(type, *, id=0, name='', subject_id=None, sub_category_id=None, l2_id=None)`。
   - `_build_display_node(...)`：构造 `display_points` 节点，字段见设计 §4.2。
   - `_build_display_points_for_subcat(...)`：输入 sub_question_ids、question_point_ids、L2/L3 映射、answer_map，输出 `display_points` 与 `other_count`。
2. 在 `get_sub_categories` 的每张子科目卡中新增：
   - `display_points`
   - `has_specific_points`
   - `other_count`
3. 在响应顶层新增 `filters`：
   - `years`：可见题 `year` 去重降序；
   - `types`：按 `type_id` 聚合，join `QuestionType` 取名；
   - `difficulties`：1–5 聚合。
4. 全局「未分类」卡片：
   - 保留 `knowledge_points=[]`；
   - 新增 `display_points=[other 节点]`；
   - 文案仍返回「未分类」，前端可显示「其他（未归类）」。
5. 不修改旧 `knowledge_points` 生成逻辑。

### 3.2 测试

新增 `backend/tests/test_quick_practice_display_points.py`：

- 场景 A：L2 只有 canonical other L3 + 直挂题 → `display_points` 一个节点，`children=[]`，`is_other=True/is_direct=True`。
- 场景 B：L2 有具体 L3 + other L3 + 直挂题 → 具体 L3 children + 一个合成 other child；L2 total 不含 other。
- 场景 C：子科目有 `point_id IS NULL` 题 → 末尾子科目 other 节点。
- 场景 D：0 题 L2/L3 不出现；旧 `knowledge_points` 字段与旧测试一致。

### 3.3 验收

- 旧 4 个测试文件全绿。
- 新测试全绿。
- 手工 GET `/api/quick-practice/sub-categories?subjectId=1`：`display_points` 中无逐条「其他」；`other_count` 与截图中的 6/6、3/3 可对上。

### 3.4 回滚

- 仅新增字段与 helper；删除新增代码即可，旧字段不受影响。

## 4. P2 scope 抽题 + 题组展开

### 4.1 后端改动

文件：`backend/app/api/v1/exam/quick_practice.py`、`backend/app/services/paper_group_selector.py`

1. `get_practice_questions` 参数扩展：
   - `knowledge_point_ids: str = Query("", ...)`（从必填改为可空，旧调用仍传）。
   - 新增 `scope`、`scope_id`、`subject_id`、`sub_category_id`、`l2_id`、`point_id`、`include_descendants`、`include_other`、`year_from`、`year_to`、`type_ids`、`difficulties`、`order`、`dedupe`。
2. 新增 `_resolve_scope_query(db, ...)`：
   - 基础：`QuestionStatsService.visible_query(db)`；
   - subject/subcategory/l2/l3/other 分支按设计 §4.1；
   - other 分支：
     ```python
     or_(
         QuestionBank.point_id.is_(None),
         QuestionBank.point_id.in_(other_l3_ids),
         QuestionBank.point_id.in_(l2_ids),  # 直挂 L2
     )
     ```
     若限定 `l2_id`，只取该 L2 的 other L3 与直挂题。
3. 旧路径保留：
   - 未传 `scope` 且未传新参数 → 原 `bySubCategory` / QK 反查逻辑。
4. 过滤：
   - `year_from/year_to`；
   - `type_ids`、`difficulties`；
   - `order=random` 用 `func.random()`；`weak/unseen` 需 join `PracticeRecord` 聚合，首期可只实现 random，另两个返回 400/降级并在文档标注。
5. 去重与题组：
   - 先按题干 `min(question_id)` 去重；
   - 取 `limit` 后，若命中 `group_id>0`，查询整组可见成员并合并；
   - 按 `group_id, sort_order, question_id` 排序，独立题保持随机顺序；
   - 返回 `requested_limit`、`actual_count`、`group_expanded`。
6. 新增 helper `expand_question_groups(db, questions, subject_id=None)` 到 `paper_group_selector.py`，供练习复用；不改动现有 `select_questions_with_groups` 行为。

### 4.2 测试

新增 `backend/tests/test_quick_practice_scope_questions.py`：

- `scope=l3` 只返回该 L3 题；
- `scope=l2&include_descendants=true` 返回 L2 直挂 + 具体 L3，不含 other；
- `scope=l2&include_other=true` 含 other；
- `scope=other&sub_category_id=X` 返回 null + canonical other + 直挂 L2；
- `scope=subcategory` 返回全部；
- 题组命中一题时返回全组，`actual_count > requested_limit`。

### 4.3 验收

- 旧 `test_quick_practice_consistency.py` 3 条全绿。
- 新测试全绿。
- 手工：`scope=other&sub_category_id=8` 题数与 `display_points.other_count` 一致。

### 4.4 回滚

- 新参数默认关闭；旧调用路径原样保留。回滚只删新分支。

|---|---|---|
| raw 页 script 改动破坏渲染 | 页面白屏/编译错 | `git checkout -- .vtj/vue/question_bank.vue` |
| display_points 计数与旧字段不一致 | 新测试/人工对账差异 | 关闭前端新字段读取，回退旧 `knowledge_points` |
| scope 抽题空集 | 某 scope 返回 0 但 total>0 | 回退到旧 kpId/bySubCategory 路径 |
| 回填写错 | 抽样不一致/科目错 | 备份库替换；脚本幂等重跑 |
| 记录列自愈失败 | 启动 warning/500 | 手工 ALTER 或回滚模型列 |
| 新页路由冲突 | 404/重复路由 | 删除路由行，恢复旧跳转 |
