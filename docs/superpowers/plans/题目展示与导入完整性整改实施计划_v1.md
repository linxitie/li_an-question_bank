## 1. 实施原则

1. **先修契约，再修展示**：选项对象契约、来源真源、解析器拆分先落地，前端才不会被“假数据”误导。
2. **先做 dry-run，再 apply**：所有历史数据修复默认只读；执行前 `sqlite3.Connection.backup()`。
3. **raw 页零模板改动**：只改 script / CSS / 后端契约；确需模板改动单独审批。
4. **每批可独立回滚**：P1–P5 各自一个提交或一组可回滚文件。
5. **没有门禁输出的“完成”不算完成**：定向测试、quick gate、typecheck、build、浏览器验收缺一不可。
