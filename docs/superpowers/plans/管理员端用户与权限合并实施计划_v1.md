## 风险检查点

- **每个 Phase 结束**：跑定向测试 + gate quick；失败不进下一阶段。
- **迁移前**：备份必须成功且可读；迁移脚本先 dry-run。
- **批量前**：预览接口先于 apply 上线；前端不允许跳过预览。
- **权限变更前**：最后超管/自我/越级三类守卫必须有单测。
- **raw 页**：任何 `.vtj/vue/*.vue` 改动前先确认 raw；只改 script，不改 template。

### 修复记录：角色模板保存后 GET 仍返回旧值

- 根因：`ROLE_PERMISSIONS` 的键是 `UserRole` 枚举，`GET /api/admin/permissions` 用 f-string 拼出 `role_permissions_UserRole.TEACHER`，而 `PUT` 写的是 `role_permissions_teacher`，两者永远不相等；数据库已更新，读取回退到硬编码默认值。
- 修复：`backend/app/api/v1/platform/admin.py` 在循环入口将 `role_key` 归一化为 `.value` 字符串，再拼 `SysConfig` 键与 `ROLE_NAME_CN`。
- 回归：`backend/tests/test_admin_permissions.py` 新增 `test_role_template_update_can_be_undone`；12 passed。
