# 电脑端论坛：上传入口可见性与用户卡片层级 实施计划 v1.1

> 状态：**已批准待执行**（2026-10-25，决定一 = A `:has()`，决定二 = A 隐藏旧上传按钮）
> Spec：`docs/plans/电脑端论坛上传入口与用户卡片层级_设计方案_v1.1.md`

**Goal:** 帖子详情打开后评论输入区常驻底部；用户卡片盖在帖子详情之上；隐藏发帖弹窗里误导性的旧上传按钮。

**Architecture:** 三处改动全部落在 `.vtj/vue/forum.vue` 的 `<style scoped>`，不改 `<template>`、不改后端、不执行 DSL 同步。

**Tech Stack:** Vue SFC scoped CSS、CSS `position: sticky`、CSS `:has()` + `@supports`、Playwright 实机断言、vitest/typecheck 基线。

## Global Constraints

- 只改 `.vtj/vue/forum.vue` 的 `<style>` 段。
- 禁止改 `<template>`（R3）、禁止 `vtj_sync_vue_to_dsl`（R2，raw 页）。
- 后端零改动。
- 改完必须跑 §验证 的 10 条断言，不靠读代码下结论。

### Task 2: 用户卡片提层

**Files:** Modify `.vtj/vue/forum.vue`（`.modal-overlay` 规则之后，约 :1546 后）

- [ ] **Step 1: 加样式**

```css
/* 用户信息卡片必须盖在帖子详情之上：两者默认同为 z-index 2000，
   由 DOM 顺序决定，用户卡片在更前面会被压住 */
@supports selector(:has(*)) {
  .modal-overlay:has(.profile-card) {
    z-index: 2100;
  }
}
```

- [ ] **Step 2: 实机断言**

```js
// 打开帖子详情 → 点评论头像 → 计算用户卡片中心点命中谁
const card = document.querySelector('.profile-card');
const r = card.getBoundingClientRect();
const hit = document.elementFromPoint(r.left + r.width / 2, r.top + 20);
({
  profileOnTop: !!hit.closest('.profile-card'),
  detailStillOpen: !!document.querySelector('.post-detail-card')
})
```

Expected: `profileOnTop=true`, `detailStillOpen=true`

- [ ] **Step 3: 断言关闭卡片后详情仍在**

点卡片「关闭」按钮 → `.post-detail-card` 存在，`.profile-card` 消失。

- [ ] **Step 4: 提交**

```bash
git add .vtj/vue/forum.vue
git commit -m "fix(forum): 用户信息卡片抬到帖子详情之上（z-index 2100）"
```
