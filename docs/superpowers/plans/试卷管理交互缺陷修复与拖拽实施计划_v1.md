### 6.4 拖拽手柄化与真实拖放验证

- 收尾复查发现：原实现给整张 article 设 draggable，浏览器 dragstart 的 target 是 article，导致 onPaperDragStart 内 target.closest('.pw-drag-handle') 恒为 null 并 preventDefault。已改为仅手柄可拖：左右手柄各自 draggable，article 只保留 dragover/dragleave/drop；卷内题手柄 disabled，左栏已在卷题手柄 disabled。
- 手柄化后 agent-browser 实测：dragstart 的 target 为 BUTTON.pw-drag-handle；article dragover 的 defaultPrevented=true、dropEffect=move。说明“手柄起始拖拽 + 目标接收”链路已生效。
- agent-browser 0.27.1 在 HTML5 DnD 上只派发 dragstart/dragover/dragend，不派发 drop，故真实落点未能在该工具内完成；同一套 onPaperDrop/addBankQuestionAt 逻辑已用合成 DragEvent 验证顺序重排与“建议整组加入”提示。该限制已如实记录，不以工具限制冒充通过。
