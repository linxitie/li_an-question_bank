# 论坛三端分类、头像、表情修复实施计划 v1

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 让论坛分类在三端一致且由后端筛选，补齐平板头像与 PC 表情入口。

**Architecture:** 以 `share_type` 作为唯一分类契约；新增一份共享分类常量供 PC/平板/手机复用；后端枚举补 `QUESTION`；头像沿用 `avatarInitial()` 回退；表情复用 `EmojiStickerPicker` + `ForumContent`。

**Tech Stack:** Vue 3.5 / VTJ raw 页 / Pinia / FastAPI / SQLite / vitest / pytest

**Spec:** `docs/superpowers/specs/论坛三端分类头像表情修复_v1.md`

## Global Constraints

- 分支：`feature/forum-category-avatar-emoji`，父分支 `feature/forum`；禁止直接向 `main` 合并。
- `.vtj/vue/*.vue` 只做增量修改，改前备份 `*.bak_20261023`。
- 不改 `/api/v1` 前缀，不改页面 id / 文件名 / 路由。
- 不引入新的 emoji 依赖。
- 表情插入策略：末尾追加，与手机端一致。

## Review Focus

- 分类切换到没有帖子的分类：应显示空状态，不得沿用上一分类的列表。
- 翻页后再切分类：必须回到第 1 页，且结果来自服务端而非当前页。
- 头像 URL 失效：回退首字，不得出现破图。
- 纯数字昵称（学号）：回退「友」，不得显示数字。
- 评论含 `[[sticker:...]]`：PC 与手机渲染一致，不得显示原始标记。
