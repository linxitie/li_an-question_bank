- 改任何 `.vtj/vue/*.vue` 的 template 前，先复制 `.bak_20261026` 备份；只改目标片段，不重排无关代码。
- 数据库变更前用 `sqlite3.backup()` 备份，禁用 `shutil.copy2`（R10）。
- 新增接口一律挂在 `/api/forum/...`，不加 `/api/v1`（R11）。
- 每阶段结束跑：`npx vitest run`、`npm run typecheck`、相关 `pytest`。
- 每阶段单独提交。

## P1 纯前端

### T1 退出登录兜底
**改** `.vtj/vue/TeacherNavHeader.vue`（script，:373）
```js
function handleLogout() {
  showUserMenu.value = false;
  const auth = (window as any).__VTJ_AUTH__;
  try { auth?.logout?.(); } catch {}
  try { localStorage.removeItem('__VTJ_AUTH_STATE__'); } catch {}
  emit('logout');
  router.push('/login');
}
```
验收：点「退出登录」→ 跳 `/login`，`localStorage.__VTJ_AUTH_STATE__` 为 null。

## P3 后端 + 收藏/喜欢/可见范围

### T9 收藏表与接口
- `models.py` 新增 `ForumFavorite`（post_id, user_id, create_time，唯一约束）
- `main.py` 迁移段：`create_all` + 缺列检查（沿用现有模式）
- `forum.py` 新增：
  - `POST /api/forum/posts/{id}/favorite` → toggle，返回 `{favorited, favoriteCount}`，同步 `forum_post.collect_count`
  - `GET /api/forum/my-favorites?limit&offset`
  - `GET /api/forum/my-likes?limit&offset`
  - `_serialize_post` 增加 `favorited`、`favoriteCount`（列表与详情都需要，需批量查询）
- `pytest tests/test_forum_favorite.py`：收藏/取消/重复/他人不可见/列表过滤

### T10 反应收敛为「爱心」
- `REACTION_CODES = ("like",)`；其它 code 返回 422
- 数据清理：`DELETE FROM forum_like WHERE reaction_code IS NOT NULL AND reaction_code <> 'like'`，随后按 `like` 重算 `forum_post.like_count`
- 前端：PC / 手机详情 / 平板详情 的 6 个反应按钮 → 单个爱心（PC 模板改动在 P2 一起做；手机/平板是手写页）
- 验收：「我的喜欢」与帖子爱心数一致

### T11 教师发帖可见范围
- `forum_post` 新增 `visibility VARCHAR(16) DEFAULT 'ALL'`、`visible_classes JSON`
- `create_post` 接收 `visibility`、`visible_classes`；仅教师/管理员可设为 `CLASSES`
- 学生列表过滤：`visibility='ALL' OR 学生 class_name ∈ visible_classes`；教师/管理员不过滤
- `pytest tests/test_forum_visibility.py`：全校可见/指定班级/外班不可见/教师可见全部

### T12 PC 收藏/喜欢弹窗 + 爱心按钮
- 弹窗：两个 tab（我的收藏 / 我的喜欢），列表项点击回到帖子
- 帖子项爱心按钮 → `POST .../favorite`

### T13 教师端侧栏 + 发帖
- 侧栏三卡（热门帖子 / 论坛活跃 / 我的帖子），数据复用 `/api/forum/stats`、`/api/forum/posts?sort=likes`、`/api/forum/my-posts`
- 发帖弹窗：标题、颜色、正文、附件、**可见范围（全校 / 指定班级多选）**

### T14 手机/平板反应按钮收敛
- `mobile_forum_detail.vue`、`tablet_forum_detail.vue`：6 反应 → 单爱心
