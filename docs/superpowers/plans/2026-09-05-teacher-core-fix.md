## 任务分解

### Task 1: 图片路径标准化函数 (高优先级)

**目标**: 实现 `normalize_image_path()` 函数，统一图片路径格式

**修改文件**: `backend/app/services/image_service.py`

**实现步骤**:
1. 添加 `normalize_image_path(path, question_id)` 函数
2. 支持多种路径格式转换
3. 支持 `[IMAGE:xxx]` 占位符转换
4. 添加路径安全检查

**验收标准**:
- [ ] 函数能正确处理各种路径格式
- [ ] 输出统一为 `/static/questions/{qid}/{filename}`
- [ ] 路径安全检查生效

---

### Task 2: 数据迁移脚本 (高优先级)

**目标**: 创建数据迁移脚本修复现有图片路径

**新建文件**: `backend/scripts/fix_image_paths.py`

**实现步骤**:
1. 扫描 `question_bank` 表中含图片的题目
2. 检查图片文件是否存在
3. 从 `question_images` 表查找有效路径
4. 修复路径格式不一致的问题
5. 支持 `--dry-run` 模式

**验收标准**:
- [ ] 脚本能正常运行
- [ ] 支持预览模式
- [ ] 生成修复报告

---

### Task 3: 前端图片加载失败处理 (中优先级)

**目标**: 增强图片加载失败时的重试机制

**修改文件**: `.vtj/vue/teacher_questions.vue`

**实现步骤**:
1. 增强 `handleImageError()` 函数
2. 添加多级重试机制
3. 显示占位图作为最终兜底

**验收标准**:
- [ ] 图片加载失败时自动重试
- [ ] 显示占位图
- [ ] 不影响其他功能

---

### Task 4: 试卷创建阈值检查 (中优先级)

**目标**: 修改试卷创建逻辑，少于5题不创建试卷

**修改文件**: `backend/app/api/v1/question_import.py`

**实现步骤**:
1. 修改 `_get_or_create_import_paper()` 函数
2. 添加 `question_count` 参数
3. 添加阈值检查（至少5题）
4. 修改调用处传入实际题目数量

**验收标准**:
- [ ] 少于5题不创建试卷
- [ ] 多于5题正常创建
- [ ] 同名试卷复用

---

### Task 5: 编辑保存流程修复 (中优先级)

**目标**: 修复编辑对话框保存后数据不生效的问题

**修改文件**: `.vtj/vue/question_preview_list.vue`

**实现步骤**:
1. 修改 `saveEdit()` 函数
2. 确保数据正确写回 `questions` 数组
3. 使用 `emit('edit-question', { index, data })` 通知父组件

**验收标准**:
- [ ] 编辑对话框能正常打开
- [ ] 保存后数据在前端正确显示
- [ ] 必填字段验证生效

---

### Task 6: 缺失信息检测与提示 (中优先级)

**目标**: 在预览阶段自动检测缺失信息并提示

**修改文件**: `.vtj/vue/question_preview_list.vue`

**实现步骤**:
1. 添加 `missingStats` 计算属性
2. 统计缺失答案、解析的题目数量
3. 在顶部统计栏显示缺失信息

**验收标准**:
- [ ] 缺失信息统计准确
- [ ] 显示缺失题目数量
- [ ] 提供批量编辑入口
