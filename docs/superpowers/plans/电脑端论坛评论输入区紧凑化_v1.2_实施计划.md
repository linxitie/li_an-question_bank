# 电脑端论坛评论输入区紧凑化 实施计划 v1.2

> 状态：**已执行（2026-10-26，提交 401f054）**：实机断言全部通过（输入区 135px，控件同行，＋按钮 36×36 圆形，表情面板浮于上方）。
> Spec：`docs/plans/电脑端论坛评论输入区紧凑化_设计方案_v1.2.md`

**Goal:** 评论输入区从四层 ≈300px 压成两行 ≈100px，控件集中到输入框下方一行，上传框缩成 36×36「＋」。

**Architecture:** 全部落在 `.vtj/vue/forum.vue` 的 `<style>`：flex `order` 重排视觉顺序 + `:deep()` 缩小 `FileUploader` 内部元素。「关闭」按钮用 `display:none` 隐藏，不删 DOM，避免 R3。

## Global Constraints

- 只改 `<style>`，不改 `<template>`（R3）、不执行 DSL 同步（R2）。
- `.modal-actions` 与发帖弹窗共用，选择器必须带 `.comment-input-area` 前缀。
- 输入框默认 44px，保留 `resize: vertical`，上限 160px。
- 上传按钮的文字用视觉隐藏保留，读屏仍可读。
