# 论坛敏感词自生长知识库 实施计划 v1

> 归档：docs/superpowers/plans/论坛敏感词自生长知识库_v1_实施计划.md
> 关联设计：docs/superpowers/specs/论坛敏感词自生长知识库_v1.md
> 状态：已实施（2026-11-03），验收见 §5。

## 1. 目标

把论坛硬编码敏感词升级为「可运营、可审计、可自生长」的知识库：
命中可回溯政策条款，人工复核反哺词条，红队主动找盲区，Obsidian 与人机运营台双向协同。

## 2. 范围

- 在 SQLite 新增 cg_* 12 张表与启动迁移；
- 新增 content_guard 服务包（归一化/DFA/判定/提案/红队/图谱/Obsidian/对账/统计）；
- 论坛发帖、评论、编辑、昵称签名四条写路径接入；
- 管理端 30 个 API + 单文件 HTML 运营台；
- Obsidian 投影与受控回写；
- 每日 03:30 自维护任务；
- 运维 CLI；
- 回归与新增测试。

不在范围：图片 OCR、音视频转写、跨模态编码、大模型直接阻断、Neo4j 强制依赖。

## 6. 风险与回滚

| 风险 | 缓解 |
|---|---|
| 词库误伤 | 置信度阈值 + 人工队列 + 误判 3 次自动降级提案 |
| 审核变慢 | DFA 纯内存；无命中零写入；日聚合 |
| 多进程词库不一致 | engine_version 版本号 + 请求时比对重建 |
| 投影覆盖人工修改 | 待审队列只写一次；只读投影按哈希增量重写 |
| 需要回滚 | CONTENT_GUARD_ENABLED=false；或路由摘除；数据保留可重建 |
