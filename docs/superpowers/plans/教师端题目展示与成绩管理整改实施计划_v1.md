## 0. 执行原则

1. **先证据后改动**：每个任务先跑基线命令，记录输出，再改。
2. **一任务一提交**：提交信息写“任务 ID + 验收命令 + 结果”，便于回滚。
3. **开关隔离**：新页/新渲染/OCR 审阅均有开关，默认关闭或 review 模式。
4. **数据修复双闸**：dry-run 输出 diff → 人工抽样 → --apply；执行前 sqlite3.backup()。
5. **不碰 raw template**：需要布局的地方新建手写页；只读展示用脚本挂载。
6. **门禁即完成**：没有 pytest/typecheck/gate 输出，不报“完成”。
