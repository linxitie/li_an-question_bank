## 执行目标
为用户匹配适配的开源资源，提供可靠的引入建议，避免重复造轮子，同时确保开源协议合规。

## 执行流程
1. 分析当前项目的需求场景，明确需要的外部功能、技术指标（语言、框架、性能要求、协议要求）

2. 检索GitHub、Gitee等平台的开源库，筛选出3-5个匹配度高的候选资源

3. 每个候选资源包含：
   - 项目名称、地址
   - 核心功能、适配度说明
   - Star数、维护状态、开源协议
   - 优缺点分析

4. 给出推荐建议：优先推荐维护活跃、协议宽松、适配度高的资源，同时标注潜在的兼容性、安全风险

5. 等待用户确认选择后，才可执行依赖安装、代码引入操作

## 输出规范
推荐结果使用表格形式呈现：
```
| 项目 | 地址 | 功能 | Star | 协议 | 优点 | 缺点 |
|------|------|------|------|------|------|------|
| ... | ... | ... | ... | ... | ... | ... |
```

## 禁止行为
- 禁止未经用户确认直接执行pip install、npm install等依赖安装操作
- 禁止推荐存在安全漏洞、协议不合规（如GPL用于商业项目）的开源库
- 禁止隐瞒开源库的潜在风险
