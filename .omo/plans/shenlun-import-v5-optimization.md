## 0. 用户实测暴露的 6 个缺陷

| # | 缺陷 | 用户原话 | 严重度 |
|---|---|---|---|
| D1 | 预览缺总题干 | 「缺失总题干信息，针对复合题目请设计好怎么在导入匹配后总体预览的题目排版」 | 高 |

## 1. 全语料结构分析（实测数据，非推测）

### 1.1 规模与特征分布

```
语料库 PDF 总数 = 254
含答案区的文档 = 127 份（50%），其余为纯题本
含真实图片(≥60×60)的文档 = 118 份（46%）  ← 答案区的思维导图/答案逻辑图
```

**结构特征出现率**：

| 特征 | 出现文档数 | 占比 |
|---|---|---|
| `材料N` / `给定资料N` | 238 | 94% |
| `参考答案` 独立行 | 125 | 49% |
| `参考答案说明` | 119 | 47% |
| `参考答案` 带分值 | 93 | 37% |
| `思路方面`（解析惯用开头） | 37 | 15% |
| `【参考答案】` | 4 | 2% |
| `参考答案：` | 1 | 0.4% |

### 1.2 答案/解析分隔标记分布（**核心**）

在 127 份有答案区的文档中：

```
有明确分隔标记 = 119 份 (94%)
无分隔标记     =   8 份 (6%)
```

| 分隔标记 | 份数 |
|---|---|
| `参考答案说明` | **17**（另有大量混在 `参考答案` 独立行统计里，实际约 119） |
| `【参考答案】` | 4 |
| 其余（`解析`/`思路方面`/图示） | 98 |

**关键结论**：`参考答案说明` 是**绝对主流**的分隔标记（94% 的文档靠它或无分隔）。
**6% 的文档答案与解析本就无分界** —— 这类必须靠题型语义判断，否则不能硬拆。

### 1.3 D3 的真实根因（已定位）

用户截图显示：**答案区里 `参考答案说明：…` 被同时写进了 `answer` 和 `analysis`**（重复），导致「答案为参考答案、解析为空」或二者混杂。

原因：`_essay_is_ans_anchor()` 把 `参考答案说明：` 当成了**新的答案段起点**（我上一轮为解决 2019 阻断加的负向断言只在部分路径生效），于是：
- 段被切错 → `answer` 收尾包含说明文字
- `analysis` 又按 `note_at` 切了一次 → 说明文字同时出现在两处

### 1.4 D4 串题的根因（已定位）

形态②/③（就地配对）下，`_essay_is_ans_anchor` 命中的行会被 `cur=[]` + `continue` **丢弃该行**，但段尾没有「下一个题号」兜底。答案区若出现 `【参考答案】`（2022 行政执法卷那种带卷别的编号体例，`_ESSAY_ANS_NUMBERED_RE` 只认 `参考答案`，不认 `【参考答案】`），切段点就会错位，后续内容整段落进上一题 → **下一题题干被当成上一题的解析**。

### 1.5 D2 图片的根因

`question_import.py` 的图片提取只对**题干/选项**做（`_extract_and_save_images(content + options)`），
**答案与解析从不提取图片**。而 46% 的答案文档图片恰恰在答案区（思维导图）。
用户截图里的 `[[IMAGE:f4419932_2_0]]` 占位符说明 PDF 里有图片但**未被落库成可访问 URL**。

### 1.6 D1 总题干缺失的根因

申论复合题的「总题干」= 给定资料（material），已存入 `question_groups.shared_content`，
但**预览卡片完全没有渲染它**。用户只能看到孤立的小题，无法理解小题在问什么。
这是**产品设计缺口**，不是解析 bug。

## 2. 改造方案（去粗取精）

### 2.1 统一答案段边界判定（根治 D3/D4）

建立**单一权威函数** `split_answer_analysis(lines) -> (answer_lines, analysis_lines)`，规则优先级：

1. **最高优先级**：`参考答案说明` / `【参考答案说明】` / `答案解析` / `试题解析` / `思路方面`
   → 该行**归入解析**，且**不是**段起点（必须从锚点集合中剔除）
2. 段起点只认：`参考答案` / `参考答案：` / `【参考答案】` / `N、参考答案` / `N、（N分）`
3. **段尾兜底**：遇到下一个题号行（复用 `_ESSAY_NUM_RES` 四体例）立即截断
   —— 这一条直接根治 D4 串题
4. 段起点必须**同时**满足「行首是答案锚点」或「行首是编号+分值」，
   `【参考答案】` 必须加入 `_ESSAY_ANS_NUMBERED_RE` 的可选包装

**禁止**在解析器与 API 层各自实现一套切分，必须共用这一个函数。

### 2.2 答案/解析去重（根治 D3 的重复）

切分后校验：`analysis` 全文若为 `answer` 的子串，说明文本被两边同时收了 → 以 `answer` 为准、`analysis` 置空。
反向亦然。绝不两边都留。

### 2.3 答案区图片提取（根治 D2）

- 扩展图片提取范围：`content + options + answer + analysis` 四者合并后提取
- PDF 页级顺序定位：记录每张图所属段落（答案段 or 解析段），落到 `question_image.image_type`
  （新增值 `答案图` / `解析图`，与既有 `题干图` 并列，不改既有枚举语义）
- `[[IMAGE:xxx]]` 占位符必须在**答案/解析文本中原位保留**，
  落库时替换为可访问 URL，前端按 `white-space:pre-wrap` 渲染
- 参考既有 PDF 图片链路：`question_import.py` 的 `_pdf_image_to_png` /
  `_PDF_MIN_IMG_DIM` / `_compress_and_store` / `_extract_and_save_images`，
  **不得新建 `question_image_ref` 表**（用户既有约束）

### 2.4 复合题预览排版（根治 D1）

同一 `group_id` 的多道小题，在预览卡片中**聚合展示**：

```
┌─ 复合题组 #N　材料 7402 字　4 道小题 ────────────┐
│ 📄 给定材料（可折叠，默认展开首屏）                │
│   材料1 走进A市政务服务中心一楼大厅…               │
│   材料2 …                                        │
│   [展开全部 7402 字]                              │
├─────────────────────────────────────────────────┤
│ 第1题  15分   根据"给定资料1"，请概括…            │
│   要求：（1）准确全面；（2）分条列出…              │
│   参考答案：1.创新项目落地机制…（已匹配）          │
│   参考答案说明：本参考答案从…四个方面…             │
│   [答案图 ×1]                                    │
├─────────────────────────────────────────────────┤
│ 第2题  20分   请结合"给定资料2"…                  │
│   …                                             │
└─────────────────────────────────────────────────┘
```

实现要点：
- 后端预览响应按 `group_id` 分组，新增 `group_preview` 字段
- 前端 `question_preview_list.vue` 增加组容器：小题内缩、共享材料头
- 材料默认折叠（>800 字），避免首屏被上万字材料淹没
- 每道小题**必须**带自己的答案/解析/图片，**绝不允许跨小题串内容**

### 2.5 科目与匹配率（根治 D5/D6）

- `format=='essay'` → `subject_name` 强制定为「申论」，**优先级高于任何启发式**
- 申论分离导入的 `match_rate` 必须走三方交叉校验结果（已修），
  且**前端不应因 essay 文档的 match_rate 弹「请手动匹配」**——
  申论的匹配判据是题号/分值/指纹，不是选项匹配

## 3. 必须新增的验证脚本

`backend/scripts/verify_shenlun_corpus.py`：
- 遍历全部 254 份 PDF
- 逐份输出：体例 / 块数 / 题号序列 / 分值序列 / 答案段数 / 解析段数 / **串题检测** / 图片数
- **串题检测判据（关键）**：任一小题的 `answer` 或 `analysis` 中出现
  `（N分）` + 题干特征词（如「请根据」「请谈谈」「结合上述」）→ 判定为串题
- 验收线：块数与分值锚点数一致、题号连续、**串题数 = 0**、答案非空率 ≥ 95%
