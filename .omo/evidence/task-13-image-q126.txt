### ★ 与计划描述不符，如实更正

计划称「2025 国考地市级 Q126 为纯图片选项题：A./B./C./D. **四行文字全空**，
饼图为独立图片」。**实测不符**：

- 选项不是「四键全空」，而是**仅 2 个键**（A、C）
- 值不是空串，而是**字面标签 `'B.'` / `'D.'`**

即：切分点落在了选项行**内部**（把 `B.`/`D.` 当成了 A/C 的内容），
属**选项解析错位**，而非纯图片选项。已按新增的两类标记
`选项残缺` + `选项值疑似错位` 标为待复核，符合用户决策 Q2（入库并标红）。

### `options` 数据形态修正

实测 `options` **恒为 list** of `{'key','value'}`（行测 130/130），
**不是** dict。首版 `_xingce_review_flags` 写了 `opts.values()`，
在真实 Q126 上抛 `AttributeError: 'list' object has no attribute 'values'`。
已改为同时兼容 list 与 dict（公专链路产出 dict）。

## 5. need_review 标记（5 类，11/11 断言通过）

| 情形 | 标记 |
|---|---|
| 选项四键全空（纯图片选项） | `选项待补文字` |
| 答案缺失 | `答案缺失` |
| 解析缺失（纯空白亦计） | `解析缺失` |
| 资料分析未关联材料 | `材料关联异常` |
| 选项键数 1-3 | `选项残缺` |
| 选项值形如 `B.` | `选项值疑似错位` |
| 解析器判 suspicious | `题型存疑`（保留原语义） |

### 与 `blocked` 的语义隔离（两套，不可混用）

- `blocked` → **阻断**「确认入库」，前端按钮置灰
- `need_review` → 只标红提示，**仍然入库**（用户决策 Q2：不达标也入库）

已断言：blocked 题经过 `_xingce_review_flags` 后**不会**产生任何阻断语义。
标记计算置于 `material_group` 定档之后，否则「材料关联异常」会误标全部未归组题。
