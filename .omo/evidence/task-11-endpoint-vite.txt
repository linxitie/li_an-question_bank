
## 根因（已定位，非推测）

查询运行中后端的 OpenAPI：

```
$ GET http://localhost:8000/openapi.json
  含 separate-match 的路径:
    /api/questions/import/separate-match
  >> 缺少 /api/questions/import/separate-match-xingce
```

**运行中的 8000 进程启动于本次代码改动之前，且未启用 `--reload`**，
因此它服务的仍是改动前的代码，新端点根本不存在。
Vite 代理把请求转发给一个不认识该路由的后端，故 502/405。

对照：同一端点经 `TestClient`（真实 ASGI 栈 + 真实 `Depends(get_current_user)`
+ 真实 SQLite + 真实 PDF）已 **27/27 项断言通过**，详见
`task-11-endpoint.txt` 与 `task-11-auth-validation.txt`。

重启用户正在运行的后端服务属于影响外部环境的操作，且不清楚其原始启动方式
（是否带 `--reload`、是否有其他依赖进程）。已停止在此并上报，等待确认。
