五、为何不用 text_parser/ 目录（实测，非推测）
--------------------------------------------------------------------------------
Windows/Python 3.13.5 三组对照实验：
  A. pkg/pkg.py + pkg/pkg/__init__.py   -> AttributeError: module 'pkg.pkg' has no attribute 'X'
     （同名的目录包**遮蔽**了 .py，from pkg.pkg import X 全部失效）
  B. pkg/pkg.py + pkg/pkg/（无 __init__.py）
     -> ModuleNotFoundError: No module named 'pkg.pkg.sub'; 'pkg.pkg' is not a package
  C. 仅 pkg/pkg.py                       -> 正常

结论：在「text_parser.py 必须保持为可导入模块」的前提下（L0 红线按**文件路径**
读取该文件），text_parser/xingce.py 这一路径**不可行**。故采用等价扁平模块
backend/app/services/text_parser_xingce.py。
