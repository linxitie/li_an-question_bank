## 2. 根治 110 vs 101（任务 1 定位的缺陷）

```
=== 安徽行测 2023（此前题本110 / 答案101）===
  题本块数      : 110
  锚点块数      : 110        ← 从 101 修复
  配对成功      : 110  (100%)
  缺答案题号    : []
  只在题本      : []
  只在答案      : []
  blocked_count : 0
```

**机制**：`780.9毫米` 后面不跟「正确答案」，故不会被 `N. 正确答案：X` 锚点误判为块边界。

## 3. 关键发现：同一缺陷在题本侧的「前向跳跃」形态

首版实现后仍有 11 卷各缺 1 题答案，题号反常（469 / 176 / 213），远超答案侧区间上界。
逐一定位后确认**全部是题本侧伪题号**：

| 卷 | 伪题号原文 | blocks 最大 | 真实上界 | 清洁题号数 |
|---|---|---|---|---|
| 国考2023副省级 | `469.9亿美元，同比下降11.1%；…` | **469** | 135 | **135** |
| 贵州2024 | `176.0亿元、142.1亿元、121.9亿元…` | **176** | 110 | **110** |
| 河南2025 | `213.4万辆、176.6万辆，同比分别增加…` | **213** | 120 | **120** |

**与 780 的关系**：780 相对前题 100 是**前向跳跃** → monotonic 挡不住；
469/176/213 同样是前向跳跃 → 同样挡不住。
区别在于：780 在**答案侧**（被 `split_xingce_answer_blocks` 根治），
469/176/213 在**题本侧**（`extract_question_blocks` 是生产函数，**红线禁止修改**）。

**解法（守住红线）**：在配对层用清洁题号集（`(?!\d)` 正则）作权威，
剔除不在其中的块，并记入 `report['spurious_question_numbers']`。
实测清洁题号集与答案锚点集**精确相等**（135/135、110/110、120/120），故该过滤无损。

### 正则约束
```python
XINGCE_QNUM_PATTERN = re.compile(r"^[ \t]*(\d{1,3})[ \t]*[.．、](?!\d)", re.M)
```
- `780.9毫米` → `.` 后是 `9` → **排除** ✔
- `60.` + 空格 + `。`（填横线题） → `.` 后是空格 → **保留** ✔

实测：安徽 2023 题本旧正则得 111（多 1），排除小数后得 **110**，与锚点数精确相等。

## 4. X-2 判据的一次修正（T2 门禁实测得出）

T2 基线显示：**分节头序列全等 85/85，但块区间全等仅 4/85**。
原因是块区间被伪题号压缩。

修正：**X-2 必须用「答案锚点区间」而非「块区间」**。
实现上进一步分两侧口径：

| 侧 | 口径 | 理由 |
|---|---|---|
| 题本侧 | `_xingce_clean_qnums`（排除小数） | 权威且无损 |
| 答案侧 | `_xingce_anchor_nums`（锚点） | 权威 |

**两侧口径不同，正因如此才能互为校验。**

## 6. ★ 安全网核心价值证明（错年份配对必须被拦截）

```
用例                          卷级blocked  题数  blocked数  每题blocked  配对
2025题本+2025答案(正确)         False       130     0         False     130/130
2025题本+2024答案(错配)         True        130    130         True      130/130
2024题本+2025答案(错配)         True        130    130         True      130/130
```

拦截依据（题本侧 vs 答案侧区间差异一目了然）：
```
2025题本: 政治理论1-20 常识21-35 言语36-65 数量66-75 判断76-110 资料111-130  (6 节)
2024答案: 常识1-20 言语21-60 数量61-70 判断71-110 资料111-130              (5 节)
→ X-1 分节序列不等 + X-2 区间不等 → blocked
```

### 防御深度（自查发现并修复的安全性缺陷）

首版实现在卷级 blocked 时 `blocked_count=0` —— **题目仍带着答案被返回**。
若调用方只看 `questions` 列表而忽略 `report['blocked']`，错配答案就会被当作正常结果落库。

已修复：卷级 blocked 时**每道题也强制 blocked**，并继承卷级 `block_reasons`。
实测 `blocked_count 130/130`、`每题都blocked=True`。

### 就近填充防护
```
缺答案题号: [2]
第2题 answer='' blocked=True reasons=['answer_missing_for_question']
第3题答案='D'，第2题答案='' → 两者不同（正确，未就近填充）
```
