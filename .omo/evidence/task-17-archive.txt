## 4. vtj.md 勘误内容

### 4.1 端口 5173 → 9527（4 处）

依据：`vite.config.ts:8` `DEV_PORT = 9527`，且 `strictPort: true`。

### 4.2 附录F：强制同步 → raw:true 禁止同步

原文要求「每次修改 .vue 后**必须**同步 `.vtj/files/*.json`」。
现改为判定流程：

```
查 .vtj/projects/*.json 中该页 "raw": true ?
  ├── 是（raw 手写页）→ ✅ 禁止同步，只改 <script>，UI 结构回设计器
  └── 否（设计器管理页）→ 按原流程同步
```

依据（实证，非推断）：`question_import.vue` 共 48 个方法，
同步工具连 `_pollImportStatus` 都提取不到 —— 同步会**丢方法**，
且设计器再保存时会把丢失部分**反向覆盖**到手写代码。

附`raw:true` 页面改动自检命令：

```powershell
git diff --stat -- .vtj/files/xxx.json     # 必须为空
Select-String -Path .vtj/vue/xxx.vue -Pattern 'useProvider\(\{'   # version 不得变更
```
