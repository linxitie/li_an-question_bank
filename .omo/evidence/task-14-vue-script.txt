### 2.1 按科目分流

新增 `_detectXingceSubject()`，从**题本正文前 8000 字**探测行测分节头
（言语理解与表达/ 判断推理 / 资料分析 / 数量关系 / 常识判断 / 知觉速度与准确性 / 科学推理 / 政治理论）。

> **关键坑**：`state.form.subject_category` 的**默认值是「公专」**（L521）。
> 若依赖表单值判断，行测会被误送到通用端点。必须从正文探测。

```javascript
var detectedXingce = this._detectXingceSubject();
var matchEndpoint = detectedXingce === '行测'
  ? '/api/questions/import/separate-match-xingce'
  : '/api/questions/import/separate-match';
```

申论/公专**仍走原端点**，既有分支逻辑零改动。

### 2.2 行测字段透传（否则既有UI 全部失效）

`blockedQuestionList()`（L609）读 `q.blocked` 与 `q.block_reasons`；
不透传则「存在阻断问题，无法入库」的按钮禁用与提示**完全失效**。
故转换层必须携带：`blocked` / `block_reasons` / `need_review` /
`review_reasons` / `xingce_subcategory` / `kao_points_normalized` / `material_group`。

### 2.3 顺带修正 `options` 形态（任务 13 已查明）

原映射对对象是**空操作**：
```javascript
value: typeof o === 'string' ? o : o     // o 为对象时value = 整个 {key,value}
```
行测实测 `options` 恒为 `[{key,value}]`（130/130），故已改为取 `o.value`，
并保留字符串兼容分支。
