P4 招考信息 — 问题诊断与设计方案

内容直展 + 过滤优化 + 卡片排版 + 数据库完善

📋 问题#1: 直接展示完整招考内容

❌ 当前状态

• 列表展示标题+标签
• 点击后需要跳转"查看原文"
• content字段已存储但前端未渲染
• 用户体验割裂

✅ 优化方案

交互改为"点击展开"模式：

1. 列表卡片：标题 + 单位 + 地区 + 状态标签
2. 点击卡片 → 原地展开（Accordion/Collapse）
3. 展开后显示完整内容：
├─ 招聘条件
├─ 报名时间
├─ 考试方式
├─ 正文（HTML渲染）
└─ 图片（如有）
4. 支持再次点击收起

🔍 问题#2: 内容过滤 + 排版

内容过滤规则
过滤类型 规则 示例
HTML标签移除 script, style, iframe<script>广告代码</script>
非正文区块移除 nav, footer, .sidebar, .ad"上一篇/下一篇"、"推荐阅读"
空白噪音合并连续空行（>2 → 1）段间距统一
图片保留正文图片，移除装饰图二维码保留、无关icon移除
