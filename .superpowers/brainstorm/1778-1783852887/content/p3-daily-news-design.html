✅ 优化方案

改进的爬取流程：

1. Playwright 打开 people.com.cn
2. 等待JS渲染完成

4. 逐条进入详情页抓取：
├─ 正文（多选择器回退）

5. 过滤规则增强：
├─ 移除：登录/注册/党建/记住密码/广告
├─ 保留：标题/正文/图片/来源/日期

🖼️ 问题#2: 公安报图片获取

图片提取增强

当前：只提取文本，忽略图片

优化：

步骤 操作
1. 图片发现详情页中提取所有 <img> 标签的src
2. 图片过滤跳过logo/icon/ad等（尺寸>50x50, 非广告域名）

⭐ 问题#4: 收藏 + 笔记功能

新闻收藏与笔记 — 完整交互设计

📌 收藏新闻

• 新闻详情页顶部 ⭐ 收藏按钮
• 一键收藏整篇新闻
• 后端: POST /api/news/{id}/favorite
• 表: news_favorite (user_id + news_id)
• 前端"收藏"Tab展示已收藏新闻列表

📝 收藏语句

• 长按/选中文字 → 弹出"收藏"按钮
• 保存选中文本 + 位置锚点
• 后端: POST /api/news/{id}/highlight
• 表: news_highlight (user_id + news_id + text + offset)
• 前端"收藏"Tab中按新闻分组展示

✏️ 划线笔记

• 选中文字 → 划线标注
• 划线自动保存到"笔记"
• 划线颜色：黄/绿/蓝（3色可选）

💬 写想法

• 划线后弹出输入框写想法
• 或独立"添加笔记"按钮
• 后端: POST /api/news/{id}/note
• 表: news_note (user_id + news_id + text + quote + position)
• 自动保存，无需手动提交
