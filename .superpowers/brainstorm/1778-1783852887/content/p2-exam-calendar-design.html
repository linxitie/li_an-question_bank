🔄 问题#3: 状态判定错误 + 过期自动删除

状态判定逻辑修复

当前问题根因：

1. exam_scraper.py 爬取时未解析 registration_start/end
2. calendar.py 的 _compute_status() 依赖registration字段但数据为空
3. cleanup_expired_exams() 按 exam_date 删除而非 registration_end

修复方案：

修复点 文件 具体操作
爬虫增强 exam_scraper.py 进入详情页抓取registration_start/end + exam_format + description完整内容
状态判定 calendar.py 优先用registration字段判定：reg_end < now → 已截止；reg_start > now → 即将报名；else → 报名中
过期删除 scheduler.py 每日定时任务：硬删除 registration_end < now - 1day 的记录
