- 状态：**待人工审核（工作流第二节）**

## 一、任务目标

彻底修复两个用户实测发现的导入缺陷，使题目导入稳定、高效：

1. **判断题被误判为简述题**
2. **选择题被填入随意编造的字母答案**

---

## 二、已完成的根因定位（有原始数据支撑，非推测）

### 缺陷 1：分节声明的题型未传递给分类函数

该文档含 3 个分节标题：

| 分节原文 | 题号 | 应有题型 |
|---|---|---|
| `一、单项选择题。每题所设选项中只有一个正确答案…` | 1–50 | 单选题 |
| `二、多项选择题。每题所设选项中至少有两个正确答案…` | 51–80 | 多选题 |
| `三、判断题。判断下列说法的正误。` | 81–90 | **判断题** |

实测：

- `_SECTION_TYPE_WORDS`（L1702 附近）**已包含**「判断题/单项选择题/多项选择题」等词。
- 但 `_detect_question_type('地方性法规…（  ）', [])` 返回 **`('简答题', 0.4)`**。
- 81–90 题本身**无选项**（判断题在本文档以「陈述句 +（ ）」呈现，答案取自答案 PDF），因此落入 `opt_count==0` 的兜底分支 → 简答题。
- P2 已实现 `_find_section_directive()`（L1702）用于**边界与污染**，但分节解析出的题型**从未传给** `_detect_question_type`（L2163）。

**结论：分节信息在题型分类环节被丢弃。**

### 缺陷 2：判断题答案无对应模式，触发单字母兜底

答案 PDF 对 81–90 题的实际写法是文字，不是字母：

```
81、本题考查行政法
根据《行政处罚法》第十一条第一款规定：「地方性法规可以设定除限制人身自由、吊销企业营业执照以外的行政处罚。」
故表述错误
82、…
故表述正确
```

实测抽取结果（生产入口 `smart_match_questions_answers`）：

```
q81 type=简答题 ans='C' opts=0
q82 type=简答题 ans='D' opts=0
q85 type=简答题 ans='D' opts=0
q90 type=简答题 ans='B' opts=0
```

这些题**无任何选项**，却被写入 C/D/D/B。来源是单字母兜底
`re.search(r'\b([A-Da-d])\b', text)`（L306）——从邻近解析文字中抓到孤立字母
（q81 的 'C' 来自上一题遗留的「A项、B项错误，**C**项正确」）。

**结论：缺少判断题（正确/错误）答案模式，且兜底逻辑未校验「题目是否有选项」。**

## 三、修复方案

### 修复 1：分节题型优先（核心）

在 `extract_question_blocks`（L1780）遍历中，记录当前分节声明的题型，
写入每个题块的 `section_type_hint`；`_detect_question_type` 增加该参数。

判定优先级（保持"强规则优先"设计不变，仅在最外层加分节兜底）：

1. 题目自身强证据（选项数 ≥ 2、可识别选项文本）→ 保持现有投票结果
2. 无选项 + 分节声明为选择型 → 用分节题型
3. 无选项 + 分节声明为判断题 → **判断题**
4. 无分节信息 → 保持现有兜底

对本文档的效果：81–90 → 判断题（而非 10 道简答题）。

### 修复 2：判断题答案模式

在 `ANSWER_PATTERNS` 与 `EMBEDDED_ANSWER_PATTERNS` 中新增判断题答案模式，
把中文判定词归一化为 `T` / `F`：

| 原文 | 归一化 |
|---|---|
| 正确 / 对 / 是 / √ / T / true | `T` |
| 错误 / 错 / 否 / × / x / F / false | `F` |

需覆盖 `故表述正确`、`故表述错误`、`判断：正确`、`答案：对`、
`本题为判断题，正确` 等句式；要求**判定词前不得有字母选项上下文**，
避免与选择题答案混淆。

### 修复 3：封堵随意字母兜底（防复发）

1. `extract_with_context` 的单字母兜底增加前置条件：
   **仅当 `question_type` 为选择题且题目确有选项时**才允许抓取 A–D。
2. 题型与答案格式不一致时（判断题却得到字母 / 无选项题却得到字母），
   答案置空并保留 `need_review` 标记，交由教师复核，**不再写入猜测值**。
3. `_validate_choice_answer` 对无选项题的字母答案直接判否。

7. Playwright 实测：走「题目导入」模块真实上传该 docx + PDF，预览页
   题型与答案正确、控制台无报错、无 4xx。

## 六、风险点

- **R1（高）分节题型优先可能误伤无分节或分节含糊的文档。**
  缓解：仅在「无选项 + 分节明确声明」时生效；有选项证据时仍走原投票。
- **R2（中）判断题归一化为 T/F 会改变既有答案格式。**
  需确认前端/答题判分对判断题答案的期望格式（T/F、正确/错误、对/错），
  统一为一种并在 `validate_answer` 中接受多种等价写法。
- **R3（中）封堵字母兜底会使部分历史"恰好正确"的答案变为待补充。**
  这是正确行为（宁可标记复核，不可写入错答），但会改变导入统计，
  需在报告中说明。
- **R4（低）答案 PDF 文本层质量影响判断题答案抽取。**
  若个别 PDF 无文本层，需依赖既有 OCR 链路，属既有能力范围。
- **R5（低）修改 `text_parser.py` 影响面大。**
  必须以 30 份真实文档回归 + HEAD 基线比对双重把关。
